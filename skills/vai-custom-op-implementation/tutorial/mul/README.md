# Custom Op example: mul
# 사용자 정의 작업 예: mul

The examples in this directory demonstrate a simple custom op with two inputs.
이 디렉터리의 예는 두 개의 입력이 있는 간단한 사용자 지정 작업을 보여줍니다.
It computes the product of its inputs, e.g., like the [onnx Mul op](https://onnx.ai/onnx/operators/onnx__Mul.html).
예를 들어 [onnx Mul op](https://onnx.ai/onnx/operators/onnx__Mul.html)와 같이 입력의 곱을 계산합니다.
