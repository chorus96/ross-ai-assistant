# 8-9179: attribute target identifier '!%1!' not found in this scope
# 8-9179: 속성 대상 식별자 '!%1!' 이 범위에서 찾을 수 없습니다.

**Message:** `[Synth 8-9179] attribute target identifier '!%1!' not found in this scope`
**메시지:** `[Synth 8-9179] 속성 대상 식별자 '!%1!' 이 범위에서 찾을 수 없습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An attribute's target identifier is not visible in the current scope.
속성의 대상 식별자는 현재 범위에 표시되지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Attribute target not found in scope
### P1: 범위에서 속성 대상을 찾을 수 없습니다.

**Problematic Code:**
**문제가 있는 코드:**
```verilog
(* mark_debug = "true" *) missing_sig;
```

**Recommended Fix:**
**권장 수정 사항:**
```verilog
(* mark_debug = "true" *) wire real_sig;
```

---

## Fix Strategy
## 전략 수정

1. Apply the attribute to an identifier that exists in scope.
1. 범위에 존재하는 식별자에 특성을 적용합니다.
2. Declare the target before attributing it.
2. 속성을 지정하기 전에 대상을 선언하세요.
3. Fix the target name (typo).
3. 대상 이름(오타)을 수정하세요.
