# 8-521: Parameter Assignment Not Constant
# 8-521: 매개변수 할당이 일정하지 않음

**Message:** `[Synth 8-521] parameter assignment could not be resolved to a constant`
**메시지:** `[Synth 8-521] 매개변수 할당을 상수로 확인할 수 없습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A parameter override value cannot be resolved to a constant.
매개변수 재정의 값은 상수로 분석될 수 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Non-constant parameter override value
### P1: 상수가 아닌 매개변수 재정의 값

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: non-constant parameter value
wire [7:0] w;
my_mod #(.P(w)) inst(...);  // ERROR: w is not constant
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use constant value
localparam LP = 8;
my_mod #(.P(LP)) inst(...);  // constant
```

---

## Fix Strategy
## 전략 수정

1. Provide a compile-time constant for the parameter override — a literal, `localparam`, or another parameter — never a `wire`/`reg`/signal.
1. 매개변수 재정의에 대한 컴파일 시간 상수(리터럴, `localparam` 또는 다른 매개변수)를 제공하세요. 절대로 `wire`/`reg`/signal이 아닙니다.
2. If the value is currently derived from a signal, restructure so it is known at elaboration (compute it from parameters, not from runtime logic).
2. 값이 현재 신호에서 파생된 경우 정교하게 알 수 있도록 재구성합니다(런타임 로직이 아닌 매개변수에서 계산).
3. Remember parameters are fixed at elaboration; if the value must change at runtime, it is data, not a parameter — route it through a port instead.
3. 매개변수는 정교하게 수정될 수 있다는 점을 기억하세요. 런타임 시 값을 변경해야 하는 경우 매개변수가 아닌 데이터입니다. 대신 포트를 통해 라우팅하세요.
4. Share common constant values via a package/`localparam` rather than recomputing them from signals.
4. 신호에서 값을 다시 계산하는 대신 package/`localparam`을 통해 공통 상수 값을 공유하세요.
