# 8-4169: Package Not Found in Library
# 8-4169: 라이브러리에서 패키지를 찾을 수 없습니다.

**Message:** `[Synth 8-4169] error in use clause: package '!%1!' not found in library '!%2!'`
**메시지:** `[Synth 8-4169] 사용 절에 오류가 있습니다: 패키지 '!%1!' 라이브러리 '!%2!'`에서 찾을 수 없습니다.
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL `use` clause references a package that doesn't exist in the specified library.
VHDL `use` 절이 지정된 라이브러리에 존재하지 않는 패키지를 참조합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: use clause for a non-existent package
### P1: 존재하지 않는 패키지에 대한 사용 절

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: package not in library
use synplify.attributes.all;  -- ERROR: 'attributes' not in 'synplify'
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use correct library/package or remove
-- Synplify-specific attributes are not portable
-- Remove or replace with Vivado equivalents:
attribute syn_keep : boolean;
-- becomes:
attribute keep : string;
```

---

## Fix Strategy
## 전략 수정

1. Remove `use`/`library` clauses that reference non-portable, tool-specific packages (e.g., `synplify.attributes`) not present in Vivado.
1. Vivado에 없는 이식 불가능한 도구별 패키지(예: `synplify.attributes`)를 참조하는 `use`/`library` 절을 제거하세요.
2. Replace vendor attributes with Vivado-native equivalents (e.g., `syn_keep` -> `(* keep = "true" *)`, `syn_preserve` -> `(* dont_touch = "true" *)`).
2. 공급업체 속성을 Vivado 고유의 해당 속성으로 대체합니다(예: `syn_keep` -> `(* keep = "true" *)`, `syn_preserve` -> `(* dont_touch = "true" *)`).
3. If the package is your own, ensure it is compiled into the referenced library before this file and the names match exactly.
3. 패키지가 자신의 것인 경우 이 파일 전에 참조 라이브러리로 컴파일되고 이름이 정확히 일치하는지 확인하십시오.
4. Verify the library is declared (`library <name>;`) and mapped in the project.
4. 라이브러리가 선언(`library <name>;`)되고 프로젝트에 매핑되었는지 확인하세요.
