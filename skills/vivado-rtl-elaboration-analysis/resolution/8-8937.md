# 8-8937: Not an Entity
# 8-8937: 실체가 아님

**Message:** `[Synth 8-8937] identifier is not an entity`
**메시지:** `[Synth 8-8937] 식별자는 엔터티가 아닙니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A configuration spec references a name that is not an entity.
구성 사양이 엔터티가 아닌 이름을 참조합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Config binds to a non-entity
### P1: 구성이 비엔티티에 바인딩됩니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
for inst : comp use entity work.subunit(arch);  -- ERROR: subunit not an entity
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- Ensure the referenced name is compiled as an entity
-- Or remove the configuration specification
```

---

## Fix Strategy
## 전략 수정

1. Ensure the name in the configuration/binding is a real **entity** compiled into the referenced library.
1. 구성/바인딩의 이름이 참조 라이브러리에 컴파일된 실제 **엔티티**인지 확인하세요.
2. Fix typos in the entity/architecture/library names so the reference resolves.
2. 참조가 해결되도록 엔터티/아키텍처/라이브러리 이름의 오타를 수정하세요.
3. Verify compile order — the entity must be analyzed before the configuration that binds it.
3. 컴파일 순서 확인 - 엔터티를 바인딩하는 구성 전에 엔터티를 분석해야 합니다.
4. If default binding suffices, remove the configuration specification entirely.
4. 기본 바인딩으로 충분하다면 구성 사양을 완전히 제거하세요.
