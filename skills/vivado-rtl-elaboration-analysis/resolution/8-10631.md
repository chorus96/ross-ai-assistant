# 8-10631: Decimal Constant Overflow
# 8-10631: 소수 상수 오버플로

**Message:** `[Synth 8-10631] decimal constant should be smaller than 2147483648`
**메시지:** `[Synth 8-10631] 소수점 상수는 2147483648보다 작아야 합니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10631] decimal constant should be smaller than 2147483648 [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

An unsized decimal literal exceeds the 32-bit integer range (2^31).
크기가 지정되지 않은 10진수 리터럴이 32비트 정수 범위(2^31)를 초과합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Unsized decimal literal overflow
### P1: 크기가 지정되지 않은 십진수 리터럴 오버플로

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: oversized decimal literal
assign {c,a,b} = {101110101101};  // ERROR: treated as decimal, too large
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use proper binary literal syntax
assign {c,a,b} = 12'b101110101101;  // add size and base prefix
```

---

## Fix Strategy
## 전략 수정

Add proper size and base prefix (`'b`, `'h`, `'d`) to numeric literals.
숫자 리터럴에 적절한 크기와 기본 접두사(`'b`, `'h`, `'d`)를 추가합니다.
Unsized numbers default to decimal and must fit in 32 bits.
크기가 지정되지 않은 숫자는 기본적으로 10진수이며 32비트에 맞아야 합니다.
