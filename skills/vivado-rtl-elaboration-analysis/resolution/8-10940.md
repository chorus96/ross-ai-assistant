# 8-10940: macro '!%1!' is redefined
# 8-10940: 매크로 '!%1!' 재정의된다

**Message:** `[Synth 8-10940] macro '!%1!' is redefined`
**메시지:** `[Synth 8-10940] 매크로 '!%1!' 재정의된다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A `` `define `` macro is defined more than once.
`` ``define `` 매크로가 두 번 이상 정의되었습니다.
The later definition overrides the earlier one.
나중 정의가 이전 정의보다 우선합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Macro redefined
### P1: 매크로 재정의

**Problematic Code:**
**문제가 있는 코드:**
```verilog
`define W 8
`define W 16   // redefined
```

**Recommended Fix:**
**권장 수정 사항:**
```verilog
`ifndef W
`define W 8
`endif
```

---

## Fix Strategy
## 전략 수정

1. Guard the definition with `` `ifndef ``/`` `endif ``.
1. `` ifndef ``/`` `endif ``로 정의를 보호하세요.
2. Remove the duplicate `` `define `` if unintended.
2. 의도하지 않은 경우 중복된 ``define ``을 제거하세요.
3. Ensure a single header owns each macro.
3. 단일 헤더가 각 매크로를 소유하는지 확인하세요.
