# 8-11325: Expression Out of Range
# 8-11325: 표현식이 범위를 벗어났습니다.

**Message:** `[Synth 8-11325] expression !%1! out of range`
**메시지:** `[Synth 8-11325] 표현식 !%1! 범위를 벗어났습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL expression evaluates to a value outside the allowed range.
VHDL 표현식은 허용된 범위를 벗어난 값으로 평가됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Expression value out of range
### P1: 표현식 값이 범위를 벗어났습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: expression result out of range
type nibble is range 0 to 15;
signal n : nibble;
n <= 6 * 3;  -- ERROR: 18 > 15
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: ensure expression stays in range
n <= 5 * 3;  -- 15, within range
-- Or widen the type
```

---

## Fix Strategy
## 전략 수정

1. Ensure arithmetic expressions produce values within the target type's range — widen intermediate types or clamp results.
1. 산술 표현식이 대상 유형 범위 내의 값을 생성하는지 확인하십시오. 중간 유형 또는 클램프 결과를 넓히십시오.
2. Watch for intermediate overflow in multiplies/shifts; compute in a wider `unsigned`/`signed` then resize.
2. 곱셈/이동 시 중간 오버플로를 주의하세요. 더 넓은 'unsigned'/'signed'로 계산한 다음 크기를 조정하세요.
3. Check constant/generic inputs that make the expression exceed the range.
3. 표현식이 범위를 초과하게 만드는 상수/일반 입력을 확인하세요.
4. Use `resize`/saturation logic where the value can legitimately exceed the target.
4. 값이 합법적으로 목표를 초과할 수 있는 '크기 조정'/채도 로직을 사용하세요.
