# 8-10690: Event Type Variable Not Allowed
# 8-10690: 이벤트 유형 변수가 허용되지 않음

**Message:** `[Synth 8-10690] event type variable is not allowed here`
**메시지:** `[Synth 8-10690] 이벤트 유형 변수는 여기서 허용되지 않습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10690] event type variable is not allowed here [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

`event` type variables and event trigger statements (`->`, `->>`) are simulation-only and not synthesizable.
`이벤트` 유형 변수 및 이벤트 트리거 문(`->`, `->>`)은 시뮬레이션 전용이며 합성할 수 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: event-type variable/trigger
### P1: 이벤트형 변수/트리거

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: event type in synthesizable code
event ev1;
->> repeat(2) @* ev1;   // ERROR: event not synthesizable
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: replace with synthesizable signaling
reg ev1_flag;
// Use flag-based signaling instead of events
always @(posedge clk) ev1_flag <= trigger_condition;
```

---

## Fix Strategy
## 전략 수정

1. Replace `event`-type variables and triggers (`->`, `->>`, `@`) with `reg`/`logic` flag signals — named events are simulation-only.
1. `이벤트` 유형 변수 및 트리거(`->`, `->>`, `@`)를 `reg`/`logic` 플래그 신호로 대체합니다. 명명된 이벤트는 시뮬레이션 전용입니다.
2. Model synchronization with valid/ready handshakes or level/edge signals in clocked logic.
2. 클럭 로직의 유효/준비 핸드셰이크 또는 레벨/에지 신호를 사용한 모델 동기화.
3. Keep any genuine event usage in the testbench, out of synthesizable RTL.
3. 합성 가능한 RTL을 제외하고 테스트벤치에서 실제 이벤트 사용을 유지하세요.
4. Verify the flag-based scheme reproduces the intended triggering behavior.
4. 플래그 기반 체계가 의도한 트리거링 동작을 재현하는지 확인합니다.
