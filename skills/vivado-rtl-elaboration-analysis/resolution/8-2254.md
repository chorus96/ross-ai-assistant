# 8-2254: instance name '!%1!' matches net/port name
# 8-2254: 인스턴스 이름 '!%1!' 네트/포트 이름과 일치

**Message:** `[Synth 8-2254] instance name '!%1!' matches net/port name`
**메시지:** `[Synth 8-2254] 인스턴스 이름 '!%1!' 네트/포트 이름과 일치`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An instance name is the same as a net or port name in the same scope, creating a name clash.
인스턴스 이름은 동일한 범위의 넷 또는 포트 이름과 동일하여 이름 충돌이 발생합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Instance name matches a net/port name
### P1: 인스턴스 이름이 넷/포트 이름과 일치합니다.

**Problematic Code:**
**문제가 있는 코드:**
```verilog
wire a;
sub a (...);   // instance 'a' clashes with wire 'a'
```

**Recommended Fix:**
**권장 수정 사항:**
```verilog
wire a;
sub u_a (...);   // unique instance name
```

---

## Fix Strategy
## 전략 수정

1. Give the instance a unique name distinct from nets/ports.
1. 인스턴스에 네트/포트와 구별되는 고유한 이름을 지정하십시오.
2. Adopt a naming convention (e.g.
2. 명명 규칙을 채택합니다(예:
2. `u_` prefix) for instances.
2. `u_` 접두사)를 사용합니다.
3. Rename either the instance or the conflicting net.
3. 인스턴스 또는 충돌하는 네트의 이름을 바꿉니다.
