# 8-944: No Matching Operator
# 8-944: 일치하는 연산자가 없습니다.

**Message:** `[Synth 8-944] 0 definitions of operator match here`
**메시지:** `[Synth 8-944] 여기서 일치하는 연산자 정의 0개`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL operator has no visible definition for the given operand types.
VHDL 연산자에는 지정된 피연산자 유형에 대한 가시적 정의가 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Operator undefined for operand types
### P1: 피연산자 유형에 대해 연산자가 정의되지 않았습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
sig <= a ?? b;  -- ERROR: no ?? operator defined for these types
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- Import correct package or use supported operator
use ieee.std_logic_1164.all;
```

---

## Fix Strategy
## 전략 수정

1. `use` the package that defines the operator for the given operand types (e.g., `ieee.numeric_std.all` for arithmetic on `unsigned`/`signed`, `ieee.std_logic_1164.all` for logic on `std_logic`).
1. 주어진 피연산자 유형에 대한 연산자를 정의하는 패키지를 `사용`합니다(예: `unsigned`/`signed`에 대한 산술의 경우 `ieee.numeric_std.all`, `std_logic`의 논리에 대한 `ieee.std_logic_1164.all`).
2. Convert operands to a type the operator is defined for (`unsigned(...)`, `signed(...)`, `std_logic_vector(...)`) before applying it.
2. 피연산자를 적용하기 전에 (`unsigned(...)`, `signed(...)`, `std_logic_Vector(...)`)에 대해 연산자가 정의된 유형으로 변환합니다.
3. If you rely on a user-defined operator, ensure its overload is declared and its package is visible in this scope.
3. 사용자 정의 연산자를 사용하는 경우 오버로드가 선언되고 해당 패키지가 이 범위에 표시되는지 확인하세요.
4. If no valid operator exists for the intended semantics, restructure the expression using supported operators/functions.
4. 의도한 의미에 맞는 유효한 연산자가 없으면 지원되는 연산자/함수를 사용하여 표현식을 재구성하십시오.
