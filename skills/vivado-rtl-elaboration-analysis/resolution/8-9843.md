# 8-9843: non-module variable '!%1!' cannot be initialized at declaration
# 8-9843: 모듈이 아닌 변수 '!%1!' 선언 시 초기화할 수 없습니다.

**Message:** `[Synth 8-9843] non-module variable '!%1!' cannot be initialized at declaration`
**메시지:** `[Synth 8-9843] 비모듈 변수 '!%1!' 선언시 초기화할 수 없습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A variable outside module scope (e.g. in a package/$unit) is initialized at its declaration where not allowed.
모듈 범위 외부의 변수(예: package/$unit)는 허용되지 않는 선언에서 초기화됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Non-module variable initialized at declaration
### P1: 선언 시 초기화된 비모듈 변수

**Problematic Code:**
**문제가 있는 코드:**
```systemverilog
package p; int g = 5; endpackage   // flagged
```

**Recommended Fix:**
**권장 수정 사항:**
```systemverilog
package p; int g; endpackage   // initialize elsewhere if needed
```

---

## Fix Strategy
## 전략 수정

1. Remove the declaration initializer in the disallowed scope.
1. 허용되지 않는 범위에서 선언 이니셜라이저를 제거합니다.
2. Initialize in an `initial` block or at the point of use.
2. '초기' 블록이나 사용 시점에서 초기화하세요.
3. Keep such initialized variables inside modules.
3. 이러한 초기화된 변수를 모듈 내부에 보관하십시오.
