# 8-9222: cannot call impure function '!%1!' from within pure function '!%2!'
# 8-9222: 순수하지 않은 함수 '!%1!'을 호출할 수 없습니다. 순수 함수 '!%2!' 내에서

**Message:** `[Synth 8-9222] cannot call impure function '!%1!' from within pure function '!%2!'`
**메시지:** `[Synth 8-9222]는 순수하지 않은 함수 '!%1!'을 호출할 수 없습니다. 순수 함수 '!%2!'` 내에서
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A pure function calls an impure function, which is not allowed - pure functions may not have side effects.
순수 함수는 허용되지 않는 불순한 함수를 호출합니다. 순수 함수에는 부작용이 없을 수 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Impure function called from a pure function
### P1: 순수 함수에서 호출된 순수하지 않은 함수

**Problematic Code:**
**문제가 있는 코드:**
```vhdl
function f return integer is begin return impure_g(); end;
```

**Recommended Fix:**
**권장 수정 사항:**
```vhdl
impure function f return integer is begin return impure_g(); end;
```

---

## Fix Strategy
## 전략 수정

1. Mark the caller `impure`, or avoid calling impure functions from pure ones.
1. 호출자를 `불순`으로 표시하거나 순수한 함수에서 불순한 함수를 호출하지 마세요.
2. Keep pure functions free of side effects.
2. 부작용이 없는 순수 기능을 유지하세요.
3. Refactor side-effecting logic out of the pure function.
3. 순수 함수에서 부작용을 일으키는 논리를 리팩터링합니다.
