# 8-10298: Pure/Impure Subprogram Mismatch
# 8-10298: 순수/불순 하위 프로그램 불일치

**Message:** `[Synth 8-10298] impure interface subprogram is associated with actual subprogram that is pure`
**메시지:** `[Synth 8-10298] 불순한 인터페이스 하위 프로그램이 순수한 실제 하위 프로그램과 연결되어 있습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10298] impure interface subprogram is associated with actual subprogram that is pure [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A VHDL generic subprogram interface declared as `impure` is mapped to a `pure` actual function.
`불순`으로 선언된 VHDL 일반 하위 프로그램 인터페이스는 `순수` 실제 함수에 매핑됩니다.
Purity must match.
순도가 일치해야 합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Pure actual for an impure formal
### P1: 불순한 형식에 대한 순수 실제

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: impure generic mapped to pure actual
function doOpt(a : signed) return signed is  -- pure function
begin return a; end;
-- generic map says impure, actual is pure -> ERROR
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: match purity
impure function doOpt(a : signed) return signed is
begin return a; end;
-- Or change the interface declaration to 'pure'
```

---

## Fix Strategy
## 전략 수정

1. Match the purity of the actual subprogram to the interface declaration — an `impure` formal needs an `impure` actual (and vice versa).
1. 실제 하위 프로그램의 순수성을 인터페이스 선언과 일치시킵니다. '불순한' 형식에는 '불순한' 실제가 필요합니다(그 반대도 마찬가지).
2. Mark the actual function `impure` if it has side effects/reads external state, or declare the formal `pure` if the actual is truly pure.
2. 부작용이 있거나 외부 상태를 읽는 경우 실제 함수를 '불순함'으로 표시하고, 실제 함수가 정말 순수하면 형식적 '순수함'을 선언하세요.
3. Keep purity consistent across all associations of the generic subprogram.
3. 일반 하위 프로그램의 모든 연결에서 일관성을 유지하십시오.
4. Confirm the flow supports VHDL-2008 generic subprograms; otherwise use a concrete subprogram.
4. 흐름이 VHDL-2008 일반 하위 프로그램을 지원하는지 확인합니다. 그렇지 않으면 구체적인 하위 프로그램을 사용하십시오.
