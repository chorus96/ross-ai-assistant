# 8-5551: Signal Driven Twice in Process
# 8-5551: 처리 중 두 번 구동되는 신호

**Message:** `[Synth 8-5551] signal '!%1!' is driven twice in the same process, second time by procedure '!%2!'`
**메시지:** `[Synth 8-5551] 신호 '!%1!' 동일한 프로세스에서 두 번 구동되고 두 번째는 '!%2!'` 절차로 구동됩니다.
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL signal is driven multiple times in the same process (second time by a procedure call).
VHDL 신호는 동일한 프로세스에서 여러 번 구동됩니다(두 번째는 프로시저 호출에 의해).

---

## Common Patterns
## 일반적인 패턴

### P1: Signal driven twice within a process
### P1: 프로세스 내에서 두 번 구동되는 신호

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: signal driven twice
process(clk)
begin
  sig <= value1;       -- first driver
  my_proc(sig);        -- procedure also drives sig
end process;
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: single driver
process(clk)
begin
  my_proc(sig);  -- only one driver (through procedure)
end process;
```

---

## Fix Strategy
## 전략 수정

1. Ensure each signal has exactly one driver within a process — remove the redundant direct assignment when a called procedure also drives the signal (or vice versa).
1. 프로세스 내에서 각 신호에 정확히 하나의 드라이버가 있는지 확인하십시오. 호출된 프로시저가 신호도 구동하는 경우(또는 그 반대의 경우) 중복된 직접 할당을 제거하십시오.
2. Consolidate the logic so a single assignment/procedure determines the signal's value on each path.
2. 단일 할당/절차로 각 경로의 신호 값을 결정하도록 논리를 통합합니다.
3. If two independent behaviors are needed, split them across separate signals or separate processes, each with a single driver.
3. 두 개의 독립적인 동작이 필요한 경우 각각 단일 드라이버를 사용하여 별도의 신호 또는 별도의 프로세스로 분할합니다.
4. Check `out`/`inout` procedure parameters — passing the same signal to a driving procedure and also assigning it directly is the usual cause.
4. `out`/`inout` 절차 매개변수를 확인하세요. 동일한 신호를 운전 절차에 전달하고 이를 직접 할당하는 것이 일반적인 원인입니다.
