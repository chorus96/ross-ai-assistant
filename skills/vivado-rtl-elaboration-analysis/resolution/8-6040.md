**Recommended Fix:**

// Remove the initial value on the ROM address register; reset it synchronously

## Fix Strategy
## 전략 수정

1. Remove the **initial value** on the register that drives the ROM address — BRAM/URAM address registers cannot carry one, which blocks packing into the block.
1. ROM 주소를 구동하는 레지스터에서 **초기 값**을 제거합니다. BRAM/URAM 주소 레지스터는 블록으로 패킹하는 것을 차단하는 값을 전달할 수 없습니다.
2. Establish the needed start value via a synchronous reset in the clocked process instead of an initializer.
2. 초기화 대신 클록 프로세스에서 동기식 재설정을 통해 필요한 시작 값을 설정합니다.
3. Verify the ROM read still produces the intended first-address behavior after moving to reset-based initialization.
3. 재설정 기반 초기화로 이동한 후에도 ROM 읽기가 여전히 의도한 첫 번째 주소 동작을 생성하는지 확인합니다.
4. Re-check the synthesis report to confirm the address register now packs into BRAM/URAM.
4. 주소 레지스터가 이제 BRAM/URAM에 포함되어 있는지 확인하려면 합성 보고서를 다시 확인하세요.
