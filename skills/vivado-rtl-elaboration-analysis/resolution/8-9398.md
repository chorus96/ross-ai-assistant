# 8-9398: empty port in !%1! declaration
# 8-9398: !%1!의 빈 포트 선언

**Message:** `[Synth 8-9398] empty port in !%1! declaration`
**메시지:** `[Synth 8-9398] !%1의 빈 포트! 선언`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A port list contains an empty port (e.g. a trailing/stray comma).
포트 목록에 빈 포트(예: 후행/길어난 쉼표)가 포함되어 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Empty port in declaration
### P1: 선언의 빈 포트

**Problematic Code:**
**문제가 있는 코드:**
```verilog
module m(a, , b);   // empty port
```

**Recommended Fix:**
**권장 수정 사항:**
```verilog
module m(a, b);
```

---

## Fix Strategy
## 전략 수정

1. Remove the empty port / stray comma from the port list.
1. 포트 목록에서 빈 포트/길어진 쉼표를 제거합니다.
2. Ensure every port position has a name.
2. 모든 포트 위치에 이름이 있는지 확인하십시오.
3. Check for a deleted port that left a comma.
3. 쉼표를 남긴 삭제된 포트를 확인하세요.
