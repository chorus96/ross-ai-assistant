# 8-10571: String Literal as Object Alias Designator
# 8-10571: 객체 별칭 지정자로서의 문자열 리터럴

**Message:** `[Synth 8-10571] character/string literal cannot be the designator for an object alias`
**메시지:** `[Synth 8-10571] 문자/문자열 리터럴은 객체 별칭에 대한 지정자가 될 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10571] character/string literal cannot be the designator for an object alias [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A VHDL alias uses a character or string literal as its name, which is only valid for subprogram aliases.
VHDL 별칭은 문자 또는 문자열 리터럴을 이름으로 사용하며 이는 하위 프로그램 별칭에만 유효합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: String literal as object alias name
### P1: 객체 별칭 이름으로서의 문자열 리터럴

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: character literal as object alias name
signal S : bit;
alias 'A' : bit is S;  -- ERROR: character literal not valid for object alias
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use an identifier as alias name
signal S : bit;
alias A_alias : bit is S;  -- use identifier, not character literal
```

---

## Fix Strategy
## 전략 수정

Use a regular identifier for object alias names.
개체 별칭 이름에는 일반 식별자를 사용합니다.
Character/string literals are only valid as designators for subprogram (operator) aliases.
문자/문자열 리터럴은 하위 프로그램(연산자) 별칭에 대한 지정자로만 유효합니다.
