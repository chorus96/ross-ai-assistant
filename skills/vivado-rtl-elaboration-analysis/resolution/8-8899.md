# 8-8899: Illegal in Expression
# 8-8899: 표현이 잘못되었습니다.

**Message:** `[Synth 8-8899] '!%1!' is illegal in an expression`
**메시지:** `[Synth 8-8899] '!%1!' 표현은 불법입니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An entity or non-expression identifier is used in an expression context.
엔터티 또는 비표현식 식별자가 표현식 컨텍스트에서 사용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Non-value identifier in an expression
### P1: 표현식의 값이 아닌 식별자

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: entity name in expression
sig <= ch0701_p00801_19_ent;  -- ERROR: entity not valid in expression
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use signal or constant
sig <= my_constant;  -- use proper expression
```

---

## Fix Strategy
## 전략 수정

1. Only value-bearing objects — signals, variables, constants, and function calls — may appear in expressions; do not use an entity/type/label name there.
1. 값을 포함하는 객체(신호, 변수, 상수, 함수 호출)만 표현식에 나타날 수 있습니다. 거기에 엔터티/유형/라벨 이름을 사용하지 마세요.
2. Replace the offending identifier with the correct signal/constant that holds the intended value.
2. 잘못된 식별자를 의도한 값을 보유하는 올바른 신호/상수로 바꾸십시오.
3. If you meant to reference a component's output, route it through a signal/port rather than naming the unit.
3. 컴포넌트의 출력을 참조하려는 경우 장치 이름을 지정하는 대신 신호/포트를 통해 라우팅하십시오.
4. Fix typos where an object name collides with an entity/type name.
4. 개체 이름이 엔터티/유형 이름과 충돌하는 오타를 수정합니다.
