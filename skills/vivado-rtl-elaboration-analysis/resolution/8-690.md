# 8-690: Width Mismatch in Assignment
# 8-690: 할당 시 너비 불일치

**Message:** `[Synth 8-690] width mismatch in assignment; target has !%1! bits, source has !%2! bits`
**메시지:** `[Synth 8-690] 할당의 너비 불일치; 대상에 !%1!이 있습니다. 비트, 소스에는 !%2! 비트'
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

VHDL assignment has a width mismatch between target and source.
VHDL 할당에 대상과 소스 간의 너비가 일치하지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Width mismatch in VHDL assignment
### P1: VHDL 할당의 너비 불일치

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: 2-bit target, 1-bit source
signal dest : std_logic_vector(1 downto 0);
dest <= src;  -- ERROR: src is 1 bit, dest is 2 bits
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: match widths
dest <= '0' & src;  -- pad to 2 bits
-- Or: dest(0) <= src;  -- partial assignment
```

---

## Fix Strategy
## 전략 수정

1. Make the source and target the same width using explicit padding (`'0' & src`, `(others => '0')`) or `resize()` from `numeric_std`.
1. 명시적 패딩(`'0' & src`, `(others => '0')`) 또는 `numeric_std`의 `resize()`를 사용하여 소스와 대상을 동일한 너비로 만듭니다.
2. Choose sign-correct extension — use `unsigned`/`signed` and `resize` so the value zero- or sign-extends as intended.
2. 올바른 부호 확장을 선택하십시오. `unsigned`/`signed` 및 `resize`를 사용하여 값이 의도한 대로 0 또는 부호 확장되도록 하십시오.
3. Assign sub-ranges explicitly (`dest(0) <= src;`) when only part of the target should be driven, and define the remaining bits to avoid latches/undriven bits.
3. 대상의 일부만 구동해야 하는 경우 하위 범위를 명시적으로 할당하고(`dest(0) <= src;`) 래치/구동되지 않은 비트를 방지하기 위해 나머지 비트를 정의합니다.
4. If a width is simply wrong, fix the declaration of the source or target rather than padding at each use.
4. 너비가 단순히 잘못된 경우에는 사용할 때마다 패딩을 적용하는 대신 소스 또는 대상 선언을 수정하세요.
