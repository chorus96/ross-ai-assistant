# 8-78: Generic Value Required
# 8-78: 일반 값이 필요함

**Message:** `[Synth 8-78] a value must be associated with generic !%1!`
**메시지:** `[Synth 8-78] 값은 일반 !%1!과 연결되어야 합니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-78] a value must be associated with generic 'WIDTH' [/path/to/file.vhd:100]
```

---

## Root Cause
## 근본 원인

A VHDL entity has a generic parameter without a default value, and the instantiation does not provide a value for it.
VHDL 엔터티에는 기본값이 없는 일반 매개 변수가 있으며 인스턴스화는 이에 대한 값을 제공하지 않습니다.

---

## Example
## 예

```vhdl
-- Entity with required generic (no default)
entity my_fifo is
  generic (
    DEPTH : integer;        -- No default - REQUIRED
    WIDTH : integer := 8    -- Has default - optional
  );
  port (...);
end my_fifo;

-- Instantiation missing DEPTH value
-- ERROR: a value must be associated with generic 'DEPTH'
U0: entity work.my_fifo
  port map (...);
```

---

## Fix Options
## 수정 옵션

### Option 1: Provide Generic Value in Instantiation
### 옵션 1: 인스턴스화에 일반 값 제공

```vhdl
-- After - provide all required generics
U0: entity work.my_fifo
  generic map (
    DEPTH => 16    -- provide required value
  )
  port map (...);
```

### Option 2: Add Default Value to Generic Declaration
### 옵션 2: 일반 선언에 기본값 추가

```vhdl
-- Modify entity to have default
entity my_fifo is
  generic (
    DEPTH : integer := 16;  -- add default
    WIDTH : integer := 8
  );
```

---

## Verilog Equivalent
## Verilog와 동등

```verilog
// Module with required parameter
module my_fifo #(
  parameter DEPTH,        // No default - error if not overridden
  parameter WIDTH = 8
) (...);

// Must override DEPTH
my_fifo #(.DEPTH(16)) U0 (...);
```
