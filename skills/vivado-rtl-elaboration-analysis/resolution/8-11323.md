# 8-11323: Assigned Value Out of Range
# 8-11323: 할당된 값이 범위를 벗어났습니다.

**Message:** `[Synth 8-11323] !%1! value '!%2!' out of range`
**메시지:** `[Synth 8-11323] !%1! 값 '!%2!' 범위를 벗어났습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL assignment value exceeds the declared range of the target type.
VHDL 할당 값이 대상 유형의 선언된 범위를 초과합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Assigned value out of range
### P1: 할당된 값이 범위를 벗어났습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: value exceeds type range
type my_range is range 0 to 1024;
signal s : my_range := 1025;  -- ERROR: 1025 > 1024
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use value within range
signal s : my_range := 1024;  -- within range
-- Or widen the range:
type my_range is range 0 to 2048;
```

---

## Fix Strategy
## 전략 수정

1. Ensure the assigned value is within the target type's declared range (widen the subtype or clamp the value).
1. 할당된 값이 대상 유형의 선언된 범위 내에 있는지 확인하세요(하위 유형을 넓히거나 값을 제한).
2. For counters/accumulators, add saturation or use a wider type to avoid overflow assignments.
2. 카운터/누산기의 경우 채도를 추가하거나 더 넓은 유형을 사용하여 오버플로 할당을 방지하세요.
3. Check parameter/generic values that feed the assignment for out-of-range constants.
3. 범위를 벗어난 상수에 대한 할당을 제공하는 매개변수/일반 값을 확인하십시오.
4. Use `numeric_std` conversions with the correct width so values fit the target.
4. 값이 목표에 맞도록 올바른 너비로 `numeric_std` 변환을 사용하세요.
