# 8-7136: Module Port Binding Error
# 8-7136: 모듈 포트 바인딩 오류

**Message:** `[Synth 8-7136] In the module '!%1!' declared at '!%2!:!%3!', parameter '!%4!' used as named parameter override, !%5!`
**메시지:** `[Synth 8-7136] '!%1!' 모듈에서 '!%2!:!%3!', 매개변수 '!%4!'에 선언되었습니다. 명명된 매개변수 재정의로 사용됨, !%5!`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A module instance has a port binding error — typically a direction or type incompatibility.
모듈 인스턴스에 포트 바인딩 오류(일반적으로 방향 또는 유형 비호환성)가 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Component/module port binding mismatch
### P1: 구성 요소/모듈 포트 바인딩 불일치

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: port binding mismatch in mixed-language design
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: check that component declaration matches actual module ports
-- Verify port names, widths, and directions
-- In mixed VHDL/Verilog, ensure case matches
```

---

## Fix Strategy
## 전략 수정

1. Align the component declaration with the actual module/entity ports — same names, directions, widths, and (in mixed-language) matching case.
1. 구성 요소 선언을 실제 모듈/엔티티 포트(동일한 이름, 방향, 너비 및 (혼합 언어의 경우) 대소문자 일치)에 맞춥니다.
2. In mixed VHDL/Verilog designs, remember Verilog identifiers are case-sensitive; ensure the VHDL component names match exactly.
2. VHDL/Verilog 혼합 디자인에서는 Verilog 식별자가 대소문자를 구분한다는 점을 기억하세요. VHDL 구성 요소 이름이 정확하게 일치하는지 확인하세요.
3. Use named association so any direction/width/name mismatch is localized.
3. 방향/너비/이름 불일치가 현지화되도록 명명된 연관을 사용하십시오.
4. Confirm the intended module version is bound; a stale component declaration is a common cause.
4. 의도한 모듈 버전이 바인딩되었는지 확인하세요. 오래된 구성 요소 선언이 일반적인 원인입니다.
