# 8-11376: RAM Style Attribute Ignored
# 8-11376: RAM 스타일 속성이 무시됨

**Message:** `[Synth 8-11376] The 'ram_style' set on memory is ignored`
**메시지:** `[Synth 8-11376] 메모리에 설정된 'ram_style'이 무시됩니다`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

Vivado ignores the `ram_style` attribute because the memory doesn't meet RAM inference requirements.
Vivado는 메모리가 RAM 추론 요구 사항을 충족하지 않기 때문에 'ram_style' 속성을 무시합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: ram_style ignored (not inferred as RAM)
### P1: ram_style 무시됨(RAM으로 추론되지 않음)

**Problematic Code:**
**문제가 있는 코드:**
```diff
attribute ram_style of mem : signal is "block";  -- WARNING: ignored
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- Ensure RAM meets inference criteria:
-- Synchronous read/write, proper address width
-- Check UG901 RAM templates
```

---

## Fix Strategy
## 전략 수정

1. The `ram_style` attribute is ignored when the code is not recognized as a RAM — restructure it to a UG901 memory template (array indexed by address, synchronous access).
1. 코드가 RAM으로 인식되지 않으면 'ram_style' 속성이 무시됩니다. 이를 UG901 메모리 템플릿(주소로 인덱스된 배열, 동기 액세스)으로 재구성합니다.
2. Use a synchronous (registered) read so the memory is inferable.
2. 메모리를 추론할 수 있도록 동기(등록된) 읽기를 사용합니다.
3. Apply `ram_style` to the actual memory array signal, not a scalar/vector.
3. 스칼라/벡터가 아닌 실제 메모리 배열 신호에 `ram_style`을 적용합니다.
4. If it should not be a RAM, remove the attribute to clear the warning.
4. RAM이 아니어야 하는 경우 속성을 제거하여 경고를 지웁니다.
