# 8-11303: Record Element Name Not Found
# 8-11303: 레코드 요소 이름을 찾을 수 없습니다.

**Message:** `[Synth 8-11303] Cannot find record element name for the item '!%1!'`
**메시지:** `[Synth 8-11303] '!%1!' 항목에 대한 레코드 요소 이름을 찾을 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

The keyword `all` or a specific name is used where a record element name is expected but doesn't exist.
레코드 요소 이름이 예상되지만 존재하지 않는 경우 'all' 키워드 또는 특정 이름이 사용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Invalid record element name
### P1: 잘못된 레코드 요소 이름

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: 'all' used as record element
type rec_t is record x,y : integer; end record;
sig <= (all => 0);  -- ERROR: 'all' is not a record element
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: name each field
sig <= (x => 0, y => 0);  -- name fields explicitly
-- Or use 'others' for arrays, not 'all' for records
```

---

## Fix Strategy
## 전략 수정

1. Use explicit **field names** in record aggregates (`(a => x, b => y)`); `all` is not valid for records.
1. 레코드 집계에 명시적인 **필드 이름**을 사용합니다(`(a => x, b => y)`). 'all'은 레코드에 유효하지 않습니다.
2. Use `others =>` for remaining record fields (or array elements), not `all`.
2. 나머지 레코드 필드(또는 배열 요소)에는 `all`이 아닌 `others =>`를 사용하세요.
3. Verify each named field exists in the record type (fix typos).
3. 레코드 유형에 명명된 각 필드가 있는지 확인합니다(오타 수정).
4. Provide values for every field, or cover the rest with `others =>`.
4. 모든 필드에 값을 제공하거나 나머지는 `others =>`로 처리하세요.
