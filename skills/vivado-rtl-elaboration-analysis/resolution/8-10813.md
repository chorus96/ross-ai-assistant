# 8-10813: illegal empty item in case item list
# 8-10813: 케이스 항목 목록의 빈 항목이 잘못되었습니다.

**Message:** `[Synth 8-10813] illegal empty item in case item list`
**메시지:** `[Synth 8-10813] 케이스 항목 목록의 빈 항목이 잘못되었습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A `case` item list contains an empty/missing item (e.g. a stray comma), which is illegal.
'case' 항목 목록에는 비어 있거나 누락된 항목(예: 쉼표가 흩어진 항목)이 포함되어 있으며 이는 불법입니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Empty item in case item list
### P1: 케이스 항목 목록의 빈 항목

**Problematic Code:**
**문제가 있는 코드:**
```verilog
case (s)
  2'b00, : y=1;   // empty item before ':'
endcase
```

**Recommended Fix:**
**권장 수정 사항:**
```verilog
case (s)
  2'b00: y=1;
endcase
```

---

## Fix Strategy
## 전략 수정

1. Remove the empty item / stray comma in the case label list.
1. 케이스 라벨 목록에서 빈 항목/길어난 쉼표를 제거하세요.
2. Every case item must be a valid expression.
2. 모든 사례 항목은 유효한 표현식이어야 합니다.
3. Add a `default:` if you intended a catch-all.
3. 포괄적인 기능을 사용하려는 경우 `default:`를 추가하세요.
