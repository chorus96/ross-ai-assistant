# 8-6073: Cast Source Must Be Singular
# 8-6073: 캐스트 소스는 단수여야 합니다.

**Message:** `[Synth 8-6073] !%1! of $cast must be singular`
**메시지:** `[Synth 8-6073] !%1! $cast는 단수형이어야 합니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A `$cast` source expression must be a singular (scalar or single-element) type.
`$cast` 소스 표현식은 단일(스칼라 또는 단일 요소) 유형이어야 합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Non-singular $cast source
### P1: 비단수 $cast 소스

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: non-singular $cast source
$cast(target, array_expr);  // ERROR: array not singular
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: cast individual elements
$cast(target, array_expr[0]);  // singular element
```

---

## Fix Strategy
## 전략 수정

`$cast` requires singular source.
`$cast`에는 단일 소스가 필요합니다.
Cast individual elements, not arrays.
배열이 아닌 개별 요소를 캐스팅합니다.
