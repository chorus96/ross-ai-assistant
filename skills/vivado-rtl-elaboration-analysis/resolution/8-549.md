# 8-549: Port Width Mismatch
# 8-549: 포트 폭 불일치

**Message:** `[Synth 8-549] port width mismatch for port '!%1!': port width = !%2!, actual width = !%3!`
**메시지:** `[Synth 8-549] 포트 '!%1!'에 대한 포트 너비 불일치: 포트 너비 = !%2!, 실제 너비 = !%3!`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-549] port width mismatch for port 'A': port width = 8, actual width = 4 [/path/to/file.vhd:65]
```

---

## Root Cause
## 근본 원인

The signal connected to a module/entity port has a different width than the port declaration.
모듈/엔티티 포트에 연결된 신호는 포트 선언과 너비가 다릅니다.
The instantiation connects a signal of width X to a port declared as width Y.
인스턴스화는 너비 X의 신호를 너비 Y로 선언된 포트에 연결합니다.

### Real Example
### 실제 사례

```vhdl
-- Entity 'sub' has 8-bit port A
entity sub is
  port (
    clk : in  std_logic;
    rst : in  std_logic;
    A   : in  std_logic_vector(7 downto 0);  -- 8 bits
    Z   : out std_logic_vector(7 downto 0)
  );
end sub;

-- Top entity has 4-bit signal P
entity test is
  port (
    clk : in  std_logic;
    rst : in  std_logic;
    P   : in  std_logic_vector(3 downto 0);  -- 4 bits
    Q   : out std_logic_vector(7 downto 0)
  );
end test;

architecture behavioral of test is
begin
  -- ERROR: A expects 8 bits, P is only 4 bits
  sub_u : sub port map(clk=>clk, rst=>rst, A=>P, Z=>Q);
end behavioral;
```

## Common Patterns
## 일반적인 패턴

### P1: Positional connection with wrong order / mismatched width
### P1: 순서가 잘못되었거나 너비가 일치하지 않는 위치 연결

**Problematic Code:**
**문제가 있는 코드:**
```verilog
module child(input [7:0] a, input [3:0] b, output o);
  ...
endmodule

// parent: positional order swaps 'a' and 'b'
wire [3:0] x; wire [7:0] y;
child inst(x, y, o);   // ERROR: 4-bit x -> 8-bit port a, 8-bit y -> 4-bit port b
```

**Fix — use named connections so width and order are unambiguous:**
**수정 — 명명된 연결을 사용하여 너비와 순서가 모호하지 않게 합니다.**
```verilog
child inst(.a(y), .b(x), .o(o));   // widths line up, order explicit
```

### P2: Intentional width difference needs explicit resize/slice
### P2: 의도적인 너비 차이에는 명시적인 크기 조정/슬라이스 필요

**Problematic Code:**
**문제가 있는 코드:**
```vhdl
-- port A is 8 bits, signal P is 4 bits, and 4 bits is intended
sub_u : sub port map(clk=>clk, rst=>rst, A=>P, Z=>Q);  -- ERROR
```

**Fix — make the width adaptation explicit (extend to widen, slice to narrow):**
**수정 — 너비 적응을 명시적으로 만듭니다(확장하려면 확장, 축소하려면 슬라이스):**
```vhdl
sub_u : sub port map(clk=>clk, rst=>rst, A=>("0000" & P), Z=>Q);  -- zero-extend
-- or, if narrowing an 8-bit signal to a 4-bit port:
-- port map(..., A => wide(3 downto 0), ...);
```

## Fix Options
## 수정 옵션

### Option 1: Resize Signal at Connection (Zero/Sign Extend)
### 옵션 1: 연결 시 신호 크기 조정(제로/부호 확장)

```vhdl
-- Zero extend 4-bit P to 8-bit
sub_u : sub port map(
  clk => clk,
  rst => rst,
  A   => "0000" & P,  -- zero extend: {4'b0000, P}
  Z   => Q
);
```

```verilog
// Verilog equivalent
sub sub_u (
  .clk(clk),
  .rst(rst),
  .A({4'b0, P}),      // zero extend
  .Z(Q)
);
```

### Option 2: Create Intermediate Signal
### 옵션 2: 중간 신호 생성

```vhdl
signal P_extended : std_logic_vector(7 downto 0);
...
P_extended <= "0000" & P;  -- or use resize() for numeric types
sub_u : sub port map(clk=>clk, rst=>rst, A=>P_extended, Z=>Q);
```

### Option 3: Change Port Width
### 옵션 3: 포트 너비 변경

If the narrower width is intentional, modify the submodule port:
의도적으로 너비를 더 좁히려는 경우 하위 모듈 포트를 수정합니다.

```vhdl
-- Change submodule port to match
entity sub is
  port (
    A : in std_logic_vector(3 downto 0);  -- changed from 8 to 4
    ...
  );
end sub;
```

### Option 4: Use Generics for Parameterized Width
### 옵션 4: 매개변수화된 너비에 제네릭 사용

```vhdl
entity sub is
  generic (WIDTH : integer := 8);
  port (
    A : in std_logic_vector(WIDTH-1 downto 0);
    Z : out std_logic_vector(WIDTH-1 downto 0)
  );
end sub;

-- Instantiate with correct width
sub_u : entity work.sub
  generic map(WIDTH => 4)
  port map(clk=>clk, rst=>rst, A=>P, Z=>Q(3 downto 0));
```

## Diagnostic Steps
## 진단 단계

1. Find port declaration width in submodule
1. 하위 모듈에서 포트 선언 너비 찾기
2. Find signal declaration width at instantiation site
2. 인스턴스화 사이트에서 신호 선언 너비 찾기
3. Determine correct width based on design intent
3. 설계 의도에 따라 올바른 너비 결정
4. Choose resize strategy (extend, truncate, or modify declarations)
4. 크기 조정 전략 선택(선언 확장, 자르기 또는 수정)
