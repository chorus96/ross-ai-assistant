# 8-5733: Ignoring Attributes on Constant
# 8-5733: 상수의 속성 무시

**Message:** `[Synth 8-5733] ignoring attributes on constant declaration`
**메시지:** `[Synth 8-5733] 상수 선언의 속성을 무시하는 중`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

Attributes on constants are ignored during synthesis.
상수의 속성은 합성 중에 무시됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Attribute placed on a constant
### P1: 상수에 배치된 속성

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: attribute on constant
attribute keep of time1 : constant is true;  -- WARNING: ignored
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: move attribute to signal
attribute keep of sig1 : signal is "true";
```

---

## Fix Strategy
## 전략 수정

1. Attributes like `keep`/`dont_touch` have no effect on `constant`s (they hold no hardware) — move them to the `signal`/net you actually want preserved.
1. `keep`/`dont_touch`와 같은 속성은 `constant`에 영향을 미치지 않습니다(하드웨어를 보유하지 않음). 실제로 보존하려는 `signal`/net으로 이동합니다.
2. If you wanted to keep a computed value, drive a signal with it and attribute that signal.
2. 계산된 값을 유지하려면 이를 사용하여 신호를 구동하고 해당 신호의 속성을 지정하십시오.
3. Remove the attribute from the constant to clear the warning if no preservation is needed.
3. 보존이 필요하지 않은 경우 경고를 지우려면 상수에서 속성을 제거하세요.
4. Verify the attribute name and value syntax match Vivado's expected form for signals.
4. 속성 이름과 값 구문이 Vivado의 예상 신호 형식과 일치하는지 확인하세요.
