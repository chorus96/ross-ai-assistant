# 8-660: Unable to Resolve
# 8-660: 해결할 수 없음

**Message:** `[Synth 8-660] unable to resolve '!%1!'`
**메시지:** `[Synth 8-660] '!%1!'을 해결할 수 없습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-660] unable to resolve 'my_identifier' [/path/to/file.v:42]
```

---

## Root Cause
## 근본 원인

The synthesis tool cannot resolve a reference to an identifier, signal, function, or type.
합성 도구는 식별자, 신호, 함수 또는 유형에 대한 참조를 확인할 수 없습니다.
This is similar to "not declared" but often involves more complex resolution failures like:
이는 "선언되지 않음"과 유사하지만 종종 다음과 같이 더 복잡한 해결 실패를 포함합니다.

- Function calls that cannot be evaluated
- 평가할 수 없는 함수 호출
- Type conversions that fail
- 실패한 유형 변환
- Circular dependencies
- 순환 종속성
- Ambiguous references
- 모호한 참조

---

## Common Patterns
## 일반적인 패턴

### P1: Unresolvable Function Call
### P1: 확인할 수 없는 함수 호출

```verilog
// Before - function result cannot be determined
function integer calc_width;
  input integer depth;
  calc_width = $clog2(depth);  // $clog2 requires constant argument
endfunction

// ERROR if 'runtime_depth' is not constant
parameter WIDTH = calc_width(runtime_depth);
```

```diff
// After - use constant argument
- parameter WIDTH = calc_width(runtime_depth);
+ parameter DEPTH = 16;
+ parameter WIDTH = calc_width(DEPTH);
```

### P2: Circular Type/Parameter Dependency
### P2: 원형 유형/매개변수 종속성

```verilog
// Before - circular dependency
parameter A = B + 1;
parameter B = A + 1;  // ERROR: unable to resolve
```

```diff
// After - break circular dependency
- parameter A = B + 1;
- parameter B = A + 1;
+ parameter A = 5;
+ parameter B = A + 1;  // B = 6
```

### P3: Ambiguous Hierarchical Reference
### P3: 모호한 계층적 참조

```verilog
// Before - ambiguous path
assign out = inst.sub.data;  // ERROR if 'inst.sub' doesn't exist

// After - verify hierarchical path
assign out = inst1.sub_mod.data;  // use correct instance names
```

### P4: VHDL Overloaded Function Resolution
### P4: VHDL 오버로드된 함수 해결

```vhdl
-- Before - ambiguous overloaded function
signal result : std_logic_vector(7 downto 0);
result <= to_unsigned(255);  -- ERROR: unable to resolve (missing size)

-- After - provide required arguments
result <= std_logic_vector(to_unsigned(255, 8));  -- specify width
```

### P5: Missing Package/Library Import
### P5: 패키지/라이브러리 가져오기 누락

```vhdl
-- Before - function not visible
signal x : unsigned(7 downto 0);
x <= resize(a, 8);  -- ERROR: unable to resolve 'resize'

-- After - import required package
use ieee.numeric_std.all;
signal x : unsigned(7 downto 0);
x <= resize(a, 8);
```

## Diagnostic Steps
## 진단 단계

1. Identify what type of identifier is unresolved (signal, function, type, parameter)
1. 해결되지 않은 식별자 유형 식별(신호, 기능, 유형, 매개변수)
2. Check if all required packages/libraries are imported
2. 필요한 모든 패키지/라이브러리를 가져왔는지 확인하세요.
3. Verify the identifier exists in the expected scope
3. 식별자가 예상 범위에 존재하는지 확인하세요.
4. Check for circular dependencies in parameters/constants
4. 매개변수/상수에서 순환 종속성을 확인하세요.
5. For functions, ensure all arguments are constants if required
5. 함수의 경우 필요한 경우 모든 인수가 상수인지 확인하세요.

## Fix Strategy
## 전략 수정

| Unresolved Type<br>해결되지 않은 유형 | Check<br>확인 | Fix<br>수정 |
|-----------------|-------|-----|
| Signal<br>신호 | Declaration exists?<br>선언이 존재합니까? | Add declaration or fix scope<br>선언 추가 또는 범위 수정 |
| Function<br>기능 | Package imported?<br>패키지를 가져왔나요? | Add use clause<br>사용 조항 추가 |
| Parameter<br>매개변수 | Circular dependency?<br>순환 의존성? | Break dependency chain<br>종속성 체인 끊기 |
| Type<br>유형 | Library visible?<br>도서관이 보이나요? | Add library/use clause<br>라이브러리/사용 조항 추가 |
| Hierarchical ref<br>계층적 참조 | Path correct?<br>경로가 맞나요? | Fix instance hierarchy<br>인스턴스 계층 구조 수정 |
