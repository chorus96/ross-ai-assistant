# 8-9382: Dynamic Types in Non-Tagged Union
# 8-9382: 태그가 지정되지 않은 공용체의 동적 유형

**Message:** `[Synth 8-9382] dynamic types are not allowed in non-tagged unions`
**메시지:** `[Synth 8-9382] 태그가 지정되지 않은 공용체에서는 동적 유형이 허용되지 않습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A SystemVerilog union (non-tagged) contains dynamic types like queues or strings.
SystemVerilog 공용체(태그 없음)에는 대기열이나 문자열과 같은 동적 유형이 포함되어 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Dynamic type in a non-tagged union
### P1: 태그가 지정되지 않은 공용체의 동적 유형

**Problematic Code:**
**문제가 있는 코드:**
```diff
union { string s; int i; } u;  // ERROR: string is dynamic
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
union { int s; int i; } u;  // all packed/static types
```

---

## Fix Strategy
## 전략 수정

1. Remove dynamic types (`string`, queues `[$]`, dynamic arrays `[]`) from a non-tagged union — use only static/packed types.
1. 태그가 지정되지 않은 공용체에서 동적 유형(`string`, 큐 `[$]`, 동적 배열 `[]`)을 제거합니다. 정적/패킹된 유형만 사용하세요.
2. Make the union `packed` with all members the same width if you need overlaid bit access.
2. 중첩된 비트 액세스가 필요한 경우 모든 멤버가 동일한 너비로 '압축'된 공용체를 만드세요.
3. If variable-length data is required, that is not synthesizable — model it with a fixed-size structure.
3. 가변 길이 데이터가 필요한 경우 합성이 불가능합니다. 고정 크기 구조로 모델링하세요.
4. Verify all union members are synthesizable, same-width packed types.
4. 모든 공용체 멤버가 합성 가능하고 동일한 너비의 압축 유형인지 확인하십시오.
