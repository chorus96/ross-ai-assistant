# 8-2691: Label and Block ID Together
# 8-2691: 라벨 및 블록 ID 함께

**Message:** `[Synth 8-2691] statement label and block identifier are not allowed together`
**메시지:** `[Synth 8-2691] 명령문 라벨과 블록 식별자는 함께 허용되지 않습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A SystemVerilog statement has both a statement label and a block identifier, which is not allowed.
SystemVerilog 문에는 허용되지 않는 문 레이블과 블록 식별자가 모두 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Statement label plus block identifier
### P1: 명령문 라벨과 블록 식별자

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: label + block identifier
label: begin : block_name  // ERROR: can't have both
  ...
end
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use one or the other
begin : block_name  // block identifier only
  ...
end
```

---

## Fix Strategy
## 전략 수정

1. Use **either** a statement label (`label: begin`) **or** a block identifier (`begin : block_name`), not both on the same block.
1. 동일한 블록에 둘 다 사용하지 말고 **문 레이블(`label: Begin`) **또는** 블록 식별자(`begin : block_name`) 중 하나를 사용하십시오.
2. Prefer the block identifier form (`begin : name ... end : name`) for named scopes, which is the modern SystemVerilog style.
2. 명명된 범위에는 최신 SystemVerilog 스타일인 블록 식별자 형식(`begin : name ... end : name`)을 선호합니다.
3. Remove the redundant leading label if a block name is present.
3. 블록 이름이 있는 경우 중복된 선행 레이블을 제거합니다.
4. Ensure the closing `end : name` (if used) matches the block identifier.
4. 닫는 `end : name`(사용된 경우)이 블록 식별자와 일치하는지 확인하세요.
