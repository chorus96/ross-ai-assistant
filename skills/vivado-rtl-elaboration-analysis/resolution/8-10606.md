# 8-10606: Non-Static If-Generate Condition
# 8-10606: 비정적 If 생성 조건

**Message:** `[Synth 8-10606] condition of if-generate statement must be static`
**메시지:** `[Synth 8-10606] if-generate 문의 조건은 정적이어야 합니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10606] condition of if-generate statement must be static [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A VHDL `if...generate` uses a signal or non-constant expression as its condition.
VHDL `if...generate`는 신호 또는 상수가 아닌 표현식을 조건으로 사용합니다.
Generate conditions must be compile-time constants.
생성 조건은 컴파일 타임 상수여야 합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Signal-based if-generate condition
### P1: 신호 기반 if 생성 조건

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: signal used in generate condition
l1: if (in11 xor in12) generate   -- ERROR: in11/in12 are signals
  out1 <= in1;
end generate;
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use constant/generic or move to process
-- Option 1: use generic
generic (USE_PATH1 : boolean := true);
l1: if USE_PATH1 generate
  out1 <= in1;
end generate;
-- Option 2: use runtime logic instead of generate
out1 <= in1 when (in11 xor in12) = '1' else in2;
```

---

## Fix Strategy
## 전략 수정

Replace signal-based generate conditions with generics/constants.
신호 기반 생성 조건을 일반/상수로 대체합니다.
For runtime selection, use conditional assignment or multiplexers instead of generate.
런타임 선택의 경우 생성 대신 조건부 할당이나 멀티플렉서를 사용하세요.
