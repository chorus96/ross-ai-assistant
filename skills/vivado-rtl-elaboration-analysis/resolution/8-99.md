# 8-99: Array Type Required
# 8-99: 배열 유형 필수

**Message:** `[Synth 8-99] array type required`
**메시지:** `[Synth 8-99] 배열 유형이 필요합니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-99] array type required [/path/to/file.v:42]
```

---

## Root Cause
## 근본 원인

An operation that requires an array operand is being used with a non-array type.
배열 피연산자가 필요한 연산이 배열이 아닌 유형에서 사용되고 있습니다.
This typically occurs when:
이는 일반적으로 다음과 같은 경우에 발생합니다.
- Using array indexing on a scalar
- 스칼라에서 배열 인덱싱 사용
- Using array operations on non-array types
- 배열이 아닌 유형에 배열 작업 사용
- Incorrect type declarations
- 잘못된 유형 선언

---

## Common Patterns
## 일반적인 패턴

### P1: Indexing a Scalar
### P1: 스칼라 인덱싱

```verilog
// Before - trying to index a scalar
wire data;
assign out = data[0];  // ERROR: 'data' is not an array

// After - declare as vector
wire [7:0] data;
assign out = data[0];
```

### P2: Wrong Type in VHDL
### P2: VHDL의 잘못된 유형

```vhdl
-- Before - scalar used where array expected
signal data : std_logic;
process(data)
begin
  for i in data'range loop  -- ERROR: array type required
    ...
  end loop;
end process;

-- After - use array type
signal data : std_logic_vector(7 downto 0);
process(data)
begin
  for i in data'range loop
    ...
  end loop;
end process;
```

### P3: Function Return Type Mismatch
### P3: 함수 반환 유형 불일치

```verilog
// Before - function returns scalar but used as array
function get_value;
  input sel;
  get_value = sel;
endfunction

wire [7:0] result;
assign result[0] = get_value(sel)[0];  // ERROR

// After - return correct type
function [7:0] get_value;
  input sel;
  get_value = {8{sel}};
endfunction
```

---

## Fix Strategy
## 전략 수정

1. Check the type declaration of the signal/variable
1. 신호/변수의 유형 선언을 확인하세요.
2. Ensure array indexing is used only on array types
2. 배열 인덱싱이 배열 유형에만 사용되는지 확인하세요.
3. Verify function return types match usage
3. 함수 반환 유형이 사용법과 일치하는지 확인
