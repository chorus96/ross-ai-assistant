# 8-9696: invalid to access '!%1!' from inside pure function '!%2!'.
# 8-9696: '!%1!'에 액세스할 수 없습니다. 순수 함수 '!%2!' 내부에서.

**Message:** `[Synth 8-9696] invalid to access '!%1!' from inside pure function '!%2!'.`
**메시지:** `[Synth 8-9696] '!%1!'에 액세스할 수 없습니다. 순수 함수 '!%2!' 내부에서.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A pure function accesses an object it may not (e.g. a signal/shared variable), violating purity.
순수 함수는 순수성을 위반하여 액세스할 수 없는 객체(예: 신호/공유 변수)에 액세스합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Access from inside a pure function
### P1: 순수 함수 내부에서 접근

**Problematic Code:**
**문제가 있는 코드:**
```vhdl
function f return integer is begin return to_integer(sig); end;
```

**Recommended Fix:**
**권장 수정 사항:**
```vhdl
-- pass the value in as a parameter instead of reading a signal
function f(v : integer) return integer is begin return v; end;
```

---

## Fix Strategy
## 전략 수정

1. Pass needed values as parameters instead of reading external signals.
1. 외부 신호를 읽는 대신 필요한 값을 매개변수로 전달합니다.
2. Mark the function `impure` if it must access such objects.
2. 해당 객체에 액세스해야 하는 경우 '불순함' 함수를 표시하세요.
3. Keep pure functions dependent only on their arguments.
3. 순수 함수를 인수에만 종속되게 유지하세요.
