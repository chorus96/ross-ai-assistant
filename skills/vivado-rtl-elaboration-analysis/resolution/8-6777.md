# 8-6777: Entity Not Found in Config Spec
# 8-6777: 구성 사양에서 엔터티를 찾을 수 없습니다.

**Message:** `[Synth 8-6777] Could not find entity '!%1!' used in configuration spec.
**메시지:** `[Synth 8-6777] '!%1!' 엔터티를 찾을 수 없습니다. 구성 사양에 사용됩니다.
Use the full path with library`
라이브러리와 함께 전체 경로 사용`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL configuration specification references an entity not found in the specified path.
VHDL 구성 사양이 지정된 경로에 없는 엔터티를 참조합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Entity not found in config spec
### P1: 구성 사양에서 엔터티를 찾을 수 없습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: entity not found in config
for inst : comp use entity work.verilog_level3(rtl);  -- ERROR: not found
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use full library path
for inst : comp use entity my_lib.verilog_level3(rtl);
-- Or remove config spec for default binding
```

---

## Fix Strategy
## 전략 수정

Use the correct library path in configuration specifications, or remove the config spec to use default binding.
구성 사양에서 올바른 라이브러리 경로를 사용하거나 구성 사양을 제거하여 기본 바인딩을 사용하세요.
