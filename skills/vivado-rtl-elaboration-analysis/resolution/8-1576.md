# 8-1576: Alias Only on Net Types
# 8-1576: 네트 유형에만 별칭 적용

**Message:** `[Synth 8-1576] aliasing can be done only on net types`
**메시지:** `[Synth 8-1576] 앨리어싱은 넷 유형에서만 수행할 수 있습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

SystemVerilog `alias` statement can only be used with net types (`wire`, `tri`), not variables.
SystemVerilog `alias` 문은 변수가 아닌 네트 유형(`wire`, `tri`)에만 사용할 수 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: alias used on variable types
### P1: 변수 유형에 사용되는 별칭

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: alias on variable
logic a, b;
alias a = b;  // ERROR: alias requires net types
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use wire for alias
wire a, b;
alias a = b;  // OK: wire is net type
// Or use assign for variables:
assign a = b;
```

---

## Fix Strategy
## 전략 수정

1. Use `alias` only between **net** types (`wire`, `tri`); declare the aliased objects as nets if you need an alias.
1. **net** 유형(`wire`, `tri`) 사이에만 `별칭`을 사용하세요. 별칭이 필요한 경우 별칭이 지정된 개체를 net으로 선언하세요.
2. To connect **variables** (`logic`/`reg`), use a continuous `assign` (for one direction) instead of `alias`.
2. **변수**(`logic`/`reg`)를 연결하려면 `alias` 대신 연속 `할당`(한 방향에 대해)을 사용하세요.
3. If bidirectional equivalence is required, model both nets as `wire` and drive them from a single source, rather than aliasing variables.
3. 양방향 동등성이 필요한 경우 두 네트를 '와이어'로 모델링하고 앨리어싱 변수가 아닌 단일 소스에서 구동합니다.
4. Reconsider whether an alias is needed at all — often a direct connection or a shared name is clearer and synthesizable.
4. 별칭이 필요한지 다시 생각해 보세요. 직접 연결이나 공유 이름이 더 명확하고 통합 가능한 경우가 많습니다.
