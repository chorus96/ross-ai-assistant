# 8-10592: closing label :!%1! is only allowed in SystemVerilog mode
# 8-10592: 닫는 레이블 :!%1! SystemVerilog 모드에서만 허용됩니다.

**Message:** `[Synth 8-10592] closing label :!%1! is only allowed in SystemVerilog mode`
**메시지:** `[Synth 8-10592] 닫는 라벨 :!%1! SystemVerilog 모드에서만 허용됩니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A closing label (e.g.
닫는 라벨(예:
`endmodule : name`) is used, which is only allowed in SystemVerilog mode - the file is being compiled as plain Verilog.
`endmodule : name`)이 사용되며 이는 SystemVerilog 모드에서만 허용됩니다. 파일은 일반 Verilog로 컴파일됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Closing label only allowed in SystemVerilog mode
### P1: 닫는 레이블은 SystemVerilog 모드에서만 허용됩니다.

**Problematic Code:**
**문제가 있는 코드:**
```systemverilog
endmodule : my_mod   // in Verilog-2001 mode
```

**Recommended Fix:**
**권장 수정 사항:**
```systemverilog
endmodule            // drop the label, or compile as SystemVerilog
```

---

## Fix Strategy
## 전략 수정

1. Remove the `: name` closing label, or set the file type to SystemVerilog.
1. `: name` 닫는 레이블을 제거하거나 파일 형식을 SystemVerilog로 설정합니다.
2. Closing labels are a SystemVerilog feature.
2. 닫는 레이블은 SystemVerilog 기능입니다.
3. Ensure the project reads the file with the correct language.
3. 프로젝트가 올바른 언어로 파일을 읽는지 확인하세요.
