# 8-422: Missing Port Association
# 8-422: 포트 연결 누락

**Message:** `[Synth 8-422] missing !%1! association for '!%2!'`
**메시지:** `[Synth 8-422] 누락!%1! '!%2!'`에 대한 연관
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL instantiation is missing a required port connection.
VHDL 인스턴스화에 필수 포트 연결이 누락되었습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Missing port in VHDL instantiation
### P1: VHDL 인스턴스화에 포트가 없습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: port 'clk' not connected
U1: my_comp port map(data => d, reset => r);  -- ERROR: missing clk
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: connect all required ports
U1: my_comp port map(clk => sys_clk, data => d, reset => r);
```

---

## Fix Strategy
## 전략 수정

1. Connect every required port in the `port map`; add the missing association (e.g., `clk => sys_clk`).
1. '포트 맵'에서 필요한 모든 포트를 연결하세요. 누락된 연결을 추가합니다(예: `clk => sys_clk`).
2. Use **named** association (`port => signal`) rather than positional so missing/mis-ordered ports are obvious.
2. 위치보다는 **이름이 지정된** 연결(`포트 => 신호`)을 사용하므로 포트가 없거나 잘못 정렬된 것이 분명합니다.
3. For outputs you genuinely do not need, map them to `open`; for inputs with a default value in the component/entity, you may omit them, otherwise they must be driven.
3. 실제로 필요하지 않은 출력의 경우 `open`에 매핑하세요. 구성 요소/엔티티에 기본값이 있는 입력의 경우 이를 생략할 수 있습니다. 그렇지 않으면 구동되어야 합니다.
4. Verify the component declaration matches the entity — a stale or mismatched component declaration is a common cause of "missing" ports.
4. 구성 요소 선언이 엔터티와 일치하는지 확인하십시오. 오래되었거나 일치하지 않는 구성 요소 선언은 "누락" 포트의 일반적인 원인입니다.
