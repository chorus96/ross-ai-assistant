# 8-2203: Illegal Use of Incomplete Type
# 8-2203: 불완전한 유형의 불법 사용

**Message:** `[Synth 8-2203] illegal use of incomplete type`
**메시지:** `[Synth 8-2203] 불완전한 유형의 불법 사용`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL incomplete type is used before its full declaration.
VHDL 불완전 유형은 전체 선언 전에 사용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Incomplete type used before completion
### P1: 완료되기 전에 사용된 불완전한 유형

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: using incomplete type
type node;
type ptr is access node;  -- OK so far
signal s : node;  -- ERROR: node is incomplete
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: complete the type first
type node is record
  data : integer;
end record;
signal s : node;  -- now complete
```

---

## Fix Strategy
## 전략 수정

1. Provide the **full** type declaration before any use as a signal/variable type — an incomplete type name may only be used to define an `access` (pointer) type until it is completed.
1. 신호/변수 유형으로 사용하기 전에 **전체** 유형 선언을 제공하십시오. 불완전한 유형 이름은 완료될 때까지 `액세스`(포인터) 유형을 정의하는 데만 사용할 수 있습니다.
2. Reorder declarations so the complete `type ... is record/array ...` appears ahead of objects of that type.
2. 완전한 `type ... is Record/array ...`가 해당 유형의 객체 앞에 나타나도록 선언을 재정렬합니다.
3. Note that access/pointer types and recursive linked structures are not synthesizable — for hardware, model the data with fixed arrays/records instead.
3. 액세스/포인터 유형과 재귀적으로 연결된 구조는 합성할 수 없습니다. 하드웨어의 경우 대신 고정 배열/레코드를 사용하여 데이터를 모델링하세요.
4. Remove forward/incomplete type usage from synthesizable code if it was only needed for dynamic structures.
4. 동적 구조에만 필요한 경우 합성 가능한 코드에서 정방향/불완전 유형 사용을 제거합니다.
