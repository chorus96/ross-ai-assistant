# 8-436: Modport Mismatch
# 8-436: 모드포트 불일치

**Message:** `[Synth 8-436] modport mismatch for formal interface port '!%1!': !%2! vs. !%3!`
**메시지:** `[Synth 8-436] 공식 인터페이스 포트 '!%1!'에 대한 modport 불일치: !%2! 대 !%3!`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A SystemVerilog interface port uses modport A but the instance expects modport B.
SystemVerilog 인터페이스 포트는 modport A를 사용하지만 인스턴스는 modport B를 기대합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Wrong modport passed to port
### P1: 잘못된 모드포트가 포트에 전달되었습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: wrong modport
module m(intf.A port1);  // expects modport A
m inst(.port1(my_intf.B));  // ERROR: passing modport B
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use matching modport
m inst(.port1(my_intf.A));  // match expected modport
```

---

## Fix Strategy
## 전략 수정

1. Connect the interface using the modport the module port expects (e.g., `.port1(my_intf.A)` when the port is declared `intf.A`).
1. 모듈 포트가 예상하는 모드 포트(예: 포트가 `intf.A`로 선언된 경우 `.port1(my_intf.A)`)를 사용하여 인터페이스를 연결합니다.
2. Verify the interface instance actually provides that modport and that its signal directions match the producer/consumer roles.
2. 인터페이스 인스턴스가 실제로 해당 모드 포트를 제공하고 해당 신호 방향이 생산자/소비자 역할과 일치하는지 확인하십시오.
3. Keep producer and consumer sides consistent — the driving side and receiving side must use complementary modports of the same interface.
3. 생산자와 소비자 측의 일관성을 유지하십시오. 구동 측과 수신 측에서는 동일한 인터페이스의 보완적인 모드포트를 사용해야 합니다.
4. If the module should accept multiple views, parameterize or overload the port with the correct modport rather than forcing a mismatched one.
4. 모듈이 여러 뷰를 허용해야 하는 경우 일치하지 않는 모드포트를 강제하는 대신 올바른 모드포트로 포트를 매개변수화하거나 오버로드하세요.
