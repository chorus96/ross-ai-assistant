# 8-9185: Bad Set Membership Operand
# 8-9185: 잘못된 세트 멤버쉽 피연산자

**Message:** `[Synth 8-9185] bad operand to set membership operator`
**메시지:** `[Synth 8-9185] 멤버십 연산자를 설정하는 잘못된 피연산자`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

The `inside` operator has an invalid operand type.
'내부' 연산자에 잘못된 피연산자 유형이 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Non-integral operand to inside
### P1: 내부에 대한 비정수 피연산자

**Problematic Code:**
**문제가 있는 코드:**
```diff
if (x inside {1.5, 2.5})  // ERROR: real not valid for inside
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
if (x inside {1, 2, 3})  // integral types only
```

---

## Fix Strategy
## 전략 수정

1. Use **integral** operands with the `inside` set-membership operator — replace `real`/non-integral values with integer/logic equivalents.
1. `inside` 멤버 집합 연산자와 함께 **정수** 피연산자를 사용하세요. `실수`/비정수 값을 정수/논리적 등가물로 바꾸세요.
2. Ensure the expression and every set element share a compatible integral type/width.
2. 표현식과 모든 설정 요소가 호환 가능한 정수 유형/너비를 공유하는지 확인하세요.
3. For range membership, use `inside {[lo:hi]}` with integral bounds.
3. 범위 멤버십의 경우 정수 범위와 함께 `inside {[lo:hi]}`를 사용하세요.
4. Move any real-valued comparison out of synthesizable RTL (use fixed-point/integer scaling).
4. 합성 가능한 RTL에서 실제 값 비교를 이동합니다(고정 소수점/정수 스케일링 사용).
