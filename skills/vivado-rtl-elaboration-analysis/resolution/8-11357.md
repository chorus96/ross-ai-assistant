# 8-11357: Potential 3D-RAM Issue
# 8-11357: 잠재적인 3D-RAM 문제

**Message:** `[Synth 8-11357] Potential Runtime issue for 3D-RAM or RAM from Record/Structs`
**메시지:** `[Synth 8-11357] Record/Structs의 3D-RAM 또는 RAM에 대한 잠재적인 런타임 문제`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

Vivado warns about potential issues with complex RAM structures (3D arrays or record-based RAMs).
Vivado는 복잡한 RAM 구조(3D 어레이 또는 레코드 기반 RAM)와 관련된 잠재적인 문제에 대해 경고합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Complex 3D/record-based RAM
### P1: 복잡한 3D/기록 기반 RAM

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- RAM inferred from records or 3D arrays may have runtime issues
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- Use simpler 2D RAM arrays
-- attribute ram_style : string;
-- attribute ram_style of mem : signal is "block";
```

---

## Fix Strategy
## 전략 수정

1. Simplify the memory to a 2D array (address x word); avoid 3D arrays or record-based RAMs that Vivado cannot map cleanly.
1. 메모리를 2D 배열(주소 x 워드)로 단순화합니다. Vivado가 깔끔하게 매핑할 수 없는 3D 어레이 또는 레코드 기반 RAM을 피하세요.
2. Use a synchronous read and the `ram_style` attribute to guide inference toward BRAM.
2. 동기식 읽기와 `ram_style` 속성을 사용하여 BRAM에 대한 추론을 안내합니다.
3. If multiple planes are needed, instantiate separate 2D memories rather than one 3D array.
3. 여러 평면이 필요한 경우 하나의 3D 어레이가 아닌 별도의 2D 메모리를 인스턴스화합니다.
4. Verify the resulting inference in the synthesis report meets resource/timing goals.
4. 종합 보고서의 결과 추론이 리소스/타이밍 목표를 충족하는지 확인합니다.
