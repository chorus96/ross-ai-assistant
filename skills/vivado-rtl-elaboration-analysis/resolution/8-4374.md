# 8-4374: Same Genvar in Nested Generate
# 8-4374: 중첩 생성의 동일한 Genvar

**Message:** `[Synth 8-4374] same genvar '!%1!' used in nested generate for loop`
**메시지:** `[Synth 8-4374] 동일한 genvar '!%1!' 중첩된 생성 for 루프에 사용됨`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

The same genvar is used in nested generate for loops, which is not allowed.
동일한 genvar가 중첩된 생성 for 루프에 사용되며 이는 허용되지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Reused genvar in nested generate loops
### P1: 중첩된 생성 루프에서 재사용된 genvar

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: same genvar in nested loops
genvar i;
generate
  for (i=0; i<4; i=i+1)
    for (i=0; i<8; i=i+1)  // ERROR: reusing 'i'
      ...
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use different genvars
genvar i, j;
generate
  for (i=0; i<4; i=i+1)
    for (j=0; j<8; j=j+1)  // different genvar
      ...
```

---

## Fix Strategy
## 전략 수정

1. Give each nesting level of `generate for` loops its own distinct `genvar` (`i` for the outer, `j` for the inner).
1. `generate for` 루프의 각 중첩 수준에 고유한 `genvar`(외부에는 `i`, 내부에는 `j`)를 제공합니다.
2. Declare the genvars before the generate block (`genvar i, j;`) and do not reuse one across nested scopes.
2. 생성 블록(`genvar i, j;`) 앞에 genvar를 선언하고 중첩된 범위에서 재사용하지 마세요.
3. Ensure each loop's generate block has a unique label so the generated hierarchy names are distinct.
3. 생성된 계층 구조 이름이 구별되도록 각 루프의 생성 블록에 고유한 레이블이 있는지 확인하십시오.
4. Check for an accidental copy-paste that reused the same loop variable in the inner loop.
4. 내부 루프에서 동일한 루프 변수를 재사용한 실수로 복사-붙여넣기를 확인하세요.
