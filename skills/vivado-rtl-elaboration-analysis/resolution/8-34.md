# 8-34: Wrong Argument Count for Operator
# 8-34: 연산자에 대한 잘못된 인수 개수

**Message:** `[Synth 8-34] '!%1!' expects !%2! arguments`
**메시지:** `[Synth 8-34] '!%1!' !%2!을(를) 기대합니다! 인수'
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

VHDL operator expects a specific number of arguments (e.g., binary `*` expects 2).
VHDL 연산자는 특정 수의 인수를 기대합니다(예: 바이너리 `*`는 2를 기대합니다).

---

## Common Patterns
## 일반적인 패턴

### P1: Operator called with wrong operand count
### P1: 잘못된 피연산자 수로 호출된 연산자

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: wrong number of args for operator
result <= "*"(a);  -- ERROR: * expects 2 arguments
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: provide correct number
result <= a * b;  -- 2 operands for binary operator
```

---

## Fix Strategy
## 전략 수정

1. Identify the operator and its required arity:
1. 연산자와 필요한 개수를 식별합니다.
   - **Binary** (2 operands): `+ - * / mod rem ** & | xor and or nand nor sll srl`, relational (`= /= < <= > >=`).
   - **2진수** (2개의 피연산자): `+ - * / mod rem ** & | xor 및/또는 nand 또는 sll srl`, 관계형(`= /= < <= > >=`).
   - **Unary** (1 operand): `not abs`, unary minus/plus.
   - **단항**(피연산자 1개): `abs가 아님`, 단항 빼기/더하기.
2. Rewrite the expression in infix form with the correct number of operands, e.g.
2. 올바른 수의 피연산자를 사용하여 중위 형식으로 표현식을 다시 작성합니다.
2. `a * b` instead of `"*"(a)`.
2. `"*"(a)` 대신 `a * b`.
3. If calling an overloaded/user-defined operator function, check its declaration — the number of formal parameters must match the call.
3. 오버로드된/사용자 정의 연산자 함수를 호출하는 경우 해당 선언을 확인하십시오. 형식 매개변수의 수가 호출과 일치해야 합니다.
4. For aggregates/concatenation, use the proper syntax (`&` for concatenation, `(others => ...)` for aggregates) rather than an operator call form.
4. 집계/연결의 경우 연산자 호출 형식보다는 적절한 구문(연결의 경우 `&`, 집계의 경우 `(others => ...)`)을 사용합니다.
