# 8-11635: Cannot Associate with Private Type
# 8-11635: 개인 유형과 연결할 수 없습니다.

**Message:** `[Synth 8-11635] '!%1!' cannot be associated with unspecified '!%2!' type`
**메시지:** `[Synth 8-11635] '!%1!' 지정되지 않은 '!%2!'와 연관될 수 없습니다. 유형`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL generic maps a type to a `private` interface type that restricts associations.
VHDL 제네릭은 연결을 제한하는 `private` 인터페이스 유형에 유형을 매핑합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Association with a private type
### P1: 개인 유형과의 연관

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: associating with private type
generic map(mytype => integer);  -- ERROR: private type doesn't allow this
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use compatible type or change interface
-- Check the generic interface type constraints
-- Use a type that satisfies the private type's requirements
```

---

## Fix Strategy
## 전략 수정

1. Check the generic package's type constraints — a `private` interface type restricts which actual types may be associated.
1. 일반 패키지의 유형 제약 조건을 확인하세요. `private` 인터페이스 유형은 연관될 수 있는 실제 유형을 제한합니다.
2. Provide an actual type that satisfies the private-type constraints, or relax the interface if you control it.
2. 개인 유형 제약 조건을 충족하는 실제 유형을 제공하거나, 인터페이스를 제어하는 ​​경우 인터페이스를 완화하세요.
3. Confirm the flow supports VHDL-2008 interface/generic types; otherwise use a concrete type.
3. 흐름이 VHDL-2008 인터페이스/일반 유형을 지원하는지 확인합니다. 그렇지 않으면 구체적인 유형을 사용하십시오.
4. Ensure the mapped actual is visible and compatible where the generic is elaborated.
4. 매핑된 실제 항목이 표시되고 일반 항목이 자세히 설명된 위치와 호환되는지 확인하세요.
