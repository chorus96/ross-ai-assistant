# 8-445: Multiply Driven Output
# 8-445: 곱셈 구동 출력

**Message:** `[Synth 8-445] multiply driven output port connection in instance array`
**메시지:** `[Synth 8-445] 인스턴스 어레이의 곱셈 구동 출력 포트 연결`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An output port in an instance array is driven by multiple instances.
인스턴스 배열의 출력 포트는 여러 인스턴스에 의해 구동됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Shared output across instance array
### P1: 인스턴스 어레이 전체에서 공유 출력

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: output driven by multiple instances
my_mod bI[3:0](.out(shared_out));  // WARNING: multi-driven
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: separate output connections
wire [3:0] out_arr;
my_mod bI[3:0](.out(out_arr));  // separate per-instance
```

---

## Fix Strategy
## 전략 수정

1. Give each instance in the array its own output net — size the connected wire to the array width (`wire [N-1:0] out_arr; my_mod bI[N-1:0](.out(out_arr));`).
1. 배열의 각 인스턴스에 자체 출력 네트를 제공합니다. 연결된 와이어의 크기를 배열 너비에 맞게 지정합니다(`wire [N-1:0] out_arr; my_mod bI[N-1:0](.out(out_arr));`).
2. Never share a single scalar output net across all instances of an instance array — that creates an unintended multi-driver.
2. 의도하지 않은 다중 드라이버를 생성하는 인스턴스 배열의 모든 인스턴스에서 단일 스칼라 출력 네트를 공유하지 마십시오.
3. If a shared bus is genuinely intended, implement it explicitly with tri-state drivers or a mux, not by connecting many outputs to one net.
3. 공유 버스가 실제로 의도된 경우 많은 출력을 하나의 네트워크에 연결하지 않고 3상태 드라이버 또는 멀티플렉서를 사용하여 명시적으로 구현하십시오.
4. Verify downstream logic reads the correct per-instance bit rather than the collided shared signal.
4. 다운스트림 로직이 충돌된 공유 신호가 아닌 올바른 인스턴스별 비트를 읽는지 확인합니다.
