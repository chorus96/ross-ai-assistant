# 8-2558: Assignment Pattern Prefix Must Be Type
# 8-2558: 할당 패턴 접두사는 유형이어야 합니다.

**Message:** `[Synth 8-2558] prefix of assignment pattern must be a data type`
**메시지:** `[Synth 8-2558] 할당 패턴의 접두사는 데이터 유형이어야 합니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

The prefix of an assignment pattern must be a data type, not a signal or expression.
할당 패턴의 접두사는 신호나 표현식이 아닌 데이터 유형이어야 합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Non-type prefix on assignment pattern
### P1: 할당 패턴의 비유형 접두사

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: signal as pattern prefix
assign x = sig'{1, 2};  // ERROR: sig is not a type
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use type as prefix
typedef int arr_t[2];
assign x = arr_t'{1, 2};  // type prefix
```

---

## Fix Strategy
## 전략 수정

1. Use a **type name** as the assignment-pattern prefix (`arr_t'{1, 2}`, `my_struct_t'{...}`), never a signal/variable or expression.
1. **유형 이름**을 할당 패턴 접두사(`arr_t'{1, 2}`, `my_struct_t'{...}`)로 사용하고 신호/변수 또는 표현식은 사용하지 마세요.
2. Declare a `typedef` for the target shape and qualify the pattern with it when the context type is ambiguous.
2. 대상 모양에 대해 `typedef`를 선언하고 컨텍스트 유형이 모호할 때 이를 사용하여 패턴을 한정합니다.
3. If no qualification is needed, drop the prefix and rely on the LHS type (`x = '{1, 2};`).
3. 한정이 필요하지 않으면 접두사를 삭제하고 LHS 유형(`x = '{1, 2};`)을 사용합니다.
4. Ensure the pattern's element count/types match the referenced type exactly.
4. 패턴의 요소 개수/유형이 참조된 유형과 정확히 일치하는지 확인하세요.
