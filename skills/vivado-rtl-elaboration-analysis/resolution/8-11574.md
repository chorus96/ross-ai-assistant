# 8-11574: Non-Printable Character
# 8-11574: 인쇄할 수 없는 문자

**Message:** `[Synth 8-11574] unexpected non-printable character with the hex value '0x!%1!'`
**메시지:** `[Synth 8-11574] 16진수 값 '0x!%1!'이 포함된 예기치 않은 인쇄할 수 없는 문자'`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

The source file contains a non-printable character (e.g., Ctrl+Z/0x1A from Windows line endings).
소스 파일에 인쇄할 수 없는 문자(예: Windows 줄 끝의 Ctrl+Z/0x1A)가 포함되어 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Non-printable character in source
### P1: 소스의 인쇄할 수 없는 문자

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: file contains hidden 0x1A character
-- (invisible in editor but causes parse error)
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: clean the file
-- Use: dos2unix file.vhd
-- Or open in hex editor and remove 0x1A bytes
```

---

## Fix Strategy
## 전략 수정

1. Remove non-printable characters (e.g., `Ctrl+Z`/0x1A, stray control bytes) from the source file.
1. 소스 파일에서 인쇄할 수 없는 문자(예: `Ctrl+Z`/0x1A, 길 잃은 제어 바이트)를 제거합니다.
2. Run `dos2unix` to normalize line endings, or re-save the file as clean UTF-8/ASCII.
2. `dos2unix`를 실행하여 줄 끝을 정규화하거나 파일을 깨끗한 UTF-8/ASCII로 다시 저장하세요.
3. Check for a truncated/corrupted file transfer that injected control characters.
3. 제어 문자를 삽입하여 잘리거나 손상된 파일 전송을 확인하십시오.
4. Verify the editor is not adding a BOM or trailing EOF marker the tool rejects.
4. 편집기가 도구가 거부하는 BOM 또는 후행 EOF 마커를 추가하지 않는지 확인하십시오.
