# 8-13329: null range (-1 downto 0) not
# 8-13329: null 범위(-1부터 0까지) 아님

**Message:** `[Synth 8-13329] null range (-1 downto 0) not supported`
**메시지:** `[Synth 8-13329] null 범위(-1부터 0까지)는 지원되지 않습니다.`
**Severity:** CRITICAL WARNING
**심각도:** 심각한 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A range evaluates to a **null range** such as `(-1 downto 0)` — the high bound is
범위는 `(-1에서 0까지)`와 같은 **널 범위**로 평가됩니다. 상한은 다음과 같습니다.
less than the low bound for a `downto` range (or vice-versa for `to`).
'downto' 범위의 하한보다 작습니다(또는 'to'의 경우 그 반대).
This
이
typically happens when a width parameter is `0`, so `WIDTH-1 downto 0` becomes
일반적으로 너비 매개변수가 `0`일 때 발생하므로 `WIDTH-1 downto 0`은
`-1 downto 0`, producing an empty (zero-length) object that Vivado does not
`-1 downto 0`, Vivado가 수행하지 않는 빈(길이가 0인) 객체 생성
support here.
여기서 지원하세요.

## Common Patterns
## 일반적인 패턴

### P1: Null range from zero-width parameter
### P1: 너비가 0인 매개변수의 Null 범위

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Problematic line:
state_active      := '1';
            state_read_done   := '0';
            state_trans_index := (state_trans_index'length-1 DOWNTO 0 => '0');
            state_had_error   := '0';
            timeout_cnt       <= to_unsigned(TIMEOUT-1, timeout_cnt'length);
```

**Recommended Fix:**
**권장 수정 사항:**
```vhdl
-- Ensure the width parameter is > 0 so the range is non-null
constant WIDTH : integer := 8;                 -- was 0 -> (-1 downto 0)
signal state_trans_index : std_logic_vector(WIDTH-1 downto 0);
-- or guard the zero-width case with a generate/conditional
```

---

## Fix Strategy
## 전략 수정

1. Ensure the width parameter driving the range is greater than zero so `WIDTH-1 downto 0` is not `-1 downto 0` (a null range).
1. 범위를 구동하는 너비 매개변수가 0보다 큰지 확인하여 'WIDTH-1 downto 0'이 '-1 downto 0'(null 범위)이 되지 않도록 하세요.
2. Give the generic/constant a valid non-zero default and a valid override.
2. 일반/상수에 0이 아닌 유효한 기본값과 유효한 재정의를 제공합니다.
3. Guard configurations where a width can legitimately be 0 with a `generate`/conditional so no null-range object is created.
3. 널 범위 객체가 생성되지 않도록 `생성`/조건을 사용하여 너비가 합법적으로 0이 될 수 있는 보호 구성입니다.
4. Treat this CRITICAL WARNING as a real bug — a zero-width object usually indicates a mis-sized parameter.
4. 이 중요한 경고를 실제 버그로 취급하십시오. 너비가 0인 개체는 일반적으로 매개변수 크기가 잘못되었음을 나타냅니다.
