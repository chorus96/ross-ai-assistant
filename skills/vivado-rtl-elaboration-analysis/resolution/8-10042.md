# 8-10042: subprogram '!%1!' does not conform with its declaration
# 8-10042: 하위 프로그램 '!%1!' 선언과 일치하지 않습니다.

**Message:** `[Synth 8-10042] subprogram '!%1!' does not conform with its declaration`
**메시지:** `[Synth 8-10042] 하위 프로그램 '!%1!' 선언과 일치하지 않습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A subprogram's body (or a generic subprogram's actual) has a profile - parameter names, types, modes, or return type - that does not match its earlier declaration in the package spec or interface.
하위 프로그램의 본문(또는 일반 하위 프로그램의 실제 본문)에 패키지 사양이나 인터페이스의 이전 선언과 일치하지 않는 프로필(매개변수 이름, 유형, 모드 또는 반환 유형)이 있습니다.
VHDL requires the body to conform exactly to the declaration.
VHDL에서는 본문이 선언과 정확히 일치해야 합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Subprogram body does not match its declaration
### P1: 하위 프로그램 본문이 해당 선언과 일치하지 않습니다.

**Problematic Code:**
**문제가 있는 코드:**
```vhdl
-- spec
function f(a : in bit_vector) return bit_vector;
-- body: profile differs (std_logic_vector vs bit_vector)
function f(a : in std_logic_vector) return std_logic_vector is begin ... end;
```

**Recommended Fix:**
**권장 수정 사항:**
```vhdl
-- body matches the spec exactly
function f(a : in bit_vector) return bit_vector is begin ... end;
```

---

## Fix Strategy
## 전략 수정

1. Make the body's parameter names, types, modes and return type identical to the declaration.
1. 본문의 매개변수 이름, 유형, 모드 및 반환 유형을 선언과 동일하게 만듭니다.
2. For a generic subprogram formal, ensure the actual subprogram's profile conforms to the declared interface.
2. 일반적인 하위 프로그램 형식의 경우 실제 하위 프로그램의 프로필이 선언된 인터페이스를 준수하는지 확인하세요.
3. Watch for subtype differences (e.g. bit_vector vs std_logic_vector) - they do not conform.
3. 하위 유형의 차이점(예: bit_Vector와 std_logic_Vector)을 살펴보세요. 일치하지 않습니다.
