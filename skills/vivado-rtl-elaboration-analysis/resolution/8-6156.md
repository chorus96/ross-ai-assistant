# 8-6156: Failed Synthesizing Module
# 8-6156: 합성 모듈 실패

**Message:** `[Synth 8-6156] failed synthesizing module '!%1!'!%2!`
**메시지:** `[Synth 8-6156] '!%1!'!%2!' 모듈 합성에 실패했습니다.`

**Source:** Oasys Synthesis

## Root Cause
## 근본 원인

모듈 내의 오류로 인해 모듈 합성에 실패했습니다(다른 오류로 인해 발생).
