# 8-9493: No Matching Operator Definition
# 8-9493: 일치하는 연산자 정의가 없습니다.

**Message:** `[Synth 8-9493] found '0' definitions of operator, cannot determine exact overloaded matching definition`
**메시지:** `[Synth 8-9493] 연산자의 '0' 정의를 찾았지만 정확한 오버로드된 일치 정의를 확인할 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

No visible operator definition matches the operand types.
피연산자 유형과 일치하는 표시되는 연산자 정의가 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: No operator for these operand types
### P1: 이러한 피연산자 유형에는 연산자가 없습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
result <= a + b;  -- ERROR: no '+' for these types
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
use ieee.numeric_std.all;  -- import operator definitions
result <= unsigned(a) + unsigned(b);
```

---

## Fix Strategy
## 전략 수정

1. Import the package that defines the operator for your operand types (`use ieee.numeric_std.all;` for `unsigned`/`signed` arithmetic).
1. 피연산자 유형에 대한 연산자를 정의하는 패키지를 가져옵니다(`unsigned`/`signed` 산술의 경우 `ieee.numeric_std.all;` 사용).
2. Convert operands to a type the operator supports (`unsigned(a) + unsigned(b)`), then convert the result back if needed.
2. 피연산자를 연산자가 지원하는 유형(`unsigned(a) + unsigned(b)`)으로 변환한 다음, 필요한 경우 결과를 다시 변환합니다.
3. Ensure both operands share a compatible type/width for the operator.
3. 두 피연산자가 연산자에 대해 호환 가능한 유형/너비를 공유하는지 확인하십시오.
4. If using a user-defined operator, make its overload visible in scope.
4. 사용자 정의 연산자를 사용하는 경우 해당 오버로드가 범위에 표시되도록 합니다.
