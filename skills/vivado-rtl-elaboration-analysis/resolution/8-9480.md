# 8-9480: Formal Generic Has No Value
# 8-9480: 공식 일반에는 값이 없습니다.

**Message:** `[Synth 8-9480] formal generic has no actual or default value`
**메시지:** `[Synth 8-9480] 공식 일반에는 실제 값이나 기본값이 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL generic parameter has no default and no value provided in the generic map.
VHDL 일반 매개변수에는 기본값이 없으며 일반 맵에 제공된 값이 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Generic with no value or default
### P1: 값이나 기본값이 없는 일반

**Problematic Code:**
**문제가 있는 코드:**
```diff
generic (datawidth : integer);  -- no default
-- instantiation without generic map  -- ERROR
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
generic (datawidth : integer := 8);  -- add default
-- Or provide in generic map:
generic map(datawidth => 8)
```

---

## Fix Strategy
## 전략 수정

1. Give the generic a default value in the entity (`generic (DATAWIDTH : integer := 8)`), or supply it in every `generic map` at instantiation.
1. 제네릭에 엔터티의 기본값(`generic (DATAWIDTH : 정수 := 8)`)을 제공하거나 인스턴스화 시 모든 `generic map`에 이를 제공합니다.
2. Ensure all required generics are provided when instantiating — a generic with no default is mandatory.
2. 인스턴스화 시 필요한 모든 제네릭이 제공되었는지 확인하세요. 기본값이 없는 제네릭은 필수입니다.
3. Prefer sensible defaults for optional parameters and explicit overrides for required ones.
3. 선택적 매개변수에 대해서는 합리적인 기본값을 선호하고 필수 매개변수에 대해서는 명시적인 재정의를 선호합니다.
4. Verify the value's type/range matches the generic declaration.
4. 값의 유형/범위가 일반 선언과 일치하는지 확인하세요.
