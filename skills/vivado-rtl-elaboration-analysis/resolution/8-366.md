# 8-366: Invalid Precompiled Function
# 8-366: 잘못된 미리 컴파일된 함수

**Message:** `[Synth 8-366] invalid definition of precompiled function '!%1!'`
**메시지:** `[Synth 8-366] 미리 컴파일된 함수 '!%1!'의 정의가 잘못되었습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A precompiled IP function definition doesn't match the expected signature.
미리 컴파일된 IP 함수 정의가 예상 서명과 일치하지 않습니다.

## 일반적인 패턴

## Fix Strategy
## 전략 수정

1. Regenerate the IP core for the current Vivado version so its precompiled function signatures match the tool.
1. 현재 Vivado 버전의 IP 코어를 재생성하여 사전 컴파일된 함수 서명이 도구와 일치하도록 합니다.
2. Run the IP upgrade flow (`report_ip_status` / `upgrade_ip`) and re-synthesize.
2. IP 업그레이드 흐름(`report_ip_status` / `upgrade_ip`)을 실행하고 다시 합성하세요.
3. Verify the precompiled library/version referenced by the design matches the installed Vivado release.
3. 설계에서 참조하는 사전 컴파일된 라이브러리/버전이 설치된 Vivado 릴리스와 일치하는지 확인하세요.
4. If the signature mismatch persists, delete stale generated/cached IP outputs and rebuild the IP from its `.xci` source.
4. 서명 불일치가 지속되면 오래된 생성/캐시된 IP 출력을 삭제하고 해당 `.xci` 소스에서 IP를 다시 빌드하세요.
