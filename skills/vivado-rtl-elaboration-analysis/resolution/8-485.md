# 8-485: No Port on Instance
# 8-485: 인스턴스에 포트 없음

**Message:** `[Synth 8-485] no port '!%1!' on instance`
**메시지:** `[Synth 8-485] '!%1!' 포트가 없습니다. 예를 들어`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An instance port map references a port name that doesn't exist on the module/entity.
인스턴스 포트 맵이 모듈/엔티티에 존재하지 않는 포트 이름을 참조합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Port name not found on instance
### P1: 인스턴스에서 포트 이름을 찾을 수 없습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: port doesn't exist
U1: my_mod port map(veGatedNandIn3 => sig);  -- ERROR: no such port
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use correct port name
U1: my_mod port map(veGatedNandIn1 => sig);  -- correct name
```

---

## Fix Strategy
## 전략 수정

1. Open the child entity/module declaration and use the exact port names in the `port map`/connection (names are case-sensitive).
1. 하위 엔터티/모듈 선언을 열고 `포트 맵`/연결에서 정확한 포트 이름을 사용합니다(이름은 대소문자를 구분합니다).
2. Fix typos in the offending port name to match the declaration.
2. 선언과 일치하도록 잘못된 포트 이름의 오타를 수정하세요.
3. Verify you are instantiating the intended (and current) entity/component — a stale declaration with different port names is a common cause.
3. 의도한(및 현재) 엔터티/구성 요소를 인스턴스화하고 있는지 확인하십시오. 포트 이름이 다른 오래된 선언이 일반적인 원인입니다.
4. Prefer named association so mismatched names are caught immediately, and remove connections to ports that no longer exist.
4. 일치하지 않는 이름이 즉시 발견되도록 명명된 연결을 선호하고 더 이상 존재하지 않는 포트에 대한 연결을 제거합니다.
