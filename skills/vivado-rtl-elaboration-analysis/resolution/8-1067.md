# 8-1067: Break Statement Illegal Here
# 8-1067: 여기에서는 Break 문이 잘못되었습니다.

**Message:** `[Synth 8-1067] break statement is illegal here`
**메시지:** `[Synth 8-1067] break 문은 여기서 불법입니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-1067] break statement is illegal here [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A `break` statement is used outside a loop context (e.g., in an `if`/`else` inside a task not within a loop).
`break` 문은 루프 컨텍스트 외부에서 사용됩니다(예: 루프 내부가 아닌 작업 내부의 `if`/`else`에서).

---

## Common Patterns
## 일반적인 패턴

### P1: break used outside a loop
### P1: 루프 외부에서 사용되는 중단

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: break outside loop
task task_1(input in1, output int out1);
begin
  if (in1 == 0) out1 = out1 + 1;
  else break;    // ERROR: break not inside a loop
end
endtask
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use return or remove break
task task_1(input in1, output int out1);
begin
  if (in1 == 0) out1 = out1 + 1;
  else out1 = 0;   // replace break with actual logic
end
endtask
```

---

## Fix Strategy
## 전략 수정

1. Use `break` only inside a loop (`for`, `while`, `do-while`, `foreach`); if there is no loop, remove it.
1. 루프(`for`, `while`, `do-while`, `foreach`) 내에서만 `break`를 사용하세요. 루프가 없으면 제거하십시오.
2. To leave a `task`/`function` early, use `return` instead of `break`.
2. `task`/`function`을 일찍 종료하려면 `break` 대신 `return`을 사용하세요.
3. Replace the `break` with the actual intended behavior (e.g., set an output/flag) when it was standing in for real logic.
3. 실제 논리를 대신할 때 `break`를 실제 의도된 동작(예: 출력/플래그 설정)으로 대체합니다.
4. If early-exit within nested control was intended, restructure with a loop plus `break`, or use conditional logic that avoids the need to break.
4. 중첩된 제어 내의 조기 종료를 의도한 경우 루프와 `break`를 사용하여 재구성하거나 중단할 필요가 없는 조건부 논리를 사용하십시오.
