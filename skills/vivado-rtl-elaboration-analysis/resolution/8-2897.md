# 8-2897: Clock Used as Data
# 8-2897: 데이터로 사용되는 시계

**Message:** `[Synth 8-2897] clock signal used as data`
**메시지:** `[Synth 8-2897] 데이터로 사용되는 클럭 신호`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A clock signal is used as a data input, which may cause timing issues.
클럭 신호가 데이터 입력으로 사용되므로 타이밍 문제가 발생할 수 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Clock net routed into a data path
### P1: 데이터 경로로 라우팅된 클록 네트

**Problematic Code:**
**문제가 있는 코드:**
```diff
assign data = clk;  // WARNING: clock used as data
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- Use a dedicated signal for data, not the clock
-- If clock gating needed, use BUFGCE
```

---

## Fix Strategy
## 전략 수정

1. Do not route a clock net into a data path — use a dedicated data signal; feeding a clock as data breaks timing analysis and causes CDC issues.
1. 클록 넷을 데이터 경로로 라우팅하지 마십시오. 전용 데이터 신호를 사용하십시오. 데이터가 타이밍 분석을 중단하고 CDC 문제를 일으킬 때 시계를 공급합니다.
2. If you need to sample/observe the clock, do it through proper primitives (e.g., a clock divider/counter driven by the clock), not by assigning `clk` to data.
2. 시계를 샘플링/관찰해야 하는 경우 데이터에 'clk'를 할당하는 것이 아니라 적절한 프리미티브(예: 시계에 의해 구동되는 시계 분배기/카운터)를 통해 수행하십시오.
3. For clock gating/enable, use `BUFGCE`/clock-enable logic rather than combining the clock into data.
3. 클럭 게이팅/활성화의 경우 클럭을 데이터에 결합하는 대신 `BUFGCE`/클럭 활성화 로직을 사용하세요.
4. If the connection is intentional and safe (rare), add the appropriate timing constraint/exception in XDC and document why.
4. 연결이 의도적이고 안전한 경우(드물게) XDC에 적절한 타이밍 제약/예외를 추가하고 그 이유를 문서화하세요.
