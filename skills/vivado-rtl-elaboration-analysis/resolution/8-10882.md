# 8-10882: Incomplete Structure Literal
# 8-10882: 불완전한 구조 리터럴

**Message:** `[Synth 8-10882] incomplete structure literal; no value is specified for field`
**메시지:** `[Synth 8-10882] 불완전한 구조 리터럴; 필드에 값이 지정되지 않았습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10882] incomplete structure literal; no value is specified for field [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A SystemVerilog assignment pattern for a struct is missing a value for one or more fields.
구조체에 대한 SystemVerilog 할당 패턴에 하나 이상의 필드 값이 누락되었습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Incomplete struct assignment pattern
### P1: 불완전한 구조체 할당 패턴

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: struct literal missing field '_e'
assign a = '{default:'{default:'{_i:12, _b:'{default:a}}}};  // ERROR: _e missing
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: provide all fields
assign a = '{default:'{default:'{_i:12, _b:'{default:a}, _e:0}}};
// Or use default for remaining fields:
assign a = '{default:'{default:'{_i:12, _b:'{default:a}, default:0}}};
```

---

## Fix Strategy
## 전략 수정

1. Provide a value for **every** field in the struct assignment pattern.
1. 구조체 할당 패턴의 **모든** 필드에 값을 제공하세요.
2. Use `default: <value>` inside the pattern to fill common defaults for remaining fields.
2. 나머지 필드에 대한 공통 기본값을 채우려면 패턴 내에서 `default: <value>`를 사용하세요.
3. Prefer named field association (`'{a: x, b: y}`) so a missing field is obvious.
3. 누락된 필드가 분명하도록 명명된 필드 연결(`'{a: x, b: y}`)을 선호합니다.
4. For nested structs, ensure each sub-pattern is complete.
4. 중첩된 구조체의 경우 각 하위 패턴이 완전한지 확인하세요.
