# 8-2948: Architecture Not Found
# 8-2948: 아키텍처를 찾을 수 없음

**Message:** `[Synth 8-2948] no architecture '!%1!' for entity '!%2!'`
**메시지:** `[Synth 8-2948] 아키텍처 '!%1!'이 없습니다. 엔터티 '!%2!'`에 대해
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

VHDL entity references an architecture that doesn't exist.
VHDL 엔터티가 존재하지 않는 아키텍처를 참조합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Binding to a non-existent architecture
### P1: 존재하지 않는 아키텍처에 바인딩

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: non-existent architecture
for inst : child use entity work.child(child);  -- ERROR: no arch 'child'
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use correct architecture name
for inst : child use entity work.child(rtl);  -- correct arch name
-- Or remove config spec for default binding
```

---

## Fix Strategy
## 전략 수정

1. Use an architecture name that actually exists for the entity (e.g., `rtl`, `behavioral`) in the configuration/binding spec.
1. 구성/바인딩 사양에서 엔터티에 대해 실제로 존재하는 아키텍처 이름(예: 'rtl', 'behavioral')을 사용하세요.
2. Ensure the architecture body is compiled into the same library as the entity before the configuration is elaborated.
2. 구성을 자세히 설명하기 전에 아키텍처 본문이 엔터티와 동일한 라이브러리로 컴파일되었는지 확인하세요.
3. If default binding is acceptable, remove the explicit `for ... use entity work.<e>(<arch>)` configuration specification.
3. 기본 바인딩이 허용되는 경우 명시적인 `for ... use Entity work.<e>(<arch>)` 구성 사양을 제거합니다.
4. Fix typos in the architecture name (case-insensitive but must exist) and verify compile order.
4. 아키텍처 이름의 오타를 수정하고(대소문자를 구분하지만 존재해야 함) 컴파일 순서를 확인하세요.
