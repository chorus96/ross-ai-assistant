# 8-6902: Type Used Before Declaration
# 8-6902: 선언 이전에 사용된 유형

**Message:** `[Synth 8-6902] type '!%1!' is used before its declaration`
**메시지:** `[Synth 8-6902] '!%1!'을 입력하세요. 선언 전에 사용됩니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A type is referenced before its declaration in the source file.
유형은 소스 파일에서 선언되기 전에 참조됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Type used before its declaration
### P1: 선언 전에 사용된 유형

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: type used before declaration
st_t my_sig;  // ERROR: st_t not yet declared
typedef struct {...} st_t;
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: declare type first
typedef struct {...} st_t;
st_t my_sig;  // now declared
```

---

## Fix Strategy
## 전략 수정

1. Declare the type **before** its first use — move the `typedef`/type declaration above the signals/variables that reference it.
1. 유형을 처음 사용하기 **전에** 선언하십시오. 이를 참조하는 신호/변수 위로 `typedef`/type 선언을 이동하십시오.
2. In packages, order declarations so types precede the objects and subprograms that use them.
2. 패키지에서는 유형이 해당 유형을 사용하는 개체 및 하위 프로그램보다 앞에 오도록 선언 순서가 지정됩니다.
3. If the type comes from another package, `import`/`use` that package before the reference.
3. 유형이 다른 패키지에서 온 경우 참조 전에 해당 패키지를 `가져오기`/`사용`하세요.
4. Check for a typo where the reference does not match the actual (later) type name.
4. 참조가 실제(이후) 유형 이름과 일치하지 않는 오타를 확인하세요.
