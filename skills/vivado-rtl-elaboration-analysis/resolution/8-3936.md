# 8-3936: Unconnected Internal Register
# 8-3936: 연결되지 않은 내부 레지스터

**Message:** `[Synth 8-3936] Found unconnected internal register`
**메시지:** `[Synth 8-3936] 연결되지 않은 내부 레지스터를 찾았습니다.`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An internal register has no load — its output is never read.
내부 레지스터에는 로드가 없습니다. 즉, 출력이 읽혀지지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Register whose output is never read
### P1: 출력을 읽지 않는 레지스터

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- WARNING: register output not used
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- If intentional, add keep attribute:
(* dont_touch = "true" *) reg my_reg;
-- Otherwise, remove the unused register
```

---

## Fix Strategy
## 전략 수정

1. If the register is genuinely unused, remove it and the logic that feeds it to save resources.
1. 레지스터가 실제로 사용되지 않은 경우 해당 레지스터와 이를 제공하는 로직을 제거하여 리소스를 절약하세요.
2. If it must be kept (debug, ILA probe, external tool expectation), apply `(* dont_touch = "true" *)` / `keep` so it is not optimized away.
2. 유지해야 하는 경우(디버그, ILA 프로브, 외부 도구 예상) `(* dont_touch = "true" *)` / `keep`을 적용하여 최적화되지 않도록 하세요.
3. Check for a missing connection — often the register's output was meant to drive something but the wire was never hooked up; connect it.
3. 누락된 연결이 있는지 확인하십시오. 종종 레지스터의 출력이 무언가를 구동하기 위한 것이지만 와이어가 연결되지 않은 경우가 많습니다. 연결하세요.
4. Verify the register is not a symptom of dead logic upstream that should also be cleaned up.
4. 레지스터가 역시 정리되어야 하는 데드 로직 업스트림의 증상이 아닌지 확인하십시오.
