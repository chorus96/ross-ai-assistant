# 8-11066: Parameter on LHS of Assignment
# 8-11066: 할당의 LHS에 대한 매개변수

**Message:** `[Synth 8-11066] parameter cannot be used on the left hand side of assignment`
**메시지:** `[Synth 8-11066] 매개변수는 할당의 왼쪽에 사용할 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-11066] parameter cannot be used on the left hand side of assignment [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A `parameter` is assigned a value via `defparam` or direct assignment inside a function.
`매개변수`에는 `defparam`을 통해 값이 할당되거나 함수 내에서 직접 할당됩니다.
Parameters are constants.
매개변수는 상수입니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Assignment to a parameter
### P1: 매개변수에 할당

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: defparam inside function (illegal)
parameter p = 1;
function integer consfunc;
  input i;
  begin
    defparam p = 5;   // ERROR: parameter is constant
  end
endfunction
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use localparam or variable
localparam p = 1;     // keep as constant
function integer consfunc;
  input i;
  integer local_p;
  begin
    local_p = 5;      // use local variable
    consfunc = local_p;
  end
endfunction
```

---

## Fix Strategy
## 전략 수정

1. Parameters/localparams are constants — do not assign to them; use a local variable if the value must change.
1. 매개변수/localparams는 상수이므로 할당하지 마세요. 값을 변경해야 하는 경우 지역 변수를 사용하세요.
2. To configure a parameter, override it at instantiation (`#(.P(val))`), not by assignment in the body.
2. 매개변수를 구성하려면 본문에서 할당하는 것이 아니라 인스턴스화(`#(.P(val))`)에서 매개변수를 재정의하세요.
3. Avoid `defparam` (deprecated); prefer inline parameter overrides.
3. `defparam`(더 이상 사용되지 않음)을 피하세요. 인라인 매개변수 재정의를 선호합니다.
4. Move mutable computation into `reg`/variables inside procedural logic.
4. 변경 가능한 계산을 절차적 논리 내부의 `reg`/변수로 이동합니다.
