# 8-3522: Clock Signal Already Used
# 8-3522: 클럭 신호가 이미 사용되었습니다.

**Message:** `[Synth 8-3522] signal '!%1!' is already used in the current clocking condition`
**메시지:** `[Synth 8-3522] 신호 '!%1!' 현재 클럭킹 조건에서 이미 사용되었습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A clock signal appears multiple times in the same clocking condition within a process.
클럭 신호는 프로세스 내에서 동일한 클럭 조건으로 여러 번 나타납니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Same clock used on both edges
### P1: 양쪽 가장자리에 동일한 클록이 사용됨

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: clk used twice in same process sensitivity
process(clk, clk)  -- or complex double-edge
begin
  if rising_edge(clk) and falling_edge(clk) then  -- ERROR
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use clock once
process(clk)
begin
  if rising_edge(clk) then
    ...
  end if;
end process;
```

---

## Fix Strategy
## 전략 수정

1. Reference each clock only once in a clocking condition — a single process cannot be sensitive to both `rising_edge` and `falling_edge` of the same clock.
1. 클록 조건에서 각 클록을 한 번만 참조하십시오. 단일 프로세스는 동일한 클록의 'rising_edge'와 'falling_edge'에 모두 민감할 수 없습니다.
2. For dual-edge (DDR-style) behavior, split into two processes (one per edge) or use a dedicated DDR primitive/IP.
2. 듀얼 에지(DDR 스타일) 동작의 경우 두 개의 프로세스(에지당 하나씩)로 분할하거나 전용 DDR 기본/IP를 사용합니다.
3. Remove duplicate clock entries from the sensitivity list (`process(clk)`, not `process(clk, clk)`).
3. 민감도 목록(`process(clk, clk)`이 아닌 `process(clk)`)에서 중복된 시계 항목을 제거합니다.
4. Ensure the intended clocking is a clean single-edge flip-flop unless a DDR resource is explicitly required.
4. DDR 리소스가 명시적으로 요구되지 않는 한 의도된 클로킹이 깨끗한 단일 에지 플립플롭인지 확인하십시오.
