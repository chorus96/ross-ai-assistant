# 8-10047: Invalid Context Reference
# 8-10047: 잘못된 컨텍스트 참조

**Message:** `[Synth 8-10047] suffix in the context reference does not denote a context declaration`
**메시지:** `컨텍스트 참조의 [Synth 8-10047] 접미사는 컨텍스트 선언을 나타내지 않습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10047] suffix in the context reference does not denote a context declaration [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A VHDL `context` reference uses a name that does not refer to a context declaration in the specified library.
VHDL '컨텍스트' 참조는 지정된 라이브러리의 컨텍스트 선언을 참조하지 않는 이름을 사용합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Invalid context reference
### P1: 잘못된 컨텍스트 참조

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: referencing non-existent context
library lib2;
context lib2.clause1;  -- ERROR: 'clause1' is not a context in lib2
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: reference the correct context name or use direct library/use
library lib2;
use lib2.typePack.all;  -- direct use instead of context reference
```

---

## Fix Strategy
## 전략 수정

1. Reference an actual **context** declaration, or replace the `context` reference with direct `library` + `use` clauses.
1. 실제 **context** 선언을 참조하거나 `context` 참조를 직접 `library` + `use` 절로 바꾸세요.
2. Fix the context name so it denotes a real context in the named library.
2. 명명된 라이브러리의 실제 컨텍스트를 나타내도록 컨텍스트 이름을 수정합니다.
3. Ensure the context declaration is compiled into that library before use.
3. 사용하기 전에 컨텍스트 선언이 해당 라이브러리로 컴파일되었는지 확인하세요.
4. Confirm the flow supports VHDL-2008 context clauses; if not, use plain `library`/`use`.
4. 흐름이 VHDL-2008 컨텍스트 절을 지원하는지 확인합니다. 그렇지 않다면 일반 `library`/`use`를 사용하세요.
