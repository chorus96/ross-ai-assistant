# 8-9339: data object '!%1!' is already declared
# 8-9339: 데이터 개체 '!%1!' 이미 선언되었습니다

**Message:** `[Synth 8-9339] data object '!%1!' is already declared`
**메시지:** `[Synth 8-9339] 데이터 개체 '!%1!' 이미 선언되었습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A data object (signal/variable/constant) is declared more than once in the same scope.
데이터 객체(신호/변수/상수)가 동일한 범위에서 두 번 이상 선언되었습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Data object already declared
### P1: 데이터 개체가 이미 선언되었습니다.

**Problematic Code:**
**문제가 있는 코드:**
```vhdl
signal a : std_logic;
signal a : std_logic;   -- duplicate
```

**Recommended Fix:**
**권장 수정 사항:**
```vhdl
signal a : std_logic;   -- declare once
```

### P2: Name clash from a `use` clause (package + local object)
### P2: `use` 절의 이름 충돌(패키지 + 로컬 개체)

**Problematic Code:**
**문제가 있는 코드:**
```vhdl
library work;
use work.my_pkg.all;        -- my_pkg declares: constant DEPTH : integer := 8;
architecture rtl of top is
  constant DEPTH : integer := 16;  -- ERROR: 'DEPTH' is already declared
begin
end rtl;
```

**Recommended Fix — rename the local object or reference the package member:**
**권장 수정 — 로컬 개체의 이름을 바꾸거나 패키지 구성원을 참조하십시오.**
```vhdl
architecture rtl of top is
  constant LOCAL_DEPTH : integer := 16;   -- distinct local name
begin
end rtl;
```

### P3: Port and internal signal share a name
### P3: 포트와 내부 신호는 이름을 공유합니다.

**Problematic Code:**
**문제가 있는 코드:**
```vhdl
entity top is
  port (data : in std_logic_vector(7 downto 0));
end top;
architecture rtl of top is
  signal data : std_logic_vector(7 downto 0);  -- ERROR: 'data' already declared (port)
begin
end rtl;
```

**Recommended Fix — give the internal signal a distinct name:**
**권장 수정 — 내부 신호에 고유한 이름을 지정합니다.**
```vhdl
architecture rtl of top is
  signal data_int : std_logic_vector(7 downto 0);
begin
  data_int <= data;
end rtl;
```

---

## Fix Strategy
## 전략 수정

1. Remove the duplicate declaration.
1. 중복 선언을 제거하십시오.
2. Rename if two distinct objects were intended (e.g., port `data` vs `data_int`).
2. 두 개의 서로 다른 개체를 의도한 경우 이름을 바꿉니다(예: 포트 `data` 대 `data_int`).
3. Check for a name clash from a `use`/`import` of a package that already declares the object; qualify the reference or rename the local one.
3. 이미 객체를 선언한 패키지의 `use`/`import`에서 이름 충돌이 있는지 확인하세요. 참조를 한정하거나 로컬 이름을 바꾸십시오.
