# 8-10949: Label Mismatch at End
# 8-10949: 끝 부분의 라벨 불일치

**Message:** `[Synth 8-10949] mismatch on label; expected correct label`
**메시지:** `[Synth 8-10949] 라벨 불일치; 예상되는 올바른 라벨'
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10949] mismatch on label; expected correct label [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

The ending label of a package, entity, architecture, or block doesn't match the opening label.
패키지, 엔터티, 아키텍처 또는 블록의 끝 레이블이 시작 레이블과 일치하지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Ending label does not match
### P1: 종료 라벨이 일치하지 않습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: wrong ending label
package body my_pac is
  ...
end wrong_label;  -- ERROR: expected 'my_pac'
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: match the ending label
package body my_pac is
  ...
end my_pac;
```

---

## Fix Strategy
## 전략 수정

1. Make the ending label match the opening label exactly — fix the typo or remove the ending label.
1. 종료 라벨이 시작 라벨과 정확하게 일치하도록 만드세요. 오타를 수정하거나 종료 라벨을 삭제하세요.
2. Check for a stale label left from copy-paste of another construct.
2. 다른 구문을 복사하여 붙여넣은 후 오래된 레이블이 남아 있는지 확인하세요.
3. Ensure nested blocks/processes each have consistent open/close labels.
3. 중첩된 블록/프로세스 각각에 일관된 열기/닫기 레이블이 있는지 확인하세요.
4. If the opening had no label, do not add one at `end`.
4. 오프닝에 라벨이 없으면 `end`에 라벨을 추가하지 마세요.
