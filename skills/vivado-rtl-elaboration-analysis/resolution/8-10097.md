# 8-10097: Type Error in Expression
# 8-10097: 표현식의 유형 오류

**Message:** `[Synth 8-10097] type error near expression; current type vs expected type`
**메시지:** `[Synth 8-10097] 표현식 근처에 유형 오류가 있습니다. 현재 유형과 예상 유형`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10097] type error near expression; current type vs expected type [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A VHDL expression has a type mismatch — the actual type does not match the expected type in the context.
VHDL 표현식에 유형 불일치가 있습니다. 즉, 실제 유형이 컨텍스트에서 예상되는 유형과 일치하지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Type mismatch in an expression
### P1: 표현식의 유형 불일치

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: wrong type used in expression
type test_type is range 0 to 100;
type thallium is range 0 to 50;
variable count : thallium;
result := inp(inp'high(1), inp'high(2), count);  -- ERROR: expected test_type, got thallium
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: convert to correct type
result := inp(inp'high(1), inp'high(2), test_type(count));  -- type conversion
```

---

## Fix Strategy
## 전략 수정

1. Add an explicit type conversion so the expression's type matches the expected type (`test_type(count)`).
1. 표현식의 유형이 예상 유형(`test_type(count)`)과 일치하도록 명시적인 유형 변환을 추가합니다.
2. Alternatively, declare the variable as the expected type so no conversion is needed.
2. 또는 변수를 예상되는 유형으로 선언하여 변환이 필요하지 않도록 하세요.
3. Ensure related types (ranges/subtypes) are compatible or convertible where the expression is used.
3. 표현식이 사용되는 위치에서 관련 유형(범위/하위 유형)이 호환되거나 변환 가능한지 확인하십시오.
4. Check function/operator overloads to confirm the expected type at that context.
4. 함수/연산자 오버로드를 확인하여 해당 컨텍스트에서 예상되는 유형을 확인하세요.
