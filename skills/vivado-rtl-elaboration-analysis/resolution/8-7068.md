# 8-7068: Illegal Genvar Usage
# 8-7068: 잘못된 Genvar 사용

**Message:** `[Synth 8-7068] Usage of genvar '!%1!' is illegal here`
**메시지:** `[Synth 8-7068] genvar '!%1!' 사용 여기는 불법이에요`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A genvar is used outside a generate for loop or in an invalid context.
genvar가 generate for 루프 외부 또는 잘못된 컨텍스트에서 사용되었습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: genvar used outside generate
### P1: 생성 외부에서 사용되는 genvar

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: genvar used outside generate
genvar i;
assign out = data[i];  // ERROR: i only valid in generate
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use inside generate
generate
  for (i=0; i<4; i=i+1)
    assign out[i] = data[i];  // genvar valid here
endgenerate
```

---

## Fix Strategy
## 전략 수정

1. Use a `genvar` only inside a `generate` construct — move the code that indexes with it into a `generate for` loop.
1. `generate` 구문 내에서만 `genvar`를 사용하세요. 이를 사용하여 색인을 생성하는 코드를 `generate for` 루프로 이동하세요.
2. For runtime indexing outside generate, use a normal `integer`/`reg` variable (in procedural code) or a constant.
2. 생성 외부 런타임 인덱싱의 경우 일반 `integer`/`reg` 변수(절차 코드에서) 또는 상수를 사용하세요.
3. If you intended structural replication, wrap the logic in `generate ... endgenerate` with the genvar loop.
3. 구조적 복제를 의도한 경우 genvar 루프를 사용하여 'generate ... endgenerate'의 논리를 래핑합니다.
4. Do not reference a genvar in continuous assignments or always blocks outside generate scope.
4. 연속 할당에서 genvar를 참조하지 않거나 항상 생성 범위 외부를 차단합니다.
