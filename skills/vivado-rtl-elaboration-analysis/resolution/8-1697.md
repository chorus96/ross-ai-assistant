# 8-1697: Invalid Number Base
# 8-1697: 잘못된 숫자 베이스

**Message:** `[Synth 8-1697] base value !%1! must be at least two and at most sixteen`
**메시지:** `[Synth 8-1697] 기본 값 !%1! 최소 2개에서 최대 16개여야 합니다.
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A numeric literal has an invalid base value (must be 2-16).
숫자 리터럴에 잘못된 기본 값(2-16이어야 함)이 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Invalid numeric literal base
### P1: 잘못된 숫자 리터럴 베이스

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: base 17 in literal
int x = 17'h1F;  // ERROR: base 17 (the size prefix) must be 2-16
// Actually the size is fine, but the content format might be wrong
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use valid base
int x = 8'h1F;  // valid: 8-bit hex
```

---

## Fix Strategy
## 전략 수정

1. Use a valid base specifier in the literal: `'b` (binary), `'o` (octal), `'d` (decimal), or `'h` (hex) — e.g., `8'hff`, `4'b1010`.
1. 리터럴에 유효한 기본 지정자를 사용하세요: `'b`(2진수), `'o`(8진수), `'d`(10진수) 또는 `'h`(16진수) — 예: `8'hff`, `4'b1010`.
2. Ensure the digits match the base (no `2`+ in binary, no `8`/`9` in octal, only `0-9a-f` in hex).
2. 숫자가 밑수와 일치하는지 확인하세요(2진수에서는 `2`+ 금지, 8진수에서는 `8`/`9` 금지, 16진수에서는 `0-9a-f`만 가능).
3. Check the size/base separator syntax `<size>'<base><value>`; a malformed size or missing apostrophe is a common cause.
3. 크기/기본 구분 기호 `<size>'<base><value>`를 확인하세요. 잘못된 크기나 아포스트로피 누락이 일반적인 원인입니다.
4. Remove any accidental non-standard base and rewrite the constant in a supported base.
4. 실수로 발생한 비표준 베이스를 제거하고 지원되는 베이스에 상수를 다시 작성하세요.
