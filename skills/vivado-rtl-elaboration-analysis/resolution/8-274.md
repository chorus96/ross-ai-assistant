# 8-274: General Error
# 8-274: 일반 오류

**Message:** `[Synth 8-274] error: !%1!`
**메시지:** `[Synth 8-274] 오류: !%1!`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-274] error: <specific error message> [/path/to/file.v:42]
```

---

## Root Cause
## 근본 원인

This is a generic error message that wraps various specific errors.
이는 다양한 특정 오류를 포함하는 일반 오류 메시지입니다.
The actual cause is described in the `!%1!` placeholder.
실제 원인은 `!%1!` 자리 표시자에 설명되어 있습니다.

## Common Sub-Messages
## 공통 하위 메시지

| Sub-message<br>하위 메시지 | Likely Cause<br>가능한 원인 | Fix<br>수정 |
|-------------|--------------|-----|
| "type mismatch"<br>"유형 불일치" | Incompatible types in operation<br>작동 중인 호환되지 않는 유형 | Fix type declarations<br>유형 선언 수정 |
| "undefined identifier"<br>"정의되지 않은 식별자" | Name not declared<br>이름이 선언되지 않았습니다. | Add declaration<br>선언 추가 |
| "invalid syntax"<br>"잘못된 구문" | Parsing error<br>구문 분석 오류 | Fix syntax<br>구문 수정 |
| "out of range"<br>"범위를 벗어났습니다" | Index exceeds bounds<br>인덱스가 경계를 초과함 | Fix index values<br>인덱스 값 수정 |

## Diagnostic Steps
## 진단 단계

1. Read the full error message after "error:"
1. "error:" 다음에 나오는 전체 오류 메시지를 읽어보세요.
2. Identify the specific file and line number
2. 특정 파일 및 줄 번호 식별
3. Examine the code at that location
3. 해당 위치의 코드를 검사하세요.
4. Apply fix based on the specific sub-message
4. 특정 하위 메시지를 기반으로 수정사항 적용

---

## Example Fixes
## 수정 예시

### Type Mismatch
### 유형 불일치

```verilog
// Before
wire [7:0] a;
wire [15:0] b;
assign a = b;  // error: type mismatch

// After - explicit truncation
assign a = b[7:0];
```

### Undefined Identifier
### 정의되지 않은 식별자

```verilog
// Before
assign out = undefined_sig;  // error: undefined_sig not declared

// After
wire undefined_sig;
assign out = undefined_sig;
```

### Out of Range
### 범위를 벗어남

```verilog
// Before
wire [7:0] data;
assign bit = data[10];  // error: out of range

// After
assign bit = data[7];  // valid index
```

## Fix Strategy
## 전략 수정

1. Read the concrete sub-message after `error:` (the `!%1!` text) — it names the real problem; fix that, not the generic wrapper.
1. `error:`(`!%1!` 텍스트) 뒤의 구체적인 하위 메시지를 읽으세요. 실제 문제의 이름이 표시됩니다. 일반 래퍼가 아닌 문제를 해결하세요.
2. Go to the reported file and line and address the specific cause (type mismatch, undeclared name, out-of-range index, or syntax).
2. 보고된 파일 및 줄로 이동하여 특정 원인(유형 불일치, 선언되지 않은 이름, 범위를 벗어난 색인 또는 구문)을 해결합니다.
3. Apply the matching fix from the sub-message table above (declare the name, truncate/resize widths, correct the index, or fix syntax).
3. 위의 하위 메시지 테이블에서 일치하는 수정 사항을 적용합니다(이름 선언, 너비 자르기/크기 조정, 색인 수정 또는 구문 수정).
4. Re-run elaboration; the `8-274` line disappears once its underlying sub-error is resolved.
4. 정교화를 다시 실행하십시오. 기본 하위 오류가 해결되면 '8-274' 줄이 사라집니다.
