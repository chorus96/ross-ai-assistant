# 8-8863: Self-Reference in Interface
# 8-8863: 인터페이스의 자기 참조

**Message:** `[Synth 8-8863] '!%1!' cannot be used within its own interface list`
**메시지:** `[Synth 8-8863] '!%1!' 자체 인터페이스 목록 내에서는 사용할 수 없습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An identifier is used within its own interface/port list declaration.
식별자는 자체 인터페이스/포트 목록 선언 내에서 사용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Port name used as its own type
### P1: 자체 유형으로 사용되는 포트 이름

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: self-reference in port list
entity e is port(i1 : in i1);  -- ERROR: i1 references itself
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use proper type
entity e is port(i1 : in std_logic);  -- correct type name
```

---

## Fix Strategy
## 전략 수정

1. Use an actual **type name** for a port's type, not the port's own name — `port(i1 : in std_logic)`, not `port(i1 : in i1)`.
1. 포트 유형에 대해 포트 자체 이름이 아닌 실제 **유형 이름**을 사용하십시오. 즉 `port(i1 : in i1)`이 아닌 `port(i1 : in std_logic)`를 사용하십시오.
2. Check for a typo where the type and object share a name; rename one so the type reference is unambiguous.
2. 유형과 객체가 이름을 공유하는 곳에 오타가 있는지 확인하세요. 유형 참조가 명확하도록 이름을 바꾸십시오.
3. Ensure the intended type is declared/visible (import its package if needed).
3. 의도한 유형이 선언/표시되는지 확인합니다(필요한 경우 해당 패키지를 가져옵니다).
4. Review the whole port/declaration list for other self-references introduced by copy-paste.
4. 복사-붙여넣기로 도입된 다른 자체 참조에 대해서는 전체 포트/선언 목록을 검토하세요.
