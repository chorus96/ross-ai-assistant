# 8-476: No Matching Instance for Defparam
# 8-476: Defparam에 대해 일치하는 인스턴스가 없습니다.

**Message:** `[Synth 8-476] no matching instance '!%1!' for defparam`
**메시지:** `[Synth 8-476] 일치하는 인스턴스 '!%1!'이 없습니다. defparam의 경우`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A `defparam` references an instance path that doesn't exist.
'defparam'이 존재하지 않는 인스턴스 경로를 참조합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: defparam to a non-existent instance path
### P1: 존재하지 않는 인스턴스 경로에 대한 defparam

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: defparam to non-existent instance
defparam top.inst1.P = 5;  // ERROR: no instance 'top'
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use #() parameter override instead
my_mod #(.P(5)) inst1(...);  // inline override
// defparam is deprecated — avoid using it
```

---

## Fix Strategy
## 전략 수정

1. Replace `defparam` with inline `#()` parameter overrides at instantiation (`my_mod #(.P(5)) inst(...);`) — `defparam` is deprecated and discouraged for synthesis.
1. 인스턴스화 시 `defparam`을 인라인 `#()` 매개변수 재정의로 대체합니다(`my_mod #(.P(5)) inst(...);`) — `defparam`은 더 이상 사용되지 않으며 합성에 권장되지 않습니다.
2. If you must keep `defparam`, correct the hierarchical instance path so it names an instance that actually exists at that scope.
2. `defparam`을 유지해야 하는 경우 계층적 인스턴스 경로를 수정하여 해당 범위에 실제로 존재하는 인스턴스의 이름을 지정합니다.
3. Verify the instance name and hierarchy (typos, wrong level) match the real design tree.
3. 인스턴스 이름과 계층 구조(오타, 잘못된 수준)가 실제 디자인 트리와 일치하는지 확인합니다.
4. Prefer parameter passing through the module hierarchy over reaching in with `defparam`.
4. `defparam`을 사용하여 매개변수에 도달하는 것보다 모듈 계층 구조를 통해 매개변수를 전달하는 것을 선호합니다.
