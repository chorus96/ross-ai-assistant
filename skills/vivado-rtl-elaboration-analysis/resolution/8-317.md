# 8-317: Illegal Recursive Instantiation
# 8-317: 잘못된 재귀 인스턴스화

**Message:** `[Synth 8-317] illegal recursive instantiation of design '!%1!'`
**메시지:** `[Synth 8-317] 디자인 '!%1!'의 불법 재귀 인스턴스화`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-317] illegal recursive instantiation of design 'my_module' [/path/to/file.v:42]
```

---

## Root Cause
## 근본 원인

A design/entity is instantiated recursively without proper termination.
디자인/엔티티는 적절한 종료 없이 재귀적으로 인스턴스화됩니다.
This is similar to 8-316 but names the specific design causing the recursion.
이는 8-316과 유사하지만 재귀를 유발하는 특정 디자인의 이름을 지정합니다.

---

## Difference from 8-316
## 8-316과의 차이점

- **8-316**: Generic "recursion detected" message
- **8-316**: 일반 "재귀 감지" 메시지
- **8-317**: Names the specific design causing recursion
- **8-317**: 재귀를 유발하는 특정 디자인의 이름을 지정합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: VHDL Entity Self-Reference
### P1: VHDL 엔터티 자체 참조

```vhdl
-- Before - entity instantiates itself
entity counter is
  port (clk : in std_logic; count : out integer);
end counter;

architecture rtl of counter is
begin
  U0: entity work.counter  -- ERROR: recursive
    port map (clk => clk, count => open);
end rtl;
```

### P2: Parameterized Recursion Without Base Case
### P2: 기본 사례가 없는 매개변수화된 재귀

```verilog
// Before - no termination
module adder_tree #(parameter N = 8) (
  input [N-1:0] in,
  output sum
);
  // Always recurses, never terminates
  adder_tree #(N/2) left (.in(in[N-1:N/2]), .sum(left_sum));
  adder_tree #(N/2) right (.in(in[N/2-1:0]), .sum(right_sum));
endmodule
```

---

## Fix: Add Proper Base Case
## 수정: 적절한 기본 케이스 추가

```verilog
// After - with termination
module adder_tree #(parameter N = 8) (
  input [N-1:0] in,
  output sum
);
  generate
    if (N == 1) begin : base
      assign sum = in[0];
    end else if (N == 2) begin : pair
      assign sum = in[0] + in[1];
    end else begin : recurse
      wire left_sum, right_sum;
      adder_tree #(N/2) left (.in(in[N-1:N/2]), .sum(left_sum));
      adder_tree #((N+1)/2) right (.in(in[N/2-1:0]), .sum(right_sum));
      assign sum = left_sum + right_sum;
    end
  endgenerate
endmodule
```

---

## VHDL Fix
## VHDL 수정

```vhdl
entity tree is
  generic (DEPTH : integer := 3);
  port (...);
end tree;

architecture rtl of tree is
begin
  gen_recurse: if DEPTH > 0 generate
    U_left: entity work.tree
      generic map (DEPTH => DEPTH - 1)
      port map (...);
  end generate;
  
  gen_leaf: if DEPTH = 0 generate
    -- Base case logic
  end generate;
end rtl;
```

## Fix Strategy
## 전략 수정

1. Add a terminating base case so the recursion stops — guard the self-instantiation with a `generate if` on a shrinking parameter (`N == 1`, `DEPTH = 0`, etc.).
1. 재귀가 중지되도록 종료 기본 사례를 추가합니다. 축소 매개변수(`N == 1`, `DEPTH = 0` 등)에서 `generate if`를 사용하여 자체 인스턴스화를 보호합니다.
2. Ensure each recursive level strictly reduces the size parameter toward the base case (e.g., `N/2`), so depth is finite.
2. 각 재귀 수준에서 크기 매개변수를 기본 사례(예: `N/2`)로 엄격하게 줄여 깊이가 유한하도록 합니다.
3. If self-instantiation was unintended, instantiate the correct child module instead of the design named in the message.
3. 자체 인스턴스화가 의도하지 않은 경우 메시지에 명명된 디자인 대신 올바른 하위 모듈을 인스턴스화합니다.
4. Re-run elaboration; `8-317` clears once a reachable base case terminates the recursion.
4. 정교화를 다시 실행하십시오. '8-317'은 도달 가능한 기본 사례가 재귀를 종료하면 지워집니다.
