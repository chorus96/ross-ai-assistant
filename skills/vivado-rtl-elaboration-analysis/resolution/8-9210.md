# 8-9210: Cannot Access Memory Directly
# 8-9210: 메모리에 직접 액세스할 수 없습니다.

**Message:** `[Synth 8-9210] cannot access memory directly`
**메시지:** `[Synth 8-9210]은 메모리에 직접 액세스할 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A memory array is accessed in a way that's not supported (e.g., entire array in expression).
지원되지 않는 방식으로 메모리 배열에 액세스했습니다(예: 표현식의 전체 배열).

---

## Common Patterns
## 일반적인 패턴

### P1: Whole memory used in an expression
### P1: 표현식에 사용되는 전체 메모리

**Problematic Code:**
**문제가 있는 코드:**
```diff
assign out = data;  // ERROR: can't use entire memory in expression
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
assign out = data[addr];  // access individual element
```

---

## Fix Strategy
## 전략 수정

1. Access a memory only by index (`mem[addr]`) — you cannot use the whole array as a single value in an expression.
1. 인덱스(`mem[addr]`)로만 메모리에 액세스합니다. 전체 배열을 표현식의 단일 값으로 사용할 수 없습니다.
2. To copy/compare memories, loop element-by-element rather than referencing the array directly.
2. 메모리를 복사/비교하려면 배열을 직접 참조하는 대신 요소별로 반복하세요.
3. If you intended a vector, declare a packed vector, not an unpacked memory array.
3. 벡터를 의도한 경우 압축 해제된 메모리 배열이 아닌 압축된 벡터를 선언하세요.
4. For read data, register `mem[addr]` and use that registered value downstream (also helps BRAM inference).
4. 데이터를 읽으려면 'mem[addr]'을 등록하고 등록된 값을 다운스트림에 사용합니다(BRAM 추론에도 도움이 됩니다).
