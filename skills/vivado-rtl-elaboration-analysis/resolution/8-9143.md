# 8-9143: ANSI Port Redeclared
# 8-9143: ANSI 포트 재선언

**Message:** `[Synth 8-9143] ansi port cannot be redeclared in the header`
**메시지:** `[Synth 8-9143] ansi 포트는 헤더에서 다시 선언될 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An ANSI-style port is declared again inside the module body.
ANSI 스타일 포트가 모듈 본문 내부에서 다시 선언됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: ANSI port redeclared in the body
### P1: 본문에 다시 선언된 ANSI 포트

**Problematic Code:**
**문제가 있는 코드:**
```diff
module m(input x);
input x;  // ERROR: already declared in ANSI header
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
module m(input x);
// Don't redeclare x
```

---

## Fix Strategy
## 전략 수정

1. Remove the redundant body-level declaration — an ANSI-style port (`module m(input x)`) is already fully declared in the header.
1. 중복된 본문 수준 선언을 제거합니다. ANSI 스타일 포트(`module m(input x)`)가 이미 헤더에 완전히 선언되어 있습니다.
2. Choose one style: either ANSI headers (declare type/direction/width in the port list) or non-ANSI (bare names in the list, declared in the body), never both for the same port.
2. 하나의 스타일을 선택하십시오. ANSI 헤더(포트 목록에 유형/방향/너비 선언) 또는 비ANSI(목록에 있는 이름, 본문에 선언됨) 중 하나를 선택하십시오. 동일한 포트에 대해 둘 다 사용해서는 안 됩니다.
3. If you need to add an attribute to an ANSI port, apply it in the header, not via a re-declaration.
3. ANSI 포트에 속성을 추가해야 하는 경우 재선언을 통하지 않고 헤더에 속성을 적용하세요.
4. Check for copy-paste that duplicated the port declaration.
4. 포트 선언과 중복된 복사-붙여넣기를 확인하세요.
