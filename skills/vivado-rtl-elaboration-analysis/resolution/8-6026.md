# 8-6026: Keep 관련 속성 무시(keep/mark_debu...

**Message:** `[Synth 8-6026] Ignoring keep related attribute (keep/mark_debug/dont_touch) applied on memory`
**메시지:** `[Synth 8-6026] 메모리에 적용된 Keep 관련 속성(keep/mark_debug/dont_touch) 무시`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A `keep`/`mark_debug`/`dont_touch` attribute is applied to a **memory** (a
`keep`/`mark_debug`/`dont_touch` 속성은 **메모리**에 적용됩니다(a
RAM/ROM array).
RAM/ROM 배열).
These attributes apply to signals/nets, not to memory arrays,
이러한 속성은 메모리 배열이 아닌 신호/네트에 적용됩니다.
so they are ignored on the memory.
그래서 그들은 메모리에서 무시됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: keep attribute on a memory
### P1: 메모리에 속성 유지

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Problematic line:
signal rd_col_window_expire : std_logic;
  signal rd_col_window_pipe   : cntl_pipe;
  signal wr_col_window_pipe   : cntl_pipe;
  
  signal wr_fifo_overflow     : std_logic;
```

**Recommended Fix:**
**권장 수정 사항:**
```vhdl
-- Apply keep/mark_debug to a net (e.g., the registered read-data output),
-- not to the memory array; use ram_style to control the RAM itself.
attribute mark_debug of rd_data : signal is "true";
attribute ram_style of mem      : signal is "block";
```

---

## Fix Strategy
## 전략 수정

1. Move `keep`/`mark_debug`/`dont_touch` from the memory array to a specific **signal/net** (e.g., the RAM's registered read-data output) — these attributes do not apply to memories.
1. `keep`/`mark_debug`/`dont_touch`를 메모리 배열에서 특정 **signal/net**(예: RAM에 등록된 읽기 데이터 출력)으로 이동합니다. 이러한 속성은 메모리에 적용되지 않습니다.
2. To control the memory's implementation, use `ram_style`/`rom_style` instead of keep-type attributes.
2. 메모리 구현을 제어하려면 keep 유형 속성 대신 `ram_style`/`rom_style`을 사용하세요.
3. If you need to probe the memory, register its output and mark that register for debug.
3. 메모리를 조사해야 하는 경우 해당 출력을 등록하고 해당 레지스터를 디버그용으로 표시합니다.
4. Remove the ineffective attribute from the memory to clear the warning.
4. 경고를 지우려면 메모리에서 유효하지 않은 속성을 제거하십시오.
