# 8-3492: Module Binding Mismatch
# 8-3492: 모듈 바인딩 불일치

**Message:** `[Synth 8-3492] module '!%1!' declared at '!%2!:!%3!' does not have matching formal generic for component generic '!%4!'`
**메시지:** `[Synth 8-3492] 모듈 '!%1!' '!%2!:!%3!'에 선언되었습니다. 구성 요소 일반 '!%4!'`에 대해 일치하는 형식 일반이 없습니다.
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL configuration binds to a module declared in a library that has incompatible ports.
VHDL 구성은 호환되지 않는 포트가 있는 라이브러리에 선언된 모듈에 바인딩됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Bound entity ports mismatch component
### P1: 바인딩된 엔터티 포트 불일치 구성 요소

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: binding to library module with port mismatch
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: fix port mapping or use correct library entity
-- Check that the bound entity's ports match the component declaration
```

---

## Fix Strategy
## 전략 수정

1. Make the bound entity's ports match the component declaration exactly — same names, directions, and types/widths.
1. 바인딩된 엔터티의 포트가 구성 요소 선언과 정확하게 일치하도록 만듭니다(이름, 방향 및 유형/너비 동일).
2. Fix the configuration/binding to target the correct entity (and architecture) in the correct library.
2. 올바른 라이브러리에서 올바른 엔터티(및 아키텍처)를 대상으로 하도록 구성/바인딩을 수정합니다.
3. Update the component declaration to mirror the actual entity if the entity is the source of truth.
3. 엔터티가 진실의 소스인 경우 실제 엔터티를 반영하도록 구성 요소 선언을 업데이트합니다.
4. Verify the intended library is compiled and referenced; binding to a stale or wrong-library entity is a common cause.
4. 의도한 라이브러리가 컴파일되고 참조되었는지 확인하십시오. 부실하거나 잘못된 라이브러리 엔터티에 바인딩하는 것이 일반적인 원인입니다.
