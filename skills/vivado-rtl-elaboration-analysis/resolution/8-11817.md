# 8-11817: Net Type for Task Ref/Output
# 8-11817: 태스크 참조/출력을 위한 넷 유형

**Message:** `[Synth 8-11817] illegal net type actual for formal '!%1!' in '!%2!' call`
**메시지:** `[Synth 8-11817] 공식 '!%1!'에 대한 실제 넷 유형이 잘못되었습니다. '!%2!' 전화`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A net type (`wire`) is used as actual argument for a task `output` or `ref` formal port.
네트 유형(`wire`)은 작업 `output` 또는 `ref` 공식 포트에 대한 실제 인수로 사용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Net actual for a task output/ref
### P1: 작업 출력/참조에 대한 순 실제

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: wire as task output
wire w;
task my_task(output logic o); o = 1; endtask
always @(*) my_task(w);  // ERROR: w is net type
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use variable type
reg r;
always @(*) my_task(r);  // reg is variable type
```

---

## Fix Strategy
## 전략 수정

1. Task `output`/`inout`/`ref` formals require **variable** actuals — pass a `reg`/`logic` variable, not a `wire`.
1. 작업 `output`/`inout`/`ref` 형식에는 **변수** 실제값이 필요합니다 — `wire`가 아닌 `reg`/`logic` 변수를 전달합니다.
2. Change the actual's declaration from `wire` to `reg`/`logic`, or capture the task result into a variable.
2. 실제 선언을 `wire`에서 `reg`/`logic`으로 변경하거나 작업 결과를 변수에 캡처합니다.
3. Drive nets with continuous assignments separately from task calls.
3. 작업 호출과 별도로 연속 할당으로 네트를 구동합니다.
4. Ensure the actual's type/width matches the task formal.
4. 실제 유형/폭이 작업 형식과 일치하는지 확인하세요.
