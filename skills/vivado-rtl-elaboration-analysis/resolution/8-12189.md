# 8-12189: Failed to Read VHDL File
# 8-12189: VHDL 파일을 읽지 못했습니다.

**Message:** `[Synth 8-12189] Failed to read vhdl '!%1!'`
**메시지:** `[Synth 8-12189] vhdl '!%1!'을 읽지 못했습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

Vivado could not read/parse a VHDL source file.
Vivado가 VHDL 소스 파일을 읽거나 구문 분석할 수 없습니다.

---

## 일반적인 패턴

### P1: VHDL 파일을 구문 분석하지 못했습니다.

**문제가 있는 코드:**

-- The file has fundamental parse errors that prevent reading

**권장 수정 사항:**
```diff
-- Fix: check for:
-- 1. Missing library/use clauses

```

---

## Fix Strategy
## 전략 수정

1. Fix the first VHDL syntax error, then re-run — later errors are often cascades.
1. 첫 번째 VHDL 구문 오류를 수정한 후 다시 실행하세요. 이후 오류는 연쇄적으로 발생하는 경우가 많습니다.
2. Verify the file path/encoding and that required `library`/`use` clauses and packages are compiled first.
2. 파일 경로/인코딩을 확인하고 필수 `library`/`use` 절과 패키지가 먼저 컴파일되었는지 확인하세요.
3. Check balanced `entity`/`end`, `architecture`/`end`, `process`/`end process`, and matched parentheses.
3. 균형 잡힌 `entity`/`end`, `architecture`/`end`, `process`/`end process` 및 일치하는 괄호를 확인하세요.
4. Confirm the correct VHDL standard (93/2008) is set for the constructs used.
4. 사용된 구성에 대해 올바른 VHDL 표준(93/2008)이 설정되어 있는지 확인하십시오.
