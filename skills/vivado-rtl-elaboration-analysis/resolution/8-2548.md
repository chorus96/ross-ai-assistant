# 8-2548: Positional After Named Arguments
# 8-2548: 명명된 인수 이후의 위치

**Message:** `[Synth 8-2548] positional arguments must occur before named arguments`
**메시지:** `[Synth 8-2548] 위치 인수는 명명된 인수 앞에 와야 합니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

Positional arguments appear after named arguments in a call.
위치 인수는 호출에서 명명된 인수 뒤에 나타납니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Positional argument after a named one
### P1: 이름이 지정된 위치 인수 뒤의 위치 인수

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: positional after named
func(.a(1), 2);  // ERROR: positional after named
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: all named
func(.a(1), .b(2));  // all named
```

---

## Fix Strategy
## 전략 수정

1. Put all positional arguments first, then named ones — a positional argument may not follow a named argument.
1. 모든 위치 인수를 먼저 배치한 다음 명명된 인수를 배치합니다. 위치 인수는 명명된 인수 뒤에 올 수 없습니다.
2. Simplest robust fix: make **every** argument named (`func(.a(1), .b(2))`).
2. 가장 간단하고 강력한 수정: **모든** 인수를 (`func(.a(1), .b(2))`)라는 이름으로 만듭니다.
3. Check for a missing argument that shifted the positional/named boundary.
3. 위치/이름이 지정된 경계를 이동한 인수가 누락되었는지 확인하세요.
4. Verify each named argument matches a real formal of the subprogram/instance.
4. 각 명명된 인수가 하위 프로그램/인스턴스의 실제 형식과 일치하는지 확인합니다.
