# 8-10219: Missing Protected Type Body
# 8-10219: 보호 유형 본문 누락

**Message:** `[Synth 8-10219] missing body for protected type`
**메시지:** `[Synth 8-10219] 보호 유형에 대한 본문 누락`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10219] missing body for protected type [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A VHDL protected type is declared but has no corresponding body.
VHDL 보호 유형이 선언되었지만 해당 본문이 없습니다.
Protected types are also not synthesizable.
보호된 유형도 합성할 수 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Protected type without a body
### P1: 몸체가 없는 보호형

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: protected type without body (not synthesizable)
type t1 is protected
  procedure proc_new(...);
end protected t1;
shared variable var1 : t1;  -- ERROR: no body for t1
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: replace with synthesizable construct
signal sig1 : signed(7 downto 0);
-- Protected types are not synthesizable. Replace shared variable
-- access with regular signals and proper synchronization.
```

---

## Fix Strategy
## 전략 수정

1. Protected types are not synthesizable — remove them and model shared state with `signal`s plus explicit synchronization.
1. 보호된 유형은 합성할 수 없습니다. 이를 제거하고 '신호'와 명시적인 동기화를 통해 공유 상태를 모델링하세요.
2. A protected type also requires a body; even with one it will not synthesize, so replace the construct entirely.
2. 보호 유형에는 본문도 필요합니다. 하나라도 합성되지 않으므로 구성을 완전히 교체하십시오.
3. Convert `shared variable`-based access into ordinary signals driven by well-defined logic.
3. '공유 변수' 기반 액세스를 잘 정의된 논리에 의해 구동되는 일반 신호로 변환합니다.
4. Keep any genuine protected-type modeling in simulation-only code.
4. 시뮬레이션 전용 코드에서 진정한 보호 유형 모델링을 유지하세요.
