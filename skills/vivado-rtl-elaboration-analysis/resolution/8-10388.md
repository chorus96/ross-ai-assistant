# 8-10388: /* is inside a comment
# 8-10388: /*는 주석 안에 있습니다.

**Message:** `[Synth 8-10388] /* is inside a comment`
**메시지:** `[Synth 8-10388] /* 주석 안에 있습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A `/*` sequence appears inside an existing block comment.
기존 블록 주석 안에 `/*` 시퀀스가 나타납니다.
Verilog block comments do not nest, so the parser treats the region unexpectedly.
Verilog 블록 주석은 중첩되지 않으므로 파서가 해당 영역을 예기치 않게 처리합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Nested comment ('/*' inside a comment)
### P1: 중첩된 주석(주석 내부의 '/*')

**Problematic Code:**
**문제가 있는 코드:**
```verilog
/* outer comment /* inner */ still comment? */
```

**Recommended Fix:**
**권장 수정 사항:**
```verilog
/* outer comment - inner note without a second /* */
// or use // line comments inside
```

---

## Fix Strategy
## 전략 수정

1. Remove the inner `/*` (or close the first comment before it).
1. 내부 `/*`를 제거하십시오(또는 그 앞의 첫 번째 주석을 닫으십시오).
2. Use `//` line comments to avoid accidental nesting.
2. 실수로 중첩되는 것을 방지하려면 `//` 줄 주석을 사용하세요.
3. Check for an unterminated earlier `/*` that swallowed later code.
3. 이후 코드를 삼킨 종료되지 않은 이전 `/*`를 확인하세요.
