# 8-8936: Not an Attribute
# 8-8936: 속성이 아님

**Message:** `[Synth 8-8936] 'structure' is not an attribute`
**메시지:** `[Synth 8-8936] '구조'는 속성이 아닙니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An identifier used as a VHDL attribute is not a declared attribute.
VHDL 속성으로 사용된 식별자는 선언된 속성이 아닙니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Undeclared attribute name
### P1: 선언되지 않은 속성 이름

**Problematic Code:**
**문제가 있는 코드:**
```diff
attribute structure of sig : signal is true;  -- ERROR: 'structure' not declared
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
attribute keep : string;
attribute keep of sig : signal is "true";  -- use standard attribute
```

---

## Fix Strategy
## 전략 수정

1. Declare a custom attribute before applying it (`attribute <name> : <type>;`), or use a standard Vivado attribute name (`keep`, `mark_debug`, `dont_touch`, `ram_style`, ...).
1. 적용하기 전에 사용자 정의 속성을 선언하거나(`attribute <name> : <type>;`) 표준 Vivado 속성 이름(`keep`, `mark_debug`, `dont_touch`, `ram_style`, ...)을 사용하세요.
2. Check for a typo or a non-existent attribute name in the specification.
2. 사양에 오타가 있거나 존재하지 않는 속성 이름이 있는지 확인하세요.
3. Match the attribute's declared type to the value you assign.
3. 속성의 선언된 유형을 할당한 값과 일치시킵니다.
4. Ensure the attribute declaration is visible in the scope where it is applied.
4. 속성 선언이 적용되는 범위에 표시되는지 확인하세요.
