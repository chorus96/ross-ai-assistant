# 8-11001: Assignment Pattern in Wrong Context
# 8-11001: 잘못된 컨텍스트의 할당 패턴

**Message:** `[Synth 8-11001] non-array or non-structure context is not legal for assignment-pattern`
**메시지:** `[Synth 8-11001] 비배열 또는 비구조 컨텍스트는 할당 패턴에 적합하지 않습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-11001] non-array or non-structure context is not legal for assignment-pattern [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A SystemVerilog assignment pattern `'{...}` is used in a context that is not an array or structure (e.g., in a `case` match expression).
SystemVerilog 할당 패턴 `'{...}`은 배열이나 구조가 아닌 컨텍스트(예: `case` 일치 표현식)에서 사용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Assignment pattern in a case label
### P1: 케이스 라벨의 할당 패턴

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: assignment pattern in case match
priority case({f0.a, f0.b.a}) matches
  '{a:.in1, b:'{a:.in2, b:.in3}} : out1 = 111;  // ERROR: wrong context
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use regular case with bit patterns
priority case({f0.a, f0.b.a, f0.b.b})
  3'b000 : out1 = 111;
  3'b001 : out1 = 222;
  default : out1 = 444;
endcase
```

---

## Fix Strategy
## 전략 수정

1. Do not use assignment patterns `'{...}` in `case` labels — they are for initialization/assignment of arrays/structs.
1. `case` 라벨에 할당 패턴 `'{...}`을 사용하지 마세요. 이는 배열/구조체의 초기화/할당을 위한 것입니다.
2. Use bit concatenation (`{a, b}`) or plain constant values in `case` labels.
2. `case` 라벨에는 비트 연결(`{a, b}`) 또는 일반 상수 값을 사용하세요.
3. Match the case-label form to the selector's type (packed vector vs. enum).
3. 케이스 레이블 형식을 선택기 유형(패킹 벡터 대 열거형)과 일치시킵니다.
4. If you meant to compare a struct, compare fields or use a packed representation.
4. 구조체를 비교하려면 필드를 비교하거나 압축 표현을 사용하세요.
