# 8-2114: Illegal Concatenation of Unpacked
# 8-2114: Unpacked의 잘못된 연결

**Message:** `[Synth 8-2114] illegal concatenation of unpacked value`
**메시지:** `[Synth 8-2114] 압축 해제된 값의 잘못된 연결`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An unpacked value is used in a concatenation `{...}`, which only works with packed types.
압축 해제된 값은 압축된 유형에서만 작동하는 `{...}` 연결에 사용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Unpacked operand in concatenation
### P1: 연결의 압축이 풀린 피연산자

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: unpacked in concatenation
int a, b;
logic [63:0] c = {a, b};  // ERROR: int is unpacked in some contexts
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use streaming or explicit conversion
logic [63:0] c = {32'(a), 32'(b)};  // explicit width cast
```

---

## Fix Strategy
## 전략 수정

1. Concatenation `{...}` requires **packed** operands — apply an explicit size cast (`32'(a)`) to give each operand a defined packed width.
1. `{...}` 연결에는 **패킹된** 피연산자가 필요합니다. 각 피연산자에 정의된 패킹된 너비를 제공하려면 명시적인 크기 캐스트(`32'(a)`)를 적용하세요.
2. To pack an unpacked array into a vector, use the streaming operator (`{>>{arr}}` / `{<<{arr}}`) with a deliberate direction.
2. 압축이 풀린 배열을 벡터로 압축하려면 의도적인 방향으로 스트리밍 연산자(`{>>{arr}}` / `{<<{arr}}`)를 사용하세요.
3. Ensure the total packed width of the operands equals the target width.
3. 피연산자의 압축된 전체 너비가 대상 너비와 동일한지 확인하세요.
4. Prefer declaring the data as packed from the start when it will be concatenated, avoiding the conversion.
4. 변환을 피하면서 연결될 때 데이터를 처음부터 압축된 것으로 선언하는 것이 좋습니다.
