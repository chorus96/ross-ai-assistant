# 8-9901: Part-Select of Memory Not Allowed
# 8-9901: 메모리 부분 선택이 허용되지 않음

**Message:** `[Synth 8-9901] part-select of memory is not allowed`
**메시지:** `[Synth 8-9901] 메모리 부분 선택은 허용되지 않습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A part-select (range) is applied to a memory array, which isn't supported.
지원되지 않는 메모리 배열에 부분 선택(범위)이 적용되었습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Part-select of a memory array
### P1: 메모리 어레이의 부분 선택

**Problematic Code:**
**문제가 있는 코드:**
```diff
reg [7:0] byte1 [0:255];
assign out = byte1[3:0];  // ERROR: can't part-select memory
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
assign out = byte1[0][3:0];  // index then part-select the element
```

---

## Fix Strategy
## 전략 수정

1. Index the memory to select an element first, then part-select that element (`mem[addr][3:0]`) — you cannot part-select the whole memory array.
1. 메모리를 인덱싱하여 요소를 먼저 선택한 다음 해당 요소를 부분 선택합니다(`mem[addr][3:0]`). 전체 메모리 배열을 부분 선택할 수는 없습니다.
2. Do not apply a range to the memory name itself; a memory is an array of words, not a vector.
2. 메모리 이름 자체에 범위를 적용하지 마십시오. 메모리는 벡터가 아니라 단어의 배열입니다.
3. If you need a contiguous slice across words, loop over elements or restructure the storage as a packed vector.
3. 단어 전체에 연속적인 슬라이스가 필요한 경우 요소를 반복하거나 저장 공간을 압축된 벡터로 재구성하세요.
4. Register `mem[addr]` and slice the registered word downstream.
4. `mem[addr]`을 등록하고 등록된 단어를 다운스트림으로 분할합니다.
