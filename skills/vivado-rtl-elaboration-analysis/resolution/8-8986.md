# 8-8986: Output Mode Cannot Be Read
# 8-8986: 출력 모드를 읽을 수 없습니다.

**Message:** `[Synth 8-8986] output with mode 'out' cannot be read`
**메시지:** `[Synth 8-8986] 'out' 모드의 출력을 읽을 수 없습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL output port is read inside the architecture.
VHDL 출력 포트는 아키텍처 내부에서 읽혀집니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Reading an output port
### P1: 출력 포트 읽기

**Problematic Code:**
**문제가 있는 코드:**
```diff
port (q : out std_logic);
sig <= q;  -- ERROR: can't read out port
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
port (q : buffer std_logic);  -- buffer allows read-back
-- Or use internal signal:
signal q_int : std_logic;
q <= q_int;  -- drive output
sig <= q_int;  -- read internal
```

---

## Fix Strategy
## 전략 수정

1. Do not read an `out` port directly — drive it from an internal signal and read that signal instead (`q <= q_int; sig <= q_int;`).
1. `out` 포트를 직접 읽지 마십시오. 내부 신호에서 이를 구동하고 대신 해당 신호를 읽으십시오(`q <= q_int; sig <= q_int;`).
2. Alternatively, declare the port as `buffer` (or in VHDL-2008, `out` ports are readable) if your standard/flow allows it.
2. 또는 표준/흐름이 허용하는 경우 포트를 '버퍼'(또는 VHDL-2008에서는 'out' 포트를 읽을 수 있음)로 선언하세요.
3. Keep the internal signal as the single source of truth for both the output and internal readers.
3. 내부 신호를 출력 및 내부 판독기 모두에 대한 단일 정보 소스로 유지하십시오.
4. Verify the output value and the internally-read value stay consistent after the change.
4. 변경 후에도 출력 값과 내부 판독 값이 일관되게 유지되는지 확인하십시오.
