# 8-9481: Generic Package Mismatch
# 8-9481: 일반 패키지 불일치

**Message:** `[Synth 8-9481] formal generic package does not match with actual`
**메시지:** `[Synth 8-9481] 공식 일반 패키지가 실제 패키지와 일치하지 않습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL generic package instantiation's actual doesn't match the formal's constraints.
VHDL 일반 패키지 인스턴스화의 실제가 형식의 제약 조건과 일치하지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Generic package actual mismatch
### P1: 일반 패키지 실제 불일치

**Problematic Code:**
**문제가 있는 코드:**
```diff
generic(package pack is new gen_pkg generic map(<>));
-- actual doesn't match constraints  -- ERROR
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- Ensure actual package matches formal constraints exactly
```

---

## Fix Strategy
## 전략 수정

1. Instantiate the actual generic package so its generics satisfy the formal package's constraints exactly (matching types/subtypes/values).
1. 실제 일반 패키지를 인스턴스화하여 해당 일반 패키지가 공식 패키지의 제약 조건(유형/하위 유형/값 일치)을 정확하게 충족하도록 합니다.
2. Check the formal generic package declaration and align the actual's parameters to it.
2. 공식적인 일반 패키지 선언을 확인하고 실제 매개변수를 이에 맞춰 정렬하세요.
3. Ensure the actual is a fully instantiated package, not an uninstantiated generic one.
3. 실제 패키지가 인스턴스화되지 않은 일반 패키지가 아니라 완전히 인스턴스화된 패키지인지 확인하세요.
4. Confirm the synthesis flow supports VHDL-2008 generic packages; otherwise use a concrete package.
4. 합성 흐름이 VHDL-2008 일반 패키지를 지원하는지 확인합니다. 그렇지 않으면 구체적인 패키지를 사용하십시오.
