# 8-1819: Choice Must Be Discrete Range
# 8-1819: 선택은 이산 범위여야 합니다.

**Message:** `[Synth 8-1819] choice must be a discrete range`
**메시지:** `[Synth 8-1819] 선택은 개별 범위여야 합니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL case choice or array aggregate choice must be a discrete range or value, not a continuous type.
VHDL 사례 선택 또는 배열 집계 선택은 연속 유형이 아닌 불연속 범위 또는 값이어야 합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Non-discrete case selector
### P1: 비분리형 케이스 선택기

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: non-discrete choice in case
case real_sig is  -- ERROR: real is not discrete
  when 1.0 => ...
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use discrete type
case int_sig is
  when 1 => ...
  when others => ...
end case;
```

---

## Fix Strategy
## 전략 수정

1. Use a **discrete** selector for `case`/aggregate choices — `integer`, `natural`, enumeration, or `std_logic`/`std_logic_vector`; `real`/`time` and other non-discrete types are not allowed.
1. `케이스`/집합 선택에는 **개별** 선택기를 사용하세요(`정수`, `자연`, 열거형 또는 `std_logic`/`std_logic_Vector`). `real`/`time` 및 기타 비이산형 유형은 허용되지 않습니다.
2. If comparing a non-discrete value, quantize it to a discrete code first (e.g., map ranges to an integer index) and case on that.
2. 이산되지 않은 값을 비교하는 경우 먼저 이산된 코드로 양자화하고(예: 범위를 정수 인덱스로 매핑) 그에 대한 사례를 지정합니다.
3. For aggregate index choices, ensure they are discrete ranges (`0 to 3`) or discrete values, not continuous types.
3. 집계 인덱스 선택의 경우 연속 유형이 아닌 이산 범위(`0~3`) 또는 이산 값인지 확인하세요.
4. Replace `real`-based decisions with fixed-point/integer representations, which are both discrete and synthesizable.
4. '실제' 기반 결정을 이산적이고 합성 가능한 고정 소수점/정수 표현으로 대체합니다.
