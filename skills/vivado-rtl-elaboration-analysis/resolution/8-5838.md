# 8-5838: Non-Contiguous Port Association
# 8-5838: 비연속 포트 연결

**Message:** `[Synth 8-5838] Formal port association for '!%1!' is non contiguous`
**메시지:** `[Synth 8-5838] '!%1!'에 대한 공식 포트 연결 연속적이지 않다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL port association references non-contiguous slices of a signal.
VHDL 포트 연결은 연속되지 않은 신호 조각을 참조합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Non-contiguous slice in port map
### P1: 포트 맵의 비연속 슬라이스

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: non-contiguous association
port map(bus(3 downto 2) & bus(0) => sig);  -- ERROR: non-contiguous
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use contiguous slice or intermediate signal
signal temp : std_logic_vector(2 downto 0);
temp <= bus(3 downto 2) & bus(0);
port map(pci_bus => temp);
```

---

## Fix Strategy
## 전략 수정

1. Associate a **contiguous** slice with a port — do not build the actual from concatenated non-adjacent bits directly in the `port map`.
1. **인접** 슬라이스를 포트와 연결합니다. `포트 맵`에서 직접 연결되지 않은 인접하지 않은 비트를 연결하여 실제를 구축하지 마세요.
2. Create an intermediate signal (`temp <= bus(3 downto 2) & bus(0);`) and connect that signal to the port.
2. 중간 신호(`temp <=bus(3 downto 2) &bus(0);`)를 생성하고 해당 신호를 포트에 연결합니다.
3. Alternatively, restructure the connected signal so the needed bits are contiguous.
3. 또는 필요한 비트가 연속되도록 연결된 신호를 재구성하십시오.
4. Prefer named association and verify the intermediate signal's width matches the port width.
4. 명명된 연결을 선호하고 중간 신호의 폭이 포트 폭과 일치하는지 확인하십시오.
