# 8-659: Type Mismatch in Port Association
# 8-659: 포트 연결의 유형 불일치

**Message:** `[Synth 8-659] type mismatch in !%1!: !%2! vs. !%3!`
**메시지:** `[Synth 8-659] !%1!의 유형 불일치: !%2! 대 !%3!`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A SystemVerilog port association has incompatible struct types.
SystemVerilog 포트 연결에 호환되지 않는 구조체 유형이 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Incompatible struct types on port
### P1: 포트에서 호환되지 않는 구조체 유형

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: struct type mismatch in port
module m(input struct {bit a; bit b;} port1);
m inst(.port1(wrong_struct_sig));  // ERROR: type mismatch
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use matching struct type
typedef struct packed {bit a; bit b;} my_t;
my_t sig;
m inst(.port1(sig));  // matching type
```

---

## Fix Strategy
## 전략 수정

1. Use the **same `typedef`** for the module port type and the connected signal — two anonymous or separately-declared structs are not type-compatible even if their fields match.
1. 모듈 포트 유형과 연결된 신호에 **동일한 `typedef`**를 사용하십시오. 두 개의 익명 또는 별도로 선언된 구조체는 해당 필드가 일치하더라도 유형이 호환되지 않습니다.
2. Define shared struct/enum types in a `package` and import it in both the module and the instantiating scope.
2. '패키지'에서 공유 구조체/열거형 유형을 정의하고 모듈과 인스턴스화 범위 모두에서 가져옵니다.
3. If a conversion is genuinely needed, cast explicitly with the target type (`target_t'(sig)`) rather than relying on implicit assignment.
3. 변환이 정말로 필요한 경우 암시적 할당에 의존하기보다는 대상 유형(`target_t'(sig)`)을 사용하여 명시적으로 캐스팅하세요.
4. Verify packed vs. unpacked struct kinds match between port and signal.
4. 포트와 신호 간에 패킹된 구조체 종류와 압축되지 않은 구조체 종류가 일치하는지 확인합니다.
