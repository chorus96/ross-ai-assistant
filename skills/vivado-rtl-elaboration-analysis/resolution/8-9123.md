# 8-9123: Enum Assignment Type Mismatch
# 8-9123: 열거형 할당 유형 불일치

**Message:** `[Synth 8-9123] an enum variable may only be assigned the same enum typed variable or one of its values`
**메시지:** `[Synth 8-9123] 열거형 변수에는 동일한 열거형 변수 또는 해당 값 중 하나만 할당될 수 있습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An enum variable is assigned a non-enum value.
열거형 변수에는 열거형이 아닌 값이 할당됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Integer assigned to an enum variable
### P1: 열거형 변수에 정수가 할당됨

**Problematic Code:**
**문제가 있는 코드:**
```diff
typedef enum {A,B,C} state_t;
state_t s;
s = 2;  // ERROR: integer not enum
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
s = B;  // assign enum value directly
```

---

## Fix Strategy
## 전략 수정

1. Assign an enum variable only an enum **literal** of its type or another variable of the same enum type — not a raw integer.
1. 열거형 변수에는 해당 유형의 열거형 **리터럴**만 할당하거나 원시 정수가 아닌 동일한 열거형 유형의 다른 변수만 할당합니다.
2. If you must convert from an integer encoding, use an explicit cast (`state_t'(int_val)`) and ensure the value is a valid member.
2. 정수 인코딩에서 변환해야 하는 경우 명시적 형변환(`state_t'(int_val)`)을 사용하고 값이 유효한 멤버인지 확인하세요.
3. Keep FSM state assignments to named enum values for readability and type safety.
3. 가독성과 유형 안전성을 위해 명명된 열거형 값에 대한 FSM 상태 할당을 유지합니다.
4. Verify all case/branch assignments use enum members, not numeric literals.
4. 모든 사례/분기 할당이 숫자 리터럴이 아닌 열거형 멤버를 사용하는지 확인하세요.
