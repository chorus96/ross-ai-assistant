# 8-9775: name of !%1! declaration in !%2! definition does not match that in ...
# 8-9775: !%1!의 이름 !%2!에 선언 정의가 일치하지 않습니다 ...

**Message:** `[Synth 8-9775] name of !%1! declaration in !%2! definition does not match that in extern !%3!`
**메시지:** `[Synth 8-9775] !%1!의 이름 !%2!에 선언 정의가 extern !%3!`의 정의와 일치하지 않습니다.
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A declaration's name in a definition does not match the corresponding `extern` declaration.
정의의 선언 이름이 해당 'extern' 선언과 일치하지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Declaration name mismatches extern
### P1: 선언 이름이 extern과 일치하지 않습니다.

**Problematic Code:**
**문제가 있는 코드:**
```systemverilog
extern module m(...);
module mm(...); ...   // name differs
```

**Recommended Fix:**
**권장 수정 사항:**
```systemverilog
extern module m(...);
module m(...); ...
```

---

## Fix Strategy
## 전략 수정

1. Make the definition name match the `extern` prototype.
1. 정의 이름이 'extern' 프로토타입과 일치하도록 만드세요.
2. Keep extern and definition identifiers identical.
2. 외부 식별자와 정의 식별자를 동일하게 유지하십시오.
3. Fix the mismatched name.
3. 일치하지 않는 이름을 수정하세요.
