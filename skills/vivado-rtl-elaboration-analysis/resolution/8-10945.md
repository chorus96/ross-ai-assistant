# 8-10945: method '!%1!' of class '!%2!' cannot have static lifetime; considering ...
# 8-10945: 메소드 '!%1!' 클래스 '!%2!' 정적 수명을 가질 수 없습니다. 고려 ...

**Message:** `[Synth 8-10945] method '!%1!' of class '!%2!' cannot have static lifetime; considering as automatic`
**메시지:** `[Synth 8-10945] 메소드 '!%1!' 클래스 '!%2!' 정적 수명을 가질 수 없습니다. 자동으로 고려`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A class method is declared `static` in a way not allowed here, so it is treated as `automatic`.
클래스 메소드는 여기서 허용되지 않는 방식으로 '정적'으로 선언되므로 '자동'으로 처리됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Class method cannot have static lifetime
### P1: 클래스 메서드는 정적 수명을 가질 수 없습니다.

**Problematic Code:**
**문제가 있는 코드:**
```systemverilog
class c; static function int f(); ... endfunction endclass  // flagged
```

**Recommended Fix:**
**권장 수정 사항:**
```systemverilog
class c; function automatic int f(); ... endfunction endclass
```

---

## Fix Strategy
## 전략 수정

1. Declare the method `automatic` (the default and required form here).
1. `automatic` 메소드를 선언하십시오(여기서는 기본 및 필수 양식).
2. Use `static` class properties/methods only where the LRM allows.
2. LRM이 허용하는 경우에만 '정적' 클래스 속성/메서드를 사용하세요.
3. Classes are testbench constructs; avoid them in synthesizable RTL.
3. 클래스는 테스트벤치 구성물입니다. 합성 가능한 RTL에서는 이를 피하세요.
