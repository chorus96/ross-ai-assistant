# 8-524: Part-Select Range Error
# 8-524: 부품 선택 범위 오류

**Message:** `[Synth 8-524] part-select [!%1!:!%2!] out of range of prefix '!%3!'`
**메시지:** `[Synth 8-524] 부분 선택 [!%1!:!%2!] 접두사 '!%3!' 범위를 벗어남`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A part-select range is invalid — reversed direction or zero width.
부품 선택 범위가 유효하지 않습니다. 방향이 바뀌었거나 너비가 0입니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Part-select direction reversed
### P1: 부품 선택 방향이 반전됨

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: reversed direction
wire [7:0] data;  // descending
assign out = data[0:3];  // ERROR: ascending on descending signal
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: match direction
assign out = data[3:0];  // descending matches declaration
```

---

## Fix Strategy
## 전략 수정

1. Match the part-select direction to the signal's declared direction — use `[3:0]` on a `[7:0]` (descending) signal, `[0:3]` only on an ascending `[0:7]` signal.
1. 부분 선택 방향을 신호가 선언한 방향과 일치시킵니다. `[7:0]`(내림차순) 신호에는 `[3:0]`을 사용하고, 상승하는 `[0:7]` 신호에는 `[0:3]`만 사용합니다.
2. Ensure the range is non-zero width and correctly ordered (high:low for descending, low:high for ascending).
2. 범위의 너비가 0이 아니고 올바른 순서인지 확인하세요(내림차순은 높음:낮음, 오름차순은 낮음:높음).
3. For a variable index, prefer `signal[base +: width]` / `signal[base -: width]`, which are direction-safe.
3. 변수 인덱스의 경우 방향이 안전한 `signal[base +: width]` / `signal[base -: width]`를 선호합니다.
4. If the direction is genuinely reversed, either fix the select or reverse the signal declaration — do not rely on implicit reordering.
4. 방향이 실제로 반대인 경우 선택을 수정하거나 신호 선언을 반대로 바꾸십시오. 암시적 재정렬에 의존하지 마십시오.
