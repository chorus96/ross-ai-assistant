# 8-10729: formal port '!%1!' of mode '!%2!' cannot be associated with actual port ...
# 8-10729: 공식 포트 '!%1!' 모드 '!%2!' 실제 포트와 연결할 수 없습니다...

**Message:** `[Synth 8-10729] formal port '!%1!' of mode '!%2!' cannot be associated with actual port '!%3!' of mode '!%4!'`
**메시지:** `[Synth 8-10729] 공식 포트 '!%1!' 모드 '!%2!' 실제 포트 '!%3!'과 연결할 수 없습니다. 모드 '!%4!'`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A formal port of one mode is associated with an actual of an incompatible mode (e.g. an `out` formal driven from an `in`-only actual).
한 모드의 형식 포트는 호환되지 않는 모드의 실제와 연결됩니다(예: 'in' 전용 실제에서 구동되는 'out' 형식).

---

## Common Patterns
## 일반적인 패턴

### P1: Port mode mismatch in association
### P1: 연결의 포트 모드 불일치

**Problematic Code:**
**문제가 있는 코드:**
```vhdl
-- formal 'q' is out, connected to an input-only signal
inst : ent port map (q => in_sig);
```

**Recommended Fix:**
**권장 수정 사항:**
```vhdl
-- connect 'q' to a signal that can be driven
inst : ent port map (q => internal_sig);
```

---

## Fix Strategy
## 전략 수정

1. Match the actual's capability to the formal's mode (in/out/inout/buffer).
1. 실제의 기능을 형식의 모드(in/out/inout/buffer)와 일치시킵니다.
2. Do not drive an `out`/`buffer` formal from a read-only actual, or vice versa.
2. 읽기 전용 실제 항목에서 'out'/'buffer' 형식을 구동하지 마세요. 또는 그 반대도 마찬가지입니다.
3. Check for swapped connections in the port map.
3. 포트 맵에서 교환된 연결을 확인하십시오.
