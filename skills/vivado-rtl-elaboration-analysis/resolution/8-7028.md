# 8-7028: Array Without Index Constraint
# 8-7028: 인덱스 제약이 없는 배열

**Message:** `[Synth 8-7028] Array type does not have index constraint`
**메시지:** `[Synth 8-7028] 배열 유형에 인덱스 제약 조건이 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL array type is used without the required index constraint.
VHDL 배열 유형은 필수 인덱스 제약 조건 없이 사용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Unconstrained array without a range
### P1: 범위가 없는 무제한 배열

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: unconstrained array without constraint
type arr_t is array (natural range <>) of integer;
signal s : arr_t;  -- ERROR: needs index constraint
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: add index constraint
signal s : arr_t(0 to 7);  -- constrained
```

---

## Fix Strategy
## 전략 수정

1. Constrain the array when declaring the object — give an unconstrained array type an explicit index range (`signal s : arr_t(0 to 7);`).
1. 객체를 선언할 때 배열을 제한합니다. 제한되지 않은 배열 유형에 명시적인 인덱스 범위(`signal s : arr_t(0 to 7);`)를 제공합니다.
2. Parameterize the range with a generic/constant so it stays fixed at elaboration but configurable.
2. 일반/상수로 범위를 매개변수화하여 정교하게 고정된 상태로 유지되지만 구성 가능하도록 합니다.
3. For ports of unconstrained type, constrain them at the instantiation/binding as required by the flow.
3. 제한되지 않은 유형의 포트의 경우 흐름에 필요한 대로 인스턴스화/바인딩 시 제한합니다.
4. Verify all downstream uses assume the same constrained range.
4. 모든 다운스트림 사용이 동일한 제한된 범위를 가정하는지 확인하십시오.
