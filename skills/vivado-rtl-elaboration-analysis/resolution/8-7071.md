# 8-7071: Unconnected Port
# 8-7071: 연결되지 않은 포트

**Message:** `[Synth 8-7071] port of module is unconnected for instance`
**메시지:** `[Synth 8-7071] 예를 들어 모듈의 포트가 연결되지 않았습니다`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A port on a module instance is not connected.
모듈 인스턴스의 포트가 연결되지 않았습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Instance port left unconnected
### P1: 인스턴스 포트가 연결되지 않은 채로 남아 있음

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: port EPB_ALE not connected
my_mod inst(.clk(clk));  // WARNING: EPB_ALE unconnected
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: connect or explicitly leave open
my_mod inst(.clk(clk), .EPB_ALE());  // explicit open
```

---

## Fix Strategy
## 전략 수정

1. Connect the port to the intended signal; a silently unconnected port often means a missing wire in the parent.
1. 포트를 의도된 신호에 연결하십시오. 자동으로 연결되지 않은 포트는 종종 상위 포트에 와이어가 없음을 의미합니다.
2. For an intentionally unused **input**, tie it to a defined constant; for an unused **output**, leave it open explicitly (`.port()`).
2. 의도적으로 사용되지 않는 **입력**의 경우 이를 정의된 상수에 연결합니다. 사용되지 않은 **출력**의 경우 명시적으로 열어 둡니다(`.port()`).
3. Prefer named connections so unconnected ports are visible and deliberate.
3. 연결되지 않은 포트가 표시되고 의도적으로 표시되도록 명명된 연결을 선호합니다.
4. Verify the instantiated module version matches the expected port list.
4. 인스턴스화된 모듈 버전이 예상 포트 목록과 일치하는지 확인합니다.
