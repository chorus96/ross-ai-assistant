# 8-6859: multi-driven net on pin
# 8-6859: 핀 위의 다중 구동 네트

**Message:** `[Synth 8-6859] multi-driven net on pin !%1! with !%2! driver pin '!%3!'`
**메시지:** `[Synth 8-6859] 핀 !%1의 다중 구동 네트! !%2!로 드라이버 핀 '!%3!'`
**Severity:** CRITICAL WARNING
**심각도:** 심각한 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

## Common Patterns
## 일반적인 패턴

### P1: Multiple continuous assignments to the same net
### P1: 동일한 네트에 대한 다중 연속 할당

**Problematic Code:**
**문제가 있는 코드:**
```verilog
wire out1;
assign out1 = in1;   // 1st driver
assign out1 = in2;   // 2nd driver -> multi-driven
```

**Recommended Fix — pick one source, or mux them explicitly:**
**권장 수정 — 하나의 소스를 선택하거나 명시적으로 다중화:**
```verilog
wire out1;
assign out1 = sel ? in2 : in1;   // single driver, intent explicit
```

### P2: Net driven by a procedural block AND a continuous assign
### P2: 절차적 블록과 연속 할당에 의해 구동되는 네트

**Problematic Code:**
**문제가 있는 코드:**
```verilog
reg out1;
assign out1 = in1;             // continuous driver
always @(*) out1 = in2;        // procedural driver -> multi-driven
```

**Recommended Fix — drive from exactly one construct:**
**권장 수정 — 정확히 하나의 구성에서 구동:**
```verilog
reg out1;
always @(*) out1 = sel ? in2 : in1;   // one procedural driver
```

### P3: Output port driven both internally and from the connection
### P3: 내부 및 연결 모두에서 구동되는 출력 포트

**Problematic Code:**
**문제가 있는 코드:**
```verilog
module child(output out1);
  assign out1 = 1'b0;          // driven inside child
endmodule

// parent also drives the same node
child u_child(.out1(net));
assign net = data;             // 2nd driver -> multi-driven on child/out1
```

**Recommended Fix — leave an output driven only by its module; drive the wire once:**
**권장 수정 — 해당 모듈에 의해서만 구동되는 출력을 그대로 둡니다. 와이어를 한 번 구동하십시오.**
```verilog
child u_child(.out1(net));     // child drives net; remove the extra assign
```

### P4: VHDL multiple concurrent assignments to one signal
### P4: 하나의 신호에 대한 VHDL 다중 동시 할당

**Problematic Code:**
**문제가 있는 코드:**
```vhdl
signal s : std_logic_vector(7 downto 0);
begin
  s <= a;                      -- 1st driver
  s <= b;                      -- 2nd driver -> multi-driven
```

**Recommended Fix — resolve to a single concurrent driver:**
**권장 수정 — 단일 동시 드라이버 해결:**
```vhdl
s <= b when sel = '1' else a;  -- one driver, selection explicit
```

### P5: Same reg written from two `always` blocks
### P5: 두 개의 `always` 블록에서 작성된 동일한 등록

**Problematic Code:**
**문제가 있는 코드:**
```verilog
reg q;
always @(posedge clk) q <= d1;   // 1st driver
always @(posedge clk) q <= d2;   // 2nd driver -> multi-driven
```

**Recommended Fix — merge the writers into one block:**
**권장 수정 — 작성자를 하나의 블록으로 병합:**
```verilog
reg q;
always @(posedge clk) q <= sel ? d2 : d1;   // single writer
```

1. **Keep exactly one driver per net.** Replace competing drivers with a single
1. **네트당 정확히 하나의 드라이버를 유지하십시오.** 경쟁 드라이버를 단일 드라이버로 교체하십시오.

than one value is genuinely needed.
하나 이상의 가치가 진정으로 필요합니다.
2. **Do not drive a module output from outside** — let the owning module drive it,

and connect the port to a wire that has no other driver.
다른 드라이버가 없는 와이어에 포트를 연결합니다.

4. **True tri-state only** — if a real bus with `Z` drivers is intended, use
