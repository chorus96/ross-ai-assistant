# 8-10681: Entity Aspect Not Found
# 8-10681: 엔터티 측면을 찾을 수 없음

**Message:** `[Synth 8-10681] entity aspect does not denote an entity or a configuration`
**메시지:** `[Synth 8-10681] 엔터티 측면은 엔터티 또는 구성을 나타내지 않습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10681] entity aspect does not denote an entity or a configuration [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A VHDL `use entity` configuration clause references an architecture name that doesn't exist in the entity.
VHDL '엔티티 사용' 구성 절이 엔터티에 존재하지 않는 아키텍처 이름을 참조합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Missing architecture in entity aspect
### P1: 엔터티 측면에서 아키텍처가 누락되었습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: referencing non-existent architecture
for inst : SubUnit
  use entity SubUnit(theresajacksoninthehouse);  -- ERROR: architecture not found
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use correct architecture name or remove config
for inst : SubUnit
  use entity SubUnit(rtl);   -- use actual architecture name
-- Or remove the configuration entirely (use default binding)
```

---

## Fix Strategy
## 전략 수정

1. Reference an architecture name that actually exists for the entity in the entity aspect.
1. 엔터티 관점에서 해당 엔터티에 대해 실제로 존재하는 아키텍처 이름을 참조합니다.
2. Ensure the architecture is compiled into the same library as the entity before binding.
2. 바인딩하기 전에 아키텍처가 엔터티와 동일한 라이브러리로 컴파일되었는지 확인하세요.
3. Fix typos in the entity/architecture name, or remove the configuration spec to use default binding.
3. 엔터티/아키텍처 이름의 오타를 수정하거나 기본 바인딩을 사용하려면 구성 사양을 제거하세요.
4. Verify the library prefix is correct for the bound entity.
4. 바인딩된 엔터티에 대한 라이브러리 접두사가 올바른지 확인하세요.
