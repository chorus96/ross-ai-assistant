# 8-2798: Unexpected EOF
# 8-2798: 예상치 못한 EOF

**Message:** `[Synth 8-2798] unexpected EOF`
**메시지:** `[Synth 8-2798] 예기치 않은 EOF`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

The Verilog/VHDL file ends unexpectedly — a module, entity, or block is not properly closed.
Verilog/VHDL 파일이 예기치 않게 종료됩니다. 모듈, 엔터티 또는 블록이 제대로 닫히지 않았습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Unclosed module/entity at end of file
### P1: 파일 끝에 닫히지 않은 모듈/엔티티

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: unclosed module
module top;
  assign out = in;
// missing: endmodule
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: close the module
module top;
  assign out = in;
endmodule
```

---

## Fix Strategy
## 전략 수정

1. Add the missing closing keyword — `endmodule`, `endfunction`, `endtask`, `end` / `endcase`, or VHDL `end architecture;` / `end entity;` — for the construct that was left open.
1. 열려 있는 구성에 대해 누락된 닫는 키워드(`endmodule`, `endfunction`, `endtask`, `end` / `endcase` 또는 VHDL `end Architecture;` / `endEntity;`)를 추가합니다.
2. Balance brackets and `begin`/`end` pairs; an unclosed `(`/`[`/`begin` earlier in the file causes the parser to hit EOF.
2. 균형 괄호 및 `begin`/`end` 쌍; 파일 앞부분에서 닫히지 않은 `(`/`[`/`begin`은 파서가 EOF에 도달하게 만듭니다.
3. Use editor bracket-matching or re-indent to locate the unclosed scope near the reported end of file.
3. 보고된 파일 끝 근처에서 닫히지 않은 범위를 찾으려면 편집기 대괄호 일치 또는 다시 들여쓰기를 사용하십시오.
4. Check for a stray block comment (`/* ... */` or `-- ...
4. 잘못된 블록 주석(`/* ... */` 또는 `-- ...)이 있는지 확인하세요.
4. `) that swallowed the closing statement.
4. `) 마지막 문장을 삼켰습니다.
