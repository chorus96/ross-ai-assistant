# 8-2856: Variable of File Type
# 8-2856: 파일 유형의 변수

**Message:** `[Synth 8-2856] variable declaration cannot be of a file type`
**메시지:** `[Synth 8-2856] 변수 선언은 파일 형식일 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

VHDL variable declaration uses a file type, which is not synthesizable.
VHDL 변수 선언은 합성할 수 없는 파일 형식을 사용합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: File-type variable in synthesizable code
### P1: 합성 가능한 코드의 파일 유형 변수

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: file type variable
variable f : text;  -- ERROR: file type not synthesizable
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: remove file operations (simulation-only)
-- File I/O is not synthesizable. Remove file variables
-- and use constant data or ROM inference instead.
```

---

## Fix Strategy
## 전략 수정

1. File types and file I/O (`text`, `file`, `read`/`write`) are not synthesizable — remove them from synthesizable RTL.
1. 파일 형식 및 파일 I/O(`text`, `file`, `read`/`write`)는 합성할 수 없습니다. 합성 가능한 RTL에서 제거하세요.
2. For memory initialization, use ROM inference from a constant array, or `$readmemh`/`$readmemb` (Verilog) instead of VHDL file reads.
2. 메모리 초기화의 경우 VHDL 파일 읽기 대신 상수 배열 또는 `$readmemh`/`$readmemb`(Verilog)에서 ROM 추론을 사용합니다.
3. Move any genuine file I/O into the testbench/simulation-only code, guarded from synthesis.
3. 실제 파일 I/O를 합성으로부터 보호되는 테스트벤치/시뮬레이션 전용 코드로 옮깁니다.
4. Replace file-driven data with elaboration-time constants or generics where the values are fixed.
4. 파일 기반 데이터를 정교화 시간 상수 또는 값이 고정된 일반 항목으로 바꿉니다.
