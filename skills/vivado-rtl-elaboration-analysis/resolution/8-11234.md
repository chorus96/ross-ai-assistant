# 8-11234: Type Error: Expected Void
# 8-11234: 유형 오류: 예상된 공백

**Message:** `[Synth 8-11234] type error near '!%1!'; expected type '!%2!'`
**메시지:** `[Synth 8-11234] '!%1!' 근처에 유형 오류가 있습니다. 예상 유형 '!%2!'`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL expression returns a non-void type where void (procedure) is expected, or vice versa.
VHDL 표현식은 void(프로시저)가 예상되는 void가 아닌 유형을 반환하거나 그 반대의 경우도 마찬가지입니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Non-void function used as void
### P1: Void로 사용되는 Non-Void 기능

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: function used where procedure expected
shift(in1, in2);  -- ERROR if shift is function returning non-void
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: capture return value or use procedure
result <= shift(in1, in2);  -- capture return
-- Or change to procedure
```

---

## Fix Strategy
## 전략 수정

1. If a function returns a value, capture/use it (assign it to a target); do not call it as a void statement where a value is expected.
1. 함수가 값을 반환하면 이를 캡처/사용합니다(대상에 할당). 값이 예상되는 void 문으로 호출하지 마세요.
2. If no return value is needed, make it a `void function`/`task` (procedure) instead.
2. 반환 값이 필요하지 않으면 대신 `void function`/`task`(프로시저)로 만드세요.
3. Match the caller's context (value vs. statement) to the subprogram's return kind.
3. 호출자의 컨텍스트(값 대 명령문)를 하위 프로그램의 반환 종류와 일치시킵니다.
4. Verify the return type matches how the result is used.
4. 반환 유형이 결과가 사용되는 방식과 일치하는지 확인하십시오.
