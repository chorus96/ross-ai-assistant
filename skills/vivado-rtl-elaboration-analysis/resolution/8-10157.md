# 8-10157: Undefined Macro
# 8-10157: 정의되지 않은 매크로

**Message:** `[Synth 8-10157] use of undefined macro`
**메시지:** `[Synth 8-10157] 정의되지 않은 매크로 사용`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10157] use of undefined macro [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A Verilog `` `define`` macro is referenced but never defined.
Verilog ``define`` 매크로가 참조되지만 정의되지는 않습니다.
The header file containing the macro definition may not be included.
매크로 정의가 포함된 헤더 파일은 포함되지 않을 수 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Reference to an undefined macro
### P1: 정의되지 않은 매크로에 대한 참조

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: macro used but not defined
assign hdr_ecc = ({7{data_in[0]}} & `APXC_SM_HDR_ECC_D00);  // ERROR: undefined macro
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: add `include or define the macro
`define APXC_SM_HDR_ECC_D00 7'h01
// Or include the header:
`include "apxc_sm_defines.vh"
assign hdr_ecc = ({7{data_in[0]}} & `APXC_SM_HDR_ECC_D00);
```

---

## Fix Strategy
## 전략 수정

1. Define the macro before use with `` `define `` or add the `` `include `` for the header that defines it.
1. 매크로를 사용하기 전에 ``define ``으로 정의하거나 이를 정의하는 헤더에 ``include ``를 추가하세요.
2. Ensure the include path/order is correct so the defining header is processed before the reference.
2. 정의 헤더가 참조 전에 처리되도록 포함 경로/순서가 올바른지 확인하세요.
3. Check for typos in the macro name (macros are case-sensitive) and matching backtick usage.
3. 매크로 이름(매크로는 대소문자를 구분함)에 오타가 있는지, 역따옴표 사용법이 일치하는지 확인하세요.
4. Verify the header is added to the fileset/compile order so its `` `define `` is visible.
4. 헤더가 파일 세트/컴파일 순서에 추가되어 ``define ``이 표시되는지 확인하세요.
