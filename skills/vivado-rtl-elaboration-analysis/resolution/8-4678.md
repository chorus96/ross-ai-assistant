# 8-4678: Aggregate in Force Assignment
# 8-4678: 강제 할당에서 집계

**Message:** `[Synth 8-4678] aggregate is not allowed as the target of signal !%1!`
**메시지:** `[Synth 8-4678] 집계는 신호 !%1!의 대상으로 허용되지 않습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL force assignment target is an aggregate, which is not allowed.
VHDL 강제 할당 대상은 집계이므로 허용되지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Aggregate as a force target
### P1: 강제 대상으로 집계

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: aggregate as force target
(a, b) <= force (c, d);  -- ERROR: aggregate not allowed
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: force individual signals
a <= force c;
b <= force d;
-- Note: force is simulation-only anyway
```

---

## Fix Strategy
## 전략 수정

1. `force`/`release` are simulation-only — remove them from synthesizable RTL entirely.
1. `force`/`release`는 시뮬레이션 전용입니다. 합성 가능한 RTL에서 완전히 제거하세요.
2. If forcing was used to override a value, model the intended behavior with real logic (a mux/enable that selects the override value).
2. 강제를 사용하여 값을 재정의한 경우 실제 논리(재정의 값을 선택하는 mux/활성화)를 사용하여 의도된 동작을 모델링합니다.
3. If the construct must stay for testbench use, force individual signals (not aggregates) and keep it out of the synthesized path.
3. 테스트벤치 사용을 위해 구성을 유지해야 하는 경우 개별 신호(집계 아님)를 강제하고 합성 경로에서 제외하십시오.
4. Aggregates are not valid force targets even in simulation — split into per-signal `force` statements.
4. 집계는 시뮬레이션에서도 유효한 힘 목표가 아닙니다. 신호별 'force' 문으로 분할됩니다.
