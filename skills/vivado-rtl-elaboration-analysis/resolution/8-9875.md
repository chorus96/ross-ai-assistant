# 8-9875: Package Not Compiled
# 8-9875: 패키지가 컴파일되지 않음

**Message:** `[Synth 8-9875] package declaration is not yet compiled`
**메시지:** `[Synth 8-9875] 패키지 선언이 아직 컴파일되지 않았습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL package is referenced before it's compiled.
VHDL 패키지는 컴파일되기 전에 참조됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Package referenced before compilation
### P1: 컴파일 전에 참조된 패키지

**Problematic Code:**
**문제가 있는 코드:**
```diff
use work.pack.all;  -- ERROR: pack not compiled yet
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- Compile pack.vhd first:
-- read_vhdl pack.vhd
-- read_vhdl this_file.vhd
```

---

## Fix Strategy
## 전략 수정

1. Compile the package source before any file that references it (correct analysis/file order).
1. 패키지 소스를 참조하는 파일보다 먼저 패키지 소스를 컴파일하십시오(올바른 분석/파일 순서).
2. Ensure the package is analyzed into the expected library and referenced with the right prefix (`use work.pack.all;`).
2. 패키지가 예상 라이브러리로 분석되고 올바른 접두사(`use work.pack.all;`)로 참조되는지 확인하세요.
3. In a project flow, add the package file to the fileset so it elaborates first.
3. 프로젝트 흐름에서 패키지 파일을 파일 세트에 추가하여 먼저 자세히 설명합니다.
4. Fix typos in the package/library name in the `use` clause.
4. `use` 절의 패키지/라이브러리 이름에 있는 오타를 수정합니다.
