# 8-10738: Function Must Have Input
# 8-10738: 함수에는 입력이 있어야 합니다.

**Message:** `[Synth 8-10738] function must have at least one input`
**메시지:** `[Synth 8-10738] 함수에는 하나 이상의 입력이 있어야 합니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10738] function must have at least one input [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A Verilog function is declared without any input arguments, which is not allowed in Verilog-2001.
Verilog 함수는 Verilog-2001에서 허용되지 않는 입력 인수 없이 선언됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Function with no input argument
### P1: 입력 인수가 없는 함수

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: function with no inputs
function [7:0] inc;
  inc = 10;              // ERROR: no input argument
endfunction
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: add at least one input
function [7:0] inc(input dummy);
  inc = 10;
endfunction
// Or use SystemVerilog void function syntax:
// function automatic [7:0] inc(); // OK in SV mode
```

---

## Fix Strategy
## 전략 수정

1. Give the function at least one `input` argument (Verilog requires it), or compile in SystemVerilog mode where zero-argument functions are allowed.
1. 함수에 최소한 하나의 '입력' 인수(Verilog에서는 필요함)를 제공하거나 인수가 없는 함수가 허용되는 SystemVerilog 모드에서 컴파일하십시오.
2. If the value comes from module scope, pass it in as an argument to keep the function pure.
2. 값이 모듈 범위에서 오는 경우 이를 인수로 전달하여 함수를 순수하게 유지하세요.
3. Prefer explicit inputs so the function is self-contained and synthesizable.
3. 함수가 독립적이고 합성 가능하도록 명시적 입력을 선호합니다.
4. Verify the return type and body use only the declared inputs.
4. 반환 유형과 본문이 선언된 입력만 사용하는지 확인하세요.
