# 8-11067: parameter '!%1!' declared inside !%2! '!%3!' shall be treated as ...
# 8-11067: 매개변수 '!%1!' !%2! 안에 선언되었습니다. '!%3!' 다음과 같이 취급됩니다 ...

**Message:** `[Synth 8-11067] parameter '!%1!' declared inside !%2! '!%3!' shall be treated as localparam`
**메시지:** `[Synth 8-11067] 매개변수 '!%1!' !%2! 안에 선언되었습니다. '!%3!' localparam으로 처리됩니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A `parameter` declared inside a `package` cannot be overridden, so it is treated as a `localparam`.
`패키지` 내부에 선언된 `매개변수`는 재정의될 수 없으므로 `localparam`으로 처리됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Package parameter treated as localparam
### P1: localparam으로 처리되는 패키지 매개변수

**Problematic Code:**
**문제가 있는 코드:**
```systemverilog
package p; parameter W = 8; endpackage
```

**Recommended Fix:**
**권장 수정 사항:**
```systemverilog
package p; localparam W = 8; endpackage
```

---

## Fix Strategy
## 전략 수정

1. Declare package constants as `localparam` to match how the tool treats them.
1. 도구가 이를 처리하는 방식과 일치하도록 패키지 상수를 `localparam`으로 선언합니다.
2. This documents that the value is not overridable.
2. 이는 값이 재정의될 수 없음을 문서화합니다.
3. Advisory only; behavior is unchanged.
3. 자문 전용; 행동은 변함이 없습니다.
