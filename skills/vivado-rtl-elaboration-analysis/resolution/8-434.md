# 8-434: Mixed Level/Edge Event Controls
# 8-434: 혼합 레벨/에지 이벤트 제어

**Message:** `[Synth 8-434] mixed level sensitive and edge triggered event controls are not supported for synthesis`
**메시지:** `[Synth 8-434] 혼합 레벨 감지 및 에지 트리거 이벤트 컨트롤은 합성에 지원되지 않습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An always block mixes level-sensitive and edge-triggered events, which synthesis doesn't support.
항상 블록은 합성이 지원하지 않는 레벨 감지 이벤트와 에지 트리거 이벤트를 혼합합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Edge mixed with level in sensitivity list
### P1: 민감도 목록의 레벨과 혼합된 에지

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: mixed level and edge
always @(posedge clk or en)  // ERROR: edge + level mixed
  if (en) out <= in;
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: separate blocks
always @(posedge clk)  // edge only
  if (en) out <= in;
// Or: always @(*)  // level only
//  out = en ? in : 0;
```

---

## Fix Strategy
## 전략 수정

1. Do not mix an edge (`posedge`/`negedge`) with a level-sensitive signal in one sensitivity list — split the logic into separate blocks.
1. 하나의 민감도 목록에서 레벨에 민감한 신호와 에지(`posedge`/`negedge`)를 혼합하지 마십시오. 로직을 별도의 블록으로 분할하십시오.
2. For a flip-flop: use `always @(posedge clk)`; for combinational logic: use `always @(*)`.
2. 플립플롭의 경우: `always @(posedge clk)`를 사용하세요. 조합 논리의 경우 `항상 @(*)`를 사용하세요.
3. For an asynchronous reset, use **two edges** — `always @(posedge clk or negedge rst_n)` — not an edge plus a level; test the reset first inside the block.
3. 비동기식 재설정의 경우 **두 개의 에지** — `항상 @(posedge clk 또는 negedge rst_n)`를 사용합니다. 에지에 레벨을 더한 것이 아닙니다. 블록 내부에서 먼저 재설정을 테스트하십시오.
4. Confirm the sensitivity list contains only edges (for sequential) or only levels (for combinational), never a mix.
4. 민감도 목록에 에지(순차의 경우) 또는 수준(조합의 경우)만 포함되어 있고 혼합이 포함되어 있지 않은지 확인하십시오.
