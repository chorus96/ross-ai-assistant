# 8-10791: illegal assignment to constant '!%1!'
# 8-10791: 상수 '!%1!'에 대한 할당이 잘못되었습니다.

**Message:** `[Synth 8-10791] illegal assignment to constant '!%1!'`
**메시지:** `[Synth 8-10791] 상수 '!%1!'에 대한 잘못된 할당`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A `localparam`/`parameter`/`const` is assigned a new value in procedural or continuous code.
`localparam`/`parameter`/`const`에는 절차적 또는 연속 코드에서 새로운 값이 할당됩니다.
Constants cannot be reassigned.
상수는 재할당될 수 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Illegal assignment to a constant
### P1: 상수에 대한 잘못된 할당

**Problematic Code:**
**문제가 있는 코드:**
```verilog
localparam W = 8;
always @* W = 16;   // illegal
```

**Recommended Fix:**
**권장 수정 사항:**
```verilog
localparam W = 8;   // keep constant; use a variable if it must change
```

---

## Fix Strategy
## 전략 수정

1. Do not assign to a constant; declare a `reg`/`logic` variable if the value must change.
1. 상수에 할당하지 마십시오. 값을 변경해야 하는 경우 `reg`/`logic` 변수를 선언하세요.
2. If the value is fixed, remove the reassignment.
2. 값이 고정된 경우 재할당을 제거합니다.
3. Check that the target is not accidentally a parameter/localparam.
3. 대상이 실수로 매개변수/localparam이 아닌지 확인하세요.
