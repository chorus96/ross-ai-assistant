# 8-36: Not Declared
# 8-36: 선언되지 않음

**Message:** `[Synth 8-36] '!%1!' is not declared`
**메시지:** `[Synth 8-36] '!%1!' 선언되지 않았습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-36] 'my_signal' is not declared [/path/to/file.v:42]
```

---

## Root Cause
## 근본 원인

A signal, variable, parameter, or identifier is used but has no visible declaration in the current scope.
신호, 변수, 매개변수 또는 식별자가 사용되었지만 현재 범위에 표시되는 선언이 없습니다.

### Common Patterns
### 일반적인 패턴

| Pattern<br>패턴 | Symptom<br>증상 | Root Cause<br>근본 원인 |
|---------|---------|------------|
| P1: Typo<br>P1: 오타 | Name close to existing declaration<br>기존 선언과 가까운 이름 | Misspelled identifier<br>철자가 틀린 식별자 |
| P2: Missing declaration<br>P2: 선언 누락 | Name not found anywhere<br>어디서도 찾을 수 없는 이름 | Declaration never added<br>선언이 추가되지 않았습니다. |
| P3: Scope issue<br>P3: 범위 문제 | Name exists elsewhere<br>이름이 다른 곳에 존재합니다. | Wrong scope or missing import<br>범위가 잘못되었거나 가져오기가 누락되었습니다. |
| P4: Syntax error<br>P4: 구문 오류 | Invalid declaration syntax<br>잘못된 선언 구문 | Declaration syntax rejected<br>선언 구문이 거부되었습니다. |

---

## Fix Options
## 수정 옵션

### P1: Fix Typo (Most Common)
### P1: 오타 수정(가장 일반적임)

Search for similar names in the file with edit distance <= 2.
편집 거리 <= 2인 파일에서 유사한 이름을 검색합니다.

```verilog
// Before - typo: 'data_vaild' instead of 'data_valid'
wire [7:0] data_valid;
assign out = data_vaild;  // ERROR: [Synth 8-36] 'data_vaild' is not declared
```

```diff
- assign out = data_vaild;
+ assign out = data_valid;   // fix typo
```

### P2: Add Missing Declaration
### P2: 누락된 선언 추가

Infer type from usage context:
사용 맥락에서 유형을 추론합니다.
- Used on LHS of `<=` inside `always @(posedge ...)` -> `reg`
- `always @(posedge ...)` -> `reg` 내부 `<=`의 LHS에 사용됩니다.
- Used on LHS of `=` inside `always @(*)` -> `reg`
- `always @(*)` -> `reg` 내부 `=`의 LHS에 사용됩니다.
- Used only on RHS or in `assign` RHS -> `wire`
- RHS 또는 `할당` RHS -> `와이어`에서만 사용됩니다.

```verilog
// Before - signal used but never declared
always @(posedge clk)
  data_out <= data_in & mask;  // ERROR: 'mask' is not declared
```

```diff
+ reg [7:0] mask;         // add missing declaration
+
  always @(posedge clk)
    data_out <= data_in & mask;
```

### P3: Fix Scope Issue (VHDL)
### P3: 범위 문제 수정(VHDL)

```vhdl
-- Before - package not imported
signal my_sig : my_custom_type;  -- ERROR: 'my_custom_type' is not declared
```

```diff
+ use work.my_package.all;
+
  signal my_sig : my_custom_type;
```

### P4: Fix Invalid Declaration Syntax
### P4: 잘못된 선언 구문 수정

```verilog
// Before - invalid syntax (scalared with signed)
reg scalared signed [3:0] my_reg;  // ERROR: declaration syntax rejected

// After - use valid syntax
reg signed [3:0] my_reg;
```
