# 8-10848: Illegal Operator for Real
# 8-10848: 실수에 대한 잘못된 연산자

**Message:** `[Synth 8-10848] illegal operator '===' for real expression`
**메시지:** `[Synth 8-10848] 실제 표현에 대한 잘못된 연산자 '==='`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10848] illegal operator '===' for real expression [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

The `===` (case equality) operator is used on `real`/`shortreal` types, which only support `==` and `!=`.
`===`(대소문자 동일) 연산자는 `==` 및 `!=`만 지원하는 `real`/`shortreal` 유형에 사용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: === used on a real type
### P1: === 실제 유형에 사용됨

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: case equality on real type
if (type(f0) === type(real))  // ERROR: === not valid for real
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use == for real comparison
if (f0 == 0.0)  // use == for real types
// Note: type() operator is also simulation-only
```

---

## Fix Strategy
## 전략 수정

1. Use `==`/`!=` for `real`/`shortreal` comparisons — `===`/`!==` (4-state case equality) apply only to integral types.
1. `real`/`shortreal` 비교에는 `==`/`!=`를 사용하세요 — `===`/`!==`(4-상태 대소문자 동일)은 정수 유형에만 적용됩니다.
2. Remember `real` is not synthesizable; move real comparisons to simulation or use fixed-point integers.
2. '진짜'는 합성할 수 없다는 것을 기억하세요. 실제 비교를 시뮬레이션으로 옮기거나 고정 소수점 정수를 사용하십시오.
3. For fixed-point hardware, compare the scaled integer representations with `==`.
3. 고정 소수점 하드웨어의 경우 스케일링된 정수 표현을 '=='와 비교하세요.
4. Verify no metavalue (`x`/`z`) semantics were relied upon for reals.
4. 실제에 의존하는 메타값(`x`/`z`) 의미 체계가 없는지 확인하세요.
