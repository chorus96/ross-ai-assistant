# 8-6774: Null subtype or type declaration found
# 8-6774: Null 하위 유형 또는 유형 선언이 발견되었습니다.

**Message:** `[Synth 8-6774] Null subtype or type declaration found`
**메시지:** `[Synth 8-6774] Null 하위 유형 또는 유형 선언이 발견되었습니다`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A subtype/type declaration resolves to a **null range** (zero or negative
하위 유형/유형 선언은 **null 범위**(0 또는 음수)로 확인됩니다.
length) — for example a vector `(C_WIDTH-1 downto 0)` where the width parameter
길이) — 예를 들어 너비 매개변수가 있는 벡터 `(C_WIDTH-1 downto 0)`
is `0`.
The resulting object has no bits.
결과 개체에는 비트가 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Null-range subtype declaration
### P1: Null 범위 하위 유형 선언

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Problematic line:
signal FaultInjectData          : std_logic_vector (C_S_AXI_DATA_WIDTH-1 downto 0) := (others => '0');
signal FaultInjectECC           : std_logic_vector (C_ECC_WIDTH-1 downto 0) := (others => '0');         -- Specific to BRAM data width
signal FaultInjectECC_i         : std_logic_vector (C_INT_ECC_WIDTH-1 downto 0) := (others => '0');     -- Specific to BRAM data width
```

**Recommended Fix:**
**권장 수정 사항:**
```vhdl
-- Ensure the width parameter is > 0 (valid non-zero generic/default)
constant C_ECC_WIDTH : integer := 8;   -- was 0 -> null range
signal FaultInjectECC : std_logic_vector(C_ECC_WIDTH-1 downto 0) := (others => '0');
```

---

## Fix Strategy
## 전략 수정

Add explicit type conversions or change declarations to compatible types.
명시적 유형 변환을 추가하거나 선언을 호환 유형으로 변경하세요.
