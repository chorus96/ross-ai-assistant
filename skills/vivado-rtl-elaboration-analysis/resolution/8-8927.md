# 8-8927: Not a Valid Constant Function Call
# 8-8927: 유효한 상수 함수 호출이 아닙니다.

**Message:** `[Synth 8-8927] 'max' is not a valid constant function call`
**메시지:** `[Synth 8-8927] 'max'는 유효한 상수 함수 호출이 아닙니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

Function call in constant context references a non-constant-evaluable function.
상수 컨텍스트의 함수 호출은 상수가 아닌 평가 가능 함수를 참조합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Non-constant function in localparam
### P1: localparam의 상수가 아닌 함수

**Problematic Code:**
**문제가 있는 코드:**
```diff
localparam P = max(A,B);  // ERROR: max not constant-evaluable
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
function integer max(input integer a,b); max=(a>b)?a:b; endfunction
localparam P = max(A,B);  // now max is pure constant function
```

---

## Fix Strategy
## 전략 수정

1. Define the function used in a `localparam`/constant as a **pure** constant function (no system tasks, delays, events, or hierarchical refs).
1. `localparam`/상수에 사용되는 함수를 **순수한** 상수 함수(시스템 작업, 지연, 이벤트 또는 계층적 참조 없음)로 정의합니다.
2. Ensure all arguments are compile-time constants so the call is elaboration-evaluable.
2. 모든 인수가 컴파일 타임 상수인지 확인하여 호출을 자세히 평가할 수 있도록 하세요.
3. Keep the body simple (arithmetic/comparison only) so it can be folded to a constant.
3. 본문을 단순하게 유지(산술/비교만)하여 상수로 접을 수 있습니다.
4. Confirm the function is declared before its use in the constant expression.
4. 상수 표현식에서 사용하기 전에 함수가 선언되었는지 확인하세요.
