# 8-324: Index Out of Range
# 8-324: 인덱스가 범위를 벗어났습니다.

**Message:** `[Synth 8-324] index out of range`
**메시지:** `[Synth 8-324] 인덱스가 범위를 벗어났습니다.`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An array index exceeds the declared bounds.
배열 인덱스가 선언된 범위를 초과했습니다.
Vivado warns but may still synthesize with truncation.
Vivado는 경고하지만 여전히 잘림으로 합성될 수 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Index outside declared range
### P1: 선언된 범위 밖의 인덱스

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: index 32 on 32-bit vector (valid: 0-31)
sig(32) <= '1';  -- WARNING: out of range
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use valid index
sig(31) <= '1';  -- within 0..31
```
