# 8-10661: Dynamic Range Not Allowed
# 8-10661: 동적 범위가 허용되지 않음

**Message:** `[Synth 8-10661] dynamic range is not allowed in this mode of Verilog`
**메시지:** `[Synth 8-10661] Verilog의 이 모드에서는 동적 범위가 허용되지 않습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10661] dynamic range is not allowed in this mode of Verilog [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A dynamic (runtime) array range is used in a context that requires Verilog-2001 compatibility.
동적(런타임) 배열 범위는 Verilog-2001 호환성이 필요한 상황에서 사용됩니다.
Use SystemVerilog mode or remove the dynamic range.
SystemVerilog 모드를 사용하거나 동적 범위를 제거하십시오.

---

## Common Patterns
## 일반적인 패턴

### P1: Dynamic range in Verilog mode
### P1: Verilog 모드의 동적 범위

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: dynamic range in Verilog mode
real variable [];  // ERROR: dynamic range not allowed in Verilog
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use fixed-size array or enable SystemVerilog
real variable [0:7];   // fixed size
// Or compile with -sv flag:
// read_verilog -sv file.v
```

---

## Fix Strategy
## 전략 수정

Use fixed-size arrays for Verilog mode.
Verilog 모드에는 고정 크기 배열을 사용합니다.
For dynamic arrays, compile with `read_verilog -sv` to enable SystemVerilog.
동적 배열의 경우 `read_verilog -sv`로 컴파일하여 SystemVerilog를 활성화합니다.
