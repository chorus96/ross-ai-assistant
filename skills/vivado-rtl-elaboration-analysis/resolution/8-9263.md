# 8-9263: Cannot Open Include File
# 8-9263: 포함 파일을 열 수 없습니다.

**Message:** `[Synth 8-9263] cannot open include file '!%1!'`
**메시지:** `[Synth 8-9263]은 포함 파일 '!%1!'을 열 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-9263] cannot open include file 'i2c_master_defines.v' [/path/to/file.v:12]
```

---

## Root Cause
## 근본 원인

A `` `include `` directive references a file that synthesis cannot find or open.
````include`` 지시문은 합성이 찾거나 열 수 없는 파일을 참조합니다.
Common causes:
일반적인 원인:
- The path or filename is wrong (typo, wrong extension, wrong case).
- 경로 또는 파일 이름이 잘못되었습니다(오타, 잘못된 확장명, 잘못된 대소문자).
- The include file exists but its directory is not on the synthesis include search path.
- 포함 파일이 존재하지만 해당 디렉터리가 합성 포함 검색 경로에 없습니다.
- The file was never added to the project / file list.
- 파일이 프로젝트/파일 목록에 추가되지 않았습니다.
- A relative path is resolved from an unexpected working directory.
- 예상치 못한 작업 디렉터리에서 상대 경로가 확인되었습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Wrong path or filename
### P1: 잘못된 경로 또는 파일 이름

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: file not found on include path
`include "i2c_master_defines.v"   // ERROR: cannot open include file
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: correct the relative path (or filename/case) to the actual location
`include "../include/i2c_master_defines.v"
```

### P2: Include directory not on the search path
### P2: 검색 경로에 없는 디렉터리 포함

The `` `include `` name is correct, but its folder is not searched.
````include`` 이름은 정확하지만 해당 폴더는 검색되지 않습니다.
Add the directory
디렉터리 추가
to the synthesis include path instead of editing the RTL:
RTL을 편집하는 대신 합성 포함 경로에:

```tcl
# Project mode: add the include directory
set_property include_dirs [list ./include ./rtl/defines] [get_filesets sources_1]

# Non-project mode: pass it to read_verilog / synth_design
read_verilog -sv -include_dirs {./include ./rtl/defines} top.v
```

### P3: File missing from the project / file list
### P3: 프로젝트/파일 목록에서 파일이 누락되었습니다.

The header exists on disk but was never added.
헤더가 디스크에 있지만 추가된 적이 없습니다.
Add it so the tool can resolve it:
도구에서 문제를 해결할 수 있도록 추가하세요.

```tcl
add_files ./include/i2c_master_defines.v
```

## Fix Strategy
## 전략 수정

1. Confirm the include file exists and note its exact name, extension, and case.
1. 포함 파일이 있는지 확인하고 정확한 이름, 확장자 및 대소문자를 기록해 두십시오.
2. If the name is correct, add its directory to the synthesis include path (P2) rather
2. 이름이 정확하면 해당 디렉토리를 합성 포함 경로(P2)에 추가하십시오.
than hard-coding a long relative path.
긴 상대 경로를 하드 코딩하는 것보다.
3. If the file is missing from the project/file list, add it (P3).
3. 프로젝트/파일 목록에서 파일이 누락된 경우 해당 파일을 추가하세요(P3).
4. Only edit the `` `include `` path in RTL when the reference itself is wrong (P1).
4. 참조 자체가 잘못된 경우(P1) RTL에서 ``include `` 경로만 편집하세요.
5. Re-run elaboration; because parsing aborts at the failed include, this error usually
5. 정교화를 다시 실행하십시오. 포함 실패 시 구문 분석이 중단되기 때문에 일반적으로 이 오류는
cascades into `8-12188 Failed to read verilog` — fixing the include clears both.
'8-12188 Verilog를 읽지 못했습니다'로 계단식으로 표시됩니다. 포함을 수정하면 둘 다 지워집니다.

## Related Messages
## 관련 메시지

- `8-12188` Failed to read verilog — downstream effect of the failed include.
- `8-12188` Verilog를 읽지 못했습니다. 실패한 포함의 다운스트림 효과입니다.
- `8-10157` use of undefined macro — a macro defined in the missing include is then undefined.
- `8-10157` 정의되지 않은 매크로 사용 — 누락된 포함에 정의된 매크로는 정의되지 않습니다.
