# 8-10387: Implicit Port with Missing Extern
# 8-10387: Extern이 누락된 암시적 포트

**Message:** `[Synth 8-10387] .* is not allowed in a port list without declaration of extern`
**메시지:** `[Synth 8-10387] .*는 extern 선언 없이 포트 목록에 허용되지 않습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10387] .* is not allowed in a port list without declaration of extern [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A module uses `.*` implicit port connections but the `extern` module declaration is not visible or has mismatched ports.
모듈이 `.*` 암시적 포트 연결을 사용하지만 `extern` 모듈 선언이 표시되지 않거나 포트가 일치하지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: .* with missing/mismatched extern
### P1: .* extern이 누락/일치하지 않음

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: .* without visible extern declaration
extern module extMod(input .in1({in11}), ...);
module extMod(.*);              // ERROR: .* needs matching extern
  bit signed [16:1] in11;
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use explicit port declarations
module extMod(
  input bit signed [16:1] in11,
  input shortint in2,
  output bit signed [16:1] out11,
  output shortint out2
);
```

---

## Fix Strategy
## 전략 수정

1. Ensure the `extern` module declaration is visible and its port list exactly matches the module definition before using `.*`.
1. `.*`를 사용하기 전에 `extern` 모듈 선언이 표시되고 해당 포트 목록이 모듈 정의와 정확히 일치하는지 확인하세요.
2. If mismatches persist, replace `.*` with explicit named port connections so each connection is verified.
2. 불일치가 지속되면 '.*'를 명시적으로 명명된 포트 연결로 바꿔 각 연결이 확인되도록 하세요.
3. Confirm the module and its `extern` prototype have identical port names, directions, and widths.
3. 모듈과 'extern' 프로토타입의 포트 이름, 방향, 너비가 동일한지 확인하세요.
4. Add the file containing the definition/`extern` to the compile so it elaborates first.
4. 정의/`extern`이 포함된 파일을 컴파일에 추가하여 먼저 자세히 설명합니다.
