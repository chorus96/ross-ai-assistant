# 8-8892: Already Declared in Region
# 8-8892: 이미 지역에 선언됨

**Message:** `[Synth 8-8892] '!%1!' is already declared in this region`
**메시지:** `[Synth 8-8892] '!%1!' 이 지역에는 이미 선언되어 있습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL identifier is declared twice in the same declarative region.
VHDL 식별자는 동일한 선언 영역에서 두 번 선언됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Duplicate declaration in one region
### P1: 한 지역에서 중복 선언

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: duplicate library declaration
library work;
library work;  -- ERROR: already declared
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: remove duplicate
library work;  -- single declaration
```

---

## Fix Strategy
## 전략 수정

1. Remove the redundant declaration from the declarative region (e.g., a repeated `library`/`signal`/type declaration).
1. 선언 영역에서 중복 선언을 제거합니다(예: 반복되는 `라이브러리`/`시그널`/유형 선언).
2. If two declarations were intended to differ, give them distinct names or move one to a different scope.
2. 두 선언을 다르게 하려는 경우 고유한 이름을 지정하거나 하나를 다른 범위로 이동하세요.
3. Check for accidental copy-paste duplicates in the same architecture/package.
3. 동일한 아키텍처/패키지에서 실수로 복사-붙여넣기 중복이 있는지 확인하세요.
4. Consolidate to a single canonical declaration and update references accordingly.
4. 단일 표준 선언으로 통합하고 이에 따라 참조를 업데이트합니다.
