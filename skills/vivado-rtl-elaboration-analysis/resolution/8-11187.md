# 8-11187: Subtype in Non-Object Alias
# 8-11187: 비객체 별칭의 하위 유형

**Message:** `[Synth 8-11187] subtype indication may not appear in a non-object alias declaration`
**메시지:** `[Synth 8-11187] 하위 유형 표시가 비객체 별칭 선언에 나타나지 않을 수 있습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL alias for a non-object (e.g., a type or subprogram) includes a subtype indication, which is not allowed.
비객체(예: 유형 또는 하위 프로그램)에 대한 VHDL 별칭에는 허용되지 않는 하위 유형 표시가 포함됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Subtype on a non-object alias
### P1: 비객체 별칭의 하위 유형

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: subtype indication in type alias
alias my_alias : integer is work.pkg.my_type;  -- ERROR
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: remove subtype indication
alias my_alias is work.pkg.my_type;  -- no subtype for non-object alias
```

---

## Fix Strategy
## 전략 수정

1. Remove the subtype indication from a **non-object** alias — only object aliases (signals/variables) may carry one.
1. **비객체** 별칭에서 하위 유형 표시를 제거합니다. 개체 별칭(신호/변수)만이 하위 유형 표시를 가질 수 있습니다.
2. For a non-object alias (subprogram/type/etc.), alias the name directly without a subtype.
2. 객체가 아닌 별칭(하위 프로그램/유형/등)의 경우 하위 유형 없이 이름에 직접 별칭을 지정합니다.
3. If you need a constrained view, alias an object and give it the subtype.
3. 제한된 뷰가 필요한 경우 객체에 별칭을 지정하고 하위 유형을 지정합니다.
4. Verify the alias kind matches the designator you provide.
4. 별칭 종류가 제공한 지정자와 일치하는지 확인하세요.
