# 8-349: Too Many Port Connections
# 8-349: 포트 연결이 너무 많습니다

**Message:** `[Synth 8-349] instance '!%1!' of module '!%2!' passed !%3! connections, but takes just !%4!`
**메시지:** `[Synth 8-349] 인스턴스 '!%1!' 모듈 '!%2!' 통과했습니다!%3! 연결하지만 !%4!`만 걸립니다.
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A module instance provides more port connections than the module has ports.
모듈 인스턴스는 모듈에 있는 포트보다 더 많은 포트 연결을 제공합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: More connections than module ports
### P1: 모듈 포트보다 더 많은 연결

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: 4 connections for 3-port module
mod3 i1(a, b, c, d);  // ERROR: mod3 only has 3 ports
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: match port count
mod3 i1(a, b, c);  // 3 connections for 3 ports
```

---

## Fix Strategy
## 전략 수정

1. Match the number of connections to the module's actual port count — remove the extra positional connection(s).
1. 연결 수를 모듈의 실제 포트 수와 일치시키십시오. 추가 위치 연결을 제거하십시오.
2. Prefer **named** connections (`.clk(clk), .d(d), ...`) over positional ordering; named connections make count/order errors obvious and self-documenting.
2. 위치 순서보다 **이름이 지정된** 연결(`.clk(clk), .d(d), ...`)을 선호합니다. 명명된 연결은 개수/순서 오류를 명백하게 만들고 자체 문서화합니다.
3. Verify you are instantiating the intended module and a current version of it — a stale definition with fewer ports is a common cause.
3. 의도한 모듈과 해당 모듈의 현재 버전을 인스턴스화하고 있는지 확인하십시오. 포트 수가 적은 오래된 정의가 일반적인 원인입니다.
4. If the extra signal is genuinely needed, add the corresponding port to the module definition rather than forcing it onto the instance.
4. 추가 신호가 실제로 필요한 경우 해당 포트를 인스턴스에 강제로 적용하는 대신 모듈 정의에 추가하십시오.
