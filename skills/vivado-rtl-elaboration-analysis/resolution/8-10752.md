# 8-10752: Hierarchical Path Error in Config
# 8-10752: 구성의 계층적 경로 오류

**Message:** `[Synth 8-10752] hierarchical path of instance should start with one of the specified designs`
**메시지:** `[Synth 8-10752] 인스턴스의 계층적 경로는 지정된 디자인 중 하나로 시작해야 합니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10752] hierarchical path of instance should start with one of the specified designs [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A Verilog config block references an instance path that doesn't match any design specified in the `design` statement.
Verilog 구성 블록은 `design` 문에 지정된 디자인과 일치하지 않는 인스턴스 경로를 참조합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Bad instance path in config
### P1: 구성의 잘못된 인스턴스 경로

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: config with wrong instance path
config cfg;
  design asd;                      // design is 'asd'
  instance test liblist testme;    // ERROR: 'test' not under 'asd'
endconfig
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: match instance path to design
config cfg;
  design test;                     // use correct top design name
  default liblist work;
endconfig
```

---

## Fix Strategy
## 전략 수정

1. Ensure `instance` paths in a `config` block reference instances under the design named in the `design` statement.
1. `design` 문에 명명된 디자인 아래의 `config` 블록 참조 인스턴스에서 `인스턴스` 경로를 확인하세요.
2. Fix hierarchical path typos so each instance exists in the design tree.
2. 각 인스턴스가 디자인 트리에 존재하도록 계층적 경로 오타를 수정합니다.
3. Verify the `design` statement points at the intended top and library.
3. 'design' 문이 의도한 상단과 라이브러리를 가리키는지 확인하세요.
4. Remove config entries for instances that no longer exist.
4. 더 이상 존재하지 않는 인스턴스의 구성 항목을 제거합니다.
