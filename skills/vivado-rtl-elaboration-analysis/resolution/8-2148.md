# 8-2148: Illegal Name in Specification
# 8-2148: 사양에 잘못된 이름이 있습니다.

**Message:** `[Synth 8-2148] illegal name in specification`
**메시지:** `[Synth 8-2148] 사양에 잘못된 이름이 있습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL specification (attribute, configuration, etc.) uses a name that is not valid in that context.
VHDL 사양(특성, 구성 등)이 해당 컨텍스트에서 유효하지 않은 이름을 사용합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Wrong entity class in specification
### P1: 사양의 잘못된 엔터티 클래스

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: illegal name in attribute spec
attribute attr of sig : wrong_kind is value;  -- ERROR
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use correct entity class
attribute attr of sig : signal is value;  -- correct class
```

---

## Fix Strategy
## 전략 수정

1. Use the correct entity class in the specification — `signal`, `variable`, `constant`, `component`, `entity`, `label`, etc. — matching the object the attribute/spec targets.
1. 사양의 올바른 엔터티 클래스(`signal`, `variable`, `constant`, `comComponent`, `entity`, `label` 등)를 사용하여 속성/사양이 대상으로 하는 개체와 일치합니다.
2. Ensure the named object actually exists and is visible in the scope where the specification appears.
2. 명명된 개체가 실제로 존재하고 사양이 나타나는 범위에 표시되는지 확인하세요.
3. For attribute specifications, confirm the attribute is declared before it is specified, and that the value type matches the attribute's type.
3. 속성 사양의 경우 속성이 지정되기 전에 선언되었는지, 값 유형이 속성 유형과 일치하는지 확인하세요.
4. Fix typos in the object name and verify the specification syntax (`attribute <attr> of <name> : <class> is <value>;`).
4. 개체 이름의 오타를 수정하고 사양 구문(`<이름>의 <attr> 속성: <클래스>는 <값>;`)을 확인합니다.
