# 8-10021: Signal of File/Access/Protected Type
# 8-10021: 파일/액세스/보호 유형의 신호

**Message:** `[Synth 8-10021] signal declaration cannot be of a file type, access type or protected type`
**메시지:** `[Synth 8-10021] 신호 선언은 파일 형식, 액세스 유형 또는 보호 유형일 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10021] signal declaration cannot be of a file type, access type or protected type [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

VHDL signal declarations cannot use file, access (pointer), or protected types.
VHDL 신호 선언은 파일, 액세스(포인터) 또는 보호 유형을 사용할 수 없습니다.
These are simulation-only types not synthesizable.
이는 합성할 수 없는 시뮬레이션 전용 유형입니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Signal of file/access/protected type
### P1: 파일/액세스/보호 유형의 신호

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: signal of access type (not synthesizable)
type access_type is access boolean;
signal sig1 : access_type;  -- ERROR
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use a synthesizable type instead
signal sig1 : std_logic;  -- or boolean, integer, etc.
```

---

## Fix Strategy
## 전략 수정

1. Replace file/access/protected-type signals with synthesizable types (`std_logic`, `std_logic_vector`, `integer`, `boolean`, records).
1. 파일/액세스/보호 유형 신호를 합성 가능한 유형(`std_logic`, `std_logic_Vector`, `integer`, `boolean`, records)으로 대체합니다.
2. Access (pointer) types and dynamic/linked structures are not synthesizable — model data with fixed-size arrays/records instead.
2. 액세스(포인터) 유형과 동적/연결된 구조는 합성할 수 없습니다. 대신 고정 크기 배열/레코드를 사용하여 데이터를 모델화합니다.
3. Keep any genuine file/access/protected usage in simulation-only code, out of the synthesized path.
3. 시뮬레이션 전용 코드의 실제 파일/액세스/보호된 사용을 합성 경로 외부에 유지하세요.
4. For shared state (protected types), use signals with explicit synchronization logic.
4. 공유 상태(보호 유형)의 경우 명시적인 동기화 로직이 포함된 신호를 사용하세요.
