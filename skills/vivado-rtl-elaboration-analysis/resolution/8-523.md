# 8-523: Part-Select Error
# 8-523: 부품 선택 오류

**Message:** `[Synth 8-523] part-select [!%1!:!%2!] does not match declaration`
**메시지:** `[Synth 8-523] 부분 선택 [!%1!:!%2!]가 선언과 일치하지 않습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A Verilog part-select has an issue — invalid range, non-constant bounds, or out of bounds.
Verilog 부분 선택에는 유효하지 않은 범위, 일정하지 않은 범위 또는 범위를 벗어난 문제가 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Part-select out of declared bounds
### P1: 선언된 범위를 벗어난 부분 선택

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: invalid part-select
wire [7:0] data;
assign out = data[10:8];  // ERROR: out of range
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: fix range
assign out = data[7:5];  // within 0..7 bounds
```

---

## Fix Strategy
## 전략 수정

1. Keep part-select bounds within the signal's declared range (for `[7:0]`, valid indices are `0..7`).
1. 신호의 선언된 범위(`[7:0]`의 경우 유효한 인덱스는 `0..7`) 내에서 부분 선택 범위를 유지합니다.
2. Use **constant** bounds for fixed part-selects; for a variable base, use an indexed part-select with constant width (`data[base +: 4]` / `data[base -: 4]`).
2. 고정된 부분 선택에는 **상수** 경계를 사용하세요. 가변 베이스의 경우 일정한 너비(`data[base +: 4]` / `data[base -: 4]`)를 사용하여 인덱스된 부분 선택을 사용합니다.
3. If a wider slice is genuinely needed, widen the signal declaration to match.
3. 더 넓은 슬라이스가 정말로 필요한 경우 일치하도록 신호 선언을 넓힙니다.
4. Check for off-by-one on the MSB and confirm the slice direction matches the declaration.
4. MSB에서 off-by-one을 확인하고 슬라이스 방향이 선언과 일치하는지 확인합니다.
