# 8-6901: identifier '!%1!' is used before its declaration
# 8-6901: 식별자 '!%1!' 선언 전에 사용됩니다.

**Message:** `[Synth 8-6901] identifier '!%1!' is used before its declaration`
**메시지:** `[Synth 8-6901] 식별자 '!%1!' 선언 전에 사용됩니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An identifier is referenced before it is declared in the same scope.
식별자는 동일한 범위에서 선언되기 전에 참조됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Identifier used before its declaration
### P1: 선언 전에 사용된 식별자

**Problematic Code:**
**문제가 있는 코드:**
```verilog
assign y = a;
wire a;   // declared after use
```

**Recommended Fix:**
**권장 수정 사항:**
```verilog
wire a;
assign y = a;   // declare before use
```

---

## Fix Strategy
## 전략 수정

1. Move the declaration above its first use.
1. 선언을 첫 번째 사용 위로 이동합니다.
2. Order declarations before references within a scope.
2. 범위 내에서 참조 앞에 선언 순서를 지정하세요.
3. Check for a typo that misses the real declaration.
3. 실제 선언을 놓친 오타가 있는지 확인하세요.
