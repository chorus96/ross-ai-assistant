# 8-11584: Unconnected Pin
# 8-11584: 연결되지 않은 핀

**Message:** `[Synth 8-11584] pin !%1! is connected to multiple driven net where the other driver is constant`
**메시지:** `[Synth 8-11584] pin !%1! 다른 드라이버가 일정한 다중 구동 넷에 연결됩니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A port is left unconnected or has a connection error.
포트가 연결되지 않은 채로 남아 있거나 연결 오류가 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Unconnected pin
### P1: 연결되지 않은 핀

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: pin connection error
my_mod inst(.in1(data), .out1());  // ERROR: empty connection
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: connect or properly leave open
my_mod inst(.in1(data), .out1(result));  // connect
// Or for unused output:
my_mod inst(.in1(data));  // omit unneeded output
```

---

## Fix Strategy
## 전략 수정

1. Connect the pin/port to the intended signal; an unconnected pin often means a missing wire in the parent.
1. 핀/포트를 의도된 신호에 연결하십시오. 연결되지 않은 핀은 종종 상위에 와이어가 없음을 의미합니다.
2. For unused inputs, tie to a defined constant; omit unused outputs entirely rather than using empty parentheses.
2. 사용되지 않는 입력의 경우 정의된 상수에 연결합니다. 빈 괄호를 사용하는 대신 사용되지 않는 출력을 완전히 생략합니다.
3. Prefer named connections so unconnected pins are deliberate and visible.
3. 연결되지 않은 핀이 의도적으로 표시되도록 명명된 연결을 선호합니다.
4. Verify the instantiated cell/module version matches the expected pin list.
4. 인스턴스화된 셀/모듈 버전이 예상 핀 목록과 일치하는지 확인합니다.
