# 8-9448: $unit(전역) 범위에 추가 세미콜론

## Root Cause
## 근본 원인

An extra semicolon appears at the compilation-unit ($unit/global) scope.
컴파일 단위($unit/global) 범위에 추가 세미콜론이 나타납니다.

## 일반적인 패턴

### P1: $unit 범위의 추가 세미콜론

```systemverilog

```

**Recommended Fix:**
**권장 수정 사항:**
```systemverilog
// remove the stray global-scope semicolon
```

---

## Fix Strategy
## 전략 수정

1. Remove the extra semicolon at global scope.
1. 전역 범위에서 추가 세미콜론을 제거합니다.
2. Keep only real declarations at $unit scope.
2. $unit 범위에서는 실제 선언만 유지하세요.
3. Check for a leftover `;` after an include/define.
3. 포함/정의 후에 남은 `;`이 있는지 확인하세요.
