# 8-10632: Declaration in Unnamed Block
# 8-10632: 이름 없는 블록의 선언

**Message:** `[Synth 8-10632] declarations are not allowed in an unnamed block`
**메시지:** `[Synth 8-10632] 선언은 이름이 지정되지 않은 블록에서 허용되지 않습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10632] declarations are not allowed in an unnamed block [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

Parameters or other declarations are placed inside an unnamed `begin`/`end` block (e.g., inside `initial` or `always`).
매개변수 또는 기타 선언은 이름이 지정되지 않은 `begin`/`end` 블록 내부에 배치됩니다(예: `initial` 또는 `always` 내부).

---

## Common Patterns
## 일반적인 패턴

### P1: Declaration in an unnamed block
### P1: 이름 없는 블록에 선언

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: parameter inside unnamed initial block
initial begin
  parameter p1 = 1;  // ERROR: not allowed in unnamed block
end
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: move declaration to module scope or name the block
parameter p1 = 1;    // move to module level
initial begin
  // use p1 here
end
// Or name the block:
initial begin : my_block
  localparam p1 = 1;  // allowed in named block
end
```

---

## Fix Strategy
## 전략 수정

Move declarations to module scope, or give the block a name.
선언을 모듈 범위로 이동하거나 블록에 이름을 지정합니다.
Only named blocks can contain local declarations.
명명된 블록에만 로컬 선언이 포함될 수 있습니다.
