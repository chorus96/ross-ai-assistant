# 8-11077: partially associated formal '!%1!' cannot have actual 'open'
# 8-11077: 부분적으로 연관된 형식 '!%1!' 실제 '열기'를 가질 수 없습니다

**Message:** `[Synth 8-11077] partially associated formal '!%1!' cannot have actual 'open'`
**메시지:** `[Synth 8-11077] 부분적으로 연관된 형식 '!%1!' 실제 '열기'를 가질 수 없습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A formal that is associated in parts (e.g. individual bits/elements) is also associated with `open`, which is not allowed.
부분(예: 개별 비트/요소)과 연관된 형식도 'open'과 연관되어 허용되지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Partially associated formal cannot have 'open' actual
### P1: 부분적으로 연관된 형식은 '개방형' 실제를 가질 수 없습니다.

**Problematic Code:**
**문제가 있는 코드:**
```vhdl
port map ( d(0) => a, d(1) => open );  -- partial + open
```

**Recommended Fix:**
**권장 수정 사항:**
```vhdl
port map ( d(0) => a, d(1) => '0' );   -- drive every associated part
```

---

## Fix Strategy
## 전략 수정

1. Do not mix element-wise association with `open` for the same formal.
1. 동일한 형식에 대해 요소별 연관과 `open`을 혼합하지 마십시오.
2. Either associate the whole formal, or drive every element explicitly.
2. 전체 형식을 연관시키거나 모든 요소를 ​​명시적으로 구동하십시오.
3. Use `open` only for a fully-unassociated formal.
3. 완전히 연관되지 않은 형식에만 'open'을 사용하세요.
