# 8-10334: VHDL Operator in Verilog
# 8-10334: Verilog의 VHDL 연산자

**Message:** `[Synth 8-10334] keyword is not allowed in this dialect; use SystemVerilog mode instead`
**메시지:** `[Synth 8-10334] 키워드는 이 방언에서 허용되지 않습니다. 대신 SystemVerilog 모드를 사용하세요`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10334] keyword is not allowed in this dialect; use SystemVerilog mode instead [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A VHDL-style operator (`or`, `xor`, `and`) is used in Verilog port connections or expressions.
VHDL 스타일 연산자(`or`, `xor`, `and`)는 Verilog 포트 연결 또는 표현식에 사용됩니다.
Use Verilog operators instead.
대신 Verilog 연산자를 사용하십시오.

---

## Common Patterns
## 일반적인 패턴

### P1: VHDL keyword operator in Verilog
### P1: Verilog의 VHDL 키워드 연산자

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: VHDL operator in Verilog
myff ff1(.reset(reset1 xor reset2));  // ERROR: 'xor' not allowed
myff ff2(.reset(reset1 or reset2));   // ERROR: 'or' not allowed
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use Verilog operators
myff ff1(.reset(reset1 ^ reset2));    // ^ for xor
myff ff2(.reset(reset1 | reset2));    // | for or
```

---

## Fix Strategy
## 전략 수정

1. In Verilog files, use Verilog operators (`^`, `|`, `&`, `~`) instead of VHDL keywords (`xor`, `or`, `and`, `not`).
1. Verilog 파일에서는 VHDL 키워드(`xor`, `or`, `and`, `not`) 대신 Verilog 연산자(`^`, `|`, `&`, `~`)를 사용합니다.
2. If the code is genuinely SystemVerilog, compile it in SystemVerilog mode (`read_verilog -sv` or set file type to SV).
2. 코드가 진짜 SystemVerilog라면 SystemVerilog 모드(`read_verilog -sv` 또는 파일 유형을 SV로 설정)에서 컴파일하세요.
3. Check port-connection expressions for stray VHDL-style keywords.
3. 길을 잃은 VHDL 스타일 키워드에 대한 포트 연결 표현식을 확인하세요.
4. Keep language dialects consistent per file to avoid keyword-context errors.
4. 키워드 컨텍스트 오류를 ​​방지하려면 파일별로 언어 방언을 일관되게 유지하세요.
