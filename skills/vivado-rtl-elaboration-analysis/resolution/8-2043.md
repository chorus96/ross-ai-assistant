# 8-2043: Formal Port/Generic Not Declared
# 8-2043: 공식 포트/일반이 선언되지 않음

**Message:** `[Synth 8-2043] formal port/generic <!%1!> is not declared in <!%2!>`
**메시지:** `[Synth 8-2043] 공식 포트/일반 <!%1!>이 <!%2!>에 선언되지 않았습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL port map or generic map references a formal name that doesn't exist in the entity.
VHDL 포트 맵 또는 일반 맵이 엔터티에 존재하지 않는 공식 이름을 참조합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Reference to an undeclared formal
### P1: 선언되지 않은 형식에 대한 참조

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: referencing non-existent formal
entity bot is port(a : in std_logic); end;
-- instantiation:
port map(t1 => sig);  -- ERROR: 't1' not declared in bot
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use correct formal name
port map(a => sig);  -- 'a' matches entity declaration
```

---

## Fix Strategy
## 전략 수정

1. Open the entity declaration and use only the port/generic names it actually declares (names are case-insensitive in VHDL but must exist).
1. 엔터티 선언을 열고 실제로 선언된 포트/일반 이름만 사용합니다(이름은 VHDL에서 대/소문자를 구분하지 않지만 존재해야 함).
2. Fix the typo in the offending formal name in the `port map`/`generic map`.
2. `포트 맵`/`일반 맵`에서 문제가 되는 공식 이름의 오타를 수정하세요.
3. Verify you are binding the intended, current entity/component; a stale component declaration with different formals is a common cause.
3. 의도한 현재 엔터티/구성 요소를 바인딩하고 있는지 확인하세요. 일반적인 원인은 형식이 다른 오래된 구성 요소 선언입니다.
4. Prefer named association so mismatched formals are caught immediately, and remove associations to formals that no longer exist.
4. 일치하지 않는 형식을 즉시 발견하고 더 이상 존재하지 않는 형식에 대한 연관을 제거하도록 명명된 연관을 선호합니다.
