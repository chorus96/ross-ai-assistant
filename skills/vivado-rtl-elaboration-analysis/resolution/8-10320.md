# 8-10320: Invalid Modport Member
# 8-10320: 잘못된 Modport 구성원

**Message:** `[Synth 8-10320] cannot be listed in a modport`
**메시지:** `[Synth 8-10320]은 모드포트에 나열될 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10320] cannot be listed in a modport [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A SystemVerilog modport lists an interface instance as a member, which is not directly allowed.
SystemVerilog modport는 인터페이스 인스턴스를 멤버로 나열하지만 이는 직접적으로 허용되지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Interface instance in a modport
### P1: 모드포트의 인터페이스 인스턴스

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: interface instance in modport
interface intr;
  nest n1();
  modport M(input c, n1);  // ERROR: n1 is interface instance, not a signal
endinterface
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: reference modport of nested interface
interface intr;
  nest n1();
  modport M(input c, n1.A);  // reference specific modport of nested interface
endinterface
```

---

## Fix Strategy
## 전략 수정

1. List only signals or **modport references of nested interfaces** in a modport — not a bare interface instance.
1. 기본 인터페이스 인스턴스가 아닌 신호 또는 **중첩 인터페이스의 모드포트 참조**만 모드포트에 나열합니다.
2. Reference a nested interface's modport explicitly (`modport M(input c, n1.A);`).
2. 중첩된 인터페이스의 modport를 명시적으로 참조합니다(`modport M(input c, n1.A);`).
3. Add the actual signals you need to the interface and list those in the modport.
3. 필요한 실제 신호를 인터페이스에 추가하고 해당 신호를 modport에 나열하십시오.
4. Verify the nested interface's modport directions match the intended usage.
4. 중첩된 인터페이스의 모드포트 방향이 의도한 용도와 일치하는지 확인하세요.
