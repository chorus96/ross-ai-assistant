# 8-9652: Indexed Name Not Correct Type
# 8-9652: 색인화된 이름이 올바르지 않은 유형입니다.

**Message:** `[Synth 8-9652] indexed name is not the expected type`
**메시지:** `[Synth 8-9652] 색인화된 이름이 예상된 유형이 아닙니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An indexed array access produces a type different from what's expected.
인덱스 배열 액세스는 예상한 것과 다른 유형을 생성합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Double-index on a 1D array
### P1: 1D 배열의 이중 인덱스

**Problematic Code:**
**문제가 있는 코드:**
```diff
signal v : std_logic_vector(7 downto 0);
v(0)(1) <= '1';  -- ERROR: v(0) is std_logic, not vector
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
v(1) <= '1';  -- single index on 1D array
```

---

## Fix Strategy
## 전략 수정

1. Match the number of index operations to the array's dimensionality — a 1D vector takes one index (`v(i)`), not two.
1. 인덱스 작업 수를 배열의 차원과 일치시킵니다. 1D 벡터는 두 개가 아닌 하나의 인덱스(`v(i)`)를 사용합니다.
2. Check the declaration: a `std_logic_vector` element is a scalar `std_logic`, so `v(i)` cannot be indexed again.
2. 선언을 확인하세요. `std_logic_Vector` 요소는 스칼라 `std_logic`이므로 `v(i)`를 다시 인덱싱할 수 없습니다.
3. For arrays-of-vectors, index the outer dimension then the inner (`a(i)(j)`) per the declared structure.
3. 벡터 배열의 경우 선언된 구조별로 외부 차원을 인덱싱한 다음 내부 차원(`a(i)(j)`)을 인덱싱합니다.
4. Fix accesses that assumed extra dimensions after a declaration change.
4. 선언 변경 후 추가 차원을 가정하는 액세스를 수정합니다.
