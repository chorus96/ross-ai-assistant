# 8-9223: cannot call side-effect procedure '!%1!' from within pure function ...
# 8-9223: 부작용 프로시저 '!%1!'을 호출할 수 없습니다. 순수 함수 내에서 ...

**Message:** `[Synth 8-9223] cannot call side-effect procedure '!%1!' from within pure function '!%2!'`
**메시지:** `[Synth 8-9223]은 부작용 프로시저 '!%1!'을 호출할 수 없습니다. 순수 함수 '!%2!'` 내에서
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A pure function calls a procedure with side effects, which pure functions may not do.
순수 함수는 순수 함수가 수행할 수 없는 부작용이 있는 프로시저를 호출합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Side-effect procedure called from pure function
### P1: 순수 함수에서 호출되는 부작용 프로시저

**Problematic Code:**
**문제가 있는 코드:**
```vhdl
function f return integer is begin do_side_effect(); ... end;
```

**Recommended Fix:**
**권장 수정 사항:**
```vhdl
-- remove the side-effecting call, or make the function impure
```

---

## Fix Strategy
## 전략 수정

1. Do not call side-effecting procedures from a pure function.
1. 순수 함수에서 부작용을 일으키는 프로시저를 호출하지 마세요.
2. Mark the function `impure` if side effects are required.
2. 부작용이 필요한 경우 '불순함' 기능을 표시하세요.
3. Move the side-effect logic outside the function.
3. 부작용 논리를 함수 외부로 이동합니다.
