# 8-2910: Pin Connection Error
# 8-2910: 핀 연결 오류

**Message:** `[Synth 8-2910] pin !%1! has multiple drivers`
**메시지:** `[Synth 8-2910] pin !%1! 여러 드라이버가 있습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A pin/port connection has an error — typically a syntax or type issue in the connection.
핀/포트 연결에 오류가 있습니다. 일반적으로 연결의 구문 또는 유형 문제입니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Mismatched pin/port connection
### P1: 일치하지 않는 핀/포트 연결

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: pin connection error
my_mod inst(.LIN_BUS(bus));  // ERROR: check type/width match
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: ensure correct type and width
wire [7:0] bus;  // match module port width
my_mod inst(.LIN_BUS(bus));
```

---

## Fix Strategy
## 전략 수정

1. Verify the connected signal's type and width match the module port exactly; size the net to the port (`wire [7:0] bus;`).
1. 연결된 신호의 유형과 폭이 모듈 포트와 정확히 일치하는지 확인하십시오. 네트 크기를 포트에 맞게 조정합니다(`wire [7:0] 버스;`).
2. Fix typos in the port name and prefer named connections so mismatches are caught immediately.
2. 포트 이름의 오타를 수정하고 이름이 지정된 연결을 선호하므로 불일치가 즉시 발견됩니다.
3. Check direction compatibility — outputs must connect to nets, inputs to drivable expressions.
3. 방향 호환성을 확인하세요. 출력은 네트에 연결되어야 하고, 입력은 구동 가능한 표현식에 연결되어야 합니다.
4. Confirm you are instantiating the intended, current module version; a stale definition with different pins is a common cause.
4. 의도한 현재 모듈 버전을 인스턴스화하고 있는지 확인하세요. 다른 핀을 사용한 오래된 정의가 일반적인 원인입니다.
