# 8-517: Overlapping Case Choices
# 8-517: 중복되는 케이스 선택

**Message:** `[Synth 8-517] overlapping choice !%1! in case statement`
**메시지:** `[Synth 8-517] 중복 선택 !%1! 경우 진술`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

VHDL case statement has overlapping choices (same value appears in multiple branches).
VHDL 케이스 문에 중복되는 선택 항목이 있습니다(동일한 값이 여러 분기에 나타남).

---

## Common Patterns
## 일반적인 패턴

### P1: Duplicate/overlapping case choice
### P1: 중복/겹치는 케이스 선택

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: overlapping choices
case opcode is
  when NOP_LM => out <= a;
  when NOP_LM => out <= b;  -- ERROR: NOP_LM already used
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: remove duplicate
case opcode is
  when NOP_LM => out <= a;
  when ADD_LM => out <= b;  -- unique choices
```

---

## Fix Strategy
## 전략 수정

1. Make every case choice unique — remove the duplicate branch or change its choice value to the intended one.
1. 모든 사례 선택을 고유하게 만듭니다. 중복 분기를 제거하거나 선택 값을 의도한 값으로 변경합니다.
2. If two branches should share behavior, combine them with the `|` choice list (`when NOP_LM | ADD_LM =>`) instead of repeating the value.
2. 두 분기가 동작을 공유해야 하는 경우 값을 반복하는 대신 `|` 선택 목록(`NOP_LM | ADD_LM =>`)과 결합합니다.
3. Watch for enumeration/constant aliases that resolve to the same value — they also count as overlapping.
3. 동일한 값으로 확인되는 열거형/상수 별칭을 주의 깊게 살펴보세요. 또한 중복되는 것으로 간주됩니다.
4. Ensure ranges in choices (`when 0 to 3`) do not overlap other explicit choices.
4. 선택 항목의 범위('0~3'인 경우)가 다른 명시적 선택 항목과 겹치지 않는지 확인하세요.
