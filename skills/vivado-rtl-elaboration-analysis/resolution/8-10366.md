# 8-10366: New Expression on Non-Class Type
# 8-10366: 비클래스 유형에 대한 새로운 표현식

**Message:** `[Synth 8-10366] 'new' expression can only be assigned to a class/covergroup handle or dynamic array`
**메시지:** `[Synth 8-10366] 'new' 표현식은 클래스/커버 그룹 핸들 또는 동적 배열에만 할당될 수 있습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10366] 'new' expression can only be assigned to a class/covergroup handle or dynamic array [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

The `new` keyword is used to initialize a queue (`$`) which does not support `new`.
`new` 키워드는 `new`를 지원하지 않는 대기열(`$`)을 초기화하는 데 사용됩니다.
Queues are also not synthesizable.
대기열도 합성할 수 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: new used on a queue
### P1: 큐에 사용되는 새로운 것

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: 'new' on queue (not synthesizable)
byte q1[$] = new [6];     // ERROR: queues don't use 'new'
integer q2[$] = new [6];
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use synthesizable array
byte q1 [0:5];             // fixed-size array instead of queue
integer q2 [0:5];
// Or for dynamic arrays (not queues):
// byte q1[] = new[6];
```

---

## Fix Strategy
## 전략 수정

1. `new` applies only to class handles, covergroups, or dynamic arrays — do not use it to size a queue (`[$]`).
1. `new`는 클래스 핸들, 커버 그룹 또는 동적 배열에만 적용됩니다. 대기열(`[$]`)의 크기를 조정하는 데 사용하지 마십시오.
2. Queues and dynamic sizing are not synthesizable; replace the queue with a fixed-size array.
2. 대기열과 동적 크기 조정은 합성할 수 없습니다. 큐를 고정 크기 배열로 교체합니다.
3. If you need a dynamic array in verification code, allocate it with `new[N]` (an array), not on a queue.
3. 인증 코드에 동적 배열이 필요한 경우 대기열이 아닌 `new[N]`(배열)으로 할당하세요.
4. Restructure the storage to a fixed depth appropriate for hardware.
4. 하드웨어에 적합한 고정 깊이로 저장소를 재구성합니다.
