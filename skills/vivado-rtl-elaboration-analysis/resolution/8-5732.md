# 8-5732: Cannot Infer BRAM on Alias
# 8-5732: 별칭에서 BRAM을 추론할 수 없습니다.

**Message:** `[Synth 8-5732] cannot infer block ram on a alias variable reference.
**메시지:** `[Synth 8-5732]는 별칭 변수 참조에서 블록 램을 추론할 수 없습니다.
Use ram_style attribute set to registers`
레지스터로 설정된 ram_style 속성을 사용하십시오.
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

Block RAM inference fails because the array is accessed through an alias or indirect reference.
별칭이나 간접 참조를 통해 어레이에 액세스하기 때문에 블록 RAM 추론이 실패합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: RAM accessed through an alias
### P1: 별칭을 통해 액세스되는 RAM

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: BRAM on alias variable
alias my_ram : ram_type is actual_ram;
my_ram(addr) <= data;
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use direct array reference
actual_ram(addr) <= data;  -- access directly
-- Or use ram_style attribute:
attribute ram_style : string;
attribute ram_style of actual_ram : signal is "registers";
```

---

## Fix Strategy
## 전략 수정

1. Access the memory array **directly** by its declared name/index, not through an `alias` or indirect reference — BRAM inference requires a recognizable memory access.
1. `별칭`이나 간접 참조를 통하지 않고 선언된 이름/인덱스를 통해 **직접** 메모리 배열에 액세스합니다. BRAM 추론에는 인식 가능한 메모리 액세스가 필요합니다.
2. Apply RAM attributes (`ram_style`) to the actual array signal, not to an alias of it.
2. 별칭이 아닌 실제 배열 신호에 RAM 속성(`ram_style`)을 적용합니다.
3. Use a synchronous (registered) read so the access matches a supported BRAM template.
3. 액세스가 지원되는 BRAM 템플릿과 일치하도록 동기(등록된) 읽기를 사용합니다.
4. If the alias is only for readability, remove it and index the real array; if you truly need indirection, that access will map to distributed RAM/registers instead of BRAM.
4. 별칭이 단지 가독성을 위한 것이라면 별칭을 제거하고 실제 배열을 인덱싱하세요. 정말로 간접 참조가 필요한 경우 해당 액세스는 BRAM 대신 분산 RAM/레지스터에 매핑됩니다.
