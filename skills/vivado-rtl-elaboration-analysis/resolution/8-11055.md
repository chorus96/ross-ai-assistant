# 8-11055: Output/Inout in Function
# 8-11055: 함수의 출력/입력

**Message:** `[Synth 8-11055] output and inout are not allowed in functions`
**메시지:** `[Synth 8-11055] 출력 및 입력은 함수에서 허용되지 않습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-11055] output and inout are not allowed in functions [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

Verilog functions cannot have `output` or `inout` arguments — they return a single value.
Verilog 함수는 'output' 또는 'inout' 인수를 가질 수 없으며 단일 값을 반환합니다.
Only `input` is allowed.
'입력'만 허용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: output/inout argument on a function
### P1: 함수의 출력/입력 인수

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: output/inout in function
function test(input [7:0] i, output o, inout io);  // ERROR
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use task for output/inout, or return value
task test(input [7:0] i, output o, inout io);  // change to task
  ...
endtask
// Or for function: use only input and return value
function [7:0] test(input [7:0] i);
  test = i + 1;
endfunction
```

---

## Fix Strategy
## 전략 수정

1. Functions may only have `input` arguments and a return value — convert to a `task` if you need `output`/`inout` arguments.
1. 함수에는 `input` 인수와 반환 값만 있을 수 있습니다. `output`/`inout` 인수가 필요한 경우 `task`로 변환하세요.
2. Alternatively, return a composite type (struct/array) to carry multiple results from a function.
2. 또는 복합 유형(구조체/배열)을 반환하여 함수에서 여러 결과를 전달합니다.
3. Keep functions side-effect free so they map to combinational logic.
3. 함수의 부작용을 방지하여 조합 논리에 매핑되도록 합니다.
4. Update call sites to match the task/function change.
4. 작업/기능 변경에 맞게 호출 사이트를 업데이트합니다.
