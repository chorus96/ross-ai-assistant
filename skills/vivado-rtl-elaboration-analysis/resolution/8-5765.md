# 8-5765: Size Mismatch in Read
# 8-5765: 읽기 크기 불일치

**Message:** `[Synth 8-5765] size mismatch in assignment; read failed`
**메시지:** `[Synth 8-5765] 할당 시 크기 불일치; 읽기 실패`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

VHDL file read operation has a size mismatch between target and data.
VHDL 파일 읽기 작업에 대상과 데이터의 크기가 일치하지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: File read size mismatch
### P1: 파일 읽기 크기 불일치

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: size mismatch in file read
-- read(file_handle, data);  -- data type doesn't match file element
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: file I/O is not synthesizable
-- Remove file operations for synthesis
-- Use ROM inference or constant arrays instead
```

---

## Fix Strategy
## 전략 수정

1. File I/O (`read`/`write`/`file`) is not synthesizable — remove it from synthesizable RTL.
1. 파일 I/O(`read`/`write`/`file`)를 합성할 수 없습니다. 합성 가능한 RTL에서 제거하세요.
2. For memory contents, use ROM inference from a constant array or `$readmemh`/`$readmemb` (Verilog) instead of VHDL file reads.
2. 메모리 내용의 경우 VHDL 파일 읽기 대신 상수 배열 또는 `$readmemh`/`$readmemb`(Verilog)에서 ROM 추론을 사용합니다.
3. Move any genuine file I/O into the testbench/simulation-only code, guarded from synthesis.
3. 실제 파일 I/O를 합성으로부터 보호되는 테스트벤치/시뮬레이션 전용 코드로 옮깁니다.
4. If a width mismatch was the trigger, ensure the read target and file element types have matching sizes in the simulation model.
4. 너비 불일치가 원인인 경우 시뮬레이션 모델에서 읽기 대상 및 파일 요소 유형의 크기가 일치하는지 확인하십시오.
