# 8-10140: unrecognized value for pragma '!%1!'
# 8-10140: pragma '!%1!'에 대한 값을 인식할 수 없습니다.

**Message:** `[Synth 8-10140] unrecognized value for pragma '!%1!'`
**메시지:** `[Synth 8-10140] pragma '!%1!'에 대해 인식할 수 없는 값입니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A synthesis pragma (e.g.
합성 프라그마(예:
`xc_props`) carries a value string that Vivado does not recognize.
`xc_props`)는 Vivado가 인식하지 못하는 값 문자열을 전달합니다.
It is usually a legacy XST/Synplify attribute; Vivado ignores it.
일반적으로 레거시 XST/Synplify 속성입니다. Vivado는 이를 무시합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Unrecognized synthesis pragma value
### P1: 인식할 수 없는 합성 pragma 값

**Problematic Code:**
**문제가 있는 코드:**
```verilog
) /* synthesis xc_props = "BITSLIP_ENABLE = TRUE, DATA_RATE = DDR" */
```

**Recommended Fix:**
**권장 수정 사항:**
```verilog
// Set the properties as real primitive parameters instead of a pragma:
ISERDESE2 #(.DATA_RATE("DDR")) u (/* ... */);
```

---

## Fix Strategy
## 전략 수정

1. Move the settings into real primitive parameters `#(.NAME(value))`, or delete the pragma if unused.
1. 설정을 실제 기본 매개변수 `#(.NAME(value))`로 이동하거나, 사용하지 않는 경우 pragma를 삭제하세요.
2. Replace legacy XST/Synplify attributes with Vivado-native ones where applicable.
2. 해당되는 경우 레거시 XST/Synplify 속성을 Vivado 네이티브 속성으로 교체하세요.
3. This is a warning; synthesis proceeds but the pragma is ignored.
3. 이는 경고입니다. 합성은 진행되지만 pragma는 무시됩니다.
