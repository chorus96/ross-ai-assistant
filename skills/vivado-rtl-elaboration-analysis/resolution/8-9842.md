# 8-9842: Non-Local in Constant Function
# 8-9842: 상수 함수의 비로컬

**Message:** `[Synth 8-9842] non-local identifier may not be used in constant function`
**메시지:** `[Synth 8-9842] 비로컬 식별자는 상수 함수에 사용할 수 없습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A constant function references an identifier from outside its scope.
상수 함수는 해당 범위 외부의 식별자를 참조합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Non-local reference in constant function
### P1: 상수 함수의 비지역 참조

**Problematic Code:**
**문제가 있는 코드:**
```diff
integer array;
function integer max; max = array; endfunction  // ERROR: array is non-local
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
function integer max(input integer arr); max = arr; endfunction  // pass as parameter
```

---

## Fix Strategy
## 전략 수정

1. Pass any external value into a constant function as a **parameter**, not by referencing a non-local identifier.
1. 로컬이 아닌 식별자를 참조하지 않고 외부 값을 **매개변수**로 상수 함수에 전달합니다.
2. Constant functions must be self-contained — they may use only their arguments and locals.
2. 상수 함수는 자체 포함되어야 합니다. 인수와 지역 변수만 사용할 수 있습니다.
3. Refactor the function signature to accept the needed inputs explicitly.
3. 필요한 입력을 명시적으로 허용하도록 함수 시그니처를 리팩터링합니다.
4. Ensure all arguments are elaboration-time constants so the call folds to a constant.
4. 호출이 상수로 접힐 수 있도록 모든 인수가 정교화 시간 상수인지 확인하세요.
