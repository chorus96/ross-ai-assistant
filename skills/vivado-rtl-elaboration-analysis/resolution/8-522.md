# 8-522: Cannot Open VHDL File
# 8-522: VHDL 파일을 열 수 없습니다.

**Message:** `[Synth 8-522] parsing error: !%1!`
**메시지:** `[Synth 8-522] 구문 분석 오류: !%1!`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

Vivado cannot open a VHDL file — file doesn't exist or path is incorrect.
Vivado가 VHDL 파일을 열 수 없습니다. 파일이 존재하지 않거나 경로가 올바르지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Wrong or missing VHDL file path
### P1: VHDL 파일 경로가 잘못되었거나 누락되었습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: wrong file path in read_vhdl
-- read_vhdl src/nonexistent.vhd  -- file not found
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: fix the file path
-- read_vhdl src/correct_filename.vhd
-- Verify the file exists at the specified path
```

---

## Fix Strategy
## 전략 수정

1. Verify the file path in the `read_vhdl`/`add_files` command is correct and the file exists at that location (check relative vs. absolute paths).
1. `read_vhdl`/`add_files` 명령의 파일 경로가 올바른지, 해당 위치에 파일이 있는지 확인하세요(상대 경로와 절대 경로 확인).
2. Confirm read permissions and that the filename case matches exactly (Linux filesystems are case-sensitive).
2. 읽기 권한을 확인하고 파일 이름 대소문자가 정확히 일치하는지 확인하십시오(Linux 파일 시스템은 대소문자를 구분합니다).
3. Ensure the file was not moved, renamed, or left out of the file set / project.
3. 파일이 이동되거나, 이름이 바뀌거나, 파일 세트/프로젝트에서 제외되지 않았는지 확인하세요.
4. If using variables or `glob` in the Tcl flow, echo the resolved path to confirm it points where you expect before reading.
4. Tcl 흐름에서 변수 또는 `glob`을 사용하는 경우 확인된 경로를 에코하여 읽기 전에 예상되는 지점을 확인하세요.
