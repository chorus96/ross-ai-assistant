# 8-11112: Case Question Mark Mismatch
# 8-11112: 대소문자 물음표 불일치

**Message:** `[Synth 8-11112] question mark delimiter should be in both places after keyword 'case'`
**메시지:** `[Synth 8-11112] 물음표 구분 기호는 키워드 '대소문자' 뒤 두 위치에 모두 있어야 합니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-11112] question mark delimiter should be in both places after keyword 'case' [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

VHDL-2008 `case?` (matching case) requires `?` after both `case` and `end case`.
VHDL-2008 `case?`(대소문자 일치)에는 `case`와 `end case` 뒤에 `?`가 필요합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: case? without end case?
### P1: 사건? 엔드케이스 없이?

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: question mark only on 'case', not 'end case'
case ?s is
  when "1-" => out1 <= '1';
end case;      -- ERROR: should be 'end case?'
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: add ? to both
case? s is
  when "1-" => out1 <= '1';
end case?;     -- matching question marks
```

---

## Fix Strategy
## 전략 수정

1. Pair `case?` with `end case?` (both carry the `?`) in VHDL-2008 matching case statements.
1. VHDL-2008 일치 사례 문에서 'case?'를 'end case?'(둘 다 '?' 포함)와 쌍으로 사용합니다.
2. Ensure the tool is in VHDL-2008 mode for `case?` support.
2. 'case?' 지원을 위해 도구가 VHDL-2008 모드인지 확인하세요.
3. If wildcard matching is not needed, use a plain `case`/`end case`.
3. 와일드카드 일치가 필요하지 않은 경우 일반 `case`/`end case`를 사용하세요.
4. Verify the selector is a `std_logic_vector`/`std_ulogic_vector` for `?` don't-care matching.
4. 선택기가 `?` 무상관 일치에 대한 `std_logic_Vector`/`std_ulogic_Vector`인지 확인하세요.
