# 8-3332: Sequential Element Issue
# 8-3332: 순차 요소 문제

**Message:** `[Synth 8-3332] Sequential element`
**메시지:** `[Synth 8-3332] 순차 요소`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A sequential element (flip-flop, FSM state) has unusual behavior — may be constant, removed, or have issues.
순차 요소(플립플롭, FSM 상태)에는 비정상적인 동작이 있습니다. 즉, 일정하거나 제거되거나 문제가 있을 수 있습니다.

## 일반적인 패턴

## Fix Strategy
## 전략 수정

1. Review the flagged register/FSM — a sequential element reported as constant or removed usually means it is never updated or its output is unused.
1. 플래그가 지정된 레지스터/FSM을 검토합니다. 상수로 보고되거나 제거된 순차 요소는 일반적으로 업데이트되지 않거나 해당 출력이 사용되지 않음을 의미합니다.
2. Ensure the FSM has a proper reset that initializes the state, and that all states are reachable via the transition logic.
2. FSM에 상태를 초기화하는 적절한 재설정이 있고 모든 상태가 전환 논리를 통해 도달할 수 있는지 확인하십시오.
3. Check for a state register driven by a constant or missing next-state assignment; drive it correctly so it is not optimized away.
3. 상수 또는 누락된 다음 상태 할당에 의해 구동되는 상태 레지스터를 확인합니다. 최적화되지 않도록 올바르게 운전하십시오.
4. If the element is intentionally constant, that is fine — otherwise fix the logic that should be updating it.
4. 요소가 의도적으로 일정하다면 괜찮습니다. 그렇지 않으면 업데이트해야 하는 로직을 수정하세요.
