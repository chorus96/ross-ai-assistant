# 8-6036: No Matching Modport
# 8-6036: 일치하는 모드포트가 없습니다.

**Message:** `[Synth 8-6036] no matching modport '!%1!'!%2!`
**메시지:** `[Synth 8-6036] 일치하는 모드포트 '!%1!'!%2!`가 없습니다.
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A SystemVerilog modport name referenced in an instantiation doesn't exist in the interface.
인스턴스화에서 참조된 SystemVerilog modport 이름이 인터페이스에 존재하지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Reference to a non-existent modport
### P1: 존재하지 않는 모드포트에 대한 참조

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: modport not found
module m(intr.n1 port1);  // ERROR: no modport 'n1' in 'intr'
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use correct modport name
module m(intr.master port1);  // use existing modport
```

---

## Fix Strategy
## 전략 수정

1. Use a modport name that actually exists in the interface definition (e.g., `master`/`slave`) on the port declaration.
1. 포트 선언 시 인터페이스 정의(예: `master`/`slave`)에 실제로 존재하는 모드포트 이름을 사용하세요.
2. Open the interface and confirm its declared modports; fix the reference to match (names are case-sensitive).
2. 인터페이스를 열고 선언된 모드포트를 확인하세요. 일치하도록 참조를 수정합니다(이름은 대소문자를 구분합니다).
3. If the needed modport does not exist, add it to the interface with the correct signal directions.
3. 필요한 모드포트가 존재하지 않는 경우 올바른 신호 방향으로 인터페이스에 추가하십시오.
4. Ensure the connected interface instance provides a modport view compatible with the module port.
4. 연결된 인터페이스 인스턴스가 모듈 포트와 호환되는 모드 포트 보기를 제공하는지 확인하십시오.
