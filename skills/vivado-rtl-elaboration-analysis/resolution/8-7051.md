# 8-7051: Interface Function Actual Not Found
# 8-7051: 실제 인터페이스 기능을 찾을 수 없음

**Message:** `[Synth 8-7051] Actual function associated with interface function !%1! not found`
**메시지:** `[Synth 8-7051] 인터페이스 함수 !%1!과 연관된 실제 함수! 찾을 수 없습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL interface function's actual (implementation) function is not found.
VHDL 인터페이스 함수의 실제(구현) 함수를 찾을 수 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Interface function actual not visible
### P1: 인터페이스 기능이 실제로 보이지 않음

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: actual function not found
generic map(max_int => nonexistent_func);  -- ERROR
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: provide existing function
generic map(max_int => my_max_func);  -- function must be visible
```

---

## Fix Strategy
## 전략 수정

1. Ensure the actual (implementation) function passed to the interface/generic function formal is **declared and visible** in the current scope.
1. 인터페이스/일반 함수 형식에 전달된 실제(구현) 함수가 현재 범위에서 **선언되고 표시**되는지 확인하세요.
2. Import the package that defines the function, or reference it with a qualified name.
2. 함수를 정의하는 패키지를 가져오거나 정규화된 이름으로 참조하세요.
3. Verify the function's signature matches what the formal interface function expects.
3. 함수의 서명이 공식 인터페이스 함수가 ​​기대하는 것과 일치하는지 확인하십시오.
4. Fix typos in the function name and confirm compile order so the function exists before use.
4. 함수 이름의 오타를 수정하고, 컴파일 순서를 확인하여 해당 함수가 존재하는지 확인한 후 사용하세요.
