# 8-9248: Packed Dimensions of Real
# 8-9248: 실수의 압축된 차원

**Message:** `[Synth 8-9248] cannot have packed dimensions of type 'real'`
**메시지:** `[Synth 8-9248]은 '실제' 유형의 압축된 차원을 가질 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A packed array dimension uses `real` type, which is not packed.
압축된 배열 차원은 압축되지 않은 '실제' 유형을 사용합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Packed dimension on real
### P1: 실제의 압축된 차원

**Problematic Code:**
**문제가 있는 코드:**
```diff
real [7:0] data;  // ERROR: real can't have packed dimensions
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
logic [63:0] data;  // use packed integer type for synthesis
```

---

## Fix Strategy
## 전략 수정

1. `real` cannot have packed dimensions — use a fixed-width integer/logic type (`logic [N-1:0]`) for synthesizable data.
1. `real`은 압축된 차원을 가질 수 없습니다. 합성 가능한 데이터에는 고정 너비 정수/논리 유형(`logic [N-1:0]`)을 사용하십시오.
2. If fractional values are needed, use a fixed-point representation (scaled integer) instead of `real`.
2. 분수 값이 필요한 경우 '실수' 대신 고정 소수점 표현(스케일링된 정수)을 사용하세요.
3. Keep any genuine `real` usage in simulation-only/parameter contexts, not in packed declarations.
3. 압축된 선언이 아닌 시뮬레이션 전용/매개변수 컨텍스트에서 실제 '실제' 사용법을 유지하세요.
4. Size the replacement vector to the precision/range you actually need.
4. 실제로 필요한 정밀도/범위로 대체 벡터의 크기를 조정하십시오.
