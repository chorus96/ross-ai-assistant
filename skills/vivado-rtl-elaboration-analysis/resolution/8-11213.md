# 8-11213: Assignment Pattern to Enum Type
# 8-11213: Enum 유형에 대한 할당 패턴

**Message:** `[Synth 8-11213] target of assignment pattern cannot be an enumeration type`
**메시지:** `[Synth 8-11213] 할당 패턴의 대상은 열거 유형이 될 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An assignment pattern `'{...}` targets an enumeration type, which is not supported.
할당 패턴 `'{...}`은 지원되지 않는 열거 유형을 대상으로 합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Assignment pattern to an enum
### P1: 열거형에 대한 할당 패턴

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: assignment pattern on enum
typedef enum {A,B,C} my_enum;
my_enum e;
e = '{A};  // ERROR: enum not valid for pattern
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: direct assignment
my_enum e;
e = A;  // direct enum value
```

---

## Fix Strategy
## 전략 수정

1. Assign enum variables a named enum value directly (`s = RUN;`), not through an assignment pattern.
1. 할당 패턴을 통하지 않고 열거형 변수에 명명된 열거형 값을 직접(`s = RUN;`) 할당합니다.
2. Reserve `'{...}` patterns for arrays/structs.
2. 배열/구조체용 `'{...}` 패턴을 예약하세요.
3. To derive an enum from an integer, use an explicit cast to the enum type and ensure it is a valid member.
3. 정수에서 열거형을 파생시키려면 열거형 유형에 대한 명시적 캐스트를 사용하고 그것이 유효한 멤버인지 확인하세요.
4. Keep FSM assignments to named enum members for type safety.
4. 유형 안전성을 위해 명명된 열거형 멤버에 대한 FSM 할당을 유지합니다.
