# 8-7032: RAM "write_block.bram_reg" have possible Byte W...
# 8-7032: RAM "write_block.bram_reg"에 가능한 바이트 W가 있습니다...

**Message:** `[Synth 8-7032] RAM "write_block.bram_reg" have possible Byte Write pattern, however the data width (47) is not multiple of supported byte widths of 8 or 9 .`
**메시지:** `[Synth 8-7032] RAM "write_block.bram_reg"에는 바이트 쓰기 패턴이 가능하지만 데이터 너비(47)가 지원되는 바이트 너비 8 또는 9의 배수가 아닙니다.`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A RAM uses a **byte-wide write-enable** pattern, but the data width is not a
RAM은 **바이트 전체 쓰기 가능** 패턴을 사용하지만 데이터 너비는
multiple of a supported byte width (8 or 9 bits).
지원되는 바이트 너비(8 또는 9비트)의 배수입니다.
Byte-write BRAMs require the
바이트 쓰기 BRAM에는 다음이 필요합니다.
data to be divisible into 8- or 9-bit byte lanes, so an odd width like 47 cannot
데이터를 8비트 또는 9비트 바이트 레인으로 나눌 수 있으므로 47과 같은 홀수 너비는
map to the byte-write template.
바이트 쓰기 템플릿에 매핑합니다.

## Common Patterns
## 일반적인 패턴

### P1: Byte-write RAM with non-byte-multiple width
### P1: 바이트 다중 폭이 아닌 바이트 쓰기 RAM

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- RAM "write_block.bram_reg" have possible Byte Write pattern, however the data width (47) is not multiple of supported byte widths of 8 or 9 .
```

**Recommended Fix:**
**권장 수정 사항:**
```verilog
// Pad the data to a byte-multiple width so byte-write maps to BRAM
localparam DW = 48;              // 47 -> 48 (multiple of 8)
reg [DW-1:0] bram [0:DEPTH-1];
// ...drive the extra bit(s) with 0 and ignore on read
```

---

## Fix Strategy
## 전략 수정

1. Make the RAM data width a multiple of 8 (or 9 for parity-byte BRAMs) so it splits into byte lanes — pad the width (e.g., 47 -> 48) and ignore the extra bit(s).
1. RAM 데이터 너비를 8의 배수(또는 패리티 바이트 BRAM의 경우 9)로 만들어 바이트 레인으로 분할합니다. 너비를 채우고(예: 47 -> 48) 추가 비트를 무시합니다.
2. If byte-write is not actually needed, drive the whole word with a single write enable instead of per-byte enables.
2. 바이트 쓰기가 실제로 필요하지 않은 경우 바이트당 활성화 대신 단일 쓰기 활성화로 전체 워드를 구동합니다.
3. Structure the write-enable and data so each 8/9-bit lane has its own enable, matching the UG901 byte-write template.
3. 각 8/9비트 레인이 UG901 바이트 쓰기 템플릿과 일치하는 자체 활성화를 갖도록 쓰기 가능 및 데이터를 구조화합니다.
4. Verify the padded bits are driven to a defined value and masked on read.
4. 패딩된 비트가 정의된 값으로 구동되고 읽기 시 마스크되는지 확인합니다.
