# 8-10307: Keyword Used in Wrong Context
# 8-10307: 잘못된 컨텍스트에서 키워드가 사용되었습니다.

**Message:** `[Synth 8-10307] keyword used in incorrect context`
**메시지:** `[Synth 8-10307] 키워드가 잘못된 컨텍스트에서 사용되었습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10307] keyword used in incorrect context [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A Verilog keyword like `scalared` is used in a context where it is not valid (e.g., on a `reg` declaration).
`scalared`와 같은 Verilog 키워드는 유효하지 않은 컨텍스트(예: `reg` 선언)에서 사용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Keyword misused on a reg
### P1: 등록 시 키워드가 잘못 사용되었습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: 'scalared' on reg (invalid)
reg scalared signed [3:0] my_reg;  // ERROR: scalared not valid here
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: remove the keyword
reg signed [3:0] my_reg;  // scalared is only valid on net types
```

---

## Fix Strategy
## 전략 수정

1. Remove `scalared`/`vectored` from `reg`/variable declarations — they apply only to net types (`wire`).
1. `reg`/변수 선언에서 `scalared`/`Vectored`를 제거하세요. 이는 네트 유형(`wire`)에만 적용됩니다.
2. If the qualifier was intentional, change the object to a net; in practice these qualifiers have no synthesis effect, so dropping them is cleanest.
2. 한정자가 의도적인 경우 개체를 net으로 변경합니다. 실제로 이러한 한정자는 합성 효과가 없으므로 삭제하는 것이 가장 깔끔합니다.
3. Check the declaration order/keywords (`reg signed [3:0] r;`) after removing the misused keyword.
3. 잘못 사용된 키워드를 제거한 후 선언 순서/키워드(`reg signed [3:0] r;`)를 확인하세요.
4. Verify no other keyword is used outside its valid context on the same declaration.
4. 동일한 선언에서 유효한 컨텍스트 외부에 다른 키워드가 사용되지 않았는지 확인하십시오.
