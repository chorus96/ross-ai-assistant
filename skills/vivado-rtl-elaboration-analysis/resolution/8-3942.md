# 8-3942: Deprecated Precompiled Function
# 8-3942: 더 이상 사용되지 않는 사전 컴파일된 함수

**Message:** `[Synth 8-3942] deprecated usage of precompiled function '!%1!'`
**메시지:** `[Synth 8-3942] 미리 컴파일된 함수 '!%1!'의 사용이 더 이상 사용되지 않습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A precompiled IP function is deprecated in the current Vivado version.
사전 컴파일된 IP 함수는 현재 Vivado 버전에서 더 이상 사용되지 않습니다.

## Fix Strategy
## 전략 수정

1. Regenerate the IP for the current Vivado version so deprecated precompiled functions are replaced with supported ones.
1. 더 이상 사용되지 않는 사전 컴파일된 기능이 지원되는 기능으로 대체되도록 현재 Vivado 버전에 대한 IP를 다시 생성합니다.
2. Run the IP upgrade flow (`report_ip_status` / `upgrade_ip`) and re-synthesize.
2. IP 업그레이드 흐름(`report_ip_status` / `upgrade_ip`)을 실행하고 다시 합성하세요.
3. Delete stale generated/cached IP outputs so the new (non-deprecated) implementation is used.
3. 새로운(더 이상 사용되지 않는) 구현이 사용되도록 오래된 생성/캐시된 IP 출력을 삭제합니다.
4. Verify the IP version referenced by the design matches the installed Vivado release.
4. 설계에서 참조하는 IP 버전이 설치된 Vivado 릴리스와 일치하는지 확인하세요.
