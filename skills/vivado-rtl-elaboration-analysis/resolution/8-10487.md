# 8-10487: argument to $bits cannot have variable or indeterminate width
# 8-10487: $bits에 대한 인수는 가변 또는 불확정 너비를 가질 수 없습니다.

**Message:** `[Synth 8-10487] argument to $bits cannot have variable or indeterminate width`
**메시지:** `$bits에 대한 [Synth 8-10487] 인수는 가변 또는 불확정 너비를 가질 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

The argument to `$bits` has a variable or indeterminate width, so its bit count cannot be computed at elaboration.
`$bits`에 대한 인수에는 가변 또는 불확정 너비가 있으므로 자세히 설명할 때 비트 수를 계산할 수 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: $bits argument has variable/indeterminate width
### P1: $bits 인수에 가변/불확정 너비가 있습니다.

**Problematic Code:**
**문제가 있는 코드:**
```systemverilog
logic [n-1:0] v;   // n not constant
int b = $bits(v);
```

**Recommended Fix:**
**권장 수정 사항:**
```systemverilog
parameter N = 8;
logic [N-1:0] v;
int b = $bits(v);
```

---

## Fix Strategy
## 전략 수정

1. Give the argument a fixed, constant width (use a parameter/localparam).
1. 인수에 고정되고 일정한 너비를 지정합니다(매개변수/localparam 사용).
2. Avoid dynamically-sized objects as `$bits` arguments.
2. 동적으로 크기가 조정되는 객체를 '$bits' 인수로 사용하지 마세요.
3. Resolve any non-constant range before the `$bits` call.
3. `$bits` 호출 전에 일정하지 않은 범위를 해결하세요.
