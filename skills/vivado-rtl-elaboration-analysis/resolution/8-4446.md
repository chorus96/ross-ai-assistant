# 8-4446: All Outputs Unconnected
# 8-4446: 모든 출력이 연결되지 않음

**Message:** `[Synth 8-4446] all outputs are unconnected for this instance and logic may be removed`
**메시지:** `[Synth 8-4446] 이 인스턴스에 대한 모든 출력이 연결되지 않았으므로 로직이 제거될 수 있습니다.`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An instance has no connected outputs, so Vivado may remove it and its logic.
인스턴스에는 연결된 출력이 없으므로 Vivado는 인스턴스와 해당 로직을 제거할 수 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Instance with no connected outputs
### P1: 연결된 출력이 없는 인스턴스

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: instance with no output connections
my_mod inst(.clk(clk), .data(d));  // no outputs connected
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: connect outputs or add dont_touch
(* dont_touch = "true" *) my_mod inst(.clk(clk), .data(d), .out(result));
```

---

## Fix Strategy
## 전략 수정

1. Connect at least one (ideally all needed) output of the instance so its logic is observable and not optimized away.
1. 해당 논리가 관찰 가능하고 최적화되지 않도록 인스턴스의 출력을 하나 이상(이상적으로는 모두 필요한) 연결합니다.
2. If the instance is intentionally kept (debug, future use), apply `(* dont_touch = "true" *)` / `keep_hierarchy` to prevent removal.
2. 인스턴스를 의도적으로 유지하는 경우(디버그, 향후 사용) `(* dont_touch = "true" *)` / `keep_hierarchy`를 적용하여 제거를 방지하세요.
3. Trace why the outputs are unconnected — often a missing wire up the hierarchy makes the whole block dead; hook it up.
3. 출력이 연결되지 않은 이유를 추적하십시오. 종종 계층 구조의 와이어가 누락되어 전체 블록이 작동하지 않게 됩니다. 연결해 보세요.
4. If the instance is genuinely unnecessary, remove it rather than forcing retention.
4. 인스턴스가 정말로 불필요한 경우 보존을 강제하기보다는 제거하십시오.
