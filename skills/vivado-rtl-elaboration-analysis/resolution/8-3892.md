# 8-3892: Undeclared Type
# 8-3892: 선언되지 않은 유형

**Message:** `[Synth 8-3892] undeclared type '!%1!'`
**메시지:** `[Synth 8-3892] 선언되지 않은 유형 '!%1!'`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A type name is used but not declared or imported.
유형 이름이 사용되지만 선언되거나 가져오지는 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Use of an undeclared type name
### P1: 선언되지 않은 유형 이름 사용

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: undeclared type
process p1;  // ERROR: 'process' is a keyword, not a type
// Or: mytype var1;  // mytype not declared
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: declare or import the type
typedef logic [7:0] mytype;
mytype var1;
```

---

## Fix Strategy
## 전략 수정

1. Declare the type before use (`typedef logic [7:0] mytype;`) or `import` the package that defines it.
1. 사용하기 전에 유형을 선언하거나(`typedef logic [7:0] mytype;`) 이를 정의하는 패키지를 `가져옵니다`.
2. Ensure the defining package/file is compiled ahead of this file and the package is imported into the current scope.
2. 정의 패키지/파일이 이 파일보다 먼저 컴파일되고 패키지를 현재 범위로 가져왔는지 확인하세요.
3. Do not use language keywords (e.g., `process`) as type/identifier names — rename to a valid identifier.
3. 유형/식별자 이름으로 언어 키워드(예: `process`)를 사용하지 마십시오. 유효한 식별자로 이름을 바꾸십시오.
4. Fix typos in the type name (case-sensitive in SystemVerilog) so it matches the declaration exactly.
4. 유형 이름(SystemVerilog에서는 대소문자 구분)의 오타를 수정하여 선언과 정확히 일치하도록 합니다.
