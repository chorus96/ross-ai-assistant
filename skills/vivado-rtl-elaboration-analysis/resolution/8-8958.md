# 8-8958: Visible via Multiple Imports
# 8-8958: 다중 가져오기를 통해 표시

**Message:** `[Synth 8-8958] identifier visible via multiple package imports`
**메시지:** `[Synth 8-8958] 여러 패키지 가져오기를 통해 표시되는 식별자`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An identifier is imported from multiple packages, creating ambiguity.
여러 패키지에서 식별자를 가져오므로 모호성이 발생합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Identifier ambiguous across imports
### P1: 가져오기 전반에 걸쳐 식별자가 모호함

**Problematic Code:**
**문제가 있는 코드:**
```diff
use pkg1.all; use pkg2.all;
sig <= a;  -- ERROR: 'a' visible from both
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
use pkg1.a;  -- import specific item
-- Or qualify: sig <= pkg1.a;
```

---

## Fix Strategy
## 전략 수정

1. Resolve the ambiguity by importing the specific item (`use pkg1.a;`) or using a qualified reference (`pkg1.a`) instead of two `use pkg.all;` wildcards.
1. 두 개의 `use pkg.all;` 와일드카드 대신 특정 항목을 가져오거나(`use pkg1.a;`) 정규 참조(`pkg1.a`)를 사용하여 모호성을 해결하십시오.
2. Avoid importing overlapping names from multiple packages with `.all`; import only what you need.
2. `.all`을 사용하여 여러 패키지에서 겹치는 이름을 가져오는 것을 피하세요. 필요한 것만 가져오세요.
3. If both packages must be visible, always qualify the ambiguous identifiers at their use sites.
3. 두 패키지가 모두 표시되어야 하는 경우 항상 사용 사이트에서 모호한 식별자를 한정하십시오.
4. Consider consolidating duplicate declarations into a single shared package.
4. 중복 선언을 단일 공유 패키지로 통합하는 것을 고려하세요.
