# 8-11560: Trailing Semicolon in Interface List
# 8-11560: 인터페이스 목록의 후행 세미콜론

**Message:** `[Synth 8-11560] semicolon after last interface declaration is only supported in VHDL 1076-2019`
**메시지:** `[Synth 8-11560] 마지막 인터페이스 선언 뒤의 세미콜론은 VHDL 1076-2019에서만 지원됩니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A semicolon after the last interface declaration is only allowed in VHDL-2019.
마지막 인터페이스 선언 뒤의 세미콜론은 VHDL-2019에서만 허용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Trailing semicolon in interface list
### P1: 인터페이스 목록의 후행 세미콜론

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: trailing semicolon (VHDL-2008)
entity e is port(
  clk : in std_logic;
  data : in std_logic;   -- trailing semicolon
);
end;
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: remove trailing semicolon
entity e is port(
  clk : in std_logic;
  data : in std_logic    -- no trailing semicolon
);
end;
```

---

## Fix Strategy
## 전략 수정

1. Remove the trailing `;` after the last port/generic declaration — it is only allowed in VHDL-2019.
1. 마지막 포트/일반 선언 뒤에 오는 ';'을 제거합니다. 이는 VHDL-2019에서만 허용됩니다.
2. Alternatively, compile in VHDL-2019 mode if your flow supports it.
2. 또는 흐름이 지원하는 경우 VHDL-2019 모드에서 컴파일하십시오.
3. Check the interface/port list for a dangling separator introduced by editing.
3. 편집으로 인해 도입된 매달린 구분 기호가 있는지 인터페이스/포트 목록을 확인하세요.
4. Ensure separators appear only *between* declarations, not after the last one.
4. 구분 기호가 마지막 선언 이후가 아닌 *선언 사이*에만 나타나는지 확인하세요.
