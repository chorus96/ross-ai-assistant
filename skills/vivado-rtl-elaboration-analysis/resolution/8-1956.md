# 8-1956: Error in Use Clause
# 8-1956: 사용 조항 오류

**Message:** `[Synth 8-1956] error in use clause`
**메시지:** `[Synth 8-1956] 사용 절에 오류가 있습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL `use` clause has a syntax error or references a non-existent library/package.
VHDL `use` 절에 구문 오류가 있거나 존재하지 않는 라이브러리/패키지를 참조합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Malformed or missing use clause
### P1: 사용 조항이 잘못되었거나 누락되었습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: malformed use clause
use work.;  -- ERROR: incomplete
use nonexistent.pkg.all;  -- ERROR: library not found
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: fix the use clause
use work.my_pkg.all;  -- complete reference
```

---

## Fix Strategy
## 전략 수정

1. Use the complete `use` syntax: `use <library>.<package>.all;` (or `.<item>`), with no dangling `use work.;`.
1. 완전한 `use` 구문을 사용하세요: `use <library>.<package>.all;`(또는 `.<item>`), 매달린 `use work.;` 없이.
2. Ensure the referenced library is declared (`library <name>;`) and the package is actually compiled into it before this file.
2. 참조된 라이브러리가 선언되었는지(`library <name>;`) 확인하고 패키지가 실제로 이 파일 이전에 해당 라이브러리로 컴파일되었는지 확인하세요.
3. Fix typos in library/package names (case-insensitive in VHDL, but must exist) and confirm compile order.
3. 라이브러리/패키지 이름의 오타를 수정하고(VHDL에서는 대소문자를 구분하지 않지만 존재해야 함) 컴파일 순서를 확인합니다.
4. For IEEE packages, add the standard clauses (`library ieee; use ieee.std_logic_1164.all; use ieee.numeric_std.all;`).
4. IEEE 패키지의 경우 표준 조항(`library ieee; use ieee.std_logic_1164.all; use ieee.numeric_std.all;`)을 추가합니다.
