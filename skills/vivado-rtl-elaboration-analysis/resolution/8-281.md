# 8-281: Expression Must Be Packed Type
# 8-281: 표현식은 팩형이어야 합니다

**Message:** `[Synth 8-281] expression must be of a packed type`
**메시지:** `[Synth 8-281] 표현식은 압축된 유형이어야 합니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-281] expression must be of a packed type [/path/to/file.sv:42]
```

---

## Root Cause
## 근본 원인

An operation that requires a packed (bit-vector) type is being applied to an unpacked type.
압축된(비트-벡터) 유형이 필요한 작업이 압축되지 않은 유형에 적용되고 있습니다.
Packed types have contiguous bit representation; unpacked types do not.
패킹된 유형은 연속적인 비트 표현을 갖습니다. 압축이 풀린 유형은 그렇지 않습니다.

---

## Packed vs Unpacked
## 포장된 것과 포장되지 않은 것

| Type<br>유형 | Packed<br>포장됨 | Example<br>예 |
|------|--------|---------|
| `logic [7:0]`<br>`논리 [7:0]` | Yes<br>예 | 8-bit vector<br>8비트 벡터 |
| `logic [7:0][3:0]`<br>`논리 [7:0][3:0]` | Yes<br>예 | 2D packed array<br>2D 압축 배열 |
| `logic [7:0] arr[4]`<br>`논리 [7:0] arr[4]` | No | Array of 8-bit values<br>8비트 값 배열 |
| `struct packed`<br>`구조체 패킹` | Yes<br>예 | Packed structure<br>포장된 구조 |
| `struct`<br>`구조체` | No | Unpacked structure<br>압축을 푼 구조 |

## Common Patterns
## 일반적인 패턴

### P1: Bit-Select on Unpacked Array
### P1: 압축 해제된 어레이의 비트 선택

```systemverilog
// Before - unpacked array, can't use as vector
logic [7:0] data [4];  // unpacked array
wire [31:0] flat = data;  // ERROR: can't flatten unpacked

// After - use packed array
logic [3:0][7:0] data;  // packed 2D array (32 bits total)
wire [31:0] flat = data;  // OK: packed can be assigned
```

### P2: Concatenation with Unpacked
### P2: Unpacked와 연결

```systemverilog
// Before - unpacked in concatenation
logic [7:0] arr [2];
wire [15:0] combined = {arr[0], arr[1]};  // ERROR if arr is unpacked

// After - declare as packed or use explicit elements
logic [1:0][7:0] arr;  // packed
wire [15:0] combined = arr;  // OK
```

### P3: Unpacked Struct in Bit Operation
### P3: 비트 연산에서 압축 해제된 구조체

```systemverilog
// Before - unpacked struct
typedef struct {
  logic [7:0] a;
  logic [7:0] b;
} my_struct_t;

my_struct_t s;
wire [15:0] bits = s;  // ERROR: unpacked

// After - packed struct
typedef struct packed {
  logic [7:0] a;
  logic [7:0] b;
} my_struct_t;

my_struct_t s;
wire [15:0] bits = s;  // OK
```

### P4: Function with Unpacked Return
### P4: 언팩 리턴 기능

```systemverilog
// Before - unpacked return type
function logic [7:0] get_bytes [4] ();  // returns unpacked
  ...
endfunction

// After - packed return or explicit handling
function logic [31:0] get_bytes();  // packed 32-bit return
  ...
endfunction
```

## Fix Strategy
## 전략 수정

1. Add `packed` keyword to structs/unions
1. 구조체/공용체에 `packed` 키워드 추가
2. Change unpacked arrays `[N]` to packed `[N-1:0]`
2. 압축되지 않은 배열 `[N]`을 압축된 `[N-1:0]`으로 변경합니다.
3. Use explicit element access for unpacked types
3. 압축이 풀린 유형에 대해 명시적인 요소 액세스 사용
4. Rearrange dimensions: `[W][D]` (packed) vs `[W] arr[D]` (unpacked)
4. 크기 재정렬: `[W][D]`(압축) 및 `[W] arr[D]`(압축 해제)
