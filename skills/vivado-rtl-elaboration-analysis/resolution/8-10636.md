# 8-10636: default field of an assignment pattern cannot contain another ...
# 8-10636: 할당 패턴의 기본 필드에는 다른 항목을 포함할 수 없습니다...

**Message:** `[Synth 8-10636] default field of an assignment pattern cannot contain another assignment pattern`
**메시지:** `[Synth 8-10636] 할당 패턴의 기본 필드는 다른 할당 패턴을 포함할 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

The `default:` field of an assignment pattern contains another assignment pattern, which is not allowed.
할당 패턴의 `default:` 필드에 허용되지 않는 다른 할당 패턴이 포함되어 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Nested assignment pattern in default field
### P1: 기본 필드의 중첩 할당 패턴

**Problematic Code:**
**문제가 있는 코드:**
```systemverilog
'{default: '{0,0}}   // nested pattern in default
```

**Recommended Fix:**
**권장 수정 사항:**
```systemverilog
'{default: 0}        // default must be a simple value
```

---

## Fix Strategy
## 전략 수정

1. Use a simple scalar value in the `default:` field.
1. `default:` 필드에 간단한 스칼라 값을 사용하세요.
2. Assign nested structures explicitly rather than via a nested default.
2. 중첩된 기본값을 통하지 않고 명시적으로 중첩된 구조를 할당합니다.
3. Restructure the assignment pattern to avoid the nesting.
3. 중첩을 방지하려면 할당 패턴을 재구성하세요.
