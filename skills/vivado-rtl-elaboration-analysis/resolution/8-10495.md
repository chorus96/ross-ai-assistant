# 8-10495: Arrays Have Different Element Types
# 8-10495: 배열의 요소 유형이 다릅니다.

**Message:** `[Synth 8-10495] arrays have different element types`
**메시지:** `[Synth 8-10495] 배열의 요소 유형이 다릅니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10495] arrays have different element types [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

Assignment between arrays where element types are incompatible.
요소 유형이 호환되지 않는 배열 간의 할당입니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Incompatible array element types
### P1: 호환되지 않는 배열 요소 유형

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: incompatible array element types
bit [2:0][1:0] M;
byte R;
int A [5];
byte E [5];
R = A;    // ERROR: int vs byte element types
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use arrays with matching element types
int A [5];
int E [5];   // changed to int to match A
E = A;
```

---

## Fix Strategy
## 전략 수정

1. Make both arrays share the **same element type**, or convert explicitly during an element-by-element assignment.
1. 두 배열이 **동일한 요소 유형**을 공유하도록 하거나 요소별 할당 중에 명시적으로 변환합니다.
2. Change one declaration to match the other's element type where a whole-array copy is intended.
2. 전체 배열 복사본이 의도된 다른 요소 유형과 일치하도록 하나의 선언을 변경합니다.
3. Use per-element type conversion (`target[i] = cast(source[i])`) when the types differ but map cleanly.
3. 유형이 다르지만 깔끔하게 매핑되는 경우 요소별 유형 변환(`target[i] = Cast(source[i])`)을 사용합니다.
4. Define shared element types in a package so both arrays stay compatible.
4. 두 배열이 모두 호환되도록 패키지에 공유 요소 유형을 정의하세요.
