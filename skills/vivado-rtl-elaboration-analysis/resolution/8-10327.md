# 8-10327: Ambiguous Identifier
# 8-10327: 모호한 식별자

**Message:** `[Synth 8-10327] has multiple possible matching identifiers`
**메시지:** `[Synth 8-10327]에는 일치하는 식별자가 여러 개 있습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10327] has multiple possible matching identifiers [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A VHDL function or identifier has multiple visible declarations from different packages, creating ambiguity.
VHDL 함수 또는 식별자에는 다양한 패키지에서 여러 개의 가시적 선언이 있어 모호성이 발생합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Ambiguous identifier across packages
### P1: 패키지 전체의 모호한 식별자

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: ambiguous function from multiple packages
use ieee.std_logic_1164.all;
use ieee.std_logic_arith.all;    -- both define to_stdlogicvector
use ieee.numeric_std.all;
constant INC : std_logic_vector := to_stdlogicvector(x"2");  -- ERROR: ambiguous
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use only one package or qualify the call
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;        -- remove std_logic_arith
constant INC : std_logic_vector(3 downto 0) := x"2";  -- direct hex literal
```

---

## Fix Strategy
## 전략 수정

1. Remove conflicting `use` clauses — `ieee.std_logic_arith` and `ieee.numeric_std` both define overlapping functions; keep only one (prefer `numeric_std`).
1. 충돌하는 `use` 절을 제거하세요. `ieee.std_logic_arith`와 `ieee.numeric_std`는 모두 겹치는 함수를 정의합니다. 하나만 유지하세요(`numeric_std` 선호).
2. If both must be visible, qualify the ambiguous call with its package (`ieee.numeric_std.to_...`).
2. 둘 다 표시되어야 하는 경우 해당 패키지(`ieee.numeric_std.to_...`)를 사용하여 모호한 호출을 한정합니다.
3. Replace ambiguous conversions with direct literals/typed expressions where possible.
3. 가능한 경우 모호한 변환을 직접 리터럴/입력된 표현식으로 바꾸세요.
4. Standardize the codebase on `numeric_std` to avoid recurring ambiguity.
4. 반복되는 모호성을 방지하려면 'numeric_std'에 대한 코드베이스를 표준화하세요.
