# 8-7043: port width mismatch for port 'FSL_Get_No':
# 8-7043: 'FSL_Get_No' 포트의 포트 너비가 일치하지 않습니다.

**Message:** `[Synth 8-7043] port width mismatch for port 'FSL_Get_No': port width = 4, actual width = 32 (integer)`
**메시지:** `[Synth 8-7043] 'FSL_Get_No' 포트의 포트 너비 불일치: 포트 너비 = 4, 실제 너비 = 32(정수)`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A port is connected to a signal of a **different width** — here a 4-bit port is
포트는 **다른 폭**의 신호에 연결됩니다. 여기서 4비트 포트는
driven by a 32-bit `integer` actual.
32비트 '정수' 실제 값으로 구동됩니다.
Vivado connects the overlapping bits and
Vivado는 겹치는 비트를 연결하고
truncates/zero-fills the rest, which is almost always unintended.
나머지 부분을 자르거나 0으로 채웁니다. 이는 거의 항상 의도하지 않은 일입니다.

---

## Common Patterns
## 일반적인 패턴

### P1: 32-bit integer driving a 4-bit port
### P1: 4비트 포트를 구동하는 32비트 정수

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- port width mismatch for port 'FSL_Get_No': port width = 4, actual width = 32 (integer)
```

**Recommended Fix:**
**권장 수정 사항:**
```verilog
// Match the actual width to the 4-bit port (slice or resize explicitly)
wire [3:0] fsl_get_no = int_value[3:0];   // take the intended 4 bits
my_mod inst (.FSL_Get_No(fsl_get_no), ...);
```

---

## Fix Strategy
## 전략 수정

1. Match the connected signal's width to the port width — slice the 32-bit `integer` down to the 4-bit port (`int_value[3:0]`) or widen the port if 32 bits are intended.
1. 연결된 신호의 너비를 포트 너비와 일치시키십시오. 32비트 `정수`를 4비트 포트(`int_value[3:0]`)로 분할하거나 32비트를 의도하는 경우 포트를 넓히십시오.
2. Convert `integer` actuals explicitly (e.g., `std_logic_vector(to_unsigned(x, 4))`) so the intended bits are selected, not silently truncated.
2. `정수` 실제 값을 명시적으로 변환하여(예: `std_logic_Vector(to_unsigned(x, 4))`) 의도한 비트가 자동으로 잘리지 않고 선택되도록 합니다.
3. Prefer named connections and confirm the intended value range fits the port width.
3. 명명된 연결을 선호하고 의도한 값 범위가 포트 너비에 맞는지 확인하십시오.
4. If the mismatch is a design error, fix the port or signal declaration so both sides agree.
4. 불일치가 설계 오류인 경우 양쪽이 동의하도록 포트 또는 신호 선언을 수정합니다.
