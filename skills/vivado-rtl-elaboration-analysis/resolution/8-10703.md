# 8-10703: Matching Select Signal Type Error
# 8-10703: 일치 선택 신호 유형 오류

**Message:** `[Synth 8-10703] expression of matching selected signal assignment is not a bit, std_ulogic, or one-dimensional array`
**메시지:** `[Synth 8-10703] 선택된 신호 할당과 일치하는 표현식이 비트, std_ulogic 또는 1차원 배열이 아닙니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10703] expression of matching selected signal assignment is not a bit, std_ulogic, or one-dimensional array [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

VHDL `select?` (matching case) requires the select expression to be `bit`, `std_ulogic`, or a 1-D array of those types.
VHDL `select?`(대소문자 일치)에는 선택 표현식이 `bit`, `std_ulogic` 또는 해당 유형의 1차원 배열이어야 합니다.
Using `integer` or other types is not allowed.
`정수` 또는 다른 유형을 사용할 수 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Matching select on wrong type
### P1: 잘못된 유형에 대한 선택 일치

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: integer in matching select
with in1 select ?             -- ERROR: in1 is integer, not bit/std_ulogic
  out1 <= in1 + in2 when 1,
          in1 - in2 when 3;
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use regular select (without ?) for non-bit types
with in1 select
  out1 <= in1 + in2 when 1,
          in1 - in2 when 3,
          in1       when others;
-- Or convert to std_logic_vector for matching select
```

---

## Fix Strategy
## 전략 수정

1. Use a plain `select`/`case` (without `?`) for integer/enumerated selectors — matching-select (`select?`/`case?`) is for `bit`/`std_ulogic` types.
1. 정수/열거형 선택기에는 일반 `select`/`case`(`?` 제외)를 사용하세요. 일치 선택(`select?`/`case?`)은 `bit`/`std_ulogic` 유형에 사용됩니다.
2. If wildcard matching is intended, make the selector a `std_logic_vector`/`bit_vector`.
2. 와일드카드 일치를 의도하는 경우 선택기를 `std_logic_Vector`/`bit_Vector`로 만드세요.
3. Ensure the case items are the same type as the selector.
3. 케이스 항목이 선택기와 동일한 유형인지 확인하십시오.
4. Reserve `?` wildcards for don't-care matching on logic vectors.
4. 논리 벡터에 대한 무정의 일치를 위해 `?` 와일드카드를 예약합니다.
