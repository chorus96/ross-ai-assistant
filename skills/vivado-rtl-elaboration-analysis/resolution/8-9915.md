# 8-9915: Port Not Defined
# 8-9915: 포트가 정의되지 않음

**Message:** `[Synth 8-9915] port is not defined`
**메시지:** `[Synth 8-9915] 포트가 정의되지 않았습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A port referenced in a connection doesn't exist.
연결에서 참조된 포트가 존재하지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Connection to an undefined port
### P1: 정의되지 않은 포트에 연결

**Problematic Code:**
**문제가 있는 코드:**
```diff
inst(.a(sig));  // ERROR: port 'a' not defined in module
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
inst(.actual_port(sig));  // use correct port name
```

---

## Fix Strategy
## 전략 수정

1. Use the exact port names from the module definition in the instance connection.
1. 인스턴스 연결의 모듈 정의에 있는 정확한 포트 이름을 사용하십시오.
2. Fix typos in the offending port name; prefer named connections so mismatches surface immediately.
2. 문제가 있는 포트 이름의 오타를 수정하세요. 이름이 지정된 연결을 선호하므로 불일치가 즉시 나타납니다.
3. Verify you are instantiating the intended, current module version.
3. 의도한 현재 모듈 버전을 인스턴스화하고 있는지 확인하십시오.
4. If the port should exist, add it to the module definition rather than forcing the connection.
4. 포트가 존재해야 하는 경우 연결을 강제하는 대신 모듈 정의에 추가하십시오.
