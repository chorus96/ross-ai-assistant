# 8-2119: Illegal Context for Multi-Assignment Pattern
# 8-2119: 다중 할당 패턴에 대한 잘못된 컨텍스트

**Message:** `[Synth 8-2119] illegal context for !%1!`
**메시지:** `[Synth 8-2119] !%1!에 대한 잘못된 컨텍스트'
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A multi-element assignment pattern is used in a context where it's not valid.
다중 요소 할당 패턴이 유효하지 않은 컨텍스트에서 사용되었습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Assignment pattern mismatched to target
### P1: 할당 패턴이 대상과 일치하지 않습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: pattern in illegal context
assign {a, b} = '{1, 2, 3};  // ERROR: pattern mismatch
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: match pattern structure to target
assign {a, b} = {1'b1, 1'b0};  // concatenation for packed
// Or: int arr[2] = '{1, 2};  // pattern for array init
```

---

## Fix Strategy
## 전략 수정

1. Match the assignment-pattern structure to the target type: use `'{...}` only for arrays/structs, and concatenation `{...}` for packed vectors.
1. 할당 패턴 구조를 대상 유형과 일치시킵니다. 배열/구조체에만 `{...}`를 사용하고 압축된 벡터에는 연결 `{...}`을 사용합니다.
2. Ensure the number of elements in the pattern equals the target's element/field count.
2. 패턴의 요소 수가 대상의 요소/필드 수와 동일한지 확인하세요.
3. Do not mix a packed concatenation target (`{a, b}`) with an array assignment pattern (`'{1, 2, 3}`) — pick the form that matches the LHS.
3. 묶음 연결 대상(`{a, b}`)을 배열 할당 패턴(`'{1, 2, 3}`)과 혼합하지 마세요. LHS와 일치하는 형식을 선택하세요.
4. For struct targets, use field-named patterns (`'{field_a: x, field_b: y}`) so the mapping is explicit and correct.
4. 구조체 대상의 경우 필드 이름이 지정된 패턴(`'{field_a: x, field_b: y}`)을 사용하여 매핑이 명확하고 정확하도록 합니다.
