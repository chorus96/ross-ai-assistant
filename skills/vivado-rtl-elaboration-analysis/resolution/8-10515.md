# 8-10515: begin/end is required for !%1! in this mode of Verilog
# 8-10515: !%1!에는 시작/끝이 필요합니다. 이 Verilog 모드에서는

**Message:** `[Synth 8-10515] begin/end is required for !%1! in this mode of Verilog`
**메시지:** `[Synth 8-10515] 시작/끝은 !%1!에 필요합니다. 이 Verilog 모드에서는`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A construct that needs an explicit `begin`/`end` block is written without one in the current Verilog dialect.
명시적인 `begin`/`end` 블록이 필요한 구성은 현재 Verilog 방언에서 블록 없이 작성됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: begin/end required in this Verilog mode
### P1: 이 Verilog 모드에서는 시작/끝이 필요합니다.

**Problematic Code:**
**문제가 있는 코드:**
```verilog
if (c) a=1; else b=1;   // flagged in this mode
```

**Recommended Fix:**
**권장 수정 사항:**
```verilog
if (c) begin a=1; end else begin b=1; end
```

---

## Fix Strategy
## 전략 수정

1. Wrap the statement(s) in `begin`/`end`.
1. 명령문을 `begin`/`end`로 묶습니다.
2. Or compile the file in SystemVerilog mode if that is intended.
2. 또는 의도한 경우 SystemVerilog 모드에서 파일을 컴파일하십시오.
3. Explicit blocks also avoid dangling-else ambiguity.
3. 명시적 블록은 또한 매달려 있는 모호함을 방지합니다.
