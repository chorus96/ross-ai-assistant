# 8-11259: unmatched !%1! 'translate/synthesis off' pragma found; expected a ...
# 8-11259: 일치하지 않는 !%1! '번역/합성 꺼짐' pragma가 발견되었습니다. 예상 ...

**Message:** `[Synth 8-11259] unmatched !%1! 'translate/synthesis off' pragma found; expected a matching pair with the same keywords`
**메시지:** `[Synth 8-11259] 일치하지 않습니다!%1! '번역/합성 꺼짐' pragma가 발견되었습니다. 동일한 키워드와 일치하는 쌍이 필요합니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A `translate_off`/`synthesis off` pragma has no matching `translate_on`/`synthesis on` with the same keyword, leaving a region permanently disabled.
`translate_off`/`synesis off` pragma에는 동일한 키워드와 일치하는 `translate_on`/`synesis on`이 없으므로 영역이 영구적으로 비활성화됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Unmatched translate/synthesis off pragma
### P1: pragma에서 비교할 수 없는 번역/합성

**Problematic Code:**
**문제가 있는 코드:**
```verilog
// synthesis translate_off
... (no matching translate_on)
```

**Recommended Fix:**
**권장 수정 사항:**
```verilog
// synthesis translate_off
...
// synthesis translate_on
```

---

## Fix Strategy
## 전략 수정

1. Add the matching `translate_on`/`synthesis on` pragma with the same keyword.
1. 동일한 키워드를 사용하여 일치하는 `translate_on`/`synesis on` pragma를 추가합니다.
2. Ensure off/on pragmas are paired and use consistent keywords.
2. off/on pragma가 쌍을 이루고 있는지 확인하고 일관된 키워드를 사용하십시오.
3. Check for a typo in the pragma keyword.
3. pragma 키워드에 오타가 있는지 확인하세요.
