# 8-9714: Localparam Without Default
# 8-9714: 기본값이 없는 Localparam

**Message:** `[Synth 8-9714] localparam cannot be declared without a default value`
**메시지:** `[Synth 8-9714] localparam은 기본값 없이 선언될 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A `localparam` has no assigned value.
`localparam`에는 할당된 값이 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: localparam with no value
### P1: 값이 없는 localparam

**Problematic Code:**
**문제가 있는 코드:**
```diff
localparam p4;  // ERROR: no value
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
localparam p4 = 42;  // must have value
```

---

## Fix Strategy
## 전략 수정

1. Always give a `localparam` a value at declaration (`localparam P = 42;`) — it cannot be overridden later, so it must be initialized.
1. 항상 선언 시 `localparam`에 값을 제공하십시오(`localparam P = 42;`). 나중에 재정의할 수 없으므로 초기화해야 합니다.
2. If the value should be configurable from outside, use a `parameter` (overridable) instead of `localparam`.
2. 값을 외부에서 구성할 수 있어야 하는 경우 `localparam` 대신 `매개변수`(재정의 가능)를 사용하세요.
3. Derive the localparam from other parameters if it is computed (`localparam W = A + B;`).
3. localparam이 계산된 경우 다른 매개변수에서 localparam을 파생시킵니다(`localparam W = A + B;`).
4. Remove any bare localparam that was intended to be assigned elsewhere.
4. 다른 곳에 할당할 예정이었던 기본 localparam을 제거합니다.
