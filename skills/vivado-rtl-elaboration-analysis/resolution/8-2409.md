# 8-2409: 4-State Net Type Required
# 8-2409: 4-상태 네트 유형 필수

**Message:** `[Synth 8-2409] net data types must be 4 state`
**메시지:** `[Synth 8-2409] net 데이터 유형은 4개 상태여야 합니다.'
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A SystemVerilog net type must be 4-state (`logic`, `reg`), not 2-state (`bit`).
SystemVerilog 넷 유형은 2상태(`bit`)가 아니라 4상태(`logic`, `reg`)여야 합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: 2-state type used for a net
### P1: 네트에 사용되는 2-state 유형

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: 2-state net type
wire bit w;  // ERROR: net must be 4-state
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use 4-state type
wire logic w;  // 4-state OK
// Or just: wire w;  // default is logic
```

---

## Fix Strategy
## 전략 수정

1. Declare nets (`wire`, `tri`) with a 4-state data type — use `logic` (the default) rather than the 2-state `bit`.
1. 4상태 데이터 유형으로 네트(`wire`, `tri`)를 선언합니다. 2상태 `bit` 대신 `logic`(기본값)을 사용합니다.
2. Reserve 2-state types (`bit`, `byte`, `int`) for variables where 4-state resolution is not needed, not for nets.
2. 넷이 아닌 4상태 해석이 필요하지 않은 변수에 대해 2상태 유형(`bit`, `byte`, `int`)을 예약합니다.
3. Simply drop the explicit `bit` on a net (`wire w;`) since `wire`/`tri` default to 4-state `logic`.
3. `wire`/`tri`의 기본값은 4-상태 `logic`이므로 네트(`wire w;`)에 명시적인 `bit`를 삭제하기만 하면 됩니다.
4. If you need multi-driver resolution on the net, 4-state is required so `x`/`z` contention can be represented.
4. 네트워크에서 다중 드라이버 해결이 필요한 경우 `x`/`z` 경합을 표현할 수 있도록 4-상태가 필요합니다.
