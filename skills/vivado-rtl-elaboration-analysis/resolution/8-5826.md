# 8-5826: Design Unit Not in Library
# 8-5826: 디자인 단위가 라이브러리에 없음

**Message:** `[Synth 8-5826] no such design unit '!%1!' in library '!%2!'`
**메시지:** `[Synth 8-5826] 해당 디자인 단위 '!%1!'이 없습니다. 라이브러리 '!%2!'`에 있음
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A design unit is not found in the specified VHDL library.
지정된 VHDL 라이브러리에서 디자인 단위를 찾을 수 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Entity not compiled into the library
### P1: 엔터티가 라이브러리에 컴파일되지 않았습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: entity not in library
U1: entity work.dut port map(...);  -- ERROR: 'dut' not in 'work'
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: compile entity into correct library
-- read_vhdl -library work dut.vhd  -- compile into 'work'
-- Or fix the library name
```

---

## Fix Strategy
## 전략 수정

1. Compile the referenced design unit into the correct library (usually `work`) before the file that instantiates it.
1. 참조된 디자인 단위를 인스턴스화하는 파일 이전에 올바른 라이브러리(일반적으로 'work')로 컴파일합니다.
2. Fix any library/name mismatch in the `use`/instantiation (`entity work.<name>` must match the compiled unit and library).
2. `use`/인스턴스화에서 라이브러리/이름 불일치를 수정합니다(`entity work.<name>`은 컴파일된 유닛 및 라이브러리와 일치해야 함).
3. Check the compile order — the entity/package must be analyzed before its user in a file-order-sensitive flow.
3. 컴파일 순서를 확인하십시오. 파일 순서에 민감한 흐름에서 사용자보다 엔터티/패키지를 분석해야 합니다.
4. If it lives in a separate library, declare and map that library and reference it explicitly.
4. 별도의 라이브러리에 있는 경우 해당 라이브러리를 선언 및 매핑하고 명시적으로 참조하세요.
