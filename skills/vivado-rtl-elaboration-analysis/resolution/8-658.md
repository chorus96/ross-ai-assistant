# 8-658: Type Mismatch for Port
# 8-658: 포트 유형 불일치

**Message:** `[Synth 8-658] type mismatch for port '!%1!'`
**메시지:** `[Synth 8-658] 포트 '!%1!'에 대한 유형 불일치`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL port connection has a type mismatch between formal and actual.
VHDL 포트 연결의 형식과 실제 유형이 일치하지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Port/signal type mismatch (VHDL)
### P1: 포트/신호 유형 불일치(VHDL)

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: type mismatch
port map(drvstate_write => integer_sig);  -- ERROR: port expects std_logic
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: match types
port map(drvstate_write => std_logic_sig);  -- types match
```

---

## Fix Strategy
## 전략 수정

1. Make the actual signal's type match the formal port type exactly (e.g., `std_logic` to `std_logic`, `unsigned` to `unsigned`).
1. 실제 신호 유형이 공식 포트 유형과 정확히 일치하도록 만드세요(예: `std_logic`에서 `std_logic`으로, `unsigned`에서 `unsigned`로).
2. Where a controlled conversion is intended, apply an explicit type conversion/cast at the connection (`std_logic_vector(sig)`, `unsigned(sig)`, `to_integer(...)`).
2. 제어된 변환이 의도된 경우 연결(`std_logic_Vector(sig)`, `unsigned(sig)`, `to_integer(...)`)에서 명시적인 유형 변환/캐스트를 적용합니다.
3. Prefer a shared subtype/package type for both the port and the connected signal so they are guaranteed compatible.
3. 포트와 연결된 신호 모두에 대해 공유 하위 유형/패키지 유형을 선호하므로 호환성이 보장됩니다.
4. Fix the port or signal declaration if one of them simply has the wrong type.
4. 포트 또는 신호 선언 중 하나에 잘못된 유형이 있는 경우 해당 선언을 수정하세요.
