# 8-2599: Range Not Allowed in Prefix
# 8-2599: 접두사에 범위가 허용되지 않음

**Message:** `[Synth 8-2599] range is not allowed in a prefix`
**메시지:** `[Synth 8-2599] 범위는 접두사에 허용되지 않습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A Verilog range selector is used on a prefix where it's not allowed.
Verilog 범위 선택기는 허용되지 않는 접두사에 사용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Range selector on an illegal prefix
### P1: 잘못된 접두사의 범위 선택기

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: range in illegal prefix
assign out = func[3:0](in);  // ERROR: range on function call
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: assign then select
wire [7:0] temp = func(in);
assign out = temp[3:0];  // select from result
```

---

## Fix Strategy
## 전략 수정

1. Apply a range/bit-select to the **result** of an expression, not directly to a function call or other non-selectable prefix.
1. 함수 호출이나 기타 선택할 수 없는 접두사에 직접 적용하지 않고 표현식의 **결과**에 범위/비트 선택을 적용합니다.
2. Store the expression's value in a wire/variable, then part-select from it (`wire [7:0] tmp = func(in); assign out = tmp[3:0];`).
2. 표현식의 값을 와이어/변수에 저장한 다음 그것에서 부분을 선택합니다(`wire [7:0] tmp = func(in); 할당 out = tmp[3:0];`).
3. If you meant to size the function's return, declare the function with the intended width and select afterward.
3. 함수의 반환 크기를 조정하려면 원하는 너비로 함수를 선언하고 나중에 선택하세요.
4. Check for a misplaced bracket that turned an index onto the wrong prefix.
4. 색인을 잘못된 접두어로 바꾸는 잘못된 위치의 대괄호를 확인하세요.
