# 8-439: Module Not Found
# 8-439: 모듈을 찾을 수 없음

**Message:** `[Synth 8-439] module '!%1!' not found`
**메시지:** `[Synth 8-439] 모듈 '!%1!' 찾을 수 없습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-439] module 'my_submodule' not found [/path/to/file.v:100]
```

---

## Root Cause
## 근본 원인

An instantiated module or entity cannot be found in the design sources.
인스턴스화된 모듈이나 엔터티를 디자인 소스에서 찾을 수 없습니다.
The module name in the instantiation doesn't match any defined module.
인스턴스화의 모듈 이름이 정의된 모듈과 일치하지 않습니다.

### Common Patterns
### 일반적인 패턴

| Pattern<br>패턴 | Symptom<br>증상 | Root Cause<br>근본 원인 |
|---------|---------|------------|
| P1: Typo<br>P1: 오타 | Name similar to existing module<br>기존 모듈과 유사한 이름 | Misspelled module name<br>철자가 틀린 모듈 이름 |
| P2: Missing file<br>P2: 파일 누락 | Module not in project<br>프로젝트에 모듈이 없습니다 | Source file not added<br>소스 파일이 추가되지 않았습니다. |
| P3: Library issue<br>P3: 라이브러리 문제 | VHDL entity in different library<br>다른 라이브러리의 VHDL 엔터티 | Missing library reference<br>누락된 라이브러리 참조 |
| P4: Case mismatch<br>P4: 대소문자 불일치 | Same name, different case<br>같은 이름, 다른 케이스 | Case-sensitive naming<br>대소문자를 구분하는 이름 지정 |

---

## Fix Options
## 수정 옵션

### P1: Fix Module Name Typo
### P1: 모듈 이름 오타 수정

```verilog
// Before - typo in module name
my_adder_inst my_ader (  // ERROR: module 'my_ader' not found
  .a(in1),
  .b(in2),
  .sum(out)
);
```

```diff
- my_adder_inst my_ader (
+ my_adder my_adder_inst (   // fix module name
    .a(in1),
    .b(in2),
    .sum(out)
  );
```

### P2: Add Missing Source File
### P2: 누락된 소스 파일 추가

Check if the module file exists and add to project:
모듈 파일이 있는지 확인하고 프로젝트에 추가하십시오.

```tcl
# In Vivado Tcl
add_files /path/to/missing_module.v
# Or for VHDL
add_files /path/to/missing_entity.vhd
```

Or in project settings, ensure the file is included:
또는 프로젝트 설정에서 파일이 포함되어 있는지 확인하세요.
```tcl
read_verilog /path/to/module.v
read_vhdl /path/to/entity.vhd
```

### P3: Fix VHDL Library Reference
### P3: VHDL 라이브러리 참조 수정

```vhdl
-- Before - entity in different library
U0: entity my_module port map(...);  -- ERROR: module 'my_module' not found

-- After - specify correct library
U0: entity work.my_module port map(...);
-- Or if in a different library:
U0: entity mylib.my_module port map(...);
```

### P4: Fix Case Mismatch (VHDL is case-insensitive, Verilog is case-sensitive)
### P4: 대소문자 불일치 수정(VHDL은 대소문자를 구분하지 않고 Verilog는 대소문자를 구분함)

```verilog
// Before - case mismatch
MyModule inst1 (  // ERROR if defined as 'mymodule'
  ...
);

// After - match exact case
mymodule inst1 (
  ...
);
```

## Diagnostic Steps
## 진단 단계

1. Search project for the module name:
1. 모듈 이름에 대한 프로젝트 검색:
   ```tcl
   # In Vivado
   get_files *module_name*
   ```

2. Check if module is in a library:
2. 모듈이 라이브러리에 있는지 확인하십시오.
   ```tcl
   report_compile_order -fileset sources_1
   ```

3. Verify module definition exists and is syntactically correct
3. 모듈 정의가 존재하고 구문이 올바른지 확인하세요.
