# 8-9315: Concurrent Assignment to Non-Net
# 8-9315: Non-Net에 동시 할당

**Message:** `[Synth 8-9315] concurrent assignment to a non-net is not permitted`
**메시지:** `[Synth 8-9315] non-net에 대한 동시 할당은 허용되지 않습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A continuous `assign` statement targets a variable (`reg`, `logic`), not a net.
연속적인 `할당` 문은 네트가 아닌 변수(`reg`, `logic`)를 대상으로 합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Continuous assign to a reg
### P1: 등록에 지속적으로 할당

**Problematic Code:**
**문제가 있는 코드:**
```diff
reg t;
assign t = in1;  // ERROR: assign to reg
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
wire t;
assign t = in1;  // wire is net type
// Or use always: always @(*) t = in1;
```

---

## Fix Strategy
## 전략 수정

1. Continuous `assign` can only target a **net** — declare the target as `wire` (Verilog) / `logic` net, not `reg`.
1. 연속 `할당`은 **net**만 대상으로 지정할 수 있습니다. 대상을 `reg`가 아닌 `wire`(Verilog) / `logic` net으로 선언합니다.
2. If the target must be a `reg`/variable, drive it in an `always @(*)` block with a blocking assignment instead of a continuous `assign`.
2. 대상이 `reg`/변수여야 하는 경우 연속 `할당` 대신 차단 할당을 사용하여 `항상 @(*)` 블록으로 구동하세요.
3. Ensure the signal has a single driver kind (continuous or procedural), never both.
3. 신호에 단일 드라이버 종류(연속 또는 절차)가 있는지 확인하고 둘 다 사용해서는 안 됩니다.
4. Pick `wire`+`assign` for simple combinational connections and `reg`/`always` for procedural logic.
4. 간단한 조합 연결의 경우 `wire`+`할당`을 선택하고 절차적 논리의 경우 `reg`/`always`를 선택하세요.
