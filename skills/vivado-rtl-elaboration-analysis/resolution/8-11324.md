# 8-11324: Array Index Out of Range
# 8-11324: 배열 인덱스가 범위를 벗어났습니다.

**Message:** `[Synth 8-11324] array index !%1! out of range`
**메시지:** `[Synth 8-11324] 배열 인덱스 !%1! 범위를 벗어났습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL array index exceeds the declared bounds.
VHDL 배열 인덱스가 선언된 범위를 초과합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Array index out of range
### P1: 배열 인덱스가 범위를 벗어났습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: index 8 on array(0 to 7)
signal arr : std_logic_vector(7 downto 0);
arr(8) <= '1';  -- ERROR: index 8 out of range
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use valid index
arr(7) <= '1';  -- within 0..7
-- Or expand array:
signal arr : std_logic_vector(8 downto 0);
```

---

## Fix Strategy
## 전략 수정

1. Keep array indices within the declared bounds (`0 ..
1. 배열 인덱스를 선언된 범위(`0 ..
1. N-1` for `(N-1 downto 0)`); check for off-by-one on the MSB.
1. `(N-1에서 0까지)`의 경우 N-1`); MSB에서 off-by-one을 확인하십시오.
2. For a computed index, add a range guard or size the index to the array's address width.
2. 계산된 인덱스의 경우 범위 가드를 추가하거나 인덱스 크기를 배열의 주소 너비에 맞게 조정합니다.
3. If a larger index is legitimate, expand the array declaration to match.
3. 더 큰 인덱스가 적합한 경우 배열 선언을 확장하여 일치시킵니다.
4. Verify index direction (`to` vs `downto`) matches the array declaration.
4. 인덱스 방향(`to` vs `downto`)이 배열 선언과 일치하는지 확인하세요.
