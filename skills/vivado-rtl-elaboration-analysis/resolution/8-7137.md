# 8-7137: Register DATA_VALID_reg in module smii2Byte has
# 8-7137: smii2Byte 모듈에 DATA_VALID_reg를 등록했습니다.

**Message:** `[Synth 8-7137] Register DATA_VALID_reg in module smii2Byte has both Set and reset with same priority.
**메시지:** `[Synth 8-7137] smii2Byte 모듈의 DATA_VALID_reg 등록에는 동일한 우선순위로 설정 및 재설정이 모두 있습니다.
This may cause simulation mismatches.
이로 인해 시뮬레이션 불일치가 발생할 수 있습니다.
Consider rewriting code`
코드 재작성을 고려해보세요`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

## Root Cause
## 근본 원인

A register is described with **both a set and a reset at the same priority**, so
레지스터는 **동일한 우선순위의 설정과 재설정**으로 설명됩니다.
the order in which they are applied is ambiguous.
적용 순서가 모호합니다.
Simulation and synthesis may
시뮬레이션과 합성은 다음과 같습니다.
resolve the tie differently, causing a mismatch.
동점을 다르게 해결하여 불일치가 발생합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Register set and reset at equal priority
### P1: 동일한 우선순위로 레지스터 설정 및 재설정

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Problematic line:
begin
         DATA           <= #Td input_shift_reg[9:2];
         DATA_VALID     <= #Td input_shift_reg[1]; 
      end  
   end
```

**Recommended Fix:**
**권장 수정 사항:**
```verilog
// Give set and reset an explicit priority (reset wins here)
always @(posedge clk)
  if      (rst)  DATA_VALID <= 1'b0;   // reset has priority
  else if (set)  DATA_VALID <= 1'b1;
  else           DATA_VALID <= input_shift_reg[1];
```

---

## Fix Strategy
## 전략 수정

1. Give the set and reset an **explicit priority** — test one before the other (`if rst ... else if set ...`) so simulation and synthesis agree.
1. 설정에 **명시적 우선순위**를 부여하고 재설정합니다. 먼저 테스트하여(`if rst ... else if set ...`) 시뮬레이션과 합성이 일치하도록 합니다.
2. Prefer a single asynchronous control and make the other synchronous, matching Xilinx-recommended register styles.
2. 단일 비동기 제어를 선호하고 Xilinx 권장 레지스터 스타일과 일치하는 다른 동기 제어를 만드십시오.
3. Avoid describing both set and reset at equal priority in the same conditional.
3. 동일한 조건부에서 동일한 우선순위로 set 및 Reset을 모두 설명하지 마십시오.
4. Verify the resulting reset/set behavior matches the intended functionality.
4. 결과적인 재설정/설정 동작이 의도한 기능과 일치하는지 확인합니다.
