# 8-10043: Subprogram Missing Body
# 8-10043: 하위 프로그램 본문 누락

**Message:** `[Synth 8-10043] subprogram does not have a body`
**메시지:** `[Synth 8-10043] 서브프로그램에 본문이 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10043] subprogram does not have a body [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A function or procedure is declared in a package specification but has no corresponding body in the package body, or the body has mismatched syntax due to translate directives.
함수 또는 프로시저가 패키지 사양에 선언되었지만 패키지 본문에 해당 본문이 없거나 번역 지시어로 인해 본문의 구문이 일치하지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Subprogram body hidden or missing
### P1: 하위 프로그램 본문이 숨겨졌거나 누락되었습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: function declared but body not properly visible
package my_pac is
  function unary (in1 : std_logic_vector) return std_logic_vector;
end my_pac;
package body my_pac is
  -- body hidden by translate_off/translate_on directives
end my_pac;
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: ensure body is visible to synthesis
package body my_pac is
  function unary (in1 : std_logic_vector(3 downto 0))
    return std_logic_vector is
  begin
    return not in1;
  end function;
end my_pac;
```

---

## Fix Strategy
## 전략 수정

1. Ensure every subprogram declared in a package spec has a matching **body** in the package body.
1. 패키지 사양에 선언된 모든 하위 프로그램에 패키지 본문에 일치하는 **본문**이 있는지 확인하세요.
2. Check that the body is not hidden by `-- synthesis translate_off/on` (or `` `ifdef ``) pragmas — move the real body outside such guards.
2. 본체가 `-- 합성 번역 오프/온`(또는 `ifdef `) 프라그마에 의해 숨겨지지 않았는지 확인하십시오. 실제 본체를 이러한 가드 밖으로 이동하십시오.
3. Match the body's signature (name, parameter types, return type) to the declaration exactly.
3. 본문의 서명(이름, 매개변수 유형, 반환 유형)을 선언과 정확하게 일치시킵니다.
4. Recompile the package body and confirm it is in the same library as the spec.
4. 패키지 본문을 다시 컴파일하고 사양과 동일한 라이브러리에 있는지 확인하세요.
