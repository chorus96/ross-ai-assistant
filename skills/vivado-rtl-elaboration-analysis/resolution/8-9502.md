# 8-9502: Generate Index Not Genvar
# 8-9502: Genvar가 아닌 인덱스 생성

**Message:** `[Synth 8-9502] generate loop index is not defined as a genvar`
**메시지:** `[Synth 8-9502] 생성 루프 인덱스가 genvar로 정의되지 않았습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A generate loop uses a variable that's not declared as `genvar`.
생성 루프는 `genvar`로 선언되지 않은 변수를 사용합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Generate index not a genvar
### P1: genvar가 아닌 인덱스 생성

**Problematic Code:**
**문제가 있는 코드:**
```diff
integer i;
generate for(i=0;i<4;i=i+1)  // ERROR: i not genvar
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
genvar i;
generate for(i=0;i<4;i=i+1)  // correct
```

---

## Fix Strategy
## 전략 수정

1. Declare the generate loop index as a `genvar` (`genvar i;`), not `integer`/`reg`.
1. 생성 루프 인덱스를 `integer`/`reg`가 아닌 `genvar`(`genvar i;`)로 선언하세요.
2. Place the `genvar` declaration before the `generate` block and use it only for elaboration-time iteration.
2. `genvar` 선언을 `generate` 블록 앞에 배치하고 정교화 시간 반복에만 사용하세요.
3. Ensure the loop bounds/step are elaboration-time constants alongside the genvar.
3. 루프 경계/단계가 genvar와 함께 정교화 시간 상수인지 확인하세요.
4. For runtime loops, use a normal variable in an always/process — but that is not a generate loop.
4. 런타임 루프의 경우 Always/process에서 일반 변수를 사용하십시오. 그러나 이는 생성 루프가 아닙니다.
