# 8-689: width (3) of port connection 'B'
# 8-689: 포트 연결 'B'의 너비(3)

**Message:** `[Synth 8-689] width (3) of port connection 'B' does not match port width (1) of module 'child'`
**메시지:** `[Synth 8-689] 포트 연결 'B'의 너비(3)가 '하위' 모듈의 포트 너비(1)와 일치하지 않습니다`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

The width of a signal connected to a port does not match the port's declared
포트에 연결된 신호의 폭이 포트에서 선언한 폭과 일치하지 않습니다.
width on the instantiated module.
인스턴스화된 모듈의 너비.
Vivado connects the overlapping bits and
Vivado는 겹치는 비트를 연결하고
zero-fills or drops the rest, which is almost always a bug.
나머지는 0으로 채우거나 삭제합니다. 이는 거의 항상 버그입니다.
It is frequently
그것은 자주
caused by **positional** port connections where the argument order is wrong, or
인수 순서가 잘못된 **위치** 포트 연결로 인해 발생하거나
by a signal whose declared width differs from the child port.
선언된 너비가 하위 포트와 다른 신호에 의해.

## Common Patterns
## 일반적인 패턴

### P1: Positional connection with mismatched widths / wrong order
### P1: 너비가 일치하지 않는 위치 연결/잘못된 순서

**Problematic Code:**
**문제가 있는 코드:**
```systemverilog
module child(input a, input [0:0] b, input c, output o);
  ...
endmodule

// parent
wire [2:0] b;                 // 3 bits
child inst(a, b, c, o);       // WARNING: 3-bit 'b' drives 1-bit port 'B'
```

**Fix — match the signal width to the port and use named connections:**
**수정 — 신호 폭을 포트에 일치시키고 명명된 연결을 사용합니다.**
```systemverilog
wire b;                       // 1 bit, matches port
child inst(.a(a), .b(b), .c(c), .o(o));   // named, unambiguous
```

### P2: Intentional width difference needs explicit slicing/padding
### P2: 의도적인 너비 차이에는 명시적인 슬라이싱/패딩이 필요합니다.

**Fix — make the width adaptation explicit:**
**수정 — 너비 적응을 명시적으로 지정:**
```systemverilog
wire [2:0] wide_b;
child inst(.a(a), .b(wide_b[0]), .c(c), .o(o));   // select the intended bit
```

## Fix Strategy
## 전략 수정

1. Compare the connected signal's width with the child module's port width and make them equal by fixing the signal declaration or the port declaration.
1. 연결된 신호의 폭을 하위 모듈의 포트 폭과 비교하고 신호 선언이나 포트 선언을 수정하여 동일하게 만듭니다.
2. Switch from **positional** to **named** port connections (`.port(sig)`) so ordering mistakes that cause width mismatches are eliminated.
2. **위치**에서 **이름이 지정된** 포트 연결(`.port(sig)`)로 전환하면 너비 불일치를 유발하는 순서 실수가 제거됩니다.
3. If the widths legitimately differ, adapt explicitly — slice (`sig[hi:lo]`) to narrow, or concatenate/zero-extend (`{{N{1'b0}}, sig}`) to widen — rather than relying on the tool's silent truncation/padding.
3. 너비가 합법적으로 다른 경우 도구의 자동 자르기/패딩에 의존하기보다는 명시적으로 조정하십시오. 즉, 슬라이스(`sig[hi:lo]`)를 사용하여 축소하거나 연결/0 확장(`{{N{1'b0}}, sig}`)을 사용하여 넓히십시오.
4. Verify the instantiated module is the intended version; a stale definition with different port widths is a common cause.
4. 인스턴스화된 모듈이 의도한 버전인지 확인하세요. 포트 너비가 다른 오래된 정의가 일반적인 원인입니다.
