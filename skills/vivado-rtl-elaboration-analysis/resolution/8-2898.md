# 8-2898: Ignoring Specify Block
# 8-2898: 지정 블록 무시

**Message:** `[Synth 8-2898] ignoring specify block`
**메시지:** `[Synth 8-2898] 지정 블록 무시`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

Vivado ignores `specify` blocks during synthesis — they are for timing annotation only.
Vivado는 합성 중에 `specify` 블록을 무시합니다. 이는 타이밍 주석에만 사용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: specify block in synthesizable RTL
### P1: 합성 가능한 RTL에서 블록을 지정합니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
specify
  (A => Z) = 5;
endspecify  // WARNING: ignored in synthesis
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// Specify blocks are simulation-only — this warning is expected
// No fix needed unless specify was intended for synthesis
```

---

## Fix Strategy
## 전략 수정

1. No RTL change is required — `specify` blocks are simulation timing annotations and are correctly ignored by synthesis.
1. RTL 변경이 필요하지 않습니다. '지정' 블록은 시뮬레이션 타이밍 주석이며 합성에서 올바르게 무시됩니다.
2. Model real timing requirements with XDC constraints (`create_clock`, `set_input_delay`, etc.), not `specify` paths.
2. '지정' 경로가 아닌 XDC 제약 조건('create_clock', 'set_input_delay' 등)을 사용하여 실제 타이밍 요구 사항을 모델링합니다.
3. If the `specify` block belongs to a cell/library model, keep it in the simulation-only view and out of synthesizable RTL.
3. '지정' 블록이 셀/라이브러리 모델에 속하는 경우 이를 시뮬레이션 전용 보기에 유지하고 합성 가능한 RTL에서 제외하세요.
4. To silence the noise, wrap the `specify`/`endspecify` in `// synthesis translate_off` / `translate_on`.
4. 소음을 없애려면 `// 합성 번역 오프` / `번역_온`에 `지정`/`종료 지정`을 래핑하세요.
