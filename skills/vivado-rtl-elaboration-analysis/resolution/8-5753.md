# 8-5753: Loadless Multi-Driven Net
# 8-5753: 로드리스 다중 구동 넷

**Message:** `[Synth 8-5753] loadless multi-driven net`
**메시지:** `[Synth 8-5753] 무부하 다중 구동 넷`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A net is driven by multiple sources but has no loads (nothing reads it).
net은 여러 소스에 의해 구동되지만 로드가 없습니다(아무 것도 읽지 않음).

---

## Common Patterns
## 일반적인 패턴

### P1: Multi-driven net with no load
### P1: 무부하 다중 구동 네트

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: multi-driven but unread
assign in21 = a;
assign in21 = b;  // WARNING: multi-driven, no load
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: remove duplicate drivers and ensure the net has a load
wire in21 = a;  // single driver
```

---

## Fix Strategy
## 전략 수정

1. Remove the duplicate/extra drivers so the net has exactly one driver.
1. 중복/추가 드라이버를 제거하여 네트에 정확히 하나의 드라이버가 있도록 하십시오.
2. Ensure the net actually has a load (something reads it) — a loadless net usually means the intended consumer connection is missing; hook it up.
2. 넷에 실제로 로드가 있는지 확인하십시오(뭔가 이를 읽음). 로드가 없는 넷은 일반적으로 의도한 소비자 연결이 누락되었음을 의미합니다. 연결해 보세요.
3. If the net is genuinely unused, delete it and its drivers to clean up dead logic.
3. 네트가 실제로 사용되지 않은 경우 해당 네트와 해당 드라이버를 삭제하여 데드 로직을 정리하십시오.
4. If multiple sources are intended, combine them through a mux/priority logic into a single driver.
4. 여러 소스를 의도하는 경우 다중화/우선순위 논리를 통해 소스를 단일 드라이버로 결합합니다.
