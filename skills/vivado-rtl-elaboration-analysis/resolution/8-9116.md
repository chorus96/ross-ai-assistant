# 8-9116: Generic Values Don't Match
# 8-9116: 일반 값이 일치하지 않습니다.

**Message:** `[Synth 8-9116] actual values for generic do not match between package instantiation`
**메시지:** `[Synth 8-9116] 일반의 실제 값이 패키지 인스턴스화 간에 일치하지 않습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

Generic values provided in a package instantiation conflict with existing constraints.
패키지 인스턴스화에 제공된 일반 값이 기존 제약 조건과 충돌합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Conflicting package generic values
### P1: 충돌하는 패키지 일반 값

**Problematic Code:**
**문제가 있는 코드:**
```diff
package p is new gen_pkg generic map(T=>integer);  -- ERROR: conflicts
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- Ensure generic values match constraints from the original generic package
```

---

## Fix Strategy
## 전략 수정

1. Provide generic values in the package instantiation that satisfy the original generic package's constraints (matching type/subtype/range).
1. 원래 일반 패키지의 제약 조건(일치하는 유형/하위 유형/범위)을 충족하는 패키지 인스턴스화에 일반 값을 제공합니다.
2. Check the base generic package's declared constraints and align every actual to them.
2. 기본 일반 패키지의 선언된 제약 조건을 확인하고 모든 실제 제약 조건을 이에 맞춰 조정하세요.
3. Ensure a consistent set of generics across multiple instantiations that must agree.
3. 동의해야 하는 여러 인스턴스화에서 일관된 제네릭 세트를 보장합니다.
4. Confirm the flow supports VHDL-2008 generic packages; if not, use a concrete package instead.
4. 흐름이 VHDL-2008 일반 패키지를 지원하는지 확인하세요. 그렇지 않다면 대신 구체적인 패키지를 사용하세요.
