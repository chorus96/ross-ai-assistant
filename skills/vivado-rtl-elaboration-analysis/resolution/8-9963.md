# 8-9963: re-analyze unit '!%1!' since unit '!%2!' is overwritten or removed
# 8-9963: '!%1!' 단위를 다시 분석합니다. '!%2!' 단위부터 덮어쓰거나 제거되었습니다.

**Message:** `[Synth 8-9963] re-analyze unit '!%1!' since unit '!%2!' is overwritten or removed`
**메시지:** `[Synth 8-9963] '!%1!' 유닛을 다시 분석합니다. '!%2!' 단위부터 덮어쓰거나 제거되었습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A unit must be re-analyzed because a unit it depends on was overwritten or removed.
해당 장치가 의존하는 장치가 덮어쓰여졌거나 제거되었기 때문에 장치를 다시 분석해야 합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Unit must be re-analyzed (dependency overwritten)
### P1: 단위를 다시 분석해야 합니다(종속성 덮어쓰기).

**Problematic Code:**
**문제가 있는 코드:**
```vhdl
-- 'a' depends on 'b'; 'b' was overwritten/removed
```

**Recommended Fix:**
**권장 수정 사항:**
```vhdl
-- recompile 'b' then 'a' in dependency order
```

---

## Fix Strategy
## 전략 수정

1. Recompile the dependency, then the dependent unit, in order.
1. 종속성을 다시 컴파일한 다음 종속 유닛을 순서대로 다시 컴파일합니다.
2. Fix the compile/file-list order so dependencies come first.
2. 종속성이 먼저 나오도록 컴파일/파일 목록 순서를 수정합니다.
3. Ensure the overwritten/removed unit is restored.
3. 덮어쓰거나 제거한 장치가 복원되었는지 확인하십시오.
