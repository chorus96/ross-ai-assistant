# 8-11615: Missing Default for Open Actual
# 8-11615: 공개 실제에 대한 기본값이 누락되었습니다.

**Message:** `[Synth 8-11615] Default expression is missing for open actual expression`
**메시지:** `[Synth 8-11615] 열린 실제 표현식에 대한 기본 표현식이 누락되었습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL port with an `open` actual expression has no default value in the entity declaration.
'open' 실제 표현식이 있는 VHDL 포트에는 엔터티 선언에 기본값이 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: open input without a default
### P1: 기본값 없이 입력 열기

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: open port without default
port (in1 : in std_logic);  -- no default
-- instantiation:
port map(in1 => open);  -- ERROR: no default for open
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: add default to port declaration
port (in1 : in std_logic := '0');  -- default for open
-- Now open is valid
```

---

## Fix Strategy
## 전략 수정

1. Give ports that may be left `open` a default value in the entity (`port (p : in std_logic := '0')`).
1. 'open' 상태로 남겨둘 수 있는 포트에 엔터티의 기본값('port (p : in std_logic := '0')`)을 지정합니다.
2. Only inputs with defaults may be `open`; required inputs must be connected.
2. 기본값이 있는 입력만 `open`일 수 있습니다. 필요한 입력을 연결해야 합니다.
3. For outputs, `open` is fine — the warning is about inputs lacking a default.
3. 출력의 경우 `open`은 괜찮습니다. 경고는 기본값이 없는 입력에 대한 것입니다.
4. Connect the port explicitly if a default is not appropriate.
4. 기본값이 적절하지 않은 경우 포트를 명시적으로 연결하십시오.
