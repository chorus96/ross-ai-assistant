# 8-9764: Multiple Timeunit Definitions
# 8-9764: 다중 시간 단위 정의

**Message:** `[Synth 8-9764] multiple definitions of timeunit`
**메시지:** `[Synth 8-9764] 시간 단위의 여러 정의`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

Multiple `timeunit` declarations in the same scope.
동일한 범위에 여러 `timeunit` 선언이 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Duplicate timeunit declaration
### P1: 중복된 시간 단위 선언

**Problematic Code:**
**문제가 있는 코드:**
```diff
timeunit 1ns;
timeunit 1ps;  // ERROR: duplicate
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
timeunit 1ns;  // keep only one
```

---

## Fix Strategy
## 전략 수정

1. Keep only one `timeunit` (and one `timeprecision`) per scope — remove the duplicate.
1. 범위당 하나의 'timeunit'(및 하나의 'timeprecision')만 유지하고 중복 항목을 제거하세요.
2. If different files need different time units, set them per-module consistently, not twice in one scope.
2. 서로 다른 파일에 서로 다른 시간 단위가 필요한 경우 한 범위에서 두 번이 아니라 모듈별로 일관되게 설정하세요.
3. Prefer a single project-wide `timescale`/`timeunit` policy to avoid conflicts.
3. 충돌을 피하기 위해 프로젝트 전반에 걸친 단일 `timescale`/`timeunit` 정책을 선호합니다.
4. Note that timeunit affects simulation only; ensure it is consistent but it does not change synthesized hardware.
4. timeunit은 시뮬레이션에만 영향을 미칩니다. 일관성을 유지하되 합성된 하드웨어를 변경하지 않는지 확인하세요.
