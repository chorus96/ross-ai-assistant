# 8-9492: Forward Typedef Not Defined
# 8-9492: 전달 Typedef가 정의되지 않음

**Message:** `[Synth 8-9492] forward typedef was not defined in the scope where it is declared`
**메시지:** `[Synth 8-9492] 정방향 typedef가 선언된 범위에 정의되지 않았습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A SystemVerilog forward type declaration (`typedef ... ;`) was never completed.
SystemVerilog 전달 유형 선언(`typedef ... ;`)이 완료되지 않았습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Forward typedef never completed
### P1: 정방향 typedef가 완료되지 않았습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
typedef state1;  // forward declaration
// state1 never fully defined  -- ERROR
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
typedef enum {IDLE,RUN,DONE} state1;  // complete definition
```

---

## Fix Strategy
## 전략 수정

1. Complete the forward `typedef` with a full definition in the **same scope** (`typedef enum {...} state1;`).
1. **동일한 범위**(`typedef enum {...} state1;`)의 전체 정의로 전달 `typedef`를 완성합니다.
2. Use forward typedefs only when needed for mutual references, and always follow with the real definition.
2. 상호 참조에 필요한 경우에만 전방 형식 정의를 사용하고 항상 실제 정의를 따르십시오.
3. Ensure the completing definition is visible before the type is used to declare objects.
3. 유형을 사용하여 객체를 선언하기 전에 완성 정의가 표시되는지 확인하세요.
4. Remove the forward declaration if the full type can simply be declared directly.
4. 전체 유형을 직접 선언할 수 있는 경우 전방 선언을 제거하십시오.
