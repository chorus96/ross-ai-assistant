# 8-2212: Incompatible Unpacked Dimensions
# 8-2212: 호환되지 않는 포장되지 않은 크기

**Message:** `[Synth 8-2212] incompatible unpacked dimensions in assignment`
**메시지:** `[Synth 8-2212] 할당 시 호환되지 않는 압축 해제된 차원`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An assignment between arrays (or array expressions) whose unpacked dimensions do not match.
압축 해제된 차원이 일치하지 않는 배열(또는 배열 표현식) 간의 할당입니다.
This includes:
여기에는 다음이 포함됩니다.
- Direct assignment between arrays with different unpacked dimension sizes or ranges.
- 압축되지 않은 차원 크기 또는 범위가 다른 배열 간의 직접 할당.
- Assigning the result of an array method (`.find`, `.sort`, `.unique`, etc.) on a multi-dimensional unpacked array to a variable with incompatible dimensions.
- 압축이 풀린 다차원 배열의 배열 메소드(`.find`, `.sort`, `.unique` 등)의 결과를 호환되지 않는 차원의 변수에 할당합니다.
- Mixing fixed-size unpacked arrays with queues (`[$]`) or dynamic arrays (`[]`) when dimension shapes differ.
- 차원 형태가 다를 때 압축되지 않은 고정 크기 배열을 대기열(`[$]`) 또는 동적 배열(`[]`)과 혼합합니다.

## Common Patterns
## 일반적인 패턴

### P1: Direct Assignment — Different Unpacked Dimensions
### P1: 직접 할당 - 압축되지 않은 다른 크기

**Problematic Code:**
**문제가 있는 코드:**
```systemverilog
int a[4][8];
int b[8][4];
a = b;  // ERROR: unpacked dimensions [4][8] vs [8][4]
```

**Fix — Match the dimensions on both sides:**
**수정 — 양쪽 치수를 일치시키세요.**
```systemverilog
int a[4][8];
int b[4][8];
a = b;  // OK: same unpacked dimensions
```

### P2: Array Method on Multi-Dimensional Array Assigned to Incompatible Target
### P2: 호환되지 않는 대상에 할당된 다차원 배열의 배열 방법

**Problematic Code:**
**문제가 있는 코드:**
```systemverilog
int a[4:0][1:0];   // 2D unpacked array
int l[$];           // 1D queue
l = a.find(x) with (x > a[1][2]);  // ERROR: .find() on 2D array returns result
                                     // with outermost unpacked dimension, not int
```

**Fix Option A — Use a manual loop (most synthesizable):**
**옵션 A 수정 — 수동 루프 사용(합성 가능성이 가장 높음):**
```systemverilog
int a[4:0][1:0];
int l[$];
l = {};
for (int i = 0; i < 5; i++)
    for (int j = 0; j < 2; j++)
        if (a[i][j] > a[1][2])
            l.push_back(a[i][j]);
```

**Fix Option B — Flatten the array to 1D before calling the array method:**
**옵션 B 수정 — 배열 메서드를 호출하기 전에 배열을 1D로 평면화합니다.**
```systemverilog
int a[4:0][1:0];
int a_flat[10];
int l[$];
for (int i = 0; i < 5; i++)
    for (int j = 0; j < 2; j++)
        a_flat[i*2 + j] = a[i][j];
l = a_flat.find(x) with (x > a[1][2]);
```

**Fix Option C — Operate on a single row (slice) of the array:**
**수정 옵션 C — 배열의 단일 행(슬라이스)에서 작동:**
```systemverilog
int a[4:0][1:0];
int row[1:0];
int l[$];
row = a[1];  // extract one row
l = row.find(x) with (x > a[1][2]);
```

### P3: Assigning Between Fixed-Size and Dynamic/Queue Arrays with Mismatched Structure
### P3: 구조가 일치하지 않는 고정 크기 배열과 동적/큐 배열 사이에 할당

**Problematic Code:**
**문제가 있는 코드:**
```systemverilog
int a[3:0][7:0];
int b[];             // dynamic array of int (1D)
b = a;               // ERROR: 2D unpacked vs 1D dynamic
```

**Fix — Flatten or restructure to match:**
**수정 — 일치하도록 평면화 또는 재구성:**
```systemverilog
int a[3:0][7:0];
int b[];
b = new[32];
for (int i = 0; i < 4; i++)
    for (int j = 0; j < 8; j++)
        b[i*8 + j] = a[i][j];
```

## Fix Strategy
## 전략 수정

1. **Inspect both sides of the assignment** — check the unpacked dimension count and sizes on the LHS and RHS.
1. **과제의 양면을 검사하세요** — LHS와 RHS에서 압축을 푼 치수 수와 크기를 확인하세요.
1. They must be identical for direct assignment.
1. 직접 할당하려면 동일해야 합니다.
2. **For array methods on multi-dimensional arrays** — array methods like `.find()`, `.sort()`, `.unique()` on N-dimensional arrays produce results whose dimensions may not match a simple 1D target.
2. **다차원 배열의 배열 메서드** — N차원 배열의 `.find()`, `.sort()`, `.unique()`와 같은 배열 메서드는 차원이 단순한 1D 대상과 일치하지 않을 수 있는 결과를 생성합니다.
2. Prefer replacing with an explicit loop (most synthesizable) or flatten the array to 1D first.
2. 명시적 루프(가장 합성 가능)로 교체하거나 먼저 배열을 1D로 평면화하는 것을 선호합니다.
3. **For synthesis** — queue (`[$]`) and dynamic array (`[]`) types are generally not synthesizable.
3. **합성의 경우** — 대기열(`[$]`) 및 동적 배열(`[]`) 유형은 일반적으로 합성할 수 없습니다.
3. Replace with fixed-size arrays and explicit loops for synthesizable designs.
3. 합성 가능한 설계를 위해 고정 크기 배열 및 명시적 루프로 대체합니다.
4. **Never just delete the offending line** — the design intent must be preserved.
4. **문제가 있는 라인을 절대로 삭제하지 마세요** — 디자인 의도가 보존되어야 합니다.
4. Choose the fix option that maintains the original logic while ensuring dimension compatibility.
4. 차원 호환성을 보장하면서 원래 논리를 유지하는 수정 옵션을 선택합니다.
