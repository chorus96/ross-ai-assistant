# 8-10039: Duplicate Struct/Union Element
# 8-10039: 중복 구조체/결합 요소

**Message:** `[Synth 8-10039] struct/union element is already declared`
**메시지:** `[Synth 8-10039] 구조체/공용체 요소가 이미 선언되었습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10039] struct/union element is already declared [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A struct or union has two members with the same name.
구조체 또는 공용체에는 동일한 이름을 가진 두 개의 멤버가 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Duplicate struct/union member
### P1: 중복된 구조체/공용 구조체 멤버

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: duplicate field 'a'
typedef struct packed {
  logic_t a;
  logic [1:0] b;
  logic_t a;     // ERROR: 'a' already declared
} str_t;
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: rename the duplicate field
typedef struct packed {
  logic_t a;
  logic [1:0] b;
  logic_t c;     // renamed from duplicate 'a'
} str_t;
```

---

## Fix Strategy
## 전략 수정

1. Give each struct/union member a unique name — rename the duplicate.
1. 각 구조체/공용체 멤버에 고유한 이름을 지정하고 중복된 이름을 바꿉니다.
2. Check for copy-paste that repeated a field within the type definition.
2. 유형 정의 내에서 필드를 반복한 복사-붙여넣기를 확인하세요.
3. If two fields represent different data, name them distinctly; if they are the same, keep one.
3. 두 필드가 서로 다른 데이터를 나타내는 경우 이름을 명확하게 지정하세요. 동일하다면 하나를 유지하십시오.
4. Update all member accesses to the corrected names.
4. 모든 구성원 액세스를 수정된 이름으로 업데이트합니다.
