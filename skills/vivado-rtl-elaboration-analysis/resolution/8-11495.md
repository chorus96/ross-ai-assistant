# 8-11495: assignment pattern cannot be used in static casting
# 8-11495: 정적 캐스팅에서는 할당 패턴을 사용할 수 없습니다.

**Message:** `[Synth 8-11495] assignment pattern cannot be used in static casting`
**메시지:** `[Synth 8-11495] 할당 패턴은 정적 캐스팅에서 사용할 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An assignment pattern `'{...}` is used inside a static cast, which is not allowed.
허용되지 않는 할당 패턴 `'{...}`이 정적 형변환 내부에서 사용되었습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Assignment pattern in static cast
### P1: 정적 캐스트의 할당 패턴

**Problematic Code:**
**문제가 있는 코드:**
```systemverilog
y = type_t'('{a,b});   // pattern in static cast
```

**Recommended Fix:**
**권장 수정 사항:**
```systemverilog
type_t tmp = '{a,b};
y = tmp;
```

---

## Fix Strategy
## 전략 수정

1. Assign the pattern to a typed temporary, then use it.
1. 패턴을 입력된 임시 항목에 할당한 다음 사용하세요.
2. Do not place an assignment pattern directly inside a static cast.
2. 정적 캐스트 내부에 직접 할당 패턴을 배치하지 마십시오.
3. Restructure to separate the pattern from the cast.
3. 패턴을 캐스트에서 분리하도록 재구성합니다.
