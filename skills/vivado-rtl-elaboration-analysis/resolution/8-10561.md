# 8-10561: Cannot Update In-Mode Object
# 8-10561: 모드 내 개체를 업데이트할 수 없습니다.

**Message:** `[Synth 8-10561] cannot update object of mode 'in'`
**메시지:** `[Synth 8-10561] 'in' 모드의 개체를 업데이트할 수 없습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10561] cannot update object of mode 'in' [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A VHDL `in` port or `in` parameter is assigned a value.
VHDL 'in' 포트 또는 'in' 매개변수에 값이 할당됩니다.
Input-mode objects are read-only.
입력 모드 개체는 읽기 전용입니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Write to an in-mode object
### P1: 모드 내 개체에 쓰기

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: assigning to input port
entity and_3 is
  port (I0, I1, I2 : in std_logic; O : in std_logic);  -- O should be 'out'
end;
architecture rtl of and_3 is
begin
  O <= I0 and I1 and I2;  -- ERROR: O is mode 'in'
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: change port mode to 'out'
entity and_3 is
  port (I0, I1, I2 : in std_logic; O : out std_logic);  -- fixed: mode 'out'
end;
```

---

## Fix Strategy
## 전략 수정

1. An `in`-mode port/parameter is read-only — change it to `out`/`inout` if it must be written.
1. `in` 모드 포트/매개변수는 읽기 전용입니다. 작성해야 하는 경우 `out`/`inout`으로 변경하세요.
2. If external logic should provide the value, remove the internal assignment and drive an internal signal instead.
2. 외부 로직이 값을 제공해야 하는 경우 내부 할당을 제거하고 대신 내부 신호를 구동하십시오.
3. For subprograms, use an `out`/`inout` parameter (or the return value) for results, not an `in` parameter.
3. 서브프로그램의 경우 결과에 대해 `in` 매개변수가 아닌 `out`/`inout` 매개변수(또는 반환 값)를 사용하세요.
4. Check for a naming mix-up where an assignment targeted the input object.
4. 할당이 입력 개체를 대상으로 하는 경우 명명 혼동이 있는지 확인하세요.
