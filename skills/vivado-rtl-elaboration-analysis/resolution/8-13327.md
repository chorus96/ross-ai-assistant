# 8-13327: Null Range Index
# 8-13327: Null 범위 인덱스

**Message:** `[Synth 8-13327] index on a null range expression`
**메시지:** `[Synth 8-13327] null 범위 표현식의 인덱스`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An index operation is performed on a null-range (empty) array.
null 범위(빈) 배열에 대해 인덱스 작업이 수행됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Index into a null range
### P1: null 범위에 대한 인덱스

**Problematic Code:**
**문제가 있는 코드:**
```diff
signal s : std_logic_vector(4 downto 7);  -- null range
s(5) <= '1';  -- WARNING: null range
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
signal s : std_logic_vector(7 downto 4);  -- valid range
```

---

## Fix Strategy
## 전략 수정

1. Fix the range direction — use `7 downto 4` (not `4 downto 7`) for a descending range so it is non-null.
1. 범위 방향을 수정하세요. 내림차순 범위에는 '7 downto 4'('4 downto 7' 아님)를 사용하여 null이 아니도록 하세요.
2. Ensure width parameters are > 0 so `WIDTH-1 downto 0` does not become a null range.
2. 너비 매개변수가 0보다 큰지 확인하여 'WIDTH-1부터 0까지'가 null 범위가 되지 않도록 하세요.
3. Guard genuinely-zero-width configurations with a `generate`/conditional.
3. `생성`/조건을 사용하여 실제로 너비가 0인 구성을 보호하세요.
4. Verify indices fall within the (now non-null) range.
4. 인덱스가 (현재는 null이 아닌) 범위 내에 있는지 확인합니다.
