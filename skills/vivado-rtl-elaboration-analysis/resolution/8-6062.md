# 8-6062: Asymmetric RAM Ratio Mismatch
# 8-6062: 비대칭 RAM 비율 불일치

**Message:** `[Synth 8-6062] Asymetric Ram !%1! width ratio of !%2! doesn't match depth ratio !%3!.
**메시지:** `[Synth 8-6062] 비대칭 램!%1! 너비 비율이 !%2! 깊이 비율 !%3!과(와) 일치하지 않습니다.
Address size difference is !%4!`
주소 크기 차이는 !%4!`입니다.
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

Asymmetric RAM width ratio doesn't match depth ratio.
비대칭 RAM 너비 비율이 깊이 비율과 일치하지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Inconsistent asymmetric RAM ratios
### P1: 일관되지 않은 비대칭 RAM 비율

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: width ratio 4 but depth ratio 1
// Read port: 32-bit, Write port: 8-bit (ratio 4)
// But address spaces don't reflect the 4:1 depth ratio
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: match ratios per UG901
// Width ratio of 4 needs depth ratio of 4
// Read addr = Write addr width + 2 (for ratio 4)
```

---

## Fix Strategy
## 전략 수정

Ensure asymmetric RAM width and depth ratios are consistent.
비대칭 RAM 너비와 깊이 비율이 일관되게 유지되는지 확인하세요.
Follow UG901 guidelines for address width adjustments.
주소 너비 조정에 대해서는 UG901 지침을 따르십시오.
