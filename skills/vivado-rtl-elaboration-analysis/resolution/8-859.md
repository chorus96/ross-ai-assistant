# 8-859: Too Many Parameter Overrides
# 8-859: 매개변수 재정의가 너무 많음

**Message:** `[Synth 8-859] too many parameter overrides for module '!%1!'`
**메시지:** `[Synth 8-859] 모듈 '!%1!'에 대한 매개변수 재정의가 너무 많습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

More parameter values are provided than the module has parameters.
모듈에 있는 매개변수보다 더 많은 매개변수 값이 제공됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: More parameter overrides than declared
### P1: 선언된 것보다 더 많은 매개변수 재정의

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: too many parameters
module m #(parameter A=1, B=2);
m #(1, 2, 3) inst(...);  // ERROR: 3 values for 2 params
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: match parameter count
m #(1, 2) inst(...);  // 2 values for 2 params
```

---

## Fix Strategy
## 전략 수정

1. Provide no more parameter values than the module declares — remove the extra positional override(s).
1. 모듈이 선언하는 것보다 더 많은 매개변수 값을 제공하지 마십시오. 추가 위치 재정의를 제거하십시오.
2. Use **named** parameter overrides (`#(.WIDTH(8), .DEPTH(16))`) instead of positional so extra/mis-ordered values are caught immediately.
2. 위치 대신 **명명된** 매개변수 재정의(`#(.WIDTH(8), .DEPTH(16))`)를 사용하여 추가/잘못 정렬된 값을 즉시 포착합니다.
3. Verify you are instantiating the intended, current module; a stale definition with fewer parameters is a common cause.
3. 의도한 현재 모듈을 인스턴스화하고 있는지 확인하십시오. 더 적은 수의 매개변수를 가진 오래된 정의가 일반적인 원인입니다.
4. If the extra value is genuinely needed, add the corresponding parameter to the module definition.
4. 추가 값이 실제로 필요한 경우 해당 매개변수를 모듈 정의에 추가하십시오.
