# 8-13374: Removed Unreachable Instance
# 8-13374: 연결할 수 없는 인스턴스가 제거되었습니다.

**Message:** `[Synth 8-13374] Removed Unreachable instance`
**메시지:** `[Synth 8-13374] 연결할 수 없는 인스턴스가 제거되었습니다.`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An instance was removed because it's unreachable — no path from inputs to outputs.
인스턴스가 연결 불가능하여 제거되었습니다. 입력에서 출력까지의 경로가 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Unreachable instance removed
### P1: 연결할 수 없는 인스턴스가 제거되었습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Instance removed — outputs never read
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- Connect outputs or add keep attribute:
(* dont_touch = "true" *) my_mod inst(...);
```

---

## Fix Strategy
## 전략 수정

1. Connect the instance's outputs into the design so there is a path from inputs to observable outputs — unreachable logic is removed.
1. 인스턴스의 출력을 디자인에 연결하여 입력에서 관찰 가능한 출력으로의 경로가 있도록 합니다. 도달할 수 없는 논리는 제거됩니다.
2. Check for a missing wire up the hierarchy that left the instance dangling.
2. 인스턴스를 매달아 놓은 계층 구조에서 누락된 와이어가 있는지 확인하십시오.
3. If the instance must be retained (debug/probe), apply `(* dont_touch = "true" *)` / `keep_hierarchy`.
3. 인스턴스를 유지해야 하는 경우(디버그/프로브) `(* dont_touch = "true" *)` / `keep_hierarchy`를 적용하세요.
4. If genuinely unused, remove the instantiation rather than forcing retention.
4. 실제로 사용되지 않은 경우 보존을 강제하는 대신 인스턴스화를 제거합니다.
