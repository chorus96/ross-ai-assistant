# 8-9729: Closing Label Mismatch
# 8-9729: 라벨 불일치 종료

**Message:** `[Synth 8-9729] mismatch in closing label`
**메시지:** `[Synth 8-9729] 닫는 라벨이 일치하지 않습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL block or process closing label doesn't match the opening label.
VHDL 블록 또는 프로세스 종료 레이블이 시작 레이블과 일치하지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Mismatched closing label
### P1: 일치하지 않는 마감 라벨

**Problematic Code:**
**문제가 있는 코드:**
```diff
block1: block
  ...
end block block2;  -- ERROR: expected 'block1'
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
block1: block
  ...
end block block1;  -- matching label
```

---

## Fix Strategy
## 전략 수정

1. Make the closing label exactly match the opening label (`block1: block ... end block block1;`).
1. 닫는 레이블이 시작 레이블(`block1: block ... end block block1;`)과 정확하게 일치하도록 만듭니다.
2. Check for a mismatched process/loop/block label and correct the closing name (or remove it).
2. 일치하지 않는 프로세스/루프/블록 레이블을 확인하고 종료 이름을 수정하거나 제거하십시오.
3. Watch for copy-paste that left a stale label from another block.
3. 다른 블록에서 오래된 라벨을 남긴 복사-붙여넣기를 주의하세요.
4. Ensure nested blocks each have consistent open/close labels.
4. 중첩된 블록마다 일관된 열기/닫기 라벨이 있는지 확인하세요.
