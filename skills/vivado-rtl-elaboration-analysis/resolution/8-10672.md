# 8-10672: Recursive Record Type
# 8-10672: 재귀 레코드 유형

**Message:** `[Synth 8-10672] element type of the record element is the same as the parent record type`
**메시지:** `[Synth 8-10672] 레코드 요소의 요소 유형이 상위 레코드 유형과 동일합니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10672] element type of the record element is the same as the parent record type [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A VHDL record type contains a field whose type is the record itself — recursive types are not synthesizable.
VHDL 레코드 유형에는 유형이 레코드 자체인 필드가 포함되어 있습니다. 재귀 유형은 합성할 수 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Self-referential record type
### P1: 자기 참조 레코드 유형

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: recursive record (not synthesizable)
type st_t is record
  pSt : st_t;                          -- ERROR: recursive
  dta : std_logic_vector(3 downto 0);
end record;
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use an enumerated state type instead
type pSt_t is (IDLE, ST1, ST2, ST3);   -- state enum
type st_t is record
  pSt : pSt_t;                         -- non-recursive
  dta : std_logic_vector(3 downto 0);
end record;
```

---

## Fix Strategy
## 전략 수정

1. Remove the self-reference from the record — a VHDL record cannot contain an instance of itself.
1. 레코드에서 자체 참조를 제거합니다. VHDL 레코드는 자체 인스턴스를 포함할 수 없습니다.
2. For state/link fields, use an enumerated type or an integer index instead of the record type.
2. 상태/링크 필드의 경우 레코드 유형 대신 열거 유형 또는 정수 인덱스를 사용합니다.
3. Recursive/linked structures are not synthesizable; model them with arrays indexed by integers.
3. 재귀적/연결된 구조는 합성할 수 없습니다. 정수로 인덱스된 배열로 모델링합니다.
4. Break any mutual record references by introducing an index/handle field.
4. 인덱스/핸들 필드를 도입하여 상호 레코드 참조를 중단합니다.
