# 8-11152: second declaration of '!%1!' is ignored
# 8-11152: '!%1!'의 두 번째 선언 무시된다

**Message:** `[Synth 8-11152] second declaration of '!%1!' is ignored`
**메시지:** `[Synth 8-11152] '!%1!'의 두 번째 선언 무시됩니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An identifier is declared twice in the same scope; the second declaration is ignored.
식별자는 동일한 범위에서 두 번 선언됩니다. 두 번째 선언은 무시됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Second declaration is ignored
### P1: 두 번째 선언은 무시됩니다.

**Problematic Code:**
**문제가 있는 코드:**
```verilog
wire a;
wire a;   // second decl ignored
```

**Recommended Fix:**
**권장 수정 사항:**
```verilog
wire a;   // declare once
```

### P2: An `include` already declares the name
### P2: `include`는 이미 이름을 선언합니다.

**Problematic Code:**
**문제가 있는 코드:**
```verilog
`include "nets.vh"    // nets.vh contains: wire busy;
wire busy;            // second declaration of 'busy' is ignored
```

**Recommended Fix — rely on the included declaration, or scope it locally:**
**권장 수정 — 포함된 선언을 사용하거나 로컬로 범위를 지정합니다.**
```verilog
`include "nets.vh"    // keep the single declaration from the header
// remove the redundant local 'wire busy;'
```

### P3: Net and parameter/localparam reuse the same identifier
### P3: Net 및 매개변수/localparam은 동일한 식별자를 재사용합니다.

**Problematic Code:**
**문제가 있는 코드:**
```verilog
localparam WIDTH = 8;
wire [WIDTH-1:0] WIDTH;   // second declaration of 'WIDTH' is ignored
```

**Recommended Fix — use distinct names for the constant and the net:**
**권장 수정 — 상수와 네트에 대해 고유한 이름을 사용하십시오.**
```verilog
localparam WIDTH = 8;
wire [WIDTH-1:0] data;    // net gets its own name
```

---

## Fix Strategy
## 전략 수정

1. Remove the duplicate declaration.
1. 중복 선언을 제거하십시오.
2. If two different objects were intended, give them distinct names.
2. 두 개의 서로 다른 개체를 의도한 경우 서로 다른 이름을 지정하십시오.
3. Check for copy-paste or an include declaring the same name.
3. 복사-붙여넣기 또는 동일한 이름을 선언하는 포함을 확인하세요.
4. Watch for a net reusing a parameter/localparam identifier in the same scope.
4. 동일한 범위에서 매개변수/localparam 식별자를 재사용하는 네트를 살펴보세요.
