# 8-2088: 알 수 없는 pragma 값을 무시하고 있습니다!%1!

**Message:** `[Synth 8-2088] ignoring unknown pragma value !%1!`

**Source:** Oasys Synthesis
**출처:** 오아시스 합성

## Root Cause
## 근본 원인

A pragma carries a value the tool does not know, so the pragma value is ignored.
pragma는 도구가 모르는 값을 전달하므로 pragma 값은 무시됩니다.
