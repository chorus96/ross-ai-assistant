# 8-2481: operator overloading is not supported yet
# 8-2481: 연산자 오버로딩은 아직 지원되지 않습니다.

**Message:** `[Synth 8-2481] operator overloading is not supported yet`
**메시지:** `[Synth 8-2481] 연산자 오버로드는 아직 지원되지 않습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

The design uses operator overloading, which Vivado synthesis does not support.
이 디자인은 Vivado 합성이 지원하지 않는 연산자 오버로딩을 사용합니다.

---

## 일반적인 패턴

### P1: 연산자 오버로딩이 지원되지 않습니다.

**문제가 있는 코드:**

```systemverilog
// overloaded operator definition/use
```

**Recommended Fix:**
**권장 수정 사항:**
```systemverilog
// replace with an explicit function call, e.g. add(a,b)
```

---

## Fix Strategy
## 전략 수정

1. Replace overloaded operators with explicit function calls.
1. 오버로드된 연산자를 명시적 함수 호출로 대체합니다.
2. Keep overloading in non-synthesizable/testbench code only.
2. 합성할 수 없는/테스트벤치 코드에서만 오버로드를 유지하세요.
3. Use plain arithmetic/logic operators in RTL.
3. RTL에서는 일반 산술/논리 연산자를 사용합니다.
