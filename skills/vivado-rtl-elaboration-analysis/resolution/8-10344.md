# 8-10344: Wrong Argument Count
# 8-10344: 잘못된 인수 개수

**Message:** `[Synth 8-10344] requires N arguments`
**메시지:** `[Synth 8-10344]에는 N개의 인수가 필요합니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10344] requires N arguments [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A task or function is called with the wrong number of arguments.
작업이나 함수가 잘못된 개수의 인수로 호출되었습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Wrong argument count in call
### P1: 호출 시 잘못된 인수 개수

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: task called with wrong number of args
task tsk1;             // 0 arguments
  ...
endtask
C11.C12.tsk1(in1,in2); // ERROR: tsk1 requires 0 arguments
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: match argument count to declaration
C11.C12.tsk1();        // call with 0 arguments
// Or fix the task declaration to accept arguments:
task tsk1(input a, input b);
```

---

## Fix Strategy
## 전략 수정

1. Match the number of arguments in the call to the task/function's declaration.
1. 작업/함수 선언에 대한 호출의 인수 수를 일치시킵니다.
2. Use named argument binding so a missing/extra argument is obvious.
2. 누락된/추가 인수가 분명하도록 명명된 인수 바인딩을 사용하십시오.
3. If the call intends to pass values, update the subprogram declaration to accept them (with correct types/directions).
3. 호출이 값을 전달하려는 경우 해당 값을 허용하도록 서브프로그램 선언을 업데이트합니다(올바른 유형/방향으로).
4. Verify you are calling the intended subprogram (not a same-named one in another scope).
4. 의도한 하위 프로그램(다른 범위의 동일한 이름이 아닌)을 호출하고 있는지 확인하십시오.
