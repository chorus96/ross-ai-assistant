# 8-10095: Type Mismatch with Integer Literal
# 8-10095: 정수 리터럴과 유형 불일치

**Message:** `[Synth 8-10095] type does not match with the integer literal`
**메시지:** `[Synth 8-10095] 유형이 정수 리터럴과 일치하지 않습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10095] type does not match with the integer literal [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A VHDL variable of type `bit` is assigned an integer literal.
'bit' 유형의 VHDL 변수에는 정수 리터럴이 할당됩니다.
`bit` can only be `'0'` or `'1'`, not integer values.
`bit`는 `'0'` 또는 `'1'`만 가능하며 정수 값은 될 수 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Integer literal assigned to bit
### P1: 비트에 할당된 정수 리터럴

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: integer assigned to bit variable
variable tmp_bit : bit := 1;  -- ERROR: bit needs '0' or '1', not integer
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use bit literal
variable tmp_bit : bit := '1';
```

---

## Fix Strategy
## 전략 수정

1. Assign `bit`/`bit_vector` with bit literals (`'0'`, `'1'`, `"0101"`), not integer literals.
1. 정수 리터럴이 아닌 비트 리터럴(`'0'`, `'1'`, `"0101"`)을 사용하여 `bit`/`bit_Vector`를 할당하세요.
2. If you need integer values, use an `integer`/`unsigned` type, or convert (`to_unsigned(n, W)` then to the vector type).
2. 정수 값이 필요한 경우 `integer`/`unsigned` 유형을 사용하거나 (`to_unsigned(n, W)`를 벡터 유형으로 변환).
3. Match every literal to its target's element type and width.
3. 모든 리터럴을 대상의 요소 유형 및 너비와 일치시킵니다.
4. For `std_logic`, likewise use `'0'`/`'1'` (and metavalues only in simulation).
4. `std_logic`의 경우 마찬가지로 `'0'`/`'1'`(및 시뮬레이션에서만 메타값)을 사용합니다.
