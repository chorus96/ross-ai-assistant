# 8-6014: Unused Sequential Element Removed
# 8-6014: 사용되지 않은 순차 요소가 제거됨

**Message:** `[Synth 8-6014] Unused sequential element was removed`
**메시지:** `[Synth 8-6014] 사용하지 않는 순차 요소가 제거되었습니다.`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A flip-flop/register was removed because its output is never used.
출력이 전혀 사용되지 않기 때문에 플립플롭/레지스터가 제거되었습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Register with unused output
### P1: 미사용 출력으로 등록

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- WARNING: PktLenght_r_reg removed — output unused
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- If needed, add keep attribute:
(* dont_touch = "true" *) reg PktLenght_r_reg;
-- Otherwise, removal is expected optimization
```

---

## Fix Strategy
## 전략 수정

1. If the register is genuinely unused, accept the removal — it is a correct optimization that saves resources.
1. 레지스터가 실제로 사용되지 않은 경우 제거를 수락합니다. 이는 리소스를 절약하는 올바른 최적화입니다.
2. If it must be kept (debug, ILA, external expectation), apply `(* dont_touch = "true" *)` / `keep` so it survives.
2. 유지해야 하는 경우(디버그, ILA, 외부 기대) `(* dont_touch = "true" *)` / `keep`을 적용하여 유지하세요.
3. Check for a missing downstream connection — often the register's output was meant to drive something but the wire was never hooked up; connect it.
3. 누락된 다운스트림 연결을 확인하십시오. 종종 레지스터의 출력이 무언가를 구동하기 위한 것이지만 와이어가 연결되지 않은 경우가 많습니다. 연결하세요.
4. Trace whether the removal indicates dead upstream logic that should also be cleaned up.
4. 제거가 정리되어야 하는 죽은 업스트림 논리를 나타내는지 여부를 추적합니다.
