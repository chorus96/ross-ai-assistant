# 8-2291: Integer Literal Exceeds Maximum
# 8-2291: 정수 리터럴이 최대값을 초과합니다.

**Message:** `[Synth 8-2291] literal !%1! exceeds maximum integer value`
**메시지:** `[Synth 8-2291] 리터럴 !%1! 최대 정수 값을 초과합니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL integer literal exceeds the maximum representable value.
VHDL 정수 리터럴이 표현 가능한 최대 값을 초과합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Integer literal beyond 32-bit range
### P1: 32비트 범위를 넘는 정수 리터럴

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: literal too large
constant big : integer := 28446744073709551616;  -- ERROR: exceeds max
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use std_logic_vector for large values
constant big : std_logic_vector(63 downto 0) := x"18AC4D6509BE1480";
```

---

## Fix Strategy
## 전략 수정

1. VHDL `integer` is limited to 32-bit signed (max 2^31-1); for larger values use `std_logic_vector`/`unsigned`/`signed` with a hex or bit literal of the required width.
1. VHDL '정수'는 부호 있는 32비트(최대 2^31-1)로 제한됩니다. 더 큰 값의 경우 필요한 너비의 16진수 또는 비트 리터럴과 함께 `std_logic_Vector`/`unsigned`/`signed`를 사용하세요.
2. Declare the constant with an explicit width (`unsigned(63 downto 0)`) and initialize with `x"..."` so no integer conversion overflows.
2. 명시적인 너비(`unsigned(63 downto 0)`)로 상수를 선언하고 `x"..."`로 초기화하여 정수 변환이 오버플로되지 않도록 합니다.
3. If the value indexes/sizes something, reconsider the design — a value beyond 2^31 is rarely a legitimate integer constant.
3. 값이 무언가를 색인화하거나 크기를 지정하는 경우 디자인을 다시 고려하십시오. 2^31을 초과하는 값은 합법적인 정수 상수가 아닙니다.
4. Use `numeric_std` conversions (`to_unsigned`, `resize`) when moving between integer and vector representations at safe widths.
4. 안전한 너비에서 정수와 벡터 표현 사이를 이동할 때 `numeric_std` 변환(`to_unsigned`, `resize`)을 사용하세요.
