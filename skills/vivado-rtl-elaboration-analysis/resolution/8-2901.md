# 8-2901: Duplicate Enum Value
# 8-2901: 열거형 값이 중복되었습니다.

**Message:** `[Synth 8-2901] value '!%1!' for enum '!%2!' already used by enum '!%3!'`
**메시지:** `[Synth 8-2901] 값 '!%1!' 열거형 '!%2!' 열거형 '!%3!'`에서 이미 사용했습니다.
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

Two enum members have the same explicit value.
두 열거형 멤버가 동일한 명시적 값을 갖습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Two enum members with the same value
### P1: 동일한 값을 가진 두 개의 열거형 멤버

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: duplicate enum value
typedef enum logic [3:0] {
  enum_2 = 4'b0z01,
  enum_3 = 4'b0z01  // ERROR: same value as enum_2
} my_enum;
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use unique values
typedef enum logic [3:0] {
  enum_2 = 4'b0001,
  enum_3 = 4'b0010  // unique values
} my_enum;
```

---

## Fix Strategy
## 전략 수정

1. Give every enum member a **unique** value — change the duplicated literal to a distinct one.
1. 모든 열거형 멤버에 **고유** 값을 부여합니다. 중복된 리터럴을 고유한 값으로 변경합니다.
2. Avoid `x`/`z` bits in synthesizable enum values; they collapse to 0/1 and can alias other members.
2. 합성 가능한 열거형 값에서는 `x`/`z` 비트를 사용하지 마세요. 0/1로 축소되고 다른 구성원의 별칭을 지정할 수 있습니다.
2. Use concrete `0`/`1` encodings.
2. 구체적인 `0`/`1` 인코딩을 사용하세요.
3. If you rely on auto-increment, do not mix it with explicit values that collide — either let all members auto-increment or assign all explicitly.
3. 자동 증가에 의존하는 경우 충돌하는 명시적 값과 혼합하지 마십시오. 모든 멤버가 자동 증가하도록 허용하거나 모두 명시적으로 할당하십시오.
4. Verify the encoding width holds all members and no two resolve to the same bit pattern.
4. 인코딩 너비에 모든 멤버가 포함되어 있고 두 멤버가 동일한 비트 패턴으로 확인되지 않는지 확인하세요.
