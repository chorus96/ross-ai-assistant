# 8-8922: Not a Subprogram
# 8-8922: 하위 프로그램이 아닙니다.

**Message:** `[Synth 8-8922] '!%1!' is not a subprogram`
**메시지:** `[Synth 8-8922] '!%1!' 하위 프로그램이 아닙니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An identifier used in a subprogram call is not actually a subprogram.
서브프로그램 호출에 사용된 식별자는 실제로 서브프로그램이 아닙니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Non-subprogram called as a function
### P1: 서브프로그램이 아닌 함수로 호출됨

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: package instance used as function
result := genpack_inst2(args);  -- ERROR: not a subprogram
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: call the actual function
result := genpack_inst2.my_func(args);  -- qualified call
```

---

## Fix Strategy
## 전략 수정

1. Call the subprogram, not the object — use a fully qualified name for functions inside a package instance (`inst.func(args)`).
1. 객체가 아닌 하위 프로그램을 호출합니다. 패키지 인스턴스 내부의 함수에 대해 정규화된 이름을 사용합니다(`inst.func(args)`).
2. Verify the identifier is actually a subprogram (function/procedure), not a package-instance or signal name.
2. 식별자가 실제로 패키지 인스턴스나 신호 이름이 아닌 하위 프로그램(함수/프로시저)인지 확인하세요.
3. Import/reference the package so the subprogram is visible, and fix typos in the call.
3. 서브프로그램이 표시되도록 패키지를 가져오거나 참조하고 호출의 오타를 수정합니다.
4. Match the argument count/types to the subprogram's declaration.
4. 인수 개수/유형을 하위 프로그램의 선언과 일치시킵니다.
