# 8-258: Duplicate Association
# 8-258: 중복 연관

**Message:** `[Synth 8-258] duplicate !%1! association for '!%2!'`
**메시지:** `[Synth 8-258] 중복!%1! '!%2!'`에 대한 연관
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-258] duplicate port association for 'clk' [/path/to/file.v:42]
```

---

## Root Cause
## 근본 원인

A port or generic/parameter is connected more than once in the same instantiation.
포트 또는 일반/매개변수가 동일한 인스턴스화에서 두 번 이상 연결되었습니다.
Each port can only have one connection.
각 포트에는 하나의 연결만 있을 수 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Same Port Named Twice (Verilog)
### P1: 동일한 포트 이름이 두 번 지정됨(Verilog)

```verilog
// Before - 'clk' connected twice
my_module inst (
  .clk(sys_clk),
  .data(data_in),
  .clk(alt_clk),    // ERROR: duplicate association for 'clk'
  .out(result)
);

// After - remove duplicate
my_module inst (
  .clk(sys_clk),
  .data(data_in),
  .out(result)
);
```

### P2: Mixed Positional and Named (Verilog)
### P2: 위치 지정 및 명명 혼합(Verilog)

```verilog
// Before - clk connected positionally AND by name
my_module inst (
  sys_clk,          // positional: connects to first port (clk)
  .clk(alt_clk),    // ERROR: clk already connected
  .data(data_in)
);

// After - use only one style
my_module inst (
  .clk(sys_clk),
  .data(data_in)
);
```

### P3: VHDL Generic Duplicate
### P3: VHDL 일반 중복

```vhdl
-- Before - WIDTH specified twice
U0: entity work.my_fifo
  generic map (
    WIDTH => 8,
    DEPTH => 16,
    WIDTH => 16    -- ERROR: duplicate association
  )
  port map (...);

-- After - remove duplicate
U0: entity work.my_fifo
  generic map (
    WIDTH => 8,
    DEPTH => 16
  )
  port map (...);
```

### P4: Mixed-Language Case-Sensitivity (VHDL instantiating Verilog)
### P4: 혼합 언어 대소문자 구분(VHDL이 Verilog를 인스턴스화함)

```verilog
// Verilog module with case-sensitive ports
module my_mod(a, A, z);    // ports 'a' and 'A' are different in Verilog
  input a;
  input [1:0] A;
  output [1:0] z;
endmodule
```

```vhdl
-- VHDL instantiation — VHDL is case-INSENSITIVE
-- Both 'a' and 'A' resolve to same identifier -> duplicate!
component my_mod
  port (a : in std_logic; \A\ : in std_logic_vector(1 downto 0); z : out std_logic_vector);
end component;

-- ERROR: port map with \A\ seen as duplicate of 'a'
U0 : my_mod port map(a => sig_a, \A\ => sig_B, z => sig_z);
```

**Root Cause:** VHDL is case-insensitive.
**근본 원인:** VHDL은 대소문자를 구분하지 않습니다.
Escaped identifier `\A\` and regular `a`
이스케이프된 식별자 `\A\` 및 일반 `a`
resolve to the same port name.
동일한 포트 이름으로 확인하십시오.
This is a mixed-language limitation.
이는 혼합 언어 제한 사항입니다.

**Fix:** Rename one port in the Verilog module to avoid case-only difference:
**수정:** 대소문자 차이를 피하기 위해 Verilog 모듈에서 한 포트의 이름을 바꿉니다.
```diff
- module my_mod(a, A, z);
-   input a;
-   input [1:0] A;
+ module my_mod(a, data_in, z);
+   input a;
+   input [1:0] data_in;
```

**Important:** This pattern CANNOT be fixed from VHDL side alone.
**중요:** 이 패턴은 VHDL 측만으로는 수정할 수 없습니다.
The Verilog
Verilog
module must be modified to avoid ports that differ only in case.
케이스만 다른 포트를 방지하려면 모듈을 수정해야 합니다.

### P4: VHDL Port Duplicate
### P4: VHDL 포트 중복

```vhdl
-- Before - data_in connected twice
U0: entity work.processor
  port map (
    clk     => sys_clk,
    data_in => input_a,
    data_in => input_b,  -- ERROR: duplicate
    data_out => result
  );

-- After
U0: entity work.processor
  port map (
    clk      => sys_clk,
    data_in  => input_a,
    data_out => result
  );
```

---

## Fix Strategy
## 전략 수정

1. Search for the duplicated port/generic name
1. 중복된 포트/일반 이름을 검색하세요.
2. Remove one of the associations
2. 연결 중 하나를 제거하세요.
3. Verify the remaining connection is correct
3. 나머지 연결이 올바른지 확인하십시오.
