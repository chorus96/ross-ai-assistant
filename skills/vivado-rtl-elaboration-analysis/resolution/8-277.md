# 8-277: Exponentiation Not Supported
# 8-277: 지수화는 지원되지 않습니다.

**Message:** `[Synth 8-277] exponentiation is not supported`
**메시지:** `[Synth 8-277] 지수 계산은 지원되지 않습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-277] exponentiation is not supported [/path/to/file.v:42]
```

---

## Root Cause
## 근본 원인

The `**` (power) operator is used in a context where synthesis cannot implement it.
`**`(전력) 연산자는 합성을 구현할 수 없는 상황에서 사용됩니다.
While Verilog/VHDL support exponentiation in constant expressions, runtime exponentiation is generally not synthesizable.
Verilog/VHDL은 상수 표현식에서 지수화를 지원하지만 런타임 지수화는 일반적으로 합성할 수 없습니다.

---

## Where Exponentiation Works
## 지수화가 작동하는 곳

| Context<br>맥락 | Supported<br>지원됨 |
|---------|-----------|
| Constant expression<br>상수 표현 | Yes<br>예 |
| Parameter calculation<br>매개변수 계산 | Yes<br>예 |
| Runtime operation<br>런타임 작업 | No |
| Variable exponent<br>변수 지수 | No |

## Common Patterns
## 일반적인 패턴

### P1: Runtime Exponentiation
### P1: 런타임 지수화

```verilog
// Before - runtime power operation
input [7:0] base;
input [3:0] exp;
output [31:0] result;
assign result = base ** exp;  // ERROR: not synthesizable

// After - use lookup table or iterative multiply
// For small ranges, use case statement
always @(*) begin
  case (exp)
    0: result = 1;
    1: result = base;
    2: result = base * base;
    3: result = base * base * base;
    default: result = 0;
  endcase
end
```

### P2: Power of 2 (Special Case)
### P2: 2의 거듭제곱(특별한 경우)

```verilog
// Before - 2^n calculation
input [3:0] n;
output [15:0] pow2;
assign pow2 = 2 ** n;  // ERROR

// After - use shift for power of 2
assign pow2 = 1 << n;  // Equivalent to 2^n
```

### P3: Constant Exponentiation (This Works)
### P3: 상수 지수화(이것이 작동함)

```verilog
// These are OK - constant expressions
parameter BASE = 2;
parameter EXP = 8;
localparam RESULT = BASE ** EXP;  // OK: 256

// Also OK
localparam SIZE = 2 ** 10;  // OK: 1024
```

### P4: VHDL Power Operation
### P4: VHDL 전원 작동

```vhdl
-- Before - runtime power
signal base : integer;
signal exp : integer;
signal result : integer;
result <= base ** exp;  -- ERROR

-- After - use function for small exponents
function power_of_2(n : integer) return integer is
begin
  return 2 ** n;  -- OK if n is constant
end function;

-- Or use shift
result <= to_integer(shift_left(to_unsigned(1, 32), exp));
```

## Fix Strategy
## 전략 수정

1. For power of 2: use left shift (`<<` or `shift_left`)
1. 2의 거듭제곱: 왼쪽 시프트(`<<` 또는 `shift_left`) 사용
2. For small fixed ranges: use case/lookup table
2. 작은 고정 범위의 경우: 사용 사례/조회 테이블
3. For constant values: keep as-is (works)
3. 상수 값의 경우: 그대로 유지(작동)
4. For general power: implement iterative multiplier
4. 일반 거듭제곱의 경우: 반복 승수 구현
