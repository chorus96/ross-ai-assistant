# 8-9111: actual expression for generic '!%1!' cannot reference a signal
# 8-9111: 일반 '!%1!'에 대한 실제 표현식 신호를 참조할 수 없습니다

**Message:** `[Synth 8-9111] actual expression for generic '!%1!' cannot reference a signal`
**메시지:** `[Synth 8-9111] 일반 '!%1!'에 대한 실제 표현식 신호를 참조할 수 없습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A generic's actual value references a signal; generics must be static (constant) at elaboration.
제네릭의 실제 값은 신호를 참조합니다. 제네릭은 정교화 시 정적(일정)이어야 합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Generic actual references a signal
### P1: 일반 실제 참조 신호

**Problematic Code:**
**문제가 있는 코드:**
```vhdl
inst : ent generic map (N => sig);   -- signal not allowed
```

**Recommended Fix:**
**권장 수정 사항:**
```vhdl
inst : ent generic map (N => 8);     -- constant/generic value
```

---

## Fix Strategy
## 전략 수정

1. Use a constant, literal, or generic for a generic actual - not a signal.
1. 신호가 아닌 일반적인 실제에는 상수, 리터럴 또는 일반을 사용하십시오.
2. Generics are fixed at elaboration and cannot depend on runtime signals.
2. 제네릭은 정교하게 수정되었으며 런타임 신호에 의존할 수 없습니다.
3. Compute the value as a constant/generic upstream.
3. 값을 상수/일반 업스트림으로 계산합니다.
