# 8-13322: Formal Out Port Type Reference
# 8-13322: 형식 출력 포트 유형 참조

**Message:** `[Synth 8-13322] actual of formal !%1! port '!%2!' cannot be type reference '!%3!'`
**메시지:** `[Synth 8-13322] 실제 형식 !%1! 포트 '!%2!' 유형 참조 '!%3!'`일 수 없습니다.
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL output port's actual is a type reference instead of a signal.
VHDL 출력 포트의 실제는 신호가 아닌 유형 참조입니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Type name on an output port actual
### P1: 실제 출력 포트에 이름을 입력하세요.

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: type reference as port actual
port map(rtlclk => t_resetclock);  -- ERROR: t_resetclock is a type, not signal
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use a signal
signal clk_sig : t_resetclock;
port map(rtlclk => clk_sig);
```

---

## Fix Strategy
## 전략 수정

1. Connect an output port to a **signal** (or expression), not a type name.
1. 출력 포트를 유형 이름이 아닌 **신호**(또는 표현식)에 연결하십시오.
2. Declare a signal of the desired type and connect that to the port.
2. 원하는 유형의 신호를 선언하고 이를 포트에 연결합니다.
3. Fix a name collision where a type and signal share a name.
3. 유형과 신호가 이름을 공유하는 이름 충돌을 수정합니다.
4. Prefer named association and verify the actual is an assignable object.
4. 명명된 연관을 선호하고 실제가 할당 가능한 객체인지 확인하세요.
