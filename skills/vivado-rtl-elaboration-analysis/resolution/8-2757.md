# 8-2757: VHDL-2008 Feature in Older Mode
# 8-2757: 이전 모드의 VHDL-2008 기능

**Message:** `[Synth 8-2757] this construct is only supported in VHDL 1076-2008`
**메시지:** `[Synth 8-2757] 이 구성은 VHDL 1076-2008에서만 지원됩니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL-2008 construct is used but the file is not compiled in VHDL-2008 mode.
VHDL-2008 구성이 사용되었지만 파일이 VHDL-2008 모드에서 컴파일되지 않았습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: VHDL-2008 construct in an older compile mode
### P1: 이전 컴파일 모드의 VHDL-2008 구성

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: VHDL-2008 feature in VHDL-93 mode
process(all)  -- ERROR: 'all' sensitivity requires VHDL-2008
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: compile with VHDL-2008 or use compatible syntax
-- Option 1: read_vhdl -vhdl2008 file.vhd
-- Option 2: use explicit sensitivity list
process(clk, rst)
```

---

## Fix Strategy
## 전략 수정

1. Compile the file in VHDL-2008 mode — `read_vhdl -vhdl2008 file.vhd`, or set the file's VHDL standard to 2008 in the project/file properties.
1. VHDL-2008 모드(`read_vhdl -vhdl2008 file.vhd`)에서 파일을 컴파일하거나 프로젝트/파일 속성에서 파일의 VHDL 표준을 2008로 설정합니다.
2. Alternatively, rewrite the construct in VHDL-93-compatible form (e.g., replace `process(all)` with an explicit sensitivity list).
2. 또는 VHDL-93 호환 형식으로 구문을 다시 작성합니다(예: 'process(all)'를 명시적인 민감도 목록으로 대체).
3. Keep the whole design unit consistent — mixing 2008-only features with a 1993 compile setting for the same file will fail.
3. 전체 디자인 단위의 일관성을 유지하십시오. 동일한 파일에 대해 2008 전용 기능과 1993 컴파일 설정을 혼합하면 실패합니다.
4. Verify all files that share packages/types are compiled with a compatible standard.
4. 패키지/유형을 공유하는 모든 파일이 호환 가능한 표준으로 컴파일되었는지 확인하십시오.
