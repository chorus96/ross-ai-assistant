# 8-2340: Out Mode in Function Parameter
# 8-2340: 기능 매개변수의 Out 모드

**Message:** `[Synth 8-2340] mode '!%1!' is not allowed for function parameters`
**메시지:** `[Synth 8-2340] 모드 '!%1!' 함수 매개변수에는 허용되지 않습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL function parameter has mode `out`, which is not allowed.
VHDL 함수 매개변수에는 허용되지 않는 'out' 모드가 있습니다.
Function parameters must be `in`.
함수 매개변수는 'in'이어야 합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: out-mode parameter on a function
### P1: 기능의 출력 모드 매개변수

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: out parameter in function
function calc(in1 : in integer; out1 : out integer) return integer;  -- ERROR
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use procedure or return value only
function calc(in1 : in integer) return integer;  -- only in params
-- Or use procedure for out params:
procedure calc(in1 : in integer; out1 : out integer);
```

---

## Fix Strategy
## 전략 수정

1. VHDL function parameters must be mode `in` — remove any `out`/`inout` formals from the function.
1. VHDL 함수 매개변수는 `in` 모드여야 합니다. 함수에서 모든 `out`/`inout` 형식을 제거합니다.
2. If the subprogram must return multiple/updated values, convert it to a `procedure` with `out`/`inout` parameters.
2. 서브프로그램이 여러/업데이트된 값을 반환해야 하는 경우 `out`/`inout` 매개변수를 사용하여 `프로시저`로 변환하세요.
3. Alternatively, return a composite type (record/array) from the function to carry multiple results while keeping all parameters `in`.
3. 또는 함수에서 복합 유형(레코드/배열)을 반환하여 모든 매개변수를 'in'으로 유지하면서 여러 결과를 전달합니다.
4. Ensure the function has no side effects on its arguments, so it maps cleanly to combinational logic.
4. 함수가 인수에 부작용이 없는지 확인하여 조합 논리에 깔끔하게 매핑되도록 합니다.
