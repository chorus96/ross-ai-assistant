# 8-120: Call Depth Limit Exceeded
# 8-120: 통화 깊이 제한이 초과되었습니다.

**Message:** `[Synth 8-120] call depth limit (!%1!) exceeded`
**메시지:** `[Synth 8-120] 호출 깊이 제한(!%1!)을 초과했습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-120] call depth limit (100) exceeded [/path/to/file.v:42]
```

---

## Root Cause
## 근본 원인

Function or task calls are nested too deeply, often due to:
함수 또는 작업 호출은 다음과 같은 이유로 인해 너무 깊게 중첩됩니다.
- Infinite recursion in functions
- 함수의 무한 재귀
- Recursive functions without proper termination
- 적절한 종료가 없는 재귀 함수
- Very deep call chains
- 매우 깊은 콜 체인
- Circular function calls
- 순환 함수 호출

---

## Common Patterns
## 일반적인 패턴

### P1: Missing Base Case in Recursive Function
### P1: 재귀 함수에서 기본 사례가 누락되었습니다.

```verilog
// Before - infinite recursion
function integer factorial;
  input integer n;
  factorial = n * factorial(n-1);  // ERROR: no base case
endfunction

// After - add base case
function integer factorial;
  input integer n;
  if (n <= 1)
    factorial = 1;
  else
    factorial = n * factorial(n-1);
endfunction
```

### P2: Circular Function Calls
### P2: 순환 함수 호출

```verilog
// Before - A calls B, B calls A
function integer func_a;
  input integer x;
  func_a = func_b(x) + 1;  // calls func_b
endfunction

function integer func_b;
  input integer x;
  func_b = func_a(x) - 1;  // calls func_a - CIRCULAR!
endfunction

// After - break circular dependency
function integer func_a;
  input integer x;
  func_a = x * 2;
endfunction

function integer func_b;
  input integer x;
  func_b = func_a(x) + 1;
endfunction
```

### P3: Convert Recursion to Iteration
### P3: 재귀를 반복으로 변환

```verilog
// Before - recursive (may exceed depth)
function integer sum_recursive;
  input integer n;
  if (n == 0)
    sum_recursive = 0;
  else
    sum_recursive = n + sum_recursive(n-1);
endfunction

// After - iterative (synthesizable)
function integer sum_iterative;
  input integer n;
  integer i, total;
  begin
    total = 0;
    for (i = 1; i <= n; i = i + 1)
      total = total + i;
    sum_iterative = total;
  end
endfunction
```

---

## Fix Strategy
## 전략 수정

1. Add proper base case to recursive functions
1. 재귀 함수에 적절한 기본 사례 추가
2. Check for circular call dependencies
2. 순환 호출 종속성을 확인하세요.
3. Convert recursion to iteration where possible
3. 가능한 경우 재귀를 반복으로 변환
4. Reduce nesting depth in call chains
4. 호출 체인의 중첩 깊이 줄이기
