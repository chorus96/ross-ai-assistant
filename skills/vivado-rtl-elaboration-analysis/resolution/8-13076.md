# 8-13076: $bits system function cannot have an argument of non bit-stream type
# 8-13076: $bits 시스템 함수는 비트스트림 유형이 아닌 인수를 가질 수 없습니다.

**Message:** `[Synth 8-13076] $bits system function cannot have an argument of non bit-stream type`
**메시지:** `[Synth 8-13076] $bits 시스템 함수는 비트스트림 유형이 아닌 인수를 가질 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

`$bits` was given a non bit-stream type (e.g. a real, event, chandle) that has no bit representation.
`$bits`에는 비트 표현이 없는 비비트 스트림 유형(예: 실제, 이벤트, 챈들)이 제공되었습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: $bits argument is not a bit-stream type
### P1: $bits 인수가 비트스트림 유형이 아닙니다.

**Problematic Code:**
**문제가 있는 코드:**
```systemverilog
event e;
int n = $bits(e);   // not a bit-stream type
```

**Recommended Fix:**
**권장 수정 사항:**
```systemverilog
logic [7:0] v;
int n = $bits(v);
```

---

## Fix Strategy
## 전략 수정

1. Pass a bit-stream (integral/packed) type to `$bits`.
1. 비트스트림(정수형/패킹형) 유형을 `$bits`에 전달합니다.
2. Do not use real/event/chandle types with `$bits`.
2. `$bits`와 함께 실제/이벤트/chandle 유형을 사용하지 마세요.
3. Model the data with packed vectors/structs.
3. 압축된 벡터/구조체로 데이터를 모델링합니다.
