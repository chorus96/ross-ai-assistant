# 8-10275: $bits system function cannot have an argument of type real
# 8-10275: $bits 시스템 함수는 실수 유형의 인수를 가질 수 없습니다.

**Message:** `[Synth 8-10275] $bits system function cannot have an argument of type real`
**메시지:** `[Synth 8-10275] $bits 시스템 함수는 실수 유형의 인수를 가질 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

The `$bits` system function was given an argument of type `real` (or `shortreal`).
`$bits` 시스템 함수에 `real`(또는 `shortreal`) 유형의 인수가 제공되었습니다.
`$bits` requires a bit-stream (integral) type; real has no defined bit width for it.
`$bits`에는 비트스트림(정수) 유형이 필요합니다. 실제에는 정의된 비트 너비가 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: $bits argument cannot be real
### P1: $bits 인수는 실수일 수 없습니다.

**Problematic Code:**
**문제가 있는 코드:**
```systemverilog
real r;
int n = $bits(r);   // real not allowed
```

**Recommended Fix:**
**권장 수정 사항:**
```systemverilog
logic [63:0] r_bits;
int n = $bits(r_bits);   // use an integral type
```

---

## Fix Strategy
## 전략 수정

1. Pass an integral/bit-stream type to `$bits`, not a real.
1. 실수가 아닌 `$bits`에 정수/비트 스트림 유형을 전달합니다.
2. If you need the storage size of a real, use a fixed 32/64-bit vector model instead.
2. 실제 저장 크기가 필요한 경우 고정된 32/64비트 벡터 모델을 대신 사용하세요.
3. Real types are non-synthesizable; remove real from the synthesizable path.
3. 실제 유형은 합성할 수 없습니다. 합성 가능한 경로에서 실수를 제거합니다.
