# 8-11095: Range Attribute on Non-Array
# 8-11095: 비 어레이의 범위 특성

**Message:** `[Synth 8-11095] prefix of attribute range should denote an array type`
**메시지:** `[Synth 8-11095] 속성 범위의 접두사는 배열 유형을 나타내야 합니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-11095] prefix of attribute range should denote an array type [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

The VHDL `'range` attribute is used on a type that is not an array (e.g., a generic type parameter that could be scalar).
VHDL `'range` 속성은 배열이 아닌 유형(예: 스칼라일 수 있는 일반 유형 매개변수)에 사용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: 'range on a non-array prefix
### P1: '배열이 아닌 접두사의 범위

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: 'range on potentially non-array type
for idx in in1'range loop  -- ERROR if in1's type is not array
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: ensure the type is an array or use alternative
-- Constrain the generic to be an array type:
generic (type t1 is array (natural range <>) of std_logic);
-- Or use explicit range:
for idx in 0 to in1'length-1 loop
```

---

## Fix Strategy
## 전략 수정

1. Apply `'range` only to an **array** prefix; scalars do not have a range attribute usable here.
1. **배열** 접두사에만 '범위'를 적용합니다. 스칼라에는 여기서 사용할 수 있는 범위 속성이 없습니다.
2. For a generic type, constrain the generic to an array type so `'range` is valid, or pass the bounds as separate generics.
2. 제네릭 유형의 경우 '범위'가 유효하도록 제네릭을 배열 유형으로 제한하거나 경계를 별도의 제네릭으로 전달합니다.
3. Verify the prefix resolves to an array object/type at the point of use.
3. 접두사가 사용 시점에 배열 객체/유형으로 확인되는지 확인하세요.
4. Use explicit constant bounds if the range cannot be derived from an array.
4. 배열에서 범위를 파생할 수 없는 경우 명시적인 상수 범위를 사용합니다.
