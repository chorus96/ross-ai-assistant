# 8-9469: Formal Cannot Be File/Access Type
# 8-9469: 형식은 파일/액세스 유형일 수 없습니다.

**Message:** `[Synth 8-9469] formal constant cannot be of a file type or access type`
**메시지:** `[Synth 8-9469] 형식 상수는 파일 유형 또는 액세스 유형일 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL generic parameter uses file or access type, which is not allowed for constants.
VHDL 일반 매개변수는 상수에 허용되지 않는 파일 또는 액세스 유형을 사용합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: File/access type as a generic
### P1: 일반적인 파일/액세스 유형

**Problematic Code:**
**문제가 있는 코드:**
```diff
generic (constant g1 : file_type);  -- ERROR: file type not allowed
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
generic (g1 : integer);  -- use synthesizable type
```

---

## Fix Strategy
## 전략 수정

1. Do not use file or access types for a generic constant — use a synthesizable type (`integer`, `std_logic_vector`, `boolean`, a record, ...).
1. 일반 상수에 파일 또는 액세스 유형을 사용하지 마십시오. 합성 가능한 유형(`정수`, `std_logic_벡터`, `부울`, 레코드 등)을 사용하십시오.
2. If the generic modeled external data, provide that data via a synthesizable constant/ROM instead.
2. 일반 모델링된 외부 데이터인 경우 대신 합성 가능한 상수/ROM을 통해 해당 데이터를 제공하십시오.
3. Keep any genuine file/access usage in simulation-only code, out of the synthesized generics.
3. 합성된 제네릭이 아닌 시뮬레이션 전용 코드에서 실제 파일/액세스 사용을 유지하세요.
4. Verify the generic's actual value at instantiation is of the synthesizable type.
4. 인스턴스화 시 제네릭의 실제 값이 합성 가능한 유형인지 확인합니다.
