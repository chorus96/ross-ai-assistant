# 8-11581: System Task Not Supported
# 8-11581: 시스템 작업이 지원되지 않음

**Message:** `[Synth 8-11581] system task call not supported`
**메시지:** `[Synth 8-11581] 시스템 작업 호출이 지원되지 않습니다`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A system task like `$dumports` is not supported for synthesis.
`$dumports`와 같은 시스템 작업은 합성을 지원하지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Unsupported system task
### P1: 지원되지 않는 시스템 작업

**Problematic Code:**
**문제가 있는 코드:**
```diff
$dumports;  // WARNING: not supported
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// Remove or guard with synthesis translate_off
// synthesis translate_off
$dumports;
// synthesis translate_on
```

---

## Fix Strategy
## 전략 수정

1. Remove unsupported system tasks (`$dumpports`, `$dumpvars`, etc.) from synthesizable RTL, or guard them with `// synthesis translate_off` / `translate_on`.
1. 지원되지 않는 시스템 작업(`$dumpports`, `$dumpvars` 등)을 합성 가능한 RTL에서 제거하거나 `// 합성 번역 오프` / `translate_on`으로 보호하세요.
2. Move waveform/dump and other simulation-only tasks into the testbench.
2. 파형/덤프 및 기타 시뮬레이션 전용 작업을 테스트벤치로 이동합니다.
3. Replace any needed behavior with real logic; system tasks have no hardware.
3. 필요한 동작을 실제 논리로 바꾸십시오. 시스템 작업에는 하드웨어가 없습니다.
4. Keep the synthesized path free of `$`-tasks except supported ones (e.g., `$readmemh`).
4. 지원되는 작업(예: `$readmemh`)을 제외하고 `$` 작업이 없는 합성 경로를 유지하세요.
