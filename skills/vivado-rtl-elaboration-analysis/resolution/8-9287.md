# 8-9287: Character Not in Type
# 8-9287: 유형에 없는 문자

**Message:** `[Synth 8-9287] character is not in element type`
**메시지:** `[Synth 8-9287] 문자가 요소 유형에 없습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A character literal used in an aggregate or expression is not valid for the element type.
집계 또는 표현식에 사용된 문자 리터럴이 요소 유형에 유효하지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Character invalid for element type
### P1: 요소 유형에 유효하지 않은 문자

**Problematic Code:**
**문제가 있는 코드:**
```diff
sig <= (others => '-');  -- ERROR if element type is 'bit' (only '0','1')
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
sig <= (others => '0');  -- valid for bit type
```

---

## Fix Strategy
## 전략 수정

1. Use only character values valid for the element type — `bit` allows only `'0'`/`'1'`; `std_logic` allows `'0','1','Z','X',...`.
1. 요소 유형에 유효한 문자 값만 사용하십시오. — `bit`는 `'0'`/`'1'`만 허용합니다. `std_logic`은 `'0','1','Z','X',...`를 허용합니다.
2. If you need `'-'`/`'Z'` semantics, change the element type to `std_logic`/`std_logic_vector`.
2. `'-'`/`'Z'` 의미가 필요한 경우 요소 유형을 `std_logic`/`std_logic_Vector`로 변경하세요.
3. Check aggregate/literal characters against the target's element type and replace invalid ones.
3. 대상의 요소 유형에 대해 집계/리터럴 문자를 확인하고 유효하지 않은 문자를 대체하십시오.
4. For don't-cares in synthesizable RTL, drive a defined value (`'0'`) instead of a metavalue.
4. 합성 가능한 RTL에서 무정의의 경우 메타값 대신 정의된 값(`'0'`)을 구동합니다.
