# 8-2512: Part-Select +: in Declaration
# 8-2512: 부분 선택 +: 선언 중

**Message:** `[Synth 8-2512] part-select !%1! is not allowed in declaration`
**메시지:** `[Synth 8-2512] 부분 선택!%1! 선언에는 허용되지 않습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A `+:` or `-:` part-select is used in a declaration context where it's not allowed.
`+:` 또는 `-:` 부분 선택이 허용되지 않는 선언 컨텍스트에서 사용되었습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Indexed part-select in a declaration
### P1: 선언에서 인덱스된 부분 선택

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: +: in port declaration
module m(input [0+:8] data);  // ERROR: +: not in declaration
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use regular range
module m(input [7:0] data);  // standard range
```

---

## Fix Strategy
## 전략 수정

1. Use a standard range `[MSB:LSB]` in declarations (ports, nets, variables); the indexed part-select operators `+:`/`-:` are not allowed there.
1. 선언(포트, 네트, 변수)에 표준 범위 `[MSB:LSB]`를 사용하십시오. 색인된 부분 선택 연산자 `+:`/`-:`는 허용되지 않습니다.
2. Reserve `signal[base +: width]` / `signal[base -: width]` for **expressions** where a variable base with constant width is needed.
2. 일정한 너비의 변수 베이스가 필요한 **표현식**에 `signal[base +: width]` / `signal[base -: width]`를 예약하세요.
3. If the declaration width is parameterized, express it directly (`[WIDTH-1:0]`), not via `+:`.
3. 선언 너비가 매개변수화된 경우 `+:`를 통하지 않고 직접(`[WIDTH-1:0]`) 표현합니다.
4. Fix any copy-paste of an expression part-select into a declaration context.
4. 표현식 부분 선택의 복사-붙여넣기를 선언 컨텍스트에 수정합니다.
