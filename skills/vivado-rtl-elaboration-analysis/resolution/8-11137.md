# 8-11137: Return Outside Subprogram
# 8-11137: 서브프로그램 외부로 복귀

**Message:** `[Synth 8-11137] return statement cannot exist outside of a subprogram`
**메시지:** `[Synth 8-11137] return 문은 서브프로그램 외부에 존재할 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-11137] return statement cannot exist outside of a subprogram [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A VHDL `return` statement appears outside a function or procedure body (e.g., in a process).
VHDL 'return' 문은 함수 또는 프로시저 본문 외부(예: 프로세스)에 나타납니다.

---

## Common Patterns
## 일반적인 패턴

### P1: return outside a subprogram
### P1: 서브프로그램 외부로 복귀

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: return in process (illegal)
process(cond1)
begin
  if cond1 then
    return result;    -- ERROR: return not valid in process
  end if;
end process;
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use signal assignment instead
process(cond1)
begin
  if cond1 then
    out_sig <= result;  -- assign to signal instead of return
  end if;
end process;
```

---

## Fix Strategy
## 전략 수정

1. Use `return` only inside a function/procedure; remove it from process/module scope.
1. 함수/프로시저 내에서만 'return'을 사용하세요. 프로세스/모듈 범위에서 제거하십시오.
2. In a process, assign to signals/variables to produce results instead of returning.
2. 프로세스에서 신호/변수에 할당하여 반환하는 대신 결과를 생성합니다.
3. If early-exit control was intended, restructure with conditional logic or a loop with `exit`.
3. 조기 종료 제어를 의도한 경우 조건부 논리 또는 `exit`가 포함된 루프를 사용하여 재구성하세요.
4. Check for a misplaced `return` outside its subprogram body.
4. 하위 프로그램 본체 외부에 잘못 배치된 '반환'이 있는지 확인하세요.
