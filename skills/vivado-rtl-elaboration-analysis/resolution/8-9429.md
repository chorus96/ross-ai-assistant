# 8-9429: Port Redeclared
# 8-9429: 포트 재선언

**Message:** `[Synth 8-9429] explicitly declared port cannot be redeclared`
**메시지:** `[Synth 8-9429] 명시적으로 선언된 포트는 다시 선언될 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A port is declared both in the port list and again in the module body.
포트는 포트 목록과 모듈 본문 모두에서 다시 선언됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Explicit port redeclared in body
### P1: 본문에 다시 선언된 명시적 포트

**Problematic Code:**
**문제가 있는 코드:**
```diff
module m(input p);
input p;  // ERROR: already declared
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
module m(input p);
// Remove duplicate declaration
```

---

## Fix Strategy
## 전략 수정

1. Remove the redundant body-level `input`/`output` declaration — an ANSI-style port is fully declared in the header.
1. 중복된 본문 수준 `input`/`output` 선언을 제거합니다. ANSI 스타일 포트가 헤더에서 완전히 선언됩니다.
2. Use one port style consistently (ANSI header or non-ANSI body declarations), not both for the same port.
2. 하나의 포트 스타일(ANSI 헤더 또는 비ANSI 본문 선언)을 일관되게 사용하고, 동일한 포트에 둘 다를 사용하지 마십시오.
3. Check for copy-paste that duplicated the declaration.
3. 선언을 복제한 복사-붙여넣기를 확인하세요.
4. If an attribute was intended, apply it in the header rather than re-declaring the port.
4. 속성을 의도한 경우 포트를 다시 선언하는 대신 헤더에 적용하세요.
