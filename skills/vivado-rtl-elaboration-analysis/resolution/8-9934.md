# 8-9934: Method Requires Enum Prefix
# 8-9934: 메서드에 열거형 접두사가 필요합니다.

**Message:** `[Synth 8-9934] prefix of method should be enum`
**메시지:** `[Synth 8-9934] 메소드의 접두사는 열거형이어야 합니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

The `num` or similar enum method is called on a non-enum type.
'num' 또는 이와 유사한 열거형 메서드는 열거형이 아닌 유형에서 호출됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Enum method on a non-enum type
### P1: 비열거형 유형의 열거형 메서드

**Problematic Code:**
**문제가 있는 코드:**
```diff
int x;
y = x.num;  // ERROR: num is enum method
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
typedef enum {A,B,C} my_e;
y = my_e.num;  // enum type prefix
```

---

## Fix Strategy
## 전략 수정

1. Call enum methods (`.num`, `.first`, `.last`, `.next`, `.name`) on an **enum type or enum variable**, not on an `int`/other type.
1. `int`/기타 유형이 아닌 **enum 유형 또는 열거형 변수**에 대해 열거형 메서드(`.num`, `.first`, `.last`, `.next`, `.name`)를 호출합니다.
2. If you need such behavior for a plain integer, define an enum type and use it.
2. 일반 정수에 대해 이러한 동작이 필요한 경우 열거형 유형을 정의하고 사용하세요.
3. Ensure the prefix's declared type is the enum you intend.
3. 접두사의 선언된 유형이 원하는 열거형인지 확인하세요.
4. Note enum methods like `.name` are simulation-only; avoid them in synthesizable RTL.
4. `.name`과 같은 열거형 메소드는 시뮬레이션 전용입니다. 합성 가능한 RTL에서는 이를 피하세요.
