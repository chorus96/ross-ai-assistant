# 8-3493: Module Port Mismatch
# 8-3493: 모듈 포트 불일치

**Message:** `[Synth 8-3493] module '!%1!' declared at '!%2!:!%3!' does not have matching formal port for component port '!%4!'`
**메시지:** `[Synth 8-3493] 모듈 '!%1!' '!%2!:!%3!'에 선언되었습니다. 구성 요소 포트 '!%4!'`와 일치하는 공식 포트가 없습니다.
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

Module instance has port connections that don't match the module's actual port definition.
모듈 인스턴스에 모듈의 실제 포트 정의와 일치하지 않는 포트 연결이 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Port map names do not match entity
### P1: 포트 맵 이름이 엔터티와 일치하지 않습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: port mismatch in binding
port map(a => sig1, b => sig2);  -- ports don't match entity
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: match ports to entity
port map(x => sig1, y => sig2);  -- use correct port names
```

---

## Fix Strategy
## 전략 수정

1. Open the actual module/entity and use its exact port names, directions, and types in the `port map`.
1. 실제 모듈/엔티티를 열고 `포트 맵`에서 정확한 포트 이름, 방향 및 유형을 사용하십시오.
2. Fix the offending associations to match the real ports; prefer named association so mismatches are obvious.
2. 실제 포트와 일치하도록 문제가 있는 연결을 수정합니다. 불일치가 분명하므로 명명된 연관을 선호합니다.
3. Verify you are binding the intended, current version of the module — a stale definition with different ports is a common cause.
3. 모듈의 의도된 현재 버전을 바인딩하고 있는지 확인하십시오. 다른 포트를 사용하는 오래된 정의가 일반적인 원인입니다.
4. Check width/type compatibility on each connection and add explicit conversions only where a controlled adaptation is intended.
4. 각 연결의 너비/유형 호환성을 확인하고 제어된 적응이 의도된 경우에만 명시적 변환을 추가하십시오.
