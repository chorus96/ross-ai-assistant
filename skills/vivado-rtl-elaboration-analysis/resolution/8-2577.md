# 8-2577: Procedural Assignment to Non-Register
# 8-2577: 비등록에 대한 절차적 할당

**Message:** `[Synth 8-2577] procedural assignment to a non-register !%1! is not permitted, left-hand side should be reg/integer/time/genvar`
**메시지:** `[Synth 8-2577] 비레지스터에 대한 절차적 할당 !%1! 허용되지 않습니다. 왼쪽은 reg/integer/time/genvar`여야 합니다.
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A procedural assignment (`=` or `<=`) targets a net (`wire`, `tri`) instead of a variable (`reg`, `logic`).
절차적 할당(`=` 또는 `<=`)은 변수(`reg`, `logic`) 대신 네트(`wire`, `tri`)를 대상으로 합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Procedural assignment to a net
### P1: 네트에 절차적 할당

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: assigning to wire in always block
wire [3:0] tri_arr;
always @(*) tri_arr = data;  // ERROR: wire can't be procedurally assigned
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: change to reg
reg [3:0] tri_arr;
always @(*) tri_arr = data;  // reg can be assigned
```

---

## Fix Strategy
## 전략 수정

1. Targets of procedural assignments (inside `always`/`initial`/`always_comb`/`always_ff`) must be **variables** — declare them `reg`/`logic`/`integer`, not `wire`.
1. 절차적 할당의 대상(`always`/`initial`/`always_comb`/`always_ff` 내부)은 **변수**여야 합니다. `wire`가 아닌 `reg`/`logic`/`integer`를 선언하세요.
2. Change the offending `wire` declaration to `reg` (Verilog) or `logic` (SystemVerilog).
2. 문제가 있는 `wire` 선언을 `reg`(Verilog) 또는 `logic`(SystemVerilog)으로 변경합니다.
3. If the signal must remain a net (e.g., driven by an instance/`assign`), do not assign it procedurally — move the logic to a continuous `assign` or drive a separate `reg`.
3. 신호가 네트(예: 인스턴스/'할당'에 의해 구동)로 유지되어야 하는 경우 절차적으로 할당하지 마십시오. 논리를 연속적인 '할당'으로 이동하거나 별도의 'reg'를 구동하십시오.
4. Ensure the signal has exactly one driver kind (procedural or continuous), not both.
4. 신호에 두 가지 드라이버 종류가 아닌 정확히 하나의 드라이버 종류(절차적 또는 연속적)가 있는지 확인하십시오.
