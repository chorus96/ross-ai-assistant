# 8-13331: No Matching Parameter for Defparam
# 8-13331: Defparam에 대해 일치하는 매개변수가 없습니다.

**Message:** `[Synth 8-13331] no matching parameter '!%1!' for defparam`
**메시지:** `[Synth 8-13331] 일치하는 매개변수 '!%1!'이 없습니다. defparam의 경우`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A `defparam` statement references a parameter name that doesn't exist in the target module.
`defparam` 문이 대상 모듈에 존재하지 않는 매개변수 이름을 참조합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: defparam to a non-existent parameter
### P1: 존재하지 않는 매개변수에 대한 defparam

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: defparam to non-existent parameter
defparam inst.width = 8;  // ERROR: no parameter 'width' in module
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use correct parameter name or #() syntax
inst #(.WIDTH(8)) inst(...);  // use parameter override
// Or fix the parameter name to match module definition
```

---

## Fix Strategy
## 전략 수정

1. Use a parameter name that actually exists in the target module for the `defparam`.
1. `defparam`에는 대상 모듈에 실제로 존재하는 매개변수 이름을 사용하세요.
2. Prefer inline `#(.P(val))` parameter overrides — `defparam` is deprecated.
2. 인라인 `#(.P(val))` 매개변수 재정의를 선호합니다. `defparam`은 더 이상 사용되지 않습니다.
3. Fix typos and verify the hierarchical instance path in the `defparam`.
3. 오타를 수정하고 `defparam`에서 계층적 인스턴스 경로를 확인하세요.
4. If the parameter should exist, add it to the module definition.
4. 매개변수가 존재해야 하는 경우 모듈 정의에 추가하십시오.
