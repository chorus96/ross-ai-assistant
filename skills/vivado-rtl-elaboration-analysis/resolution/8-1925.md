# 8-1925: Mixed Signed/Unsigned Elements
# 8-1925: 혼합된 부호 있는/부호 없는 요소

**Message:** `[Synth 8-1925] elements must both be signed or both be unsigned`
**메시지:** `[Synth 8-1925] 요소는 둘 다 서명되거나 둘 다 서명되지 않아야 합니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A SystemVerilog expression mixes signed and unsigned elements in a context that requires consistency.
SystemVerilog 표현식은 일관성이 필요한 컨텍스트에서 서명된 요소와 서명되지 않은 요소를 혼합합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Mixed signedness in an expression
### P1: 표현식에 부호가 혼합되어 있음

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: mixed signedness
logic signed [7:0] a;
logic [7:0] b;  // unsigned
assign c = {a, b};  // ERROR: mixed in concat
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: make consistent
logic signed [7:0] a;
logic signed [7:0] b;  // both signed
assign c = {a, b};
```

---

## Fix Strategy
## 전략 수정

1. Make all elements in the expression the same signedness — declare both operands `signed` (or both unsigned), or add an explicit cast (`signed'(x)` / `unsigned'(x)`).
1. 표현식의 모든 요소를 동일한 부호로 만듭니다. 두 피연산자 모두 `signed`(또는 둘 다 unsigned)를 선언하거나 명시적 캐스트(`signed'(x)` / `unsigned'(x)`)를 추가합니다.
2. In concatenations, the result is always unsigned; if signed arithmetic is intended, compute it before concatenating, not inside `{...}`.
2. 연결에서 결과는 항상 부호가 없습니다. 부호 있는 연산이 의도된 경우 `{...}` 내부가 아닌 연결하기 전에 계산하십시오.
3. Use `$signed(...)`/`$unsigned(...)` at the point of use to force a consistent interpretation for arithmetic and comparisons.
3. 산술 및 비교에 대한 일관된 해석을 강제하려면 사용 시점에 `$signed(...)`/`$unsigned(...)`를 사용하십시오.
4. Verify the target width and signedness so sign-extension behaves as intended after the fix.
4. 수정 후 부호 확장이 의도한 대로 작동하도록 대상 너비와 부호 있음을 확인합니다.
