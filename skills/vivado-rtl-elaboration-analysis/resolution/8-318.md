# 8-318: Illegal Unconstrained Array
# 8-318: 제한되지 않은 잘못된 배열

**Message:** `[Synth 8-318] illegal unconstrained array !%1! '!%2!'`
**메시지:** `[Synth 8-318] 제한되지 않은 잘못된 배열 !%1! '!%2!'`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-318] illegal unconstrained array signal 'data' [/path/to/file.vhd:42]
```

---

## Root Cause
## 근본 원인

In VHDL, an unconstrained array type is used for a signal, port, or variable without specifying the actual bounds.
VHDL에서는 실제 경계를 지정하지 않고 신호, 포트 또는 변수에 제약이 없는 배열 유형이 사용됩니다.
Synthesis requires all array sizes to be known at elaboration time.
합성을 위해서는 정교화 시 모든 배열 크기를 알아야 합니다.

---

## Unconstrained vs Constrained Arrays
## 제약이 없는 배열과 제약이 있는 배열

```vhdl
-- Unconstrained type definition (OK to define)
type byte_array is array (natural range <>) of std_logic_vector(7 downto 0);

-- Unconstrained signal (ERROR - no bounds)
signal data : byte_array;  -- ERROR: size unknown

-- Constrained signal (OK)
signal data : byte_array(0 to 15);  -- OK: 16 elements
```

## Common Patterns
## 일반적인 패턴

### P1: Unconstrained Signal
### P1: 비제약 신호

```vhdl
-- Before - unconstrained
type mem_t is array (natural range <>) of std_logic_vector(7 downto 0);
signal memory : mem_t;  -- ERROR: illegal unconstrained

-- After - add constraints
signal memory : mem_t(0 to 255);  -- OK: 256 elements
```

### P2: Unconstrained Port Without Default
### P2: 기본값이 없는 무제한 포트

```vhdl
-- Before - port without size
entity my_entity is
  port (
    data : in std_logic_vector  -- ERROR: unconstrained
  );
end my_entity;

-- After - constrain the port
entity my_entity is
  generic (WIDTH : integer := 8);
  port (
    data : in std_logic_vector(WIDTH-1 downto 0)  -- OK
  );
end my_entity;
```

### P3: Unconstrained Variable
### P3: 비제약 변수

```vhdl
-- Before
process
  variable temp : bit_vector;  -- ERROR: unconstrained
begin
  ...
end process;

-- After
process
  variable temp : bit_vector(7 downto 0);  -- OK
begin
  ...
end process;
```

### P4: Function Parameter (OK) vs Local Variable (Not OK)
### P4: 함수 매개변수(양호) 대 지역 변수(양호하지 않음)

```vhdl
-- Unconstrained parameter is OK
function process_data(data : std_logic_vector) return std_logic_vector is
  -- But local unconstrained is not OK
  variable result : std_logic_vector;  -- ERROR
begin
  ...
end function;

-- Fix: constrain local variables
function process_data(data : std_logic_vector) return std_logic_vector is
  variable result : std_logic_vector(data'range);  -- OK: uses input's range
begin
  result := data;
  return result;
end function;
```

## Fix Strategy
## 전략 수정

1. Add explicit index range: `(0 to N-1)` or `(N-1 downto 0)`
1. 명시적 인덱스 범위 추가: `(0 ~ N-1)` 또는 `(N-1부터 0)`
2. Use generics to parameterize sizes
2. 제네릭을 사용하여 크기 매개변수화
3. Use attributes like `'range`, `'length` to derive from other arrays
3. 다른 배열에서 파생하려면 '범위', '길이'와 같은 속성을 사용하세요.
