# 8-11160: sign is ignored on type '!%1!'
# 8-11160: '!%1!' 유형에서는 기호가 무시됩니다.

**Message:** `[Synth 8-11160] sign is ignored on type '!%1!'`
**메시지:** `[Synth 8-11160] 기호는 '!%1!' 유형에서 무시됩니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A sign qualifier is applied to a type that does not carry signedness, so it is ignored.
부호 있음을 전달하지 않는 유형에는 부호 한정자가 적용되므로 무시됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Sign is ignored on this type
### P1: 이 유형에서는 부호가 무시됩니다.

**Problematic Code:**
**문제가 있는 코드:**
```vhdl
signal s : signed std_logic;   -- sign meaningless here
```

**Recommended Fix:**
**권장 수정 사항:**
```vhdl
signal s : std_logic;          -- or use signed(...) on a vector
```

---

## Fix Strategy
## 전략 수정

1. Apply signedness only to vector types that support it (`signed`/`unsigned`).
1. 이를 지원하는 벡터 유형(`signed`/`unsigned`)에만 부호 있음을 적용합니다.
2. Remove the sign qualifier from scalar/unsupported types.
2. 스칼라/지원되지 않는 유형에서 부호 한정자를 제거합니다.
3. This is a warning; the sign has no effect.
3. 이는 경고입니다. 표시는 효과가 없습니다.
