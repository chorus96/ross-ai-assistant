# 8-7054: Expecting Unsigned in Resize
# 8-7054: 크기 조정 시 서명되지 않은 것으로 예상됨

**Message:** `[Synth 8-7054] Expecting unsigned argument in resize argument`
**메시지:** `[Synth 8-7054] 크기 조정 인수에 서명되지 않은 인수가 필요합니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL `resize` function expects `unsigned` type but receives a different type.
VHDL `resize` 함수는 `unsigned` 유형을 예상하지만 다른 유형을 수신합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Wrong type passed to resize
### P1: 크기 조정에 잘못된 유형이 전달되었습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: wrong type for resize
out1 <= resize(signed_val, 8);  -- ERROR: expects unsigned
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use correct type
out1 <= resize(unsigned(signed_val), 8);  -- convert first
-- Or use signed resize: out1 <= resize(signed_val, 8);  -- from numeric_std
```

---

## Fix Strategy
## 전략 수정

1. Pass the type `resize` expects — `numeric_std.resize` works on `unsigned` or `signed`; convert first (`resize(unsigned(x), N)` or `resize(signed(x), N)`).
1. `resize` 유형을 전달합니다. - `numeric_std.resize`는 `unsigned` 또는 `signed`에서 작동합니다. 먼저 변환합니다(`resize(unsigned(x), N)` 또는 `resize(signed(x), N)`).
2. Choose the conversion that matches the value's intended sign semantics (zero- vs sign-extension).
2. 값의 의도된 부호 의미(0 대 부호 확장)와 일치하는 변환을 선택합니다.
3. Ensure `use ieee.numeric_std.all;` is present so the correct `resize` overload is visible.
3. 올바른 `resize` 오버로드가 표시되도록 `use ieee.numeric_std.all;`이 있는지 확인하세요.
4. Convert the result back to `std_logic_vector` if the target is that type (`std_logic_vector(resize(...))`).
4. 대상이 해당 유형(`std_logic_Vector(resize(...))`)인 경우 결과를 다시 `std_logic_Vector`로 변환합니다.
