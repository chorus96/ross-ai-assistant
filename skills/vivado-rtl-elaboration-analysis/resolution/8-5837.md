# 8-5837: Detected dual asynchronous set and preset
# 8-5837: 이중 비동기 세트 및 사전 설정이 감지되었습니다.

**Message:** `[Synth 8-5837] Detected dual asynchronous set and preset for register Q_reg in module MY_FD3Q.
**메시지:** `[Synth 8-5837] MY_FD3Q 모듈의 Q_reg 레지스터에 대한 이중 비동기 세트 및 사전 설정이 감지되었습니다.
This is not a recommended register style for Xilinx devices`
이것은 Xilinx 장치에 권장되는 등록 스타일이 아닙니다.
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

## Root Cause
## 근본 원인

A register is described with **both** an asynchronous set and an asynchronous
레지스터는 비동기 세트와 비동기 세트 **모두**로 설명됩니다.
preset/clear.
사전 설정/지우기.
Xilinx flip-flops provide only one dedicated asynchronous control,
Xilinx 플립플롭은 단 하나의 전용 비동기 제어 기능을 제공합니다.
so this dual-async style forces extra logic and is not a recommended register
따라서 이 이중 비동기 스타일은 추가 논리를 강제하므로 권장되는 레지스터가 아닙니다.
style.
스타일.

## Common Patterns
## 일반적인 패턴

### P1: Dual asynchronous set and preset
### P1: 듀얼 비동기식 세트 및 프리셋

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Problematic line:
begin
    if (CD = '0') then 
      Q<= '0'; 
    elsif (SD ='0') then
       Q  <='1';
```

**Recommended Fix:**
**권장 수정 사항:**
```vhdl
-- Use a single asynchronous control; make the other condition synchronous
process(clk, CD)
begin
  if CD = '0' then          -- one async control (clear)
    Q <= '0';
  elsif rising_edge(clk) then
    if SD = '0' then Q <= '1'; end if;   -- set is now synchronous
  end if;
end process;
```

## Fix Strategy
## 전략 수정

1. Use only **one** asynchronous control on the register (an async reset **or** an async set) — Xilinx FFs have a single dedicated async control.
1. 레지스터에서 **하나** 비동기 제어만 사용합니다(비동기 재설정 **또는** 비동기 세트). Xilinx FF에는 단일 전용 비동기 제어가 있습니다.
2. Make the second condition **synchronous**: test it inside the clocked branch (`elsif rising_edge(clk) then if SET then Q<='1';`).
2. 두 번째 조건을 **동기**로 만듭니다. 클럭 분기 내에서 테스트합니다(`elsifrising_edge(clk) then if SET then Q<='1';`).
3. Prefer a synchronous reset/set style overall for best mapping and timing on Xilinx devices.
3. Xilinx 장치에서 최상의 매핑과 타이밍을 위해서는 전반적으로 동기식 재설정/설정 스타일을 선호합니다.
4. Verify the priority between the async and sync controls matches the intended behavior after restructuring.
4. 재구성 후 비동기 및 동기화 제어 간의 우선순위가 의도한 동작과 일치하는지 확인합니다.
