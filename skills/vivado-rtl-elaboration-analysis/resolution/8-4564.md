# 8-4564: Unsupported Asymmetric RAM
# 8-4564: 지원되지 않는 비대칭 RAM

**Message:** `[Synth 8-4564] Unsupported Asymmetric RAM pattern for RAM !%1!`
**메시지:** `[Synth 8-4564] RAM !%1에 대해 지원되지 않는 비대칭 RAM 패턴!`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

RAM inference pattern uses asymmetric read/write widths that don't match supported templates.
RAM 추론 패턴은 지원되는 템플릿과 일치하지 않는 비대칭 읽기/쓰기 너비를 사용합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Non-template asymmetric RAM
### P1: 비템플릿 비대칭 RAM

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: unsupported asymmetric RAM pattern
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: follow UG901 asymmetric RAM templates
// Ensure read/write width ratios are powers of 2
// Use matching address width adjustments
```

---

## Fix Strategy
## 전략 수정

1. Follow the UG901 asymmetric-RAM template — the wide/narrow port width ratio must be a power of two, with the narrow-side address widened accordingly.
1. UG901 비대칭 RAM 템플릿을 따르십시오. 넓은 포트/좁은 포트 폭 비율은 2의 거듭제곱이어야 하며 좁은 쪽 주소도 그에 따라 넓어집니다.
2. Keep both ports synchronous (registered) and match the supported read/write collision behavior.
2. 두 포트를 동기(등록) 상태로 유지하고 지원되는 읽기/쓰기 충돌 동작과 일치시킵니다.
3. Ensure the memory array element type and the port widths are consistent with the ratio (e.g., 4:1 requires the address on the narrow side to have 2 extra bits).
3. 메모리 어레이 요소 유형과 포트 너비가 비율과 일치하는지 확인하십시오(예: 4:1의 경우 좁은 쪽의 주소에 2개의 추가 비트가 필요함).
4. If the asymmetric pattern still will not infer, use the Block Memory Generator IP configured for asymmetric ports.
4. 비대칭 패턴이 여전히 추론되지 않으면 비대칭 포트에 대해 구성된 블록 메모리 생성기 IP를 사용하십시오.
