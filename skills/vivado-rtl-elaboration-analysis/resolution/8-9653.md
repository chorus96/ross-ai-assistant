# 8-9653: Wrong Number of Index Dimensions
# 8-9653: 잘못된 인덱스 차원 수

**Message:** `[Synth 8-9653] indexed name prefix type expects N dimensions`
**메시지:** `[Synth 8-9653] 색인화된 이름 접두사 유형에는 N 차원이 필요합니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An array access provides wrong number of index dimensions.
배열 액세스가 잘못된 수의 인덱스 차원을 제공합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Wrong index-dimension count
### P1: 잘못된 인덱스 차원 개수

**Problematic Code:**
**문제가 있는 코드:**
```diff
signal a : output_array;  -- 2D array
a(0) <= val;  -- ERROR: needs 2 indices
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
a(0,0) <= val;  -- provide both indices
-- Or: a(0)(0) <= val;  -- depending on declaration
```

---

## Fix Strategy
## 전략 수정

1. Provide the correct number of indices for the array's declared dimensions (a 2D array needs two).
1. 배열의 선언된 차원에 대해 올바른 수의 인덱스를 제공하십시오(2D 배열에는 2개가 필요함).
2. Use the syntax matching the declaration — `a(i,j)` for a multi-dimensional array, or `a(i)(j)` for an array-of-arrays.
2. 다차원 배열의 경우 `a(i,j)`, 배열 배열의 경우 `a(i)(j)` 선언과 일치하는 구문을 사용합니다.
3. Check the type definition to confirm how many dimensions it has.
3. 유형 정의를 확인하여 얼마나 많은 차원이 있는지 확인하세요.
4. Fix accesses broken by changing an array's dimensionality without updating all uses.
4. 모든 용도를 업데이트하지 않고 배열의 차원을 변경하여 액세스가 중단되는 문제를 수정합니다.
