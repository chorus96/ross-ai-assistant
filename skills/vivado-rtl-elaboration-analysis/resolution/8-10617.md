# 8-10617: Field/Method Not Found
# 8-10617: 필드/메소드를 찾을 수 없습니다.

**Message:** `[Synth 8-10617] could not find field/method name in object`
**메시지:** `[Synth 8-10617] 개체에서 필드/메서드 이름을 찾을 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10617] could not find field/method name in object [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A SystemVerilog method or field name does not exist for the given type.
해당 유형에 대한 SystemVerilog 메소드 또는 필드 이름이 존재하지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Field/method not found on type
### P1: 유형에서 필드/메서드를 찾을 수 없습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: calling non-existent method
bit [7:0] bs1;
bs1.reverse;     // ERROR: 'reverse' not a method of bit[7:0]
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use correct method for the type
bit [7:0] bs1;
// 'reverse' is for dynamic arrays/queues, not packed arrays
// For packed array bit reversal, use manual logic:
for (int i = 0; i < 8; i++) bs1_rev[i] = bs1[7-i];
```

---

## Fix Strategy
## 전략 수정

Check that the method exists for the object's type.
객체 유형에 대한 메소드가 존재하는지 확인하십시오.
Array methods like `reverse`, `sort`, `unique` are for dynamic arrays/queues, not packed arrays.
`reverse`, `sort`, `unique`와 같은 배열 메소드는 압축된 배열이 아닌 동적 배열/큐에 사용됩니다.
