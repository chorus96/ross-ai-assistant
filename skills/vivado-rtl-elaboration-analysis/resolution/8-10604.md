# 8-10604: concatenation with an unsized literal will be treated as 32 bits
# 8-10604: 크기가 지정되지 않은 리터럴과의 연결은 32비트로 처리됩니다.

**Message:** `[Synth 8-10604] concatenation with an unsized literal will be treated as 32 bits`
**메시지:** `[Synth 8-10604] 크기가 지정되지 않은 리터럴과의 연결은 32비트로 처리됩니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An unsized literal (e.g.
크기가 지정되지 않은 리터럴(예:
`'1`, `1`) is used inside a concatenation, where it defaults to 32 bits - usually not what was intended.
`'1`, `1`)은 연결 내에서 사용되며 기본값은 32비트입니다. 일반적으로 의도한 것과는 다릅니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Unsized literal in concatenation treated as 32 bits
### P1: 32비트로 처리되는 연결의 크기가 지정되지 않은 리터럴

**Problematic Code:**
**문제가 있는 코드:**
```verilog
assign y = {a, 1};   // '1' is 32 bits here
```

**Recommended Fix:**
**권장 수정 사항:**
```verilog
assign y = {a, 1'b1};   // give the literal an explicit width
```

---

## Fix Strategy
## 전략 수정

1. Give every literal in a concatenation an explicit width (`N'bxxx`).
1. 연결의 모든 리터럴에 명시적인 너비(`N'bxxx`)를 제공합니다.
2. Unsized literals default to 32 bits inside concatenations.
2. 크기가 지정되지 않은 리터럴은 연결 내에서 기본적으로 32비트입니다.
3. This is a warning; size the literal to avoid width surprises.
3. 이는 경고입니다. 너비에 대한 놀라움을 피하기 위해 리터럴의 크기를 조정하십시오.
