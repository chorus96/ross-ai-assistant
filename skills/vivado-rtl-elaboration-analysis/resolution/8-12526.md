# 8-12526: Unexpected Timeunit
# 8-12526: 예상치 못한 시간 단위

**Message:** `[Synth 8-12526] unexpected time!%1!`
**메시지:** `[Synth 8-12526] 예상치 못한 시간!%1!`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A SystemVerilog `timeunit` declaration is in an unexpected location or has invalid syntax.
SystemVerilog `timeunit` 선언이 예상치 못한 위치에 있거나 잘못된 구문이 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: timeunit in an unexpected location
### P1: 예상치 못한 위치에 있는 시간 단위

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: timeunit in wrong location
module top;
timeunit 1ns/1ps;  // ERROR: unexpected if already set
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use `timescale or fix placement
`timescale 1ns/1ps  // use preprocessor directive
module top;
```

---

## Fix Strategy
## 전략 수정

1. Place `timeunit`/`timeprecision` as the first item(s) inside the module, or use a `` `timescale `` directive before the module.
1. 모듈 내부의 첫 번째 항목으로 `timeunit`/`timeprecision`을 배치하거나 모듈 앞에 `` `timescale `` 지시어를 사용하세요.
2. Do not put `timeunit` in an unexpected location (after declarations/statements).
2. 예상치 못한 위치(선언/문 뒤)에 'timeunit'을 넣지 마세요.
3. Keep one consistent time policy per compilation unit.
3. 컴파일 단위당 하나의 일관된 시간 정책을 유지합니다.
4. Prefer a single project-wide `` `timescale `` to avoid per-module conflicts.
4. 모듈별 충돌을 피하기 위해 프로젝트 전반에 걸친 단일 ``timescale ``을 선호합니다.
