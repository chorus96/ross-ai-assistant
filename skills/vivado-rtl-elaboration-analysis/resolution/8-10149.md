# 8-10149: Wrong Assignment Operator for Signal
# 8-10149: 신호에 대한 잘못된 할당 연산자

**Message:** `[Synth 8-10149] use <= to assign to signal`
**메시지:** `[Synth 8-10149] <=를 사용하여 신호에 할당`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10149] use <= to assign to signal [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

VHDL signal assignment uses `:=` (variable assignment) instead of `<=` (signal assignment).
VHDL 신호 할당은 `<=`(신호 할당) 대신 `:=`(변수 할당)을 사용합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: := used to assign a signal
### P1: := 신호를 할당하는 데 사용됩니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: variable assignment operator on signal
signal dout : character;
process
begin
  dout := C;  -- ERROR: use <= for signal assignment
end process;
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use signal assignment operator
signal dout : character;
process
begin
  dout <= C;  -- correct: signal assignment
end process;
```

---

## Fix Strategy
## 전략 수정

1. Use `<=` (signal assignment) for **signals** and `:=` (variable assignment) for **variables** in VHDL.
1. VHDL의 **신호**에는 `<=`(신호 할당)을 사용하고 **변수**에는 `:=`(변수 할당)을 사용합니다.
2. Inside a process, decide whether the target is a signal or a variable and use the matching operator.
2. 프로세스 내에서 대상이 신호인지 변수인지 결정하고 일치 연산자를 사용합니다.
3. If you intended immediate update semantics, declare the object as a `variable` and use `:=`; for scheduled updates, use a `signal` with `<=`.
3. 즉각적인 업데이트 의미를 의도했다면 객체를 '변수'로 선언하고 ':='를 사용하세요. 예약된 업데이트의 경우 `<=`와 함께 `signal`을 사용하세요.
4. Check the declaration of the target to confirm signal vs. variable before assigning.
4. 할당하기 전에 신호와 변수를 확인하려면 대상 선언을 확인하세요.
