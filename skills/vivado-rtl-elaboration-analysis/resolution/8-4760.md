# 8-4760: Uninstantiated Package in Use
# 8-4760: 인스턴스화되지 않은 패키지가 사용 중입니다.

**Message:** `[Synth 8-4760] uninstantiated package cannot be specified in use clause`
**메시지:** `[Synth 8-4760] 인스턴스화되지 않은 패키지는 use 절에 지정할 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL `use` clause references an uninstantiated (generic) package that hasn't been instantiated.
VHDL `use` 절은 인스턴스화되지 않은 인스턴스화되지 않은(일반) 패키지를 참조합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: use of an uninstantiated generic package
### P1: 인스턴스화되지 않은 일반 패키지 사용

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: using uninstantiated generic package
use work.gen_pkg.all;  -- ERROR: gen_pkg is generic, need instance
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: instantiate the package first
package my_pkg is new work.gen_pkg generic map(T => integer);
use work.my_pkg.all;
```

---

## Fix Strategy
## 전략 수정

1. Instantiate the generic package first (`package my_pkg is new work.gen_pkg generic map(...);`), then `use work.my_pkg.all;` — you cannot `use` an uninstantiated generic package directly.
1. 먼저 일반 패키지를 인스턴스화하고(`package my_pkg is new work.gen_pkg generic map(...);`) 그런 다음 `use work.my_pkg.all;` — 인스턴스화되지 않은 일반 패키지를 직접 `사용`할 수 없습니다.
2. Provide all required generic map values for the package instantiation.
2. 패키지 인스턴스화에 필요한 모든 일반 맵 값을 제공합니다.
3. Ensure the instantiation is compiled before any file that references it.
3. 인스턴스화가 이를 참조하는 파일보다 먼저 컴파일되었는지 확인하십시오.
4. Confirm the synthesis flow supports VHDL-2008 generic packages; otherwise replace with a concrete (non-generic) package.
4. 합성 흐름이 VHDL-2008 일반 패키지를 지원하는지 확인합니다. 그렇지 않으면 구체적인(일반이 아닌) 패키지로 교체하세요.
