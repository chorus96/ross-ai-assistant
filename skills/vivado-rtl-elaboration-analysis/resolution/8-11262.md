# 8-11262: Unpacked Value in Assignment
# 8-11262: 할당에서 압축이 풀린 값

**Message:** `[Synth 8-11262] unpacked value/target cannot be used in an assignment`
**메시지:** `[Synth 8-11262] 압축이 풀린 값/대상은 할당에 사용할 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An unpacked value or target is used in an assignment where packed is required.
압축 해제된 값 또는 대상은 압축이 필요한 할당에 사용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Unpacked value where packed required
### P1: 포장이 필요한 경우 포장을 푼 값

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: unpacked in assignment
int arr[4];
logic [31:0] packed_val;
packed_val = arr;  // ERROR: can't assign unpacked to packed
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: assign element by element
packed_val = {arr[3], arr[2], arr[1], arr[0]};  // explicit packing
```

---

## Fix Strategy
## 전략 수정

1. Convert unpacked to packed explicitly before the assignment — use concatenation (`{a[1], a[0]}`) or streaming operators (`{>>{arr}}`).
1. 할당 전에 압축 해제를 명시적으로 압축으로 변환합니다. 연결(`{a[1], a[0]}`) 또는 스트리밍 연산자(`{>>{arr}}`)를 사용합니다.
2. Ensure both sides of the assignment are the same packed-vs-unpacked kind.
2. 할당의 양쪽이 동일한 패킹된 유형과 언팩된 유형인지 확인하세요.
3. Match total bit widths when packing an unpacked array into a vector.
3. 압축이 풀린 배열을 벡터로 압축할 때 총 비트 너비를 일치시킵니다.
4. Prefer declaring the data as packed from the start when it feeds packed contexts.
4. 압축된 컨텍스트를 제공할 때 처음부터 데이터를 압축된 것으로 선언하는 것이 좋습니다.
