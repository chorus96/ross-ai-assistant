# 8-10615: Ending Label Mismatch
# 8-10615: 라벨 불일치 종료

**Message:** `[Synth 8-10615] could not find a main label to match ending label`
**메시지:** `[Synth 8-10615]는 종료 라벨과 일치하는 기본 라벨을 찾을 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10615] could not find a main label to match ending label [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

The `end` statement has a label that doesn't match any enclosing block, process, or generate label.
'end' 문에 포함된 블록, 프로세스 또는 생성 라벨과 일치하지 않는 라벨이 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Ending label mismatch
### P1: 종료 라벨 불일치

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: mismatched ending label
PROCESS
  ...
END PROCESS TESTING;  -- ERROR: no process labeled TESTING
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: match or remove the ending label
TESTING: PROCESS   -- add label to match
  ...
END PROCESS TESTING;
-- Or remove the ending label:
END PROCESS;
```

---

## Fix Strategy
## 전략 수정

Either add the matching label to the opening statement or remove the label from the `end` statement.
시작 문에 일치하는 라벨을 추가하거나 'end' 문에서 라벨을 제거하세요.
