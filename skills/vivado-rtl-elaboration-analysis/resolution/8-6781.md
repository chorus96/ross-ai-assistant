# 8-6781: Nested Interface in Port
# 8-6781: 포트에 중첩된 인터페이스

**Message:** `[Synth 8-6781] Nested interface is used in interface port connection`
**메시지:** `[Synth 8-6781] 인터페이스 포트 연결에 중첩된 인터페이스가 사용됩니다.`
**Severity:** CRITICAL WARNING
**심각도:** 심각한 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A nested interface is connected through a port, which has limitations.
중첩된 인터페이스는 제한이 있는 포트를 통해 연결됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Nested interface through a port
### P1: 포트를 통한 중첩 인터페이스

**문제가 있는 코드:**

// WARNING: nested interface UB used in port connection

**권장 수정 사항:**

// Flatten the interface hierarchy or use modport references

## Fix Strategy
## 전략 수정

1. Avoid passing a **nested** interface through a port connection — flatten the hierarchy so the module port takes a single-level interface (or specific modport).
1. 포트 연결을 통해 **중첩** 인터페이스를 전달하지 마세요. 모듈 포트가 단일 레벨 인터페이스(또는 특정 모드포트)를 사용하도록 계층 구조를 평탄화하세요.
2. Expose only the needed sub-interface/modport at the boundary instead of an interface-containing-interface.
2. 인터페이스가 포함된 인터페이스 대신 경계에서 필요한 하위 인터페이스/modport만 노출합니다.
3. Restructure the connectivity so each level connects its own interface signals rather than nesting them through ports.
3. 각 레벨이 포트를 통해 중첩되지 않고 자체 인터페이스 신호를 연결하도록 연결을 재구성합니다.
4. Treat this CRITICAL WARNING as a portability/synthesis risk and verify the connection elaborates as intended.
4. 이 CRITICAL WARNING을 이식성/합성 위험으로 처리하고 연결이 의도한 대로 정교한지 확인하십시오.
