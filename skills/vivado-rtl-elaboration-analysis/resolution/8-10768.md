# 8-10768: Illegal Attribute
# 8-10768: 잘못된 속성

**Message:** `[Synth 8-10768] ignoring illegal attribute`
**메시지:** `[Synth 8-10768] 잘못된 속성 무시`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10768] ignoring illegal attribute [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

An attribute is used in a context where it's not valid, or uses non-standard syntax.
속성이 유효하지 않은 컨텍스트에서 사용되거나 비표준 구문을 사용합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Attribute in an expression
### P1: 표현식의 속성

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: attribute in expression context
this.var1.reg8[2:0](*a,b*)++;   // ERROR: (*a,b*) attribute syntax invalid here
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: remove the attribute or use valid syntax
this.var1.reg8[2:0]++;   // remove inline attributes
// Or use standard attribute syntax:
(* keep = "true" *) reg [7:0] my_reg;
```

---

## Fix Strategy
## 전략 수정

1. Apply attributes with the standard `(* attr = value *)` syntax on a **declaration**, not inside an expression.
1. 표현식 내부가 아닌 **선언**에 표준 `(* attr = value *)` 구문을 사용하여 속성을 적용합니다.
2. Move an inline attribute to the signal/instance declaration it should annotate.
2. 인라인 속성을 주석을 달아야 하는 신호/인스턴스 선언으로 이동합니다.
3. Use a Vivado-supported attribute name and a valid value type.
3. Vivado가 지원하는 속성 이름과 유효한 값 유형을 사용하세요.
4. Remove attributes that have no synthesis meaning.
4. 합성 의미가 없는 속성을 제거합니다.
