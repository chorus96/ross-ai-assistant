# 8-1621: Unpacked to String Needs Cast
# 8-1621: 문자열로 압축 풀기 캐스트 필요

**Message:** `[Synth 8-1621] assigning a !%1! type to a string requires a cast`
**메시지:** `[Synth 8-1621] !%1! 할당 중 문자열을 입력하려면 캐스트가 필요합니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

Assigning an unpacked type to a `string` requires an explicit cast.
압축이 풀린 유형을 '문자열'에 할당하려면 명시적인 형변환이 필요합니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Unpacked value assigned to string
### P1: 문자열에 할당된 압축 해제된 값

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: unpacked assigned to string without cast
int arr[4];
string s;
s = arr;  // ERROR: needs cast
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use $sformatf or cast
s = $sformatf("%p", arr);  // convert to string
// Note: string is not synthesizable
```

---

## Fix Strategy
## 전략 수정

1. `string` and dynamic-string operations are not synthesizable — remove them from synthesizable RTL or guard them in simulation-only code (`translate_off` / `ifndef SYNTHESIS`).
1. `string` 및 동적 문자열 작업은 합성할 수 없습니다. 합성 가능한 RTL에서 제거하거나 시뮬레이션 전용 코드(`translate_off` / `ifndef SYNTHESIS`)에서 보호하세요.
2. If a string was used to hold data, represent it as a fixed-width bit vector (`logic [N-1:0]`) or a packed array of bytes instead.
2. 문자열이 데이터를 보유하는 데 사용된 경우 이를 대신 고정 너비 비트 벡터(`논리 [N-1:0]`) 또는 압축된 바이트 배열로 표시합니다.
3. For debug/formatting only, move `$sformatf`/string handling into the testbench, not the design.
3. 디버그/포맷 전용의 경우 `$sformatf`/문자열 처리를 디자인이 아닌 테스트벤치로 이동하세요.
4. If a cast is genuinely required in verification code, use an explicit conversion (`$sformatf("%p", arr)`), but keep it out of the synthesized path.
4. 확인 코드에 실제로 캐스트가 필요한 경우 명시적 변환(`$sformatf("%p", arr)`)을 사용하되 합성 경로에서 제외하세요.
