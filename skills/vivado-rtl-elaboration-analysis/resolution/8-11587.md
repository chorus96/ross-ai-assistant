# 8-11587: Invalid Assignment Pattern
# 8-11587: 잘못된 할당 패턴

**Message:** `[Synth 8-11587] invalid !%1!`
**메시지:** `[Synth 8-11587] 유효하지 않습니다!%1!`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An assignment pattern has invalid syntax or structure.
할당 패턴에 잘못된 구문이나 구조가 있습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Malformed assignment pattern
### P1: 잘못된 할당 패턴

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: malformed assignment pattern
assign out = '{1:a, 2:b};  // ERROR: invalid pattern syntax
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use correct pattern syntax
assign out = '{a, b};  // positional
// Or: assign out = '{0:a, 1:b};  // indexed
```

---

## Fix Strategy
## 전략 수정

1. Use valid assignment-pattern syntax matching the target: positional `'{a, b}`, indexed `'{0:a, 1:b}`, or named `'{field:val}`.
1. 대상 `'{a, b}`, 색인화된 `'{0:a, 1:b}` 또는 이름이 지정된 `'{field:val}`과 일치하는 유효한 할당 패턴 구문을 사용하십시오.
2. Match the number/types of elements to the target array/struct.
2. 요소의 수/유형을 대상 배열/구조체와 일치시킵니다.
3. Do not mix positional and named forms inconsistently within one pattern.
3. 하나의 패턴 내에서 위치 형식과 명명 형식을 일관되지 않게 혼합하지 마세요.
4. For defaults, use `'{default:0}` to fill remaining elements.
4. 기본값의 경우 `'{default:0}`를 사용하여 나머지 요소를 채웁니다.
