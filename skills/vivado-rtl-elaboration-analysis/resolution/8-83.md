# 8-83: Packed Union Size Mismatch
# 8-83: 패킹된 유니온 크기 불일치

**Message:** `[Synth 8-83] all members of packed union must have same size`
**메시지:** `[Synth 8-83] 패킹 유니온의 모든 멤버는 동일한 크기를 가져야 합니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-83] all members of packed union must have same size [/path/to/file.sv:42]
```

---

## Root Cause
## 근본 원인

A SystemVerilog packed union requires all members to have the same bit width.
SystemVerilog 팩형 유니온에서는 모든 멤버가 동일한 비트 너비를 가져야 합니다.
When members have different sizes, the compiler cannot create a consistent memory layout.
멤버의 크기가 다르면 컴파일러는 일관된 메모리 레이아웃을 만들 수 없습니다.

---

## Example
## 예

```systemverilog
// Before - different member sizes
typedef union packed {
  logic [31:0] word;    // 32 bits
  logic [15:0] half;    // 16 bits - ERROR: different size
  logic [7:0]  byte_val; // 8 bits - ERROR: different size
} my_union_t;
```

---

## Fix Options
## 수정 옵션

### Option 1: Make All Members Same Size
### 옵션 1: 모든 멤버를 동일한 크기로 만들기

```systemverilog
// After - all members 32 bits
typedef union packed {
  logic [31:0] word;
  logic [31:0] word2;    // same size
  logic [31:0] word3;    // same size
} my_union_t;
```

### Option 2: Use Struct for Different Sizes
### 옵션 2: 다양한 크기에 구조체 사용

```systemverilog
// If you need different access patterns, use struct
typedef struct packed {
  logic [31:0] word;
} data_t;

// Access different portions via bit select
wire [15:0] half = data.word[15:0];
wire [7:0]  byte_val = data.word[7:0];
```

### Option 3: Use Packed Struct Inside Union
### 옵션 3: Union 내부에서 Packed Struct 사용

```systemverilog
// Create same-sized packed structs
typedef struct packed {
  logic [15:0] hi;
  logic [15:0] lo;
} half_word_t;

typedef struct packed {
  logic [7:0] b3, b2, b1, b0;
} bytes_t;

typedef union packed {
  logic [31:0] word;     // 32 bits
  half_word_t  halves;   // 32 bits
  bytes_t      bytes;    // 32 bits
} my_union_t;
```
