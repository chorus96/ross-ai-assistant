# 8-5832: Simulation-Only Source File
# 8-5832: 시뮬레이션 전용 소스 파일

**Message:** `[Synth 8-5832] source file was generated for simulation and is not permitted as input to synthesis`
**메시지:** `[Synth 8-5832] 소스 파일은 시뮬레이션을 위해 생성되었으며 합성에 대한 입력으로 허용되지 않습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

The source file was generated for simulation and cannot be used for synthesis.
소스 파일은 시뮬레이션을 위해 생성되었으므로 합성에 사용할 수 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Simulation-only file used for synthesis
### P1: 합성에 사용되는 시뮬레이션 전용 파일

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: simulation-only file
// File contains `timescale, $display, etc. marked as sim-only
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: use the synthesis version of the file
// Check for *_synth.v or *_stub.v alternatives
// Or regenerate the IP for synthesis output
```

---

## Fix Strategy
## 전략 수정

1. Use the IP's **synthesis** output products, not its simulation-only files — IP generates separate synth and sim filesets.
1. 시뮬레이션 전용 파일이 아닌 IP의 **합성** 출력 제품을 사용하십시오. IP는 별도의 신디사이저 및 시뮬레이션 파일 세트를 생성합니다.
2. Add the IP via its `.xci` and let Vivado pull the correct synthesis sources, rather than manually adding a simulation model.
2. '.xci'를 통해 IP를 추가하면 시뮬레이션 모델을 수동으로 추가하는 대신 Vivado가 올바른 합성 소스를 가져오도록 할 수 있습니다.
3. If a stub is needed for out-of-context flows, use the generated `*_stub.v`/`*_stub.vhdl`.
3. 컨텍스트 외부 흐름에 스텁이 필요한 경우 생성된 `*_stub.v`/`*_stub.vhdl`을 사용하세요.
4. Regenerate/upgrade the IP so current synthesis products are available, and remove the simulation-only file from the synthesis fileset.
4. 현재 합성 제품을 사용할 수 있도록 IP를 재생성/업그레이드하고 합성 파일 세트에서 시뮬레이션 전용 파일을 제거합니다.
