# 8-9910: Port Already Defined
# 8-9910: 포트가 이미 정의되어 있습니다.

**Message:** `[Synth 8-9910] port is already defined`
**메시지:** `[Synth 8-9910] 포트가 이미 정의되어 있습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A port name is declared multiple times.
포트 이름이 여러 번 선언되었습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Duplicate port name
### P1: 중복된 포트 이름

**Problematic Code:**
**문제가 있는 코드:**
```diff
module m(input a, input a);  // ERROR: 'a' defined twice
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
module m(input a, input b);  // unique names
```

---

## Fix Strategy
## 전략 수정

1. Give each port a unique name — remove or rename the duplicate.
1. 각 포트에 고유한 이름을 지정하십시오. 중복된 포트를 제거하거나 이름을 바꾸십시오.
2. Check for copy-paste that repeated a port in the header/body.
2. 헤더/본문에서 포트를 반복한 복사-붙여넣기를 확인하세요.
3. Ensure the port list and any body declarations agree and declare each port exactly once.
3. 포트 목록과 본문 선언이 일치하는지 확인하고 각 포트를 정확히 한 번 선언합니다.
4. Verify downstream connections use the corrected, unique names.
4. 다운스트림 연결이 수정된 고유 이름을 사용하는지 확인하세요.
