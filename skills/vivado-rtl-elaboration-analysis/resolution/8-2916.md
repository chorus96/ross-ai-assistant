# 8-2916: Unconnected Interface Port
# 8-2916: 연결되지 않은 인터페이스 포트

**Message:** `[Synth 8-2916] unconnected interface port '!%1!'`
**메시지:** `[Synth 8-2916] 연결되지 않은 인터페이스 포트 '!%1!'`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A SystemVerilog interface port is left unconnected in an instantiation.
SystemVerilog 인터페이스 포트는 인스턴스화 시 연결되지 않은 상태로 유지됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Interface port left unconnected
### P1: 인터페이스 포트가 연결되지 않은 채로 남아 있음

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: interface port not connected
module m(intf.master intr1);
my_mod inst();  // ERROR: intr1 unconnected
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: connect the interface
intf intf_inst();
my_mod inst(.intr1(intf_inst));  // connected
```

---

## Fix Strategy
## 전략 수정

1. Connect every interface port in the instantiation — create an interface instance and pass it (`intf intf_inst(); my_mod inst(.intr1(intf_inst));`).
1. 인스턴스화의 모든 인터페이스 포트를 연결합니다. 인터페이스 인스턴스를 생성하고 전달합니다(`intf intf_inst(); my_mod inst(.intr1(intf_inst));`).
2. Ensure the connected interface uses a modport compatible with the port's declared modport (e.g., `.intr1(bus.master)`).
2. 연결된 인터페이스가 포트에 선언된 모드포트(예: `.intr1(bus.master)`)와 호환되는 모드포트를 사용하는지 확인하세요.
3. Interface ports cannot be implicitly left open; if a connection is genuinely optional, restructure to use discrete signals instead.
3. 인터페이스 포트는 암시적으로 열린 상태로 둘 수 없습니다. 연결이 실제로 선택 사항인 경우 대신 개별 신호를 사용하도록 재구성하십시오.
4. Verify the interface is declared/compiled before the module that uses it.
4. 인터페이스를 사용하는 모듈보다 먼저 인터페이스가 선언/컴파일되었는지 확인하세요.
