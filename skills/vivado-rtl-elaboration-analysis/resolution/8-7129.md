# 8-7129: Port Unconnected or No Load
# 8-7129: 포트가 연결되지 않았거나 부하가 없음

**Message:** `[Synth 8-7129] Port is either unconnected or has no load`
**메시지:** `[Synth 8-7129] 포트가 연결되지 않았거나 로드가 없습니다`
**Severity:** WARNING
**심각도:** 경고
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A port has no connection or its connected signal has no load.
포트에 연결이 없거나 연결된 신호에 부하가 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Port with no load
### P1: 부하가 없는 포트

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- WARNING: Port output1 has no load
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- Connect the port to logic that uses it
-- Or remove the port if not needed
-- Add dont_touch to preserve if intentional
```

---

## Fix Strategy
## 전략 수정

1. Connect the port/signal to active logic that consumes (loads) it — a no-load port usually means the intended downstream connection is missing.
1. 포트/신호를 소비(로드)하는 활성 로직에 연결합니다. 무부하 포트는 일반적으로 의도한 다운스트림 연결이 누락되었음을 의미합니다.
2. If the port is genuinely unused, remove it or leave it explicitly open; do not leave a dangling driver.
2. 포트가 실제로 사용되지 않은 경우 제거하거나 명시적으로 열어 두십시오. 매달린 운전자를 두지 마십시오.
3. If the net must be retained (debug/probe), apply `(* dont_touch = "true" *)` / `keep`.
3. net을 유지해야 하는 경우(디버그/프로브) `(* dont_touch = "true" *)` / `keep`을 적용하세요.
4. Trace whether the missing load indicates dead logic that should also be cleaned up.
4. 누락된 로드가 정리되어야 하는 데드 로직을 나타내는지 여부를 추적합니다.
