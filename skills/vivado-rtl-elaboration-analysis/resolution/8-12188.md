# 8-12188: Failed to Read Verilog File
# 8-12188: Verilog 파일을 읽지 못했습니다.

**Message:** `[Synth 8-12188] Failed to read verilog '!%1!'`
**메시지:** `[Synth 8-12188] Verilog '!%1!'을 읽지 못했습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

Vivado could not read/parse a Verilog source file.
Vivado가 Verilog 소스 파일을 읽거나 구문 분석할 수 없습니다.
The file may have syntax errors, missing includes, or encoding issues.
파일에 구문 오류, 포함 누락 또는 인코딩 문제가 있을 수 있습니다.

## 일반적인 패턴

### P1: Verilog 파일을 구문 분석하지 못했습니다.

**문제가 있는 코드:**

// The file has fundamental parse errors that prevent reading

**권장 수정 사항:**
```diff
// Fix: check for:
// 1. Missing `include files

```

---

## Fix Strategy
## 전략 수정

1. This is a cascading parse failure — fix the **first** syntax error in the file, then re-run; later errors often clear.
1. 이는 계단식 구문 분석 실패입니다. 파일의 **첫 번째** 구문 오류를 수정한 후 다시 실행하세요. 나중에 오류가 종종 해결됩니다.
2. Check the file path, encoding (clean ASCII/UTF-8), and any missing `` `include `` headers.
2. 파일 경로, 인코딩(ASCII/UTF-8 정리) 및 누락된 ``include `` 헤더를 확인하세요.
3. Verify balanced `begin`/`end`, `module`/`endmodule`, and matched brackets.
3. 균형 잡힌 `begin`/`end`, `module`/`endmodule` 및 일치하는 대괄호를 확인하세요.
4. Ensure the file is added as the correct language/type (Verilog vs SystemVerilog).
4. 파일이 올바른 언어/유형(Verilog 및 SystemVerilog)으로 추가되었는지 확인하십시오.
