# 8-9400: empty statement in !%1!
# 8-9400: !%1!의 빈 문!

**Message:** `[Synth 8-9400] empty statement in !%1!`
**메시지:** `[Synth 8-9400] !%1!에 빈 문장이 있습니다!`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An empty statement (stray `;`) appears where it is flagged.
플래그가 지정된 곳에 빈 명령문(빠진 `;`)이 나타납니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Empty statement
### P1: 빈 문

**Problematic Code:**
**문제가 있는 코드:**
```systemverilog
always @* ; a=b;   // stray ';'
```

**Recommended Fix:**
**권장 수정 사항:**
```systemverilog
always @* a=b;
```

---

## Fix Strategy
## 전략 수정

1. Remove the stray semicolon / empty statement.
1. 길 잃은 세미콜론/빈 문을 제거하세요.
2. Check for a misplaced `;` after a block or condition.
2. 블록이나 조건 뒤에 잘못된 `;`이 있는지 확인하세요.
3. Empty statements are allowed in SystemVerilog but often indicate a bug.
3. SystemVerilog에서는 빈 문이 허용되지만 종종 버그를 나타냅니다.
