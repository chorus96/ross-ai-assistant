# 8-10890: Index Constraint on Non-Array
# 8-10890: 비 어레이에 대한 인덱스 제약

**Message:** `[Synth 8-10890] index constraint cannot be applied to non-array type`
**메시지:** `[Synth 8-10890] 인덱스 제약 조건은 배열이 아닌 유형에 적용될 수 없습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-10890] index constraint cannot be applied to non-array type [/path/to/file:NN]
```

---

## Root Cause
## 근본 원인

A VHDL index constraint (e.g., `'range`) is applied to a generic type that is not an array.
VHDL 인덱스 제약 조건(예: '범위')은 배열이 아닌 일반 유형에 적용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Index constraint on a non-array
### P1: 배열이 아닌 항목에 대한 인덱스 제약 조건

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: range constraint on generic type
generic (type generic_type1);
port (in1 : in generic_type1(insize'range));  -- ERROR if generic_type1 is not array
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: constrain the generic type or use unconstrained
port (in1 : in generic_type1);  -- remove index constraint
-- Or define the generic as an array type:
generic (type generic_type1 is array (natural range <>) of std_logic);
```

---

## Fix Strategy
## 전략 수정

1. Apply an index constraint only to an **array** type; scalars/records cannot be index-constrained.
1. **배열** 유형에만 인덱스 제약 조건을 적용합니다. 스칼라/레코드는 인덱스로 제한될 수 없습니다.
2. For a generic type, constrain the generic's definition (make it an array type) or remove the index constraint.
2. 제네릭 유형의 경우 제네릭 정의를 제한하거나(배열 유형으로 만들기) 인덱스 제약 조건을 제거합니다.
3. Verify the constrained object is declared as an array before constraining its index range.
3. 인덱스 범위를 제한하기 전에 제한된 객체가 배열로 선언되었는지 확인하세요.
4. Fix a mismatch where a scalar was declared with an array-style range.
4. 스칼라가 배열 스타일 범위로 선언된 불일치를 수정합니다.
