# 8-3391: Cannot Infer RAM
# 8-3391: RAM을 추론할 수 없습니다.

**Message:** `[Synth 8-3391] Unable to infer a block/distributed RAM for '!%1!' because the memory pattern used is not supported.
**메시지:** `[Synth 8-3391] '!%1!'에 대한 블록/분산 RAM을 추론할 수 없습니다. 사용된 메모리 패턴이 지원되지 않기 때문입니다.
Failed to dissolve the memory into bits because the number of bits (!%2!) is too large.
비트 수(!%2!)가 너무 커서 메모리를 비트로 분해하지 못했습니다.
Use 'set_param synth.elaboration.rodinMoreOptions {rt::set_parameter dissolveMemorySizeLimit !%3!}' to allow the memory to be dissolved into individual bits`
메모리가 개별 비트로 분해되도록 하려면 'set_param synth.elaboration.rodinMoreOptions {rt::set_parameter dissolveMemorySizeLimit !%3!}'을 사용하세요.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

RTL coding pattern doesn't match supported Block/Distributed RAM templates.
RTL 코딩 패턴이 지원되는 블록/분산 RAM 템플릿과 일치하지 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Asynchronous-read RAM pattern
### P1: 비동기 읽기 RAM 패턴

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: unsupported RAM pattern
always @(posedge clk)
  if (we) mem[addr] <= din;
assign dout = mem[addr2];  // async read with write
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: follow UG901 RAM template
always @(posedge clk) begin
  if (we) mem[addr] <= din;
  dout <= mem[addr];  // synchronous read
end
```

---

## Fix Strategy
## 전략 수정

1. Follow a Vivado RAM inference template (UG901): a clocked process that writes on a clock edge and reads **synchronously** (registered output).
1. Vivado RAM 추론 템플릿(UG901)을 따르세요. 클록 에지에 쓰고 **동기적으로**(등록된 출력) 읽는 클록 프로세스입니다.
2. Remove asynchronous reads (`assign dout = mem[addr];` outside a clocked block) — they force LUT/distributed logic and defeat BRAM inference.
2. 비동기식 읽기를 제거합니다(클럭 블록 외부의 `할당 dout = mem[addr];`). 이는 LUT/분산 로직을 강제하고 BRAM 추론을 무효화합니다.
3. Keep write and read in a consistent, supported style (read-first/write-first/no-change) and avoid mixing async and sync accesses to the same memory.
3. 일관되고 지원되는 스타일(읽기 우선/쓰기 우선/변경 없음)로 쓰기 및 읽기를 유지하고 동일한 메모리에 대한 비동기 및 동기화 액세스를 혼합하지 마십시오.
4. If inference still fails, use the Block Memory Generator IP or set `ram_style`/`rom_style` to force the desired implementation.
4. 추론이 여전히 실패하면 블록 메모리 생성기 IP를 사용하거나 `ram_style`/`rom_style`을 설정하여 원하는 구현을 강제합니다.
