# 8-8902: Not a Component
# 8-8902: 구성요소가 아님

**Message:** `[Synth 8-8902] '!%1!' is not a !%2!`
**메시지:** `[Synth 8-8902] '!%1!' !%2!`가 아닙니다.
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An identifier is used as a component in an instantiation but it's not declared as a component.
식별자는 인스턴스화에서 구성 요소로 사용되지만 구성 요소로 선언되지는 않습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Non-component used in instantiation
### P1: 인스턴스화에 사용되는 비구성요소

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: library used as component
U1: work port map(...);  -- ERROR: 'work' is a library, not component
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: use component or entity
U1: entity work.my_entity port map(...);
-- Or declare a component first
```

---

## Fix Strategy
## 전략 수정

1. Instantiate with direct entity binding (`U1: entity work.<entity>(<arch>) port map(...)`) or declare a `component` before instantiation.
1. 직접 엔터티 바인딩(`U1: 엔터티 작업.<entity>(<arch>) 포트 맵(...)`)으로 인스턴스화하거나 인스턴스화하기 전에 `구성 요소`를 선언합니다.
2. Do not use a library or package name where a component/entity is expected.
2. 구성 요소/엔티티가 예상되는 라이브러리 또는 패키지 이름을 사용하지 마십시오.
3. Ensure the referenced entity is compiled into the named library.
3. 참조된 엔터티가 명명된 라이브러리로 컴파일되었는지 확인하세요.
4. Fix typos so the instantiated name resolves to an actual entity/component.
4. 인스턴스화된 이름이 실제 엔터티/구성 요소로 확인되도록 오타를 수정합니다.
