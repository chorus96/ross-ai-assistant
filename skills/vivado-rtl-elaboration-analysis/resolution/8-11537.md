# 8-11537: Assignment Pattern Outside Assignment Context
# 8-11537: 할당 컨텍스트 외부의 할당 패턴

**Message:** `[Synth 8-11537] illegal use of assignment pattern outside of an assignment-like context`
**메시지:** `[Synth 8-11537] 할당과 유사한 컨텍스트 외부에서 할당 패턴의 불법 사용`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

An assignment pattern `'{...}` is used outside of an assignment, initialization, or port connection.
할당 패턴 `'{...}`이 할당, 초기화 또는 포트 연결 외부에서 사용됩니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Assignment pattern out of context
### P1: 상황에 맞지 않는 할당 패턴

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: pattern in non-assignment context
$display('{1, 2, 3});  // ERROR: not an assignment context
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: assign to variable first
int temp [3] = '{1, 2, 3};
$display(temp);
```

---

## Fix Strategy
## 전략 수정

1. Use assignment patterns `'{...}` only on the RHS of an assignment, in an initializer, or in a port/argument connection.
1. 할당의 RHS, 초기화 프로그램 또는 포트/인수 연결에서만 할당 패턴 `'{...}`을 사용하세요.
2. To use the pattern value elsewhere, assign it to a typed variable/constant first, then use that.
2. 패턴 값을 다른 곳에서 사용하려면 먼저 유형이 지정된 변수/상수에 할당한 다음 사용하세요.
3. Do not place a pattern in an expression/comparison context.
3. 표현식/비교 컨텍스트에 패턴을 배치하지 마세요.
4. Match the pattern shape to the target array/struct type.
4. 패턴 모양을 대상 배열/구조체 유형과 일치시킵니다.
