# 8-8926: Not a Valid Constant Function
# 8-8926: 유효한 상수 함수가 아닙니다.

**Message:** `[Synth 8-8926] '!%1!' is not a valid constant function`
**메시지:** `[Synth 8-8926] '!%1!' 유효한 상수 함수가 아닙니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A function used in a constant context is not a valid constant function.
상수 컨텍스트에 사용된 함수는 유효한 상수 함수가 아닙니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Impure function in a constant context
### P1: 상수 컨텍스트의 불순한 함수

**Problematic Code:**
**문제가 있는 코드:**
```diff
// Before: non-constant function in constant context
localparam P = max(A, B);  // ERROR if max is not constant-evaluable
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
// After: ensure function is constant-evaluable
// Constant functions cannot use system tasks, delays, or hierarchical refs
function integer max(input integer a, b);
  max = (a > b) ? a : b;
endfunction
```

---

## Fix Strategy
## 전략 수정

1. Make the function used in a constant context **pure** — no system tasks, delays, event controls, or hierarchical references.
1. 상수 컨텍스트에서 사용되는 함수를 **순수**하게 만듭니다. 시스템 작업, 지연, 이벤트 제어 또는 계층적 참조가 없습니다.
2. Ensure its inputs are elaboration-time constants and its body computes the value purely from them.
2. 입력이 정교화 시간 상수이고 본문이 그 입력에서 순수하게 값을 계산하는지 확인하세요.
3. Move any non-constant computation out of the constant context (compute it at runtime instead).
3. 상수가 아닌 계산을 상수 컨텍스트 밖으로 이동합니다(대신 런타임에 계산합니다).
4. Verify the function is visible and its result type matches the constant target.
4. 함수가 표시되고 해당 결과 유형이 상수 대상과 일치하는지 확인합니다.
