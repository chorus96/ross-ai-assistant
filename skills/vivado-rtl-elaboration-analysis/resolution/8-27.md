# 8-27: Not Supported
# 8-27: 지원되지 않음

**Message:** `[Synth 8-27] !%1! not supported`
**메시지:** `[Synth 8-27] !%1! 지원되지 않음`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-27] 'feature_name' not supported [/path/to/file.v:42]
```

---

## Root Cause
## 근본 원인

The RTL uses a language construct, feature, or syntax that is not supported by Vivado synthesis.
RTL은 Vivado 합성에서 지원되지 않는 언어 구성, 기능 또는 구문을 사용합니다.
This could be:
이는 다음과 같을 수 있습니다:
- SystemVerilog features not supported for synthesis
- SystemVerilog 기능은 합성이 지원되지 않습니다.
- VHDL constructs not synthesizable
- VHDL 구문을 합성할 수 없음
- Vendor-specific extensions
- 공급업체별 확장
- Simulation-only constructs
- 시뮬레이션 전용 구성

---

## Common Unsupported Constructs
## 지원되지 않는 일반적인 구문

| Category<br>카테고리 | Examples<br>예 |
|----------|----------|
| Timing<br>타이밍 | `#delay`, `wait`, `fork/join`<br>`#delay`, `wait`, `fork/join` |
| Dynamic<br>동적 | Dynamic arrays, queues, associative arrays<br>동적 배열, 큐, 연관 배열 |
| Object-oriented<br>객체지향 | Classes, virtual interfaces<br>클래스, 가상 인터페이스 |
| File I/O<br>파일 I/O | `$fopen`, `$fwrite`, `$readmem` (in some contexts)<br>`$fopen`, `$fwrite`, `$readmem`(일부 상황에서) |
| Assertions<br>주장 | `assert`, `assume`, `cover` (for synthesis)<br>`assert`, `assum`, `cover`(합성용) |

## Fix Options
## 수정 옵션

### Option 1: Remove Unsupported Construct
### 옵션 1: 지원되지 않는 구성 제거

```verilog
// Before - timing delay not synthesizable
always @(posedge clk) begin
  #10 data_out <= data_in;  // ERROR: '#' not supported
end
```

```diff
  always @(posedge clk) begin
-   #10 data_out <= data_in;
+   data_out <= data_in;  // remove delay
  end
```

### Option 2: Use Synthesizable Alternative
### 옵션 2: 합성 가능한 대안 사용

```verilog
// Before - dynamic array
int data[];  // ERROR: dynamic array not supported

// After - fixed-size array
int data[256];
```

### Option 3: Wrap in Synthesis Pragma
### 옵션 3: 합성 Pragma로 래핑

```verilog
// Before - simulation-only code mixed with synthesis
initial begin
  $readmemh("data.hex", memory);  // ERROR in synthesis
end

// After - use synthesis translate_off
// synthesis translate_off
initial begin
  $readmemh("data.hex", memory);
end
// synthesis translate_on
```
