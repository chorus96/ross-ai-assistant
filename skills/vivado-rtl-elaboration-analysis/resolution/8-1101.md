# 8-1101: .* token can only appear at most once in port list
# 8-1101: .* 토큰은 포트 목록에 최대 한 번만 나타날 수 있습니다.

**Message:** `[Synth 8-1101] .* token can only appear at most once in port list`
**메시지:** `[Synth 8-1101] .* 토큰은 포트 목록에 최대 한 번만 나타날 수 있습니다.`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

The implicit `.*` port connection token is used more than once in a single instantiation's port list.
암시적 `.*` 포트 연결 토큰이 단일 인스턴스화의 포트 목록에서 두 번 이상 사용되었습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: .* can appear at most once in a port list
### P1: .*는 포트 목록에 최대 한 번 나타날 수 있습니다.

**Problematic Code:**
**문제가 있는 코드:**
```systemverilog
child u (.*, .a(a), .*);   // '.*' twice
```

**Recommended Fix:**
**권장 수정 사항:**
```systemverilog
child u (.*, .a(a));       // one '.*' only
```

---

## Fix Strategy
## 전략 수정

1. Use `.*` at most once per instantiation.
1. 인스턴스화당 최대 한 번 `.*`를 사용하세요.
2. List explicit `.name(sig)` connections alongside a single `.*`.
2. 단일 `.*`와 함께 명시적인 `.name(sig)` 연결을 나열합니다.
3. Remove the duplicate `.*`.
3. 중복된 `.*`를 제거하세요.
