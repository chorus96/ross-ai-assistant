# 8-3302: Cannot Open File
# 8-3302: 파일을 열 수 없습니다

**Message:** `[Synth 8-3302] unable to open file '!%1!' in '!%2!' mode`
**메시지:** `[Synth 8-3302] '!%1!' 파일을 열 수 없습니다. '!%2!' 모드`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

Vivado cannot open a file referenced in the design (e.g., MIF/COE init file for memories).
Vivado는 설계에서 참조된 파일(예: 메모리용 MIF/COE 초기화 파일)을 열 수 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Referenced init file not found
### P1: 참조된 초기화 파일을 찾을 수 없습니다.

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: file not found
attribute ram_init_file : string;
attribute ram_init_file of ram : signal is "dec.mif";  -- file missing
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: provide the file or remove the attribute
-- Option 1: place dec.mif in the project directory
-- Option 2: remove the init file attribute
-- Option 3: use absolute path
```

---

## Fix Strategy
## 전략 수정

1. Ensure the referenced init/data file (`.mif`/`.coe`/hex) exists and is on the search path — add it to the project or fileset.
1. 참조된 초기화/데이터 파일(`.mif`/`.coe`/hex)이 존재하고 검색 경로에 있는지 확인하세요. 프로젝트나 파일 세트에 추가하세요.
2. Use a correct path: an absolute path, or a path relative to the synthesis run directory; verify case matches on Linux.
2. 올바른 경로(절대 경로 또는 합성 실행 디렉터리에 대한 상대 경로)를 사용하세요. Linux에서 대소문자 일치를 확인합니다.
3. Confirm read permissions and that the filename matches the attribute string exactly.
3. 읽기 권한을 확인하고 파일 이름이 속성 문자열과 정확히 일치하는지 확인하세요.
4. If the external file is not actually needed, remove the file-dependent attribute or initialize the memory with an in-RTL constant instead.
4. 외부 파일이 실제로 필요하지 않은 경우 파일 종속 특성을 제거하거나 대신 RTL 내 상수를 사용하여 메모리를 초기화하세요.
