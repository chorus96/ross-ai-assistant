# 8-280: Expression Must Be Constant
# 8-280: 표현식은 상수여야 합니다.

**Message:** `[Synth 8-280] expression must be constant: !%1!`
**메시지:** `[Synth 8-280] 표현식은 상수여야 합니다: !%1!`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Vivado Message
## 비바도 메시지

```
ERROR: [Synth 8-280] expression must be constant: sel [/path/to/file.v:42]
```

---

## Root Cause
## 근본 원인

A non-constant expression is used in a context requiring a compile-time constant.
컴파일 타임 상수가 필요한 컨텍스트에서 상수가 아닌 표현식이 사용되었습니다.
The specific expression is named in the error message.
특정 표현식의 이름은 오류 메시지에 나와 있습니다.

---

## Contexts Requiring Constants
## 상수가 필요한 컨텍스트

| Context<br>맥락 | Example<br>예 |
|---------|---------|
| Array dimensions<br>배열 차원 | `reg [7:0] mem [0:SIZE-1]`<br>`reg [7:0] mem [0:SIZE-1]` |
| Parameter values<br>매개변수 값 | `parameter X = expr`<br>`매개변수 X = expr` |
| Generate bounds<br>경계 생성 | `for (i=0; i<N; i++)`<br>`for (i=0; i<N; i++)` |
| Part-select bounds<br>부분 선택 범위 | `data[HIGH:LOW]` (fixed select)<br>`data[HIGH:LOW]`(고정 선택) |
| Case labels<br>케이스 라벨 | `case(x) CONST: ...`<br>`case(x) CONST: ...` |

---

## Common Patterns
## 일반적인 패턴

### P1: Array Size from Signal
### P1: 신호의 배열 크기

```verilog
// Before - signal in array dimension
input [7:0] depth;
reg [7:0] memory [0:depth-1];  // ERROR: depth not constant

// After - use parameter
parameter DEPTH = 256;
reg [7:0] memory [0:DEPTH-1];
```

### P2: Part-Select with Variable
### P2: 변수를 사용한 부분 선택

```verilog
// Before - variable indices in part-select
input [3:0] start;
wire [7:0] data;
wire [3:0] nibble;
assign nibble = data[start+3:start];  // ERROR

// After - use +: operator for variable part-select
assign nibble = data[start +: 4];  // 4-bit slice starting at 'start'
```

### P3: Case Label with Variable
### P3: 변수가 포함된 케이스 라벨

```verilog
// Before - variable in case label
input [7:0] threshold;
case (value)
  threshold: out = 1;  // ERROR: threshold not constant
endcase

// After - use if-else for variable comparison
if (value == threshold)
  out = 1;
else
  out = 0;
```

### P4: VHDL Generic with Signal
### P4: 신호가 있는 VHDL 일반

```vhdl
-- Before
signal width : integer;
component my_comp
  generic (W : integer);
end component;

U0: my_comp generic map(W => width);  -- ERROR

-- After
constant WIDTH : integer := 8;
U0: my_comp generic map(W => WIDTH);
```

---

## Fix Strategy
## 전략 수정

1. Replace signals with parameters/constants
1. 신호를 매개변수/상수로 대체
2. Use `+:` or `-:` for variable part-selects
2. 가변 부분 선택에는 `+:` 또는 `-:` 사용
3. Use if-else instead of case for variable comparisons
3. 변수 비교에는 대소문자 대신 if-else를 사용하세요.
4. Move runtime decisions to multiplexer logic
4. 런타임 결정을 멀티플렉서 로직으로 이동
