# 8-465: No Constraint on Function Return
# 8-465: 함수 반환에 대한 제약 없음

**Message:** `[Synth 8-465] no constraint on function return`
**메시지:** `[Synth 8-465] 함수 반환에 제약이 없습니다`
**Severity:** ERROR
**심각도:** 오류
**Source:** Oasys Synthesis
**출처:** 오아시스 합성

---

## Root Cause
## 근본 원인

A VHDL function return type has no constraint, making it unsynthesizable.
VHDL 함수 반환 유형에는 제약 조건이 없으므로 합성할 수 없습니다.

---

## Common Patterns
## 일반적인 패턴

### P1: Unconstrained function return type
### P1: 제약이 없는 함수 반환 유형

**Problematic Code:**
**문제가 있는 코드:**
```diff
-- Before: unconstrained return type
function f return std_logic_vector is  -- ERROR: no range constraint
```

**Recommended Fix:**
**권장 수정 사항:**
```diff
-- After: add constraint
function f return std_logic_vector(7 downto 0) is
-- Or constrain via subtype
```

---

## Fix Strategy
## 전략 수정

1. Constrain the function return type at declaration, e.g.
1. 선언 시 함수 반환 유형을 제한합니다.
1. `return std_logic_vector(WIDTH-1 downto 0)`, or return a constrained subtype.
1. `std_logic_Vector(WIDTH-1을 0으로)로 반환`하거나 제한된 하위 유형을 반환합니다.
2. Define a constrained `subtype` (e.g., `subtype byte_t is std_logic_vector(7 downto 0)`) and return that for clarity and reuse.
2. 제한된 `하위 유형`(예: `하위 유형 byte_t는 std_logic_Vector(7 downto 0)`)을 정의하고 명확성과 재사용을 위해 이를 반환합니다.
3. Parameterize the width via a generic/constant so the constraint is configurable but still fixed at elaboration.
3. 일반/상수를 통해 너비를 매개변수화하여 제약 조건을 구성할 수 있지만 여전히 정교하게 고정할 수 있습니다.
4. Verify every `return` statement inside the function produces a value of exactly the constrained width.
4. 함수 내부의 모든 'return' 문이 정확히 제한된 너비의 값을 생성하는지 확인하세요.
